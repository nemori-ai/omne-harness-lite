# DeskFigure：屏幕上至多一个形，形不会哪里都没有

本目录的模型检查应用规格的三条承诺（「[不变式](../../../SPEC.md#不变式)」的 DT-52、DT-53 与 DT-54 的后一半）：形被拿出窗口、回来、任何一方中途没了的各种交错里，屏幕上至多一个形；页面不画的时候桌面层在画；显示着的桌面层画的只能是现在这个租约的幕。模型只证明列出的有限状态，不证明实现。

## 1. 建模的对象

三方：主窗口页面里的外壳（`src/page/shell/desk/`），桌面层的页面（`src/page/desk/`），主进程（`src/main/device-figure.ts`、`desk-window.ts`）。人与故障是环境：人拿起、放下、叫回；页面与桌面层的页面随时可以没了。外壳往下发的幕按次序到；往上的回报、给主进程的 `hot`、租约流上的「没了」以任意次序、可能很晚才被处理。

| 变量 | 含义 | 代码里 |
| --- | --- | --- |
| `pageAlive`、`where` | 主窗口的页面在不在；形的所在：`page` 在座，`handPage` 在手页面画，`handDesk` 在手桌面层画，`desk` 在桌面，`home` 回程，`landing` 落座 | `whereabouts.ts` 的值 |
| `sLease`、`sSerial` | 外壳手里的租约号；它最后发的那一幕的序号 | 外壳的 `stay.ts` |
| `landed` | 外壳听到「到了」的那一幕的序号。只用来写性质 | 无：辅助变量 |
| `mLease`、`mNext`、`shown` | 主进程认的租约；下一个租约号；桌面层的窗口显示没有 | `device-figure.ts` |
| `deskLoaded`、`dScene` | 桌面层的页面加载好没有；它手里的那一幕 | 桌面层的页面 |
| `down`、`up`、`toMain`、`fromMain` | 往下的幕（序列）；往上的回报；桌面层报给主进程的 `hot`；租约流上的「没了」 | `BroadcastChannel` 与 `/device/figure` 的请求 |

## 2. 动作与代码

| 动作 | 代码里的一步 |
| --- | --- |
| `LiftFromPage` | 人在页面里拿起形。能离开时外壳开租约：主进程发号、记为现在的租约，上一个还没结束的租约在同一步里结束、窗口藏起；外壳发第一幕 |
| `DropOnPage` | 页面还画着时松手、按 Escape 或指针被取消。有租约就到落座并发空的一幕 |
| `DropOnDesk(to)` | 桌面层画着时松手：留在桌面，或回程 |
| `LiftFromDesk`、`Recall` | 在桌面层的形上拿起；在页面里按空座 |
| `DeskTakes` | 桌面层收下一幕：只留比手里新的；画东西的幕报 `hot`，空的幕报「空了」 |
| `DeskReports(kind)` | 桌面层显示着：手里是跟手的幕，画出它的第一帧报「画好了」；手里是回程的幕而那一笔写到了报「到了」。对手里的这一幕可以报不止一次：每收下一幕都再报 |
| `MainShows(m)` | 主进程处理一份 `hot`：是现在这个租约的才显示窗口 |
| `MainReleases` | 主进程看到那条请求被放弃（外壳放手，或页面没了）：结束租约、藏起窗口 |
| `ShellHears(m)` | 外壳处理一条回报：只认现在的租约、最后一幕的「画好了」「到了」「空了」；桌面层报到时把现在的一幕再发一遍 |
| `ShellToldEnded(m)` | 外壳在租约的流上读到「没了」 |
| `DeskLoads`、`DeskGone` | 桌面层的页面加载好并报到；它没了，主进程在同一步里结束租约、藏起窗口、在流上发「没了」 |
| `PageGone`、`PageBack` | 主窗口的页面没了；新的页面跑起来，前提是主进程已经结束了租约 |

## 3. 性质

- `OneFigure`：页面与桌面层同时在画时，外壳在 `handPage` 或 `landing`，桌面层画的是外壳这个租约的幕，而且是「在手」的幕，或外壳已经听到「到了」的那一笔回程。
- `NeverNowhere`：页面活着、外壳在 `handDesk`、`desk`、`home` 时，桌面层在画这个租约的幕，或者这个租约的「没了」已经在流上。
- `ShownIsCurrent`：显示着并且在画的桌面层，手里的幕属于主进程现在的租约。
- `Somewhere`（活性）：页面活着时，总会再有一处在画。前提：系统各步弱公平；人在页面里拿着形终会松手（`WF_vars(DropOnPage)`）。
- `NeverOnDesk`、`NeverBackHome`：见证，只在可达性配置里检查，被违反说明形到得了桌面、也回得了家。

## 4. 配置与反例

| 配置 | 改了什么 | 期望 |
| --- | --- | --- |
| `positive` | 两个租约，页面没一次，桌面层加载两次 | 跑完无违例 |
| `liveness` | 同上，加弱公平性 | `Somewhere` 成立 |
| `show-at-open` | 开租约就显示窗口，不等 `hot` | 违反 `OneFigure`：上一次留在桌面层里的形闪出来。`ShownIsCurrent` 只在 `positive` 里查，这一份反例间接说明少了它会怎样 |
| `adopt-any-lease` | 回报不核租约号 | 违反 `NeverNowhere`：上一个页面留下的「画好了」让新页面提前不画 |
| `ignore-serial` | 回报不核序号 | 违反 `OneFigure`：上一段回程迟到的「到了」让页面在形还在路上时就画 |
| `skip-landing` | 「到了」就算在座，不等「空了」 | 违反 `OneFigure`：页面在座位上画着，桌面层还没收掉 |
| `desk-reachable`、`home-reachable` | 只查见证 | 各违反自己的见证 |

## 5. 跑法

```sh
pnpm run check:formal-tools
python3 apps/desktop/verification/models/desk-figure/check.py --out <工作树外的目录>
```

`check.py` 只接受钉住的 TLC 1.7.4；日志、状态目录与带摘要的结果写到 `--out`。

## 6. 前提与没有覆盖的

- 桌面层靠自己的文档判「显示了」：`visibilityState` 成为 `visible` 之后的第一帧才报「画好了」。模型里这是 `DeskReports` 的前提 `shown`。实现要是在收到一幕的那一步里就报，或给桌面层的窗口关掉后台节流，这个前提就不成立。
- 外壳读到「没了」而形在手、页面画着时，规格写留在原格；模型在这里比规格宽，也允许直接到在座。
- 开租约在模型里是一步：主进程发号与外壳拿到号之间没有别的事。实现里外壳先拿到流的第一行才发第一幕，这段时间页面画着形，模型的 `handPage` 包着它。
- 主窗口的页面开始加载时主进程先结束租约，新的页面才跑起来（`PageBack` 的前提）。实现靠主进程在页面的文档开始加载时就处理；改成等页面自己来说，模型就失真。
- 桌面层的页面没了与主进程结束租约是一步。渲染进程挂住而没有死的那一段，桌面层停在最后一帧，外壳仍然认为它在画，屏幕上仍然只有一个形；模型没有这一段。
- 往下的幕按次序到，这是 `BroadcastChannel` 对同一个发送方的保证。两个不同的页面先后发的幕靠租约号分开。
- 位置不在模型里：「同一点」是由幕的种类推出的（在手的幕画在手下；外壳听到「到了」的那一笔停在座位上）。真的像素、手的位置那串小消息、换屏的那一帧都不在模型里。
- 说话笺、观测框与读窗口不在模型里：它们不改变谁在画形。

- 看一个窗口不在模型里：问 `window`、读 `read` 都不改变谁在画形。松手之后外壳要问一次 `own` 才知道落在哪，这一小段（手已经松了、答复还没到）在模型里仍是 `handDesk`：答复到了就是那一步松手。这时租约没了，实现直接到在座，相当于模型里 `ShellToldEnded` 紧接着 `DropOnPage`，所以 `WF_vars(DropOnPage)` 的前提（在页面画着的手终究会松）仍然成立：这只手已经松了。`desk-look.spec.ts` 里「等答复时租约没了」两条守这一句。

## 7. 要在真窗口里用手验的

自动的用例经调试协议把输入直接投进页面，不经过操作系统的命中判定，所以下面这些只有真的指针验得到。每条写「做什么，应当看到什么」。

1. 在家里的形上按下，拖出主窗口的边。越过边的那一刻形没有变化，一直在手下。
2. 在窗口外松手，再点形旁边另一个应用的按钮。那个应用收到这一下；它的窗口到了前面，形仍在最上面。
3. 另一个应用在前面时单击桌面上的形，在说话笺里打字。字进了说话笺；菜单栏上仍是那个应用的名字。
4. 把一个应用全屏，切到另一个桌面空间。两处都看得到形。
5. 拿着形移到另一块屏上再放下。形跟到那块屏；记下换屏的那一帧有没有跳。
6. 拿着形按住 ⌘，移过两个互相压着的窗口。框只画在最前面那个露出来的边上。
7. 形在桌面上时，在主窗口里点输入框的截图钮截一张屏。截到的图里没有形；截完形还在原处。
