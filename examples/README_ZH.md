# 可运行示例

这里存放通过包公开入口组成的开发示例，展示有明确边界的可运行流程；示例不是正式产品应用，也不扩展已接受规格。

示例是阶段性的，不长期维护：`make check` 只构建并类型检查它们，**不跑它们的测试**，结构度量也不为它们跑覆盖率。
要跑某个示例的测试，进它的目录执行 `pnpm test`。

**探路件也放这里**（或放本次任务的 `tmp/`）：为了先把一条主路径跑通而写的一次性代码。它不进 `packages/`、`apps/`，
产品包不得导入它（`group-direction` 规则会报）；跑通之后带回设计的只有一份事实清单，代码不带回去，探路件用完即弃。
什么时候该先探路、带回什么，见 `harness-design-handbook` skill 的「主路径还没跑通过：先做探路件」。
