# 身份验证义务

公开调用／结果全集、错误集合与先后、表示先于授权、租户拒绝由真实 SQL 提供者测试，不用薄 SPEC 或类型测试替代。普通提交与参与面须分开，临时成功不提前通知，最后钟失败回滚业务和活动。

| 重点 | 真实资源与反例 |
| --- | --- |
| 身份及材料 | account-identity-sql 的账号／登录／材料测试：政策认回、绑定依据／伪造、到期与不可复用、跨实例一次票据 |
| 有限登录 | provider bounded-logins：旧无限登录升级、缺部分schema、等于截止、成功读取活动、late completion 不复活、最终钟失败、Grace/ticket／重启 |
| 通知及秘密 | 三种登录拒绝同值；WAL／快照／日志／列表／事件字符串不能exchange，真实出示物正对照；独立非ASCII向量及跨进程派生 |
| 事务及关闭 | 错unit／存储身份／并发误用、污染与终结、撤除及迟到排空；提交前回滚与提交后丢回执分开，不把unknown当无effects |

模型归 [models](models/README.md)，有限模型不证明 SQL 精化、加密、多账号或重启耐久。真实组合与 lifecycle 沿 provider／应用既有设施，不因本次文档接续宣称重新完成领域验收。
