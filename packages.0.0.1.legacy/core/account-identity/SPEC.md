# 身份公共承诺

本包拥有账号、登录、凭据校验的公开形状，及出示物的表示层解析。
根入口不加载 Cordis；`./cordis` 拥有 Accounts、Logins、Credentials、唯一服务键和类型化通知。
SQL、scrypt、随机生成、登录标识派生及配置政策实现由具体提供者拥有。

本页约束账号、登录及凭据操作的业务和集成行为。账号不按租户拆分，成员关系与组织另有拥有者。

账号和登录共享账号身份、凭据代际和有效性次序。准备票据只供签发实例使用，
一次提交尝试即消费，包括失败尝试；更换提供者不得恢复旧票据。
凭据步骤按调用解析可选 credentials。同一次计算捕获原实例后不得中途换入新实例。
缺席沿原 storage-unavailable，不能伪装成 mismatch 或普通凭据拒绝。

参与面只使用调用方给出的 StorageUnit，保持存储实例身份、污染和结束状态检查。
临时成功不代表提交，不得提前通知。存储异常只在原终结边界外映射为业务失败。
account.read 可以记录单调过期事实；它不是无写入查询。
凭据换代不产生逐登录 revoke 通知；最终时钟失败仍使共同事务回滚。

Service 撤除停止服务发现，已准入工作仍由原提供者与调用者负责。
依赖须保留到实际工作结束。停止前交出的参与对象仍受原 unit 寿命及账号有效性约束，
不因服务换代取得新身份。类型和 Cordis isolate 均不能代替租户授权。

三个事件采用 account-identity 命名空间，载荷与提交后同步派发时点保持。
不双发旧名。监听失败只记诊断，不改变已提交事实；异步工作由监听者观察。

验证须覆盖操作全集、精确失败集合、公共源码/声明/运行/制品闭包、可选依赖换代、
共同事务回滚、票据跨实例及一次消费、跨租户拒绝、在途完成和凭据诊断边界。
本页拥有已采用的身份业务与集成承诺，实际算法及受控凭据验证由提供者维护。

## 账号产生、激活与清除

produce 的判定依次是表示、凭据政策、标识占用。唯一提前认回分支是未激活、未到期且材料匹配的同一记录：认回原 AccountId，不重新执行已收紧的凭据政策。已激活或未激活但不匹配都返回 identifier-taken，不披露区别。到期记录绝不认回，向可信注册组合交 identifier-held-by-expired-record 及 AccountId；本能力不跨域删组织，也不把该事实交给终端枚举。

新记录在一次提交内占用标识、保存材料并记未激活，不签登录、不发事件。政策缺席为 credential-rejected；材料验证／派生、时钟或留存不可判为 storage-unavailable，不默认可用。留存是从最初产生算的正值部署配置，认回不延长，缺值不默认。已激活账号永不到期。未激活的到期事实单调持久，调长留存或时钟回拨不复活。标识部署内唯一；删记录释放标识，但以后产生的是全新 AccountId，旧身份不复用。已激活标识不能释放或改名，不因现实同一人关联不同账号。

activate 的次序是表示→账号存在→真实签发且绑定此 AccountId 的激活依据→当前状态。已激活的幂等成功仍核依据，不重发通知。组合只在 createPersonal 已确认提交成功后产依据；依据不证明现在仍未到期，提交内须现读。purge 的次序是表示→存在分支→绑定的清除依据→状态；即使记录已无也须核依据后才幂等成功。存在时只可清未激活且已到期者，删记录与释放标识同提交。依据不消费、不作废，不能代替现读状态。

只有 produce、activate、account.read 首次落未激活到期的具名拒绝例外可提交该单调事实；其他拒绝不留下半份业务。最终时钟异常仍回滚共同事务。account.read 只交 activated／expired，不交材料、代际、组织或登录标识。普通 read 在真实提交后交最终结果，参与 read 只交暂存值。

## 登录、活动与凭据代际

issue 的不存在、不匹配、未激活，以及提交时 Account／凭据代际 G 漂移，统一 identifier-or-credential-rejected。昂贵验证可在写边界外，提交须重核同一 active Account 及 G。每次签发产生独立、至少 256 位安全随机出示物和确定不可逆 LoginStateId；I=L、g=G、revoked=false 同提交，碰撞不可覆盖。随机、时间或存储不可判不是成功。回执未知不自动重签或再次交出出示物。

出示物仅在签发成功返回。存储、列表、事件和诊断不得留可用或可恢复出示物。LoginStateId 派生为字符串逐码点 UTF-8→SHA-256→64 位小写 hex，不用进程随机盐。exchange 是跨进程认人的唯一门，须完整校验；记录 ID、列表 ID 或长得像 ID 的字符串都不是出示物，不可绕校验。

t 来自与 I／L 同一时间轴的、不可倒退的可信时钟。登录有效恰为 active Account、未撤销、g=G、t<I+8h 且 t<L+1h。等号失效，时刻为 UTC 毫秒，不用日历、DST 或自动续期；溢出无法判为 storage-unavailable。verify、exchange、list 不 touch。只有外层确定的真实成功业务（含成功读取／幂等成功），在共同提交结束阶段现取 t 再核登录，仍有效才 L=t；I／g 不变。准入、拒绝、异常和 health 不是活动。

已准入业务可晚完成并提交；届时已过期、撤销或 G 改变则不回填准入时刻，不复活登录，不追溯取消业务。自撤销和改密不得借成功 touch 复活自己。最终时钟失败使业务、活动和通知一起回滚，不能吞异常后提交。校验、当前租户和清扫都须与暂存活动排序，不能按旧 L 宣布到期。

revoke 先核表示，再在同提交核发起者有效；失效为 not-authorized。目标不存在／其他账号统一 login-state-not-found。已撤销幂等且无第二通知；过期目标仍可撤销，不更新其他登录或强制停止 runtime。list 用发起登录定位账号，在同一 t／同一序列完整过滤，须包含 caller，成功空集是缺陷。它交 I／L 及两个截止，不交 bearer／G；返回 touch 前的投影，外层结束时活动不追改这次返回值。登录或时间不可判为 storage-unavailable，不混普通拒绝；已知无需时刻即可拒绝的分支不强迫取钟。

主动改密须有效发起登录，不仅旧材料。准备时验证旧材料及 G 快照，再判新政策并派生；提交先核同账号／G，再核发起登录。G 已改为 current-credential-rejected，不借新 G 使用旧证明。一次提交换材料并 G+1，所有旧 g 登录包括发起者立即失效；新旧材料相同也明确换代。不重签登录、不改账号／组织／成员，不发改密或逐条伪 revoke 事件。没有忘记材料或管理员重置；提交未知不自动反向更换。实例内准备票一次提交尝试即消费，失败也不复用。

## 可信参与与恢复边界

produce／activate／purge 和免认证 issue 各自普通提交，参与集合按公开类型精确限定，不扩大。resolveActivatedIdentifier、finalizeActivity 仅可信组合内使用，不上线。网络 target 仅指对象，与可信 issuer／exchange／list／组织选择所得 initiator 不同。错、已结束、游离并发或不许可重入的 StorageUnit 是缺陷；异常、结果集合外值、不可编码成功都在唯一终结边界回滚。未知提交不证明没效果或没通知，不自动补偿／重做；取消不证明 SQL 停止，真实排空前不关借用依赖。

时间、凭据代际 G 和活动的持久性须覆盖采用目标的故障范围，不能从更弱故障范围的旧结果推断。跨进程或跨库必须重新兑现共同提交与撤销传播保证；缺保证不得开放组合，最终一致、补偿撤销和重试不能替代同提交。

首次有限登录升级在开闸前撤除旧无限登录，保留账号、材料、组织，不用部署时刻补 I／L。正常重启保留 I／L／g／G／revoke／截止，不续期；回退或旧备份恢复不能开放并复活旧密码。撤销只影响后续准入，不强制停已准入运行。

resolveActivatedIdentifier 只在真实可信邀请组合已证明发邀请资格之后、与邀请写入同一致边界执行；不存在／未激活统一 account-not-found，已激活只交 AccountId。该读不 touch、不落到期、不发事件，不是客户端先查名再用裸 AccountId 的授权路径。

有限模型与前提见 [models](verification/models/README.md)，提供者真实验证义务见 [verification](verification/README.md)。类型不替代业务、SQL、密码学或多账号验证。
