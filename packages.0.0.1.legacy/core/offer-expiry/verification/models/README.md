# 邀约终结的有限模型

OfferSettlement 仅覆盖 S-7/8/9 的终结不覆写与非pending不首次终结，以及 S-10/11/24 的不重复接受效果这一部分：接受、撤回、拒绝在同一个原子终结点竞争；截止相等仍 pending，过期/指定对象消失后不得首次终结。终结后时钟推进或对象消失不改记录。Remove 是存在性谓词的合成输入，不宣称当前产品允许删团队组织。

valid 检查 TerminalStable、NoLateSettlement、AcceptanceOnce；bad-overwrite 移去终结保护，bad-late 允许非pending首次终结，均应触发原不变量；当前 late 反例先命中对象消失，不声称取得独立超时反例。S-25 默认/指定时长、非法配置及清理行为不在此模型中；截止相等可终结的可达性也未单独验证。性质不读取 Mutation 开关。范围为一个邀约、三个终结候选、有限时钟；不证明授权、对象删除旅程、SQL并发、网络、清理进展或不可用优先级。共同提交的实际精化仍归治理/entry提供者。
