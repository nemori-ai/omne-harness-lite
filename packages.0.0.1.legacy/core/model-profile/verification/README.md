# Model profile 验证职责

[薄 SPEC](../SPEC.md)维护当前档案行为。根执行采用 MP5；MP6 仅是明确资源入口。[固定输入](../tests/fixtures/README.md)与独立摘要不能由被测结果重算；每次执行记录留 tmp。

| 范围 | 必须观察的性质 | 方法／实际责任 |
|---|---|---|
| 纯值与资源 | 精确默认5／retained2／资源6、完整定义及准确 URI、全部规范值和拒绝顺序、精确巨大数／optional | 纯判断、Schema 图、类型／外部消费；当前格式不回填旧形状 |
| identity 与同提交 | 同格同名一次成功含 withdrawn，异格／大小写不同可建，官方重现恢复同一行，真实读故障区分 | [目录拥有者](../../model-profile-directory/SPEC.md)：真并发或判定读取与写入同提交模型，顺序场景不能代替 |
| 更新与精确引用 | 撤回／恢复保其他值，清单 relisted 可同改；只六项内容变化动 updatedAt；引用不跨 scope 回退，三失败不同 | 目录读写及实际持久消费者，不能只核 shape |
| 路由与参数 | 每次只一家且关上游回退；false只第一家；真实 dropped／requested／sent、缺参数不补 | [模型 runtime](../../model-request-runtime/verification/README.md)及显式适配者；只看最终成功不够 |
| 原快照 | 同一次读取全部适用项及完整绑定，打开后更新／撤回不改变原调用，Ref 成对、跨境数精确 | 快照写方／恢复消费；纯接收不证明来源 |
| 限项与凭据 | 图字节／项数／最终请求字节／最终输入范围，上游 unknown 不零；档案交换和读面无凭据 | 数据表示与真实输入提供者／目录，计量事实另证 |

本纯包没有独立状态模型。并发建档与原代际责任归真正写方和 runtime；不得为资源升级抹掉未知提交或旧任务。MP6 Schema 相同不等于发送估算／余量来源已兑现。
