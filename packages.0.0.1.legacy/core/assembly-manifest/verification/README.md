# Manifest verification

Run build, typecheck, and pure value/decision tests for [SPEC](../SPEC.md). Keep exact-number input domains, failure priority, given recognition before expected head, opaque references, lossless content, fixed-H given selection, and shared AE projection checks.

The SQL [provider verification](../../../assets/assembly-manifest-store/verification/README.md) owns real commit, rollback, concurrency, crash, and lifecycle scenarios. A pure decision test cannot establish one storage commit or durable reopen. Other providers share the same public behavior and must supply equivalent evidence for their mechanisms.

MF has no separate Schema or formal model. It preserves arbitrary valid content; AR, not MF, interprets complete-fill purposes. Caller authorization and presence facts need their own real sources. Historical records currently have no deletion policy.
