# 身份值与共用隔离承诺

公开形状、解析函数和判别式归 [公开根](src/index.ts)，线上形状归 [Schema](schema/identity-values.schema.json)。本页拥有类型不能表达的身份、不变量和消费义务；不拥有账号鉴权、成员关系的写路径、资产政策或存储布局。已接受语义保持，物理迁移不接受新业务政策。解析成功不等于授权成功。

## 身份与相等

- AccountId、OrganizationId、LoginStateId 是不透明标识；逐码点比较，不解析、不折叠大小写，不从运行时地址产生。身份不能回收给另一对象。LoginStateId 每次登录新建；失效不可逆且跨系统重启保持，旧登录不得因重启复活。登录标识只供人指认账号，部署内唯一、注册后不可改；跨对象引用使用 AccountId。
- OrganizationKind 创建时确定，不能在 personal 与 team 间转换。个人组织与账号一一对应；团队组织与个人组织不是角色差异。
- TenantId 是 `(OrganizationId, AccountId)` 的结构相等值，无独立分配、登记、销毁路径。相同账号的两个不同组织租户彼此不同，不因账号相同取得跨租户资格。成员断续不改变 TenantId；角色调整不改变身份或资格效力。
- 规范 JSON 保持明确的两个身份分量；对象成员次序不决定相等。需要标量索引键时，编码必须是单射，一个部署只有一条编码规则；不能另定身份含义或把地址解码当作授权事实。编码由统一拥有者维护；跨节点成为明确协议，不能由各消费者分别选择。
- TenantRole、MembershipStanding、ScopeLayerIdentity 的闭合形状由公开类型和 Schema 定义。effective 必带一个角色；ineffective 不带角色。unavailable 是判定失败，不能折入任何效力值；表示层 invalidInput 在判定结果之外，业务结果均以返回值承载。
- 身份被用于判定或访问的输入位置，缺席、null、空字符串、缺失分量和载荷与判别式不符均拒绝；不把它们当作身份、默认范围或“全部”。official 资产合法缺席作者字段等记录组合，沿拥有者定义读取；这不是缺少访问身份，不触发输入拒绝，仍不能解释为默认租户。普通字符串解析不能证明部署唯一、签发方、对象存在或资格。

## 上级链与纯谓词

ancestorChain 在调用者明确给出的组织事实快照中求值，不读取隐式全局、当前租户或 Context。链不包含起点；每个组织至多一个上级，个人组织不隶属其他组织，也不能成为团队上级；不存在环。遇到必要记录不可用须明确失败，不能当作到头。结构不合法与依据不可读分别表达。

shareAncestor 判断两者所在的祖先闭包（包含各自）是否相交，因此同一个合法组织与自身共享祖先；两棵无交的团队树不共享，任何含个人组织且两者不同的一对都不共享。与自己同树不能用作跨组织放行依据。任一必要链不可读不能返回 false。sameAccountDistinctTenants 只判相同账号、不同组织的纯值关系，不证明任一成员资格。

## 每个消费者的隔离义务

这些义务由数据访问的实际拥有者在每条路径兑现，不能集中做一次检查后假定下层安全。

| 义务 | 必须保持的行为 |
| --- | --- |
| 明确归属 | 组织级对象携带 OrganizationId，租户级携带 TenantId；持久形状为一个带判别式的 ScopeLayerIdentity，不能用两个可空身份列代替。跨范围操作另带发起方 TenantId |
| 无默认身份 | 身份参数必需且无默认值；不从环境、目录、进程、最近调用、协程局部变量或 Cordis Context 推断 |
| 缺席拒绝 | 缺席或非法身份明确拒绝，不放行、不返空集、不降级或回退到个人／其他范围 |
| 不可用失败 | 成员资格、上级链、当前租户查询、持有／组织／账号事实的必要读数不可用时明确失败；不当作无效、无交、没有记录或合法空答案，不复用旧缓存 |
| 同一判定 | 读、写、覆盖、删除、订阅、清理六条路径调用相同资格判定；不能给读或后台清理开旁路 |
| 封闭依据 | 租户对象准入仅据 `(显式身份, 持有记录, 成员资格效力)` 三项；流转边界另据上级链判定，两道检查通常都须通过。不能把上级链或层事实加入准入三元组；路径、目录、OS用户、主机、环境变量、运行实例地址不是资格 |
| 准入现读 | 每次准入使用组织治理的成员资格判定读面；展示名单、我的租户列表及旧成功不得作为准入凭据。unavailable 与判出的 ineffective 分开 |
| 捕获身份 | 创建工作时捕获当前租户身份，之后显式传递；使用点不能重新读取用户的可变选择。同一工作不得因中途切换改归属 |
| 无隐式关联 | 账号记录不携带其他账号引用或跨账号聚类键，任何 owner 也不能另建账号关联表；登录标识、凭据、激活状态和个人 context 都不成为层设置或权限，不能被层继承或求值 |
| 失权不销毁 | 成员无效使该 TenantId 的租户级持有不可达，不删除、迁移或改键；重新成立时仍对应同一个身份 |
| 层键 | 层事实仅按所属 ScopeLayerIdentity 为键；不能以 AccountId、LoginStateId、个人 context 冒充层身份；切换组织不复制层事实，加入组织不自动共享个人资产，超管资格不取得成员个人范围 |
| 边界复核 | 跨进程、节点或协议边界重新验证身份表示、来源及当次资格；隔离标签、缓存键、路由和真实文件权限均不能代替租户授权 |

授权缓存若存在，必须明确失效条件、最大陈旧窗口和完整身份键；不以无上界旧成员缓存放行。跨节点明确成员资格的可见性窗口、上级链的读一致性及缓存失效传播上界；陈旧读不得放行流转。超时、断连、反序列化失败与必要事实读不到统一映射为返回值中的 unavailable，不抛带外业务错误。

## 交接凭证

HandoffWarrant 是一步操作交给下一步的不可伪造出示物，不是对象身份，不作为记录键。核实方不解析它，也不从其字符串读取领域事实。每个实例必须指明产出操作及成功条件，并绑定对象 AccountId；为 A 产生的凭证不能用于 B。

激活依据只在注册组合确认个人组织产生成功（含幂等认回）后签发；清除依据只在组织治理确认个人组织已清除（含原本不存在的幂等路）后签发。核实方核存在、绑定对象与产出方签发，不重新核实产出方的领域事实。组合本身没有共同提交，签发条件仍由组合负责；操作产出方在自己的判定边界负责成功事实。

两个实例只绑定对象，不绑定尝试，不因使用而作废；重放安全由核实方在自己的提交边界现读未激活状态与留存条件承担。幂等重扫仍须出示凭证，不能豁免。激活依据断言的个人组织存在事实可以在未激活账号到期并清除后变假，此时激活提交必须现读未过期条件并拒绝重放。清除依据依赖个人组织不再重建且 AccountId 不复用。两条实例分别成立，不能把安全条件概括为“领域事实永久为真”，也不能推广为任意可重放令牌。

不可伪造是保证。签名／共享存储由具体拥有者选择并保护密钥或可见性。进程内 nonce 方案依赖同进程、两步之间不重启；跨进程时必须由协议重新兑现，不能靠内存登记假定成立。

## 表示、边界与未实现责任

公开 Schema 的 URI 不因物理位置改变而变。不透明字符串不作 Unicode 规范化、大小写折叠或空白裁剪。首尾空白的26个码点集合由公开 OPAQUE_IDENTIFIER_WHITESPACE_CODE_POINTS 唯一声明，不能以引擎依赖的 `\s` 替代；中间空白不在此限制。绝对末尾检查不得以可能匹配末尾换行之前的 `$` 代替。所有交换判别式闭合，未知成员／取值按对应表示拒绝；不修补输入、不把解析错误当成“没记录”。规范拒绝值、纯谓词与领域判定分别消费，形状校验不证明隔离或签发事实。

本包不定义会话／运行身份、工作区持有键、计费口径、个人 context 内容或 OS 拦截机制。当前未建保证仍有明确拥有者：PF-015 负责会话层身份及相应持久归属形状；PF-002 负责工作区目录身份，键的形状归资产接口；产品负责人负责计量口径和个人 context 内容。LoginStateId 的更强产品身份要求归 PF-001；具体不透明词法及统一单射编码由实际实现拥有者在明确采用后提供。这些缺口不因“非本包范围”自动闭合。需新增作用域变体时，由对应产品及接口拥有者明确定义后同步消费者；不能把未定义的会话层编码为组织或租户层。身份具体生成词法、标量索引编码及凭证机制由实际实现负责，但须满足本页不变量。

验证方法、规范正反例与局限见 [verification](verification/README.md)。授权、跨边界和共享提交须在实际消费者验证，纯解析器和有限模型不证明这些性质。
