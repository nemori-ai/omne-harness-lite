# 四个 Service，共同提供者生命周期

依据 D-114 的 IC-1～IC-4 和既有共同提交语义，操作接口归定义包，SQL 提供者继承抽象 Service。
类属性直接采用公共接口的属性类型，避免重复签名。独立工厂继续拥有业务实现。

四个面在同一插件 fiber 注册。它们共享配置、依赖与事务域，拆成四条 fiber 没有独立生命周期收益。
构造的服务把操作绑定到工厂对象，本批操作不登记调用方贡献，也不通过工厂读取 Cordis Context。
未来需要调用方登记时须在 Service 方法内用 `this.ctx.effect`，不能沿用普通对象绑定来宣称 IC-13 成立。

验证公共 Service 的调用方 Context 与提供者替换/卸载，并保留原数据库竞争和回滚用例。
当某个面有独立配置、生命周期或贡献者登记时，重新核对这个选择。
