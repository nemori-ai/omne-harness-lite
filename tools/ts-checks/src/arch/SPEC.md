# 实际架构视图

本薄规格约束 N2 的视图行为。公开形状由 [view.ts](view.ts) 的类型拥有。
输入承诺仍归 [actual.ts](actual.ts)。系统级依据为已接受的
[D-115](../../../../.meta_harness/design/record/decisions/actual-architecture-and-thin-spec/decision.md)
及负责人确认的 N2 实施范围。视图不是架构预期或行为证明。

## 投影与证据

- 成员取自输入 workspace 清单。无函数和纯数据成员仍显示。
- 默认总览按清单路径聚合，应用可单独展开。目录组只组织相关能力，不表示运行、部署、事务或租户边界。
- 服务与事件节点按名称聚合，连接只表示静态同名引用。作用域和插件身份留在原始证据中。
  同名不证明同一运行绑定。提供者全部列为候选，不自动选择其中一个。
- 导入边按成员对、类型/运行类别和变化状态聚合。每条边保留全部输入身份及出处。
  架构变化对照输入的精确 BASE。删除项来自 BASE，不能冒称 HEAD 的源码位置。
- 规划与架构预期没有输入时显示“未提供”。配置选择与运行绑定没有观察时显示“未观测”。
  具体 unknown 保留。未识别写法仍可能漏检，unknown 的条数不表示全部缺口。
- 圈复杂度复用 functionMetrics。色带和阈值使用当前工具的 metrics.config.json，来源在页内显示。
  空函数集合显示“无函数”，覆盖率缺席不记为零。
- 原复杂度面板继续拥有函数过滤、风险、覆盖率、方向发现及例外。
  metrics 入口的函数变化对照 merge-base，页面显示实际 merge-base 和架构的精确 BASE。

## 离线操作与导出

页面初始显示系统总览。关系种类可分别开关。组、组件、邻接和变化选择共同决定当前子图。
聚焦成员时，邻接可经过服务或事件名称展示其他声明方，最多两跳，不据此推断实际绑定。
展开后的边只保留起点/终点为所选成员，或指向其服务/事件节点的关系。邻居之间的其他关系不在当前子图中。
过滤不得留下没有可见端点的边。变化视图包含 BASE 已删除节点和关系。
没有 BASE 时不提供新增/删除的假读数。

稳定的控件名称为：`系统总览`、`架构视图`、`复杂度与风险`、`目录组或应用`、`聚焦组件`、
`显示邻接`、`变化范围`、`叠加圈复杂度`、`叠加耦合`、`导出 SVG`、`导出 JSON`。
每种关系的复选框名称为其中文图例文字，例如 `必需服务`、`可选服务`、`运行导入`、`类型导入`。
节点与边可操作，详情列全部出处、版本、插件、作用域、分发模式和静态表达式。
成员详情有 `查看此成员的复杂度`，跳到同页已有面板。

导出的 JSON 具有 `kind: architecture-selection`、`schemaVersion: 1`、`selection`、`source`、
可选 `baseline`、`nodes` 和 `edges`。节点身份为 `id`，边端点为 `from`/`to`，
边的 `evidence` 保留输入身份、`version`（current/baseline）及 `occurrences`。
导出的 SVG 包含当前可见节点、关系和叠加。系统总览未展开时导出的是当前总览，不能偷偷导出全包关系图。
SVG 的节点组和关系路径保留 `data-node-id` 和 `data-edge-id`，用于定位及与 JSON 对照。
耦合叠加的 fanIn/fanOut 是全图当前关系中去重后的入/出邻接节点数，筛选时不重算。
目录组取组内成员相邻节点的并集。该值不等于消费者数量或运行调用量。
页面只使用内联数据、脚本和样式，file:// 打开无需服务端或网络。
名称和表达式按文本显示，不能作为 HTML 或可执行脚本。

## CLI 与失败

architecture 默认继续向 stdout 输出 N1 JSON。`--out` 仍写同一 JSON。
`--report <dir>` 另生成 `report.html`、`graph.json`、`actual.json` 和 `summary.md`。
metrics 的 `review.html` 使用同一总览和关系浏览组件，保留原输出文件。
无效参数、读取、投影和写入失败使 CLI 非零退出，不能产出假成功结论。
未执行的测试、未设的预期和未观测的运行状态分别说明。
