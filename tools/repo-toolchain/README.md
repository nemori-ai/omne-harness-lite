# repo-toolchain

`@omne-harness/repo-toolchain` is the checker package of the omne-harness-lite repository. It provides the rule engine, commit attribution, the dependency graph, declaration compatibility, contract API snapshots, the acceptance lock, actual architecture extraction, structure metrics and the clean loop.

Commands: `omne-deps`, `omne-declarations`, `omne-contract-api`, `omne-acceptance-lock`, `omne-architecture`, `omne-metrics`, `omne-loop-status`, `omne-loop-health`.

Run a command with `--help` to see its usage.
