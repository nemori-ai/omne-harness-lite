# verification/models

本目录承载本包的形式模型，例如 TLA+、Alloy 或 SMT 模型。

## 允许的内容

模型源文件、配置与说明。

## 边界

说明模型对应的 `SPEC.md` 性质、抽象前提与未覆盖的部分。模型通过不等于实现符合。

## 维护

承诺或实现结构变化时，复核模型的抽象是否仍然成立。

## 本包事实

现在为空，本成员没有形式模型。候选性质是撤除顺序：`hostFilesPlugin` 卸载与服务卸载并发时，同一个提供者只退役一次，全部租约都失效，待处置时调用方直接调用的撤除函数不以正常返回报告完成。以后建立模型时，在这里写明对应的 SPEC 章节、前提与运行命令。
