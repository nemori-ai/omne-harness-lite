# verification/models

本目录承载本包的形式模型，例如 TLA+、Alloy 或 SMT 模型。

## 允许的内容

模型源文件、配置与说明。

## 边界

说明模型对应的 `SPEC.md` 条款、抽象前提与未覆盖的部分。模型通过不等于实现符合。

## 维护

承诺或实现结构变化时，复核模型的抽象是否仍然成立。

## 本包事实

现在为空。本成员只有类型与纯函数，没有状态机的实现。获取、受管资源与设施请求的状态转移写在[对象模型](../../docs/object-model.md#生命周期)。需要用模型核对这些转移时，模型放在这里，并写明它对应的条款与前提。
