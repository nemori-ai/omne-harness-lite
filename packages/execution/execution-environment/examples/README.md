# examples

本目录承载面向真实公开入口的使用示例。

## 允许的内容

可运行的示例代码与说明。

## 边界

示例只用公开入口，并写明运行前提。示例不代替测试或规格。

## 维护

公开入口变化时，同步示例并确认它仍能运行。

## 本包事实

现在为空。独立使用的写法片段在[使用与定位](../docs/context.md#独立使用)里，它需要调用方自己的提供者、账本、守卫与恢复授权。本成员不依赖任何提供者成员，所以带真实提供者的可运行示例不放在这里，归 [execution-environment-host-local](../../execution-environment-host-local/examples/README.md)。只用替身提供者的示例可以放在这里，加入时写明运行前提，并让它随包的 `typecheck` 编译。
