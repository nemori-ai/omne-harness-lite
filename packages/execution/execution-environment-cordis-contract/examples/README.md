# examples

本目录承载面向真实公开入口的使用示例。

## 允许的内容

可运行的示例代码与说明。

## 边界

示例只用公开入口，并写明运行前提。示例不代替测试或规格。

## 维护

公开入口变化时，同步示例并确认它仍能运行。

## 本包事实

现在为空。本成员只有抽象定义，单独装载它不提供任何服务。依赖方的写法片段在[使用与定位](../docs/context.md#使用方式)里。可运行的装配示例要同时装载 Service 实现，归 [execution-environment-host-local](../../execution-environment-host-local/examples/README.md)。
