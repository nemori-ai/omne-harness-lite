# Slash Command能力组工程设计

状态：工程设计草案。正式成员及公开形状未具名，只有文档，不授予技术采用或运行支持。以下章节描述逻辑责任的机制与协作，不能据此建立统一公开契约、包、进程或数据库。

## 身份、采用值与状态

命令身份是命令名，资产类别和所选实现来源沿资产规则辨认。命令定义版本、会话集合采用依据、当前权限判断和一次展开操作是不同事实。绑定及参数声明随定义，不从分层设置读取另一份绑定。接缝显式携带可信租户、适用主体和目标 Session，不从 Context、插件实例、路径或当前客户端推断身份。

一次内容受理须能关联原输入、命令名、合法参数、本次定义/绑定、实际展开内容或可靠引用、来源和范围，以及原消息受理位置。工作流分支关联原命令请求与真实流程操作身份及结果；不强制创建消息、Run 或工具执行。公开数据形状由实际定义拥有者维护，具体编码见 Q-SC02/Q-SC03，不在此造未定 API。

会话集合由合法装配、指定范围 reload 或系统流程失效后的自动刷新发布。当前资格另在实际使用边界核验，撤权不等待集合快照刷新。客户端展示是可失效读面，须说明来源、新鲜度和不可判定状态，不能成为授权权威。命令已知集合也不沿用 Skill/Tool 的不可用占位规则，无权入口始终不可见。

## 识别、展开与提交

1. 交付面核验本次来源，识别开头至多一条命令，解析参数并预检目标会话集合。未知/无权或解析失败不发送。
2. 原受理协调者核验目标 Session、当前集合/绑定及实际资格。客户端预检或预展开不能代替这一步；失败拒绝，不落为普通文本。
3. 提示词路径形成本次定义正文及参数；Skill 路径取得合法实际正文并保持正文块与用户参数块分开。未决 Q-SK08 仅隔离其特定读取分支，不替该分支选择默认。
4. 内容展开后进入原消息落盘前扩展。脱敏后按获准内容保存，否决时原命令及展开正文一起不落正文，但具名拒绝事实可查。命令标注不能成为被拦内容的泄漏副本。
5. 原消息拥有者将获准实际内容、来源、原输入关联及待处理资格按自己的提交契约保护，并在对外确认前达到声明耐久边界。入队后的 Run/attempt 承接仍归会话与工作。
6. 系统流程路径交给真正执行者，保留其受理/原操作状态与命令摘要。摘要丢失不让已发生效果再次执行，也不替实际恢复事实。

固定实际输入和合法资格须在相应提交/准入边界共同成立。不能从同一函数调用、同一进程或同一数据库名称直接推出原子性；技术拥有者须明确保护边界及跨拥有者协议。来源读取成功只取得候选，不先授予正式采用；已有原采用记录也不恢复撤销资格。

## 动态变化与生命周期

内容/定义变更经指定刷新采用，入口撤权即时生效，新授予等待刷新。来源范围与捕获的运行结构分开：仅更新稳定注册表的条目，不自动重建消费者。同一 Session 的 Agent Definition 标识在创建时固定；reload 只能采用该标识的新版本，不能更换身份。采用同标识新版本或改变捕获的 Loop/extension 或直接必要入口时，装配拥有者校验完整构成并组织安全交接。保留原 Run、新建 attempt 的路径沿已接受运行架构，旧工具、模型调用和消费位置继续归原工作。

采用协调者保护较新选择、刷新、撤权、取消和迟到候选竞争。未形成合法一致候选时保留原采用记录且本次失败可见，不恢复整个旧全局快照、不抹掉他方合法贡献。旧回调不能重新发布过期集合或把旧结果交给新请求。具体并发机制是 Q-SC04 的技术义务；采用自定义换代/恢复协议时须履行相应行为模型义务。

定义是数据，不为每份命令创建固有 runtime。提供者、交付适配、来源读取者各自保管登记、读取句柄和临时资源；停止准入、实际读取停止、资源释放与原消息/流程责任交接分别确认。卸载只撤自身贡献，临时资源释放不能撤销已发生消息提交或流程效果。贡献登记若经 Cordis 接入，沿 IC-1 至 IC-19 的定义、纯入口、依赖和效应归属，不宣称内核自动兑现业务事务、租户授权、撤除顺序或失败处理。

## 失败、取消与恢复

| 所在位置 | 可观察结果 | 继续责任 |
|---|---|---|
| 交付预检 | 未发送、未知/无权同回应、参数错误 | 交付面保留可编辑输入，不造入站记录 |
| 受理复核 | 当前条件拒绝或无法核验 | 原受理拥有者记录具名拒绝，不能执行旧缓存 |
| 内容取用/展开 | 明确失败或实际已得范围 | 读取/展开者保管未交接内容，Skill 边界不被改写 |
| 消息提交 | 未提交、已确认或结果未知 | 原受理/消息查询对账，已确认消息不重展开重投 |
| 流程分派/执行 | 拒绝、缺席、已承接、实际完成、部分或未知 | 原流程拥有者接续，命令摘要仅呈现 |
| 刷新/装配 | 未生效、已生效或无法确认 | 采用及装配拥有者查询真实采用，失效候选不发布 |

Q-SK08 是局部设计未决，不是上述运行结果。此候选不定义该分支挂起、返回设计缺口或默认替换件；其读取结果仍待原问题的具名决定。其余已定拒绝和实际故障照常由对应拥有者处理。

取消等待不证明操作未发生，确认写入未知不得盲目重做。历史内容、控制意图、实际停止、结果消费及外部效果分别保管。准入/存储依赖不可用阻止依赖其保证的新动作，不把可选展示故障扩成全系统停机。披露、重读和恢复取得新内容均核验当前权利，事实保管不等于永久披露授权。

## 技术交接与验证

本域承诺由 INV-SC01 至 INV-SC18 及 V-SC01 至 V-SC18 展开。定义/采用、识别/内容与受理/流程接缝分别负担局部及组合证据，不以接口齐全、解析通过或一次重启证明整体行为。授权竞争、内容一致性、确认丢失、取消/迟到和跨租户访问需要真实组合及适用故障验证。耐久验证声明须说明普通进程/操作系统崩溃、断电及介质前提，不能将它们混为一种测试。

Q-SC02 至 Q-SC05 分别承接语法/公开形状、可靠受理交接、采用生命周期和流程适配。Q-SK08 的唯一产品裁定由 Skill 产品第四章维护，本域不新增重复投票。产品阶段先选完整 CAP 及条件，随后技术采用机制、provider、版本和验证方案。

## 技术后续设计与承接缺项

以下是具名逻辑责任的技术义务。尚未分配正式成员，组暂时维护缺项与交接，不成为统一公开行为拥有者。实际成员、消费者及技术采用明确后才切换完整行为唯一源。

### Q-SC02 统一定义、参数语法与原样输入公开形状

维护责任：命令定义、识别与跨客户端技术拥有者；组维护者登记正式成员承接缺项。

分类：技术义务。场景：同一输入经过人读和机读交付面，以及受理侧再次解析，必须得到同一名字、参数和绑定含义。

已知约束：名字是身份；绑定及参数声明随定义；保留命名空间不能只按现有名单保护；开头至多一条，声明解析失败不发送，未声明时余下全文作自由参数。未知与无权同回应，非交付面文字不能触发流程。

技术拥有者须确定唯一名字编码、保留前缀边界、分隔符、参数/引用方式、原样输入拼法及错误公开形状，并说明其定义拥有者和真实消费者。可共置定义与识别实现，也可按独立责任拆分，但不为未定归属创建假包或复制类型。完成证据是跨客户端/受理的同输入行为及非法名字/参数反例，不能只交一份 Schema。

### Q-SC03 原输入、实际内容及受理的可靠交接

维护责任：原受理、消息及内容消费者；组维护者登记正式成员承接缺项。

分类：技术义务。场景：Skill 正文读取成功，消息提交确认丢失，客户端准备重传同一个请求。

已知约束：展开用户内容与工具 read 返回分别保留。原输入、实际获准内容、版本/来源/范围及原消息位置需要一致关联；否决不保存原命令与展开正文，拒绝事实仍可见。已受理消息不得重展开重投，用户再次提交与技术重传也不能按文字相同混同。

原受理、消息及内容消费者须给出请求身份、固定输入、提交/确认、原受理查询、可靠引用和保留协议。具名保护同提交或跨拥有者交接，说明资格变化竞争和普通崩溃/断电的真实耐久前提。技术路线由实际提供者决定，不能从一个函数调用推原子性，不能用通知或摘要替提交事实。

### Q-SC04 指定刷新与装配交接的采用协议

维护责任：采用与装配协调拥有者；组维护者登记正式成员承接缺项。

分类：技术义务。场景：两次 scoped reload、权限撤回和较新工作区选择交错，旧候选迟到。

已知约束：内容变化经相应刷新，新授予等刷新，入口撤权即时；范围外来源不偷偷读取。Session 固定 Agent Definition 标识，只允许同标识新版本。数据更新不一律重建，真正捕获结构变化才由装配校验完整构成并安全交接。失败保留原记录而不延续失效权利。

采用/装配拥有者须定义实际发布权、候选版本、取消/较新选择保护、必要结构交接、原状态查询及贡献撤除协议，明确实际成员。可复用有适用证据的已有机制；自定义并发换代/恢复须有行为模型，依赖新可逆或可交换保证省略控制时满足手册证明门槛。未定机制不削弱已定业务边界。

### Q-SC05 系统流程分派、原操作与失败刷新接缝

维护责任：命令、原受理及真实系统流程拥有者；组维护者登记正式成员承接缺项。

分类：技术义务。场景：流程服务已经承接操作，但命令回告丢失；或服务明确缺席/拒绝而自动刷新也失败。

已知约束：流程不入队，真实能力拥有执行和结果。命令摘要不是实际恢复状态，缺席/拒绝先报告该次失败再自动刷新；取消等待不等于物理停止，未知不允许盲目重复副作用。reload 是已点名流程族，其他具体流程例子不是支持清单。

命令、原受理和各流程拥有者须定义注册/撤除、实际操作身份、承接确认/拒绝/未知、查询及控制协议，并说明自动刷新失败的读面表现与原操作保管。通知、回告和摘要丢失分别处理，实际执行不因适配退出而无人承接。具体流程列表、保留拼写和成员实现由其真实采用决定。
