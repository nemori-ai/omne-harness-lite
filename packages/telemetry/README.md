# 遥测能力组

本组是条件性工程位置，依据为[项目要求](../../docs/requirements.md)与[目标包组织](../../docs/package-organization.md#目标目录)。当前具名成员是 [diagnostic](diagnostic/README_ZH.md)。事件目录、保留时长和生产数字限额仍未接受。

## 责任与范围

具名消费者、采集目的、获准数据范围和权限明确后，再判断是否建立成员。本组不接管相邻领域的业务规则或事实权威。

## 成员与依赖

`diagnostic` 是纯模块 `@omne-harness/diagnostic`。存储和后来的模型调用方从包根注入使用。它不拥有业务结果。依赖方向见[包边界与公开入口](../../docs/package-organization.md#包边界与公开入口)。本成员没有运行时依赖。

## 关键协作

事实拥有者提供可观察事件；遥测能力在获准范围采集与传送；观测端消费。精确交接与失败行为随实际成员或协调者维护。

## 组合验证

核对采集权限、传输失败及数据缺失可识别性。事件、指标、保留时限与后端尚待决定。`diagnostic` 的 `pnpm test` 覆盖合成导出端上的拒绝、缺口、导出失败和关闭。它不证明真实日志后端已经退出。

## 维护

组技术拥有者与原语义或事实拥有者共同判断新增成员，文档维护者同步导航、登记及链接。长期个人负责人尚未具名。建包前核对[成员文档规范](../../docs/member-documentation.md)和[开发指南](../../docs/development.md#创建和整改产品包)；条件未满足时在原拥有者处维护局部机制。
