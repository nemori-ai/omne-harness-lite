# adr

本目录承载有持续消费者的实现取舍与必要理由。

## 允许的内容

每项取舍一份 Markdown 文件。

## 边界

只保留现行理由。单次评审、提案过程与执行日志归任务 tmp，不进本目录。

## 维护

取舍被替换时，更新或删除对应文件，并同步引用它的设计正文。

## 本包事实

现在为空。服务定义导出七个抽象类与取自 `provide` 的键常量、键只写在 `provide`、端口服务不写 `inject` 这几项取舍的理由写在[内部架构](../docs/architecture.md#关键机制与理由)。出现一项有持续消费者、又不属于那一页的实现取舍时，才在这里加文件。
