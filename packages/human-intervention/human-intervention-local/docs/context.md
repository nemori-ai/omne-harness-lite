# 消费侧上下文

## 消费者与边界

本成员由 C2 的独立人工请求应用装配消费，后续 Tool/Agent 适配只消费公共 HITL 服务，不导入此成员的存储细节。tenant domain、SQL 材料和组合注册归装配者。当前可消费的能力包括操作终态、请求/卡片事务、独立等待恢复及原结果回查；Identity 成员资格协调已经接入；独立等待的当前资格查询与统一池已实现；独立等待答卡及恢复应用服务已实现，人类登录接入和其他原等待适配仍未装配。

## 使用方式

装配者先登记本成员材料及组合，再用 createIndependentHitlApplication 注入同一租户域的 SqlStorage、Identity 验证和 reservation 端口、稳定 destination 与游标签名键。公开调用见[API](public-api.md)。读预算至少满足[合法批次与存储预算](../SPEC.md#合法批次与存储预算)。

停止服务时先关闭应用并排空调用，再由共享存储拥有者关闭存储。发现关系损坏时按[受管恢复](../SPEC.md#投影失效与受管恢复)停用实例；不通过重新答复或重新消费修复投影。
