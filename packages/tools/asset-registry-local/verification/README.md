# Local registry verification

Run this package's build, typecheck, and tests. Use [public registry obligations](../../../core/asset-registry/verification/README.md) with real manifest history, current/fixed sources, tenant mapping, and clock. A fabricated always-success source cannot establish those premises.

Check bounded queues, capacity exhaustion, whole-chain headMismatch retries, unknown append receipts without blind retries, stale H cache completion, generation isolation, and close with admitted work. Keep borrowed ports until actual work and diagnostics finish. Check diagnostic failure without replacing the operation result and without exposing content or credentials.

Separate historical read authority from fixed-root authority. Test original full-fill recovery after all six tables change, current versus captured roles, bad newest given with no fallback, and genuine C16 drift. Caller invalid input still has its original priority.

The standalone closure and demonstration adapter do not establish a formal provider plugin or full MCP/Session coordination. Public and provider checks must report their actual scope and failures.
