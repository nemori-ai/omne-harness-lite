# Workspace

## 总体架构

Workspace 包组回答一个问题：一个逻辑工作区是谁，和哪些租户、实例与地址有关系，从它的实例里能安全地读出哪些候选来源交给装配，以及对它的资源操作怎样如实反映真实目标与结果，而不接管主体、资产、会话选择、装配、执行环境或目录指导的事实。

| 成员        | 回答的问题                                                                                                                 |
| ----------- | -------------------------------------------------------------------------------------------------------------------------- |
| `workspace` | 工作区的身份、治理与参与关系、实例与地址关联、两根来源（`.omne`、`.omne.local`）的有限发现与同层求值、资源操作的确认与恢复 |

工作区以稳定的逻辑身份存在，路径、remote、分支都只是定位值。租户显式登记已有内容或托管新建，得到参与关系；实例与地址分别关联到这个身份。Session 把明确的工作区选择交给装配作为候选；参与条件、组织政策、实例条件与当前来源读取资格成立后，工作区按约定位置发现候选来源并交出可解释的材料与一致读取依据；装配校验并采用之后，Session 才确认附着成功。具体的管理类型（例如 Git）负责真实的资源效果；工作区只报告自己的关联变化。

## 领域边界

本组拥有：逻辑工作区的身份、类别与管理类型；托管治理归属与参与关系；实例关联与地址关联；来源读取的范围、一致依据与同层求值；工作区资源操作的确认、未知与恢复责任。

本组不拥有：主体与私有权利（Identity）；资产类别与它们的求值、禁用、资格与锁定（Assets 与规则）；当前选择与逻辑工作（Session）；候选采用与交接（装配）；真实设施、落点与资源恢复（执行环境）；AGENTS.md 等目录指导（Runtime Context 与 Request Context）；真实资源效果（具体管理类型，例如 Git）；命令型 MCP 与 hook 的运行准入（对应能力与租户治理）。本组不重做 Git、统一地址同步或物理安全边界。

本组声明、由别人实现的端口：

| 端口                     | 对方                             | 本组需要它做什么                                                   |
| ------------------------ | -------------------------------- | ------------------------------------------------------------------ |
| 主体、租户与组织治理配置 | Identity 与合法的治理配置        | 核验主体与租户关系；给出授撤、转授、移除、销毁的资格与组织参与政策 |
| 候选过滤                 | Assets 与规则                    | 对候选做禁用、资格、锁定与受限配值的过滤；本组不另造权限合成算法   |
| 管理类型的原生操作       | 具体管理类型的提供者（例如 Git） | 执行同步、分支、销毁等真实资源操作，报告实际目标、效果与未知范围   |
| 兼容格式的转换           | Skill、MCP、hook 各自的能力      | 把受支持的第三方格式转换成候选                                     |

本组为别人实现的端口：

| 端口           | 对方            | 本组提供什么                                           |
| -------------- | --------------- | ------------------------------------------------------ |
| 关联与版本依据 | Session         | 明确选择对应的工作区关联与可复核的版本依据             |
| 候选来源材料   | 装配            | 按两根求值后的可解释材料、来源与取舍原因、一致读取依据 |
| 目录访问事实   | Runtime Context | 目录指导需要的访问事实；本组不合并规范文本             |

## 心智模型

把工作区想成一份有户口的项目，而不是一个文件夹。户口（逻辑身份）在，搬家（地址变）、复印一份（新实例）、停电（实例不可达）都不改变它是谁；两个同名的文件夹也不因为名字相同就是同一份项目。谁能用它，看的是参与关系与资格，不看谁先打开、谁的电脑上有它。

来源读取是按清单查一遍，不是跑一遍：只看两个约定的根和明确声明的扩展位置，不跟随软链接，不执行任何程序，读到的东西只是候选，校验并被采用之前什么都不生效。共享的 `.omne` 进同步，实例本地的 `.omne.local` 不进；local 同身份优先，但被过滤掉的 local 不遮住合法的共享。

最容易想错的地方：结束会话、换 agent、卸载装配都不卸载实例，也不删托管资源；撤权、解除关系与删除文件是三件事；结果不知道就是不知道，取消不证明停下，销毁请求不等于销毁成功。

## 应然设计

### 身份与关联

- 每个实例与地址关联都指向一个明确的逻辑工作区；路径、remote、分支、提交与当前任务目标都不能替代身份。相同定位字符串不自动合并身份，不同节点、agent、Session 或地址不自动拆分身份；地址改变、不可达与实例重建不自动销毁或新建逻辑工作区。
- 管理类型、类别与地址提供者分别表达；具体类型只暴露真实支持的能力，非 Git 类型不提供虚构的 Git 能力。
- 实例可以先于会话存在，可被多个获准租户使用，并以各会话的身份独立求值。本地路径、worktree 与实例不是环境隔离边界；创建 worktree 不自动登记实例。卸载实例、路径失效与环境重建都不等于逻辑工作区被删除。

### 登记、参与与治理

- 只有当前目录、残留配置或普通会话创建，不登记关系，也不读取工作区候选来源。显式接入已有内容时保留原件，不重复 clone、覆盖、删除或自动上传；关系同步不承担内容同步。
- 托管工作区只有一个治理所有者；外部工作区的接入者都是参与者，登记不产生所有者或外部写权。合法治理配置明确授撤、转授、移除与销毁的资格与作用域；没有明确资格的主体不能移除他人或销毁资源；单有组织超管或一般管理名号不自动授权，已获合法组织治理授权的主体也不被固定角色名无依据地排除。授权不转移归属；存在的托管工作区不能单独删掉唯一治理所有者关系。
- 受租户约束的跨边界操作携带原租户与适用主体；跨租户默认拒绝，地址、邀请与共用实例都不授权。实际装配按本会话的租户关系与适用的组织参与政策判断，工作区所有者的私有材料不替代参与者的输入。组织政策的默认值与档位不由仓库设置补定；无所有者的外部工作区不能借首登者的组织取得归属。只读不升级为维护。
- 部分完成分别报告登记、资源关联与采用结果：关系与关联已确认而来源或装配校验失败时，保留已确认的事实，明确未采用及原因；首次没有原采用时工作区层仍为空，已有原采用时保留原采用记录；保留的记录不延续已撤销的授权。失败不新建空的替代工作区。

### 来源发现与读取

- 发现只在 Session 有明确候选选择、参与条件、组织政策、实例条件与当前读取资格都成立之后进行，只读实例根下的 `.omne` 与 `.omne.local` 约定位置，按类别格式发现，无需逐件登记。读取用于候选校验，不以装配完成为前提；校验与采用之前候选不生效。
- 两根各有一份 `workspace.json`，承担扩展路径、允许的配值、禁用与兼容配置，不另产生 `settings.json` 或 `permissions.json`。嵌套的额外发现须明确相对路径与受支持的匹配语法，不任意递归搜索。软链接与经过软链接的路径始终排除，显式路径或 glob 也不例外。类别包内部的正常资源不被误认作另一个工作区。读取不启动任何程序。
- 根或类别目录缺失是空来源；配置文件缺失仍按声明的默认范围发现，不自行补未定的部署值。存在但无法解析或格式不合法的配置明确失败，不跳过 local、不退回共享、不采用半份材料。读取不可用不是空目录。
- 一次候选组合保留可核验的读取范围与版本依据；并发改动使它无法形成一致依据时重读或失败，不声称混拼的状态已校验。读取者释放临时句柄；释放不撤销外部效果。

### 同层求值与兼容来源

- 共享与 local 属于同一工作区层。候选按类别加名字识别：先交资产拥有者过滤禁用、资格与锁定，再取合法候选的并集，local 同身份优先；被过滤的 local 不遮蔽合法的共享。完整的 local 替换实现不与共享包逐文件拼接。
- 设置按声明项取 local 的显式值，缺项才沿共享与已有规则；显式 `false` 不等于缺项，不取 OR，不自动递归合并结构值。local 只覆盖共享设置时保持共享实现；一旦选中 local 实现，不应用针对共享实现的覆盖，不迁移凭据或实现专有的设置。来源与取舍原因可解释。
- 兼容贡献要有有效准入与受支持的格式；Codex 与 Claude Code 分别配置。目录存在不等于启用，未知格式或内容明确报告。只读取同一工作区里受支持的 Skill、MCP 与 hook；不读家目录，不导入整体权限政策、Agent 定义或指令文本。保留原件，合法的原生候选优先，同一第三方能力的不同内容冲突时显式选择，多路径不重复加载或重复触发。发现成功不是执行许可。

### 共享、私有与目录指导

- `.omne` 是工作区的共享来源，每次变更都在该工作区采用的共享同步范围之内，不能任意永久排除；同步沿管理类型的原生机制，可以异步、按需。`.omne.local` 不进入共享上传或同步，两根的有效求值结果也不整体上传。local 是实例本地的，不是租户私有的保证；共用实例不自动共享租户私有的资产、配值、凭据或所有者的私人输入。
- 工作区配置不能放宽权限、落点、身份或治理锁定；外部读取与上传各自核验目的与授权。
- AGENTS.md 社区规则、嵌套首次访问加载与文本上下文归 Context；规范文本不进入资产与设置的合并。文件修改或资源同步不静默更新已采用的装配；新的实际装配或显式重新加载才读取并校验。校验失败保持原采用记录，不发布半新半旧的结果，但不延续已撤销的权限。

### 选择竞争与原调用

- Session 拥有当前选择与变更事实，工作区返回关联与版本依据，装配处理受影响的求值与交接。较新的选择与取消优先于迟到的候选；候选不基于已失效的条件暗换当前采用。
- 已发出的调用保留原输入、实现、环境、工作区与工作身份，未消费的结果仍属于原工作；新环境可用不代表旧执行转移或终止。旧建议还没执行时按当前约定核验，不暗改参数或目标。

### 提交、未知与恢复

- 登记、关系、授权与不可重建的关联事实在对外确认之前达到声明的耐久边界；外部资源效果按其托管契约另行确认。同一关系与附带授权的变更不发布相互矛盾的成功；跨拥有者的多步提交留下可解释的责任与恢复位置。
- 必要的原账号、租户、工作区、实例、Session 与工作、操作目标与采用版本跨异步、重连、重启与交接保留。恢复不用最新来源替代历史采用依据，不用旧快照恢复已撤销的权利。查询投影说明来源与新鲜度；资格判断不只靠滞后的展示。
- 区分未获准、明确未执行、已执行、部分完成、失败与效果未知。查询不可用、响应丢失、超时与取消等待都不等于不存在、回滚或物理停止。有副作用的恢复先查询或核对原生状态，不盲目重新创建、同步、销毁或重放。取消之后仍承接原动作的真实结果。
- 资源操作复用管理类型的真实原生模型：Git 允许获准的 agent 用通用工具按需同步、分支、worktree 与处理冲突，冲突不强制转人。排队、开始、完成分别可观察，结果明确落在本地实例或具体远端，不宣称所有地址已同步。超限或冲突保留原件与可判断的状态，不截断、不静默写入新身份的私有副本，不自动覆盖冲突目录。

### 撤权、解除与销毁

- 撤回治理授权保留参与关系与其他合法权利；删除关系则解除附带的授权，两者保持一致。成功解除之后，该租户之后的装配不再从原目录取得工作区或兼容来源，残留内容不自动恢复关系；再次使用须显式登记并重新核验。其他租户的关系与本地文件不连带删除。成员退出时的私有保留与重入恢复归身份与资产。
- 销毁需要所采用合法治理策略明确的本资源资格并满足本次资源授权；外部参与登记不提供外部销毁资格。提交请求、一次访问失败或结果未知不能删除关系冒充销毁成功。资源确认销毁之后，所有关系不再作为有效授权或有效参与展示；关系清理未完成时可见并可恢复，重启后只推进未完成的清理，不重做已确认的销毁。各节点的本地文件保留，之后的普通目录使用不自动创造替代工作区。

### 观测与披露

- 接受与拒绝、读取与求值、关系与授权变化、资源操作的阶段、采用、取消、未知与恢复都有可定位的记录，关联原主体、工作、来源与提供者版本、目标与失败阶段。状态界面与诊断读同一权威依据；观测查询不重做业务动作。
- 秘密值、私有内容与地址里的敏感信息按目的与授权筛选；凭据不作为普通日志或遥测输出。记录故障与展示的新鲜度缺口可见，不制造假成功。

## 原则与约束

- 身份不是定位值。路径、remote、地址都可以变，逻辑工作区不随之生灭。
- 读取不是执行，候选不是采用。发现只读约定位置，不跟随软链接，不启动程序；校验与采用之前候选不生效。
- 共享的进同步，本地的不出实例；工作区配置不能放宽权限、落点、身份或治理锁定。
- 结果不知道就是不知道。先查原操作与原生状态，再决定后续动作；取消与 disposer 不撤销已发生的效果。
- 撤权、解除关系、删除文件与销毁资源分开成立，各有自己的资格与收敛过程。
- 本组不复制相邻领域的事实：资产求值、会话选择、装配采用、执行环境与目录指导各归其拥有者。

## 不变式

| 编号     | 永远成立的性质                                                                          | 违反的后果                                 | 由什么守 |
| -------- | --------------------------------------------------------------------------------------- | ------------------------------------------ | -------- |
| INV-WS01 | 逻辑身份不由定位值替代；地址变化、不可达与实例重建不自动销毁或新建工作区                | 两个项目被合并，或一个项目被拆成两个       | 只有文字 |
| INV-WS02 | 显式登记与附着分别成立；部分完成分别报告，失败不新建替代工作区                          | 打开一个目录就悄悄登记并读入它的配置       | 只有文字 |
| INV-WS03 | 按真实主体与本会话租户关系核验资格；跨租户默认拒绝                                      | 地址或邀请被当作授权                       | 只有文字 |
| INV-WS04 | 托管工作区只有一个治理所有者；外部参与不产生所有权或外部写权                            | 首个登记者取得别人资源的所有权             | 只有文字 |
| INV-WS05 | 实例与会话寿命解耦；结束会话、卸载装配不卸载实例或删托管资源                            | 归档一个会话删掉了共享的工作区             | 只有文字 |
| INV-WS06 | 发现只读约定位置与明确扩展，不跟随软链接，读取不执行                                    | 读入工作区之外的文件，或读配置时启动了程序 | 只有文字 |
| INV-WS07 | 缺失是空、错误是失败、混拼的读取不算校验通过                                            | 半份配置被当作完整采用                     | 只有文字 |
| INV-WS08 | 同层求值按类别加名字取合法并集，local 优先但被过滤的 local 不遮蔽共享；实现不跨来源拼接 | 运行一个拼出来的、谁都没发布过的实现       | 只有文字 |
| INV-WS09 | 兼容来源要有准入与受支持格式，不读家目录，不重复加载                                    | 第三方配置绕过准入或执行两次               | 只有文字 |
| INV-WS10 | `.omne` 在共享同步范围内，`.omne.local` 与有效求值结果不上传                            | 私有配值或凭据泄露给别的租户               | 只有文字 |
| INV-WS11 | 目录指导与资产采用分开；文件变化不静默更新已采用的装配                                  | 运行中的 Run 被文件变化半路换了组合        | 只有文字 |
| INV-WS12 | 较新的选择与取消优先于迟到候选；已发调用保留原工作区与输入                              | 结果被归到错误的工作区                     | 只有文字 |
| INV-WS13 | 关系与授权的确认达到声明的耐久边界；恢复不用最新来源替代历史采用依据                    | 重启后关系与授权矛盾                       | 只有文字 |
| INV-WS14 | 未知与取消不伪装成未发生；有副作用的恢复先查询原生状态                                  | 盲目重建或重复销毁                         | 只有文字 |
| INV-WS15 | 资源操作的结果落在实际目标上，冲突与超限保留原件                                        | 宣称所有地址已同步，或静默覆盖冲突         | 只有文字 |
| INV-WS16 | 撤权、解除关系与删除文件分开；解除之后残留内容不自动恢复关系                            | 本地残留让已撤销的授权复活                 | 只有文字 |
| INV-WS17 | 销毁确认之后关系收敛；未知不清理关系，已确认的销毁不重做                                | 销毁失败却删掉了关系，或重复删除外部资源   | 只有文字 |
| INV-WS18 | 观测读同一权威依据，凭据与私有内容按授权筛选                                            | 诊断泄露秘密，或展示假成功                 | 只有文字 |
