# workspace/workspace 长期行为候选

状态：具名成员目标的完整行为草案。只有文档目录，运行成员及公开类型尚未成立，未获产品或技术接受。本规格维护类型之外的必要行为，不预造方法、事件、数据库字段或提供者协议。公开形状、一致读取和跨拥有者确认的技术缺项见[问题记录](../../../.meta_harness/design/product/workspaces/design.md#未决问题与待定事项)；这些缺项不抹去以下可检验规则。

## 责任、消费者与采用范围

工作区能力对治理应用、Session、装配、环境适配、来源消费者和资源操作交付面承诺身份、参与、实例/地址关联、获准来源及可解释结果。身份拥有主体与私有权利，资产拥有类别及求值，Session 拥有选择和逻辑工作，装配拥有候选采用与交接，环境拥有真实设施与资源恢复，Context 拥有目录指导。具体管理类型承担真实资源效果；本成员不重做 Git、统一地址同步或物理安全边界。

独立消费同样须传入可核验的主体、工作区和本次操作条件；系统组合才能成立的授权供给、Session 采用与跨提供者恢复必须由装配方核验，不能以独立库方法成功声称组合成功。进入 Cordis 的集成不能把领域含义交给作用域或 disposer 决定。

前提来自[项目要求](../../../docs/requirements.md)、[数据与状态](../../../docs/architecture/data-and-state.md)、[正式领域责任](../../../docs/domains/workspaces/README.md)；产品规则从[工作区产品正文](../../../.meta_harness/design/product/workspaces/design.md)核对，过程筛选报告不作为长期依据。本规格不承诺 0.0.0 → 0.1.0 全部能力，不继承旧 PF 的部署默认或首版支持清单。

## 身份、资格与关系

### INV-WS01 逻辑身份不可由定位值替代

每个实例和地址关联必须指向明确逻辑工作区；路径、remote、分支、提交及当前任务目标均不能替代身份。相同定位字符串不自动合并身份，不同节点、agent、Session 或地址不自动拆分身份。地址改变、不可达和实例重建不自动销毁或新建逻辑工作区。管理类型、类别与地址提供者分别表达；具体类型只暴露真实支持的能力。验证义务 V-WS01。

### INV-WS02 显式登记与附着分别成立

仅有当前目录、残留配置或普通会话创建不得登记关系或读取工作区候选来源。显式请求接入已有内容时保留原件，不重复 clone、覆盖、删除或自动上传；关系同步不承担内容同步。Session 将明确选择交装配作为候选；有效参与条件、适用组织政策、实例条件及当前来源读取资格成立后，允许读取和校验候选，无须先完成装配。来源校验通过且采用与交接条件成立后，Session 才确认当前选择已正式采用并报告附着成功。

部分完成分别报告登记、资源关联与采用结果。已确认关系和关联但来源或装配校验失败时，保留已确认事实，明确未采用及原因；候选材料不生效，首次没有原采用时工作区层仍为空，已有原采用时保留原采用记录。保留记录不延续已撤销授权，后续资格仍各自核验；失败不新建空替代工作区。验证义务 V-WS02。

### INV-WS03 按真实主体核验资格

受租户约束的跨边界操作携带原租户及适用主体；跨租户默认拒绝，地址、邀请和共用实例均不授权。实际装配按本会话租户关系及适用组织参与政策判断，工作区所有者的私有材料不替代参与者输入。组织政策由合法治理配置提供，其默认值和档位不由仓库设置补定；按治理归属限定范围时无所有者的外部工作区不能借首登者组织获得归属。政策变化不推定运行期热重判；本次动作的资源授权和当前读取资格仍核验。只读不升级为维护，工作区路径拒绝不撤销本来合法的普通目录权限或宣称物理隔离。验证义务 V-WS03、V-WS04。

### INV-WS04 托管治理与外部参与不混同

托管工作区保持唯一治理所有者；外部工作区接入者均为参与者，登记不产生所有者或外部写权。合法治理配置须明确授撤、转授、移除与销毁资格、配置修改者及授权作用域，上界与明确禁止仍有效。无明确资格的主体不得移除他人或销毁资源；单有组织超管或一般管理名号不自动授权，已获合法组织治理授权的主体也不能被固定角色名称无依据排除。PF-020 的仅创建者授撤、超管不转授方案为具名策略候选，策略支持及采用待负责人选择。授权不转移归属、不绕过其他资源资格；自身退出遵循其关系，存在的托管工作区未经合法归属变更不能单独删除唯一治理所有者关系。验证义务 V-WS04、V-WS12。

### INV-WS05 实例和会话寿命解耦

实例可以先于会话存在，可被多个获准租户使用，并以各会话身份独立求值。结束或归档 Session、改变 agent、卸载装配不自动卸载实例或删除托管资源。本地路径、worktree 与实例不是环境隔离边界；创建 worktree 不自动注册实例。卸载实例、路径失效及环境重建均不等于逻辑工作区删除。验证义务 V-WS01、V-WS05。

## 来源贡献与安全采用

### INV-WS06 有限发现且读取不执行

Session 已有明确候选选择，有效参与条件、适用组织政策、实例条件及当前来源读取资格成立后，才从实例根 `.omne`、`.omne.local` 约定位置按类别格式发现，无需逐件登记或空目录。此读取用于候选校验，不以装配完成或正式采用为前提；来源校验及采用与交接条件未成立前，候选材料不生效。两根 `workspace.json` 各自承担扩展路径、允许配值、禁用和兼容配置，不产生重复 `settings.json` 或授权 `permissions.json`。嵌套额外发现须明确相对路径及受支持匹配语法；不任意递归搜索。软链接及经过软链接的路径始终排除，显式路径或 glob 不例外。类别包内部正常资源不误作另一工作区；读取文件不启动程序。验证义务 V-WS02、V-WS06。

### INV-WS07 缺失、错误与一致读取可区分

根或类别目录缺失是空来源；配置文件缺失仍发现声明默认范围，不自行补未定部署值。存在的配置无法解析或格式不合法必须明确失败，不跳过 local、退回共享或采用半份材料。一次候选组合保留可核验读取范围及版本依据；并发改动使其无法形成一致依据时重读或失败，不声称从未成立的混拼状态已校验。读取不可用不能等同空目录。来源读取者释放临时句柄，不能通过释放承诺撤销外部效果。验证义务 V-WS06、V-WS07。

### INV-WS08 同层求值不跨实现混拼

共享和 local 属同一工作区层。候选按类别＋name 识别能力，先过滤禁用、资格和锁定，再取合法候选并集，local 同身份优先；被过滤的 local 不遮蔽合法共享。完整 local 替换实现不得逐文件拼共享包。设置按声明项取 local 显式值，缺项才沿共享及已有规则，显式 false 不等于缺项、不取 OR、不自动递归合并结构值。local 仅覆盖共享设置时保持共享实现；一旦选中 local 实现，不应用针对共享实现的覆盖，不迁移凭据或实现专有设置。来源与取舍原因可解释，资产专有求值仍沿其拥有者。验证义务 V-WS08。

### INV-WS09 兼容范围、冲突与去重明确

兼容贡献须有有效准入和已支持格式；Codex、Claude Code 分别配置，Codex 覆盖其工作区约定入口。目录存在不启用，未知格式或不支持内容明确报告。只读取同工作区受支持 Skill/MCP/hook，hook 转换归对应能力；不读取家目录，不导入整体权限政策、Agent Definition 或指令文本。保留原件，合法原生候选优先，同第三方能力不同内容冲突显式选择，多路径不重复加载或触发同来源。发现成功不等于执行许可，命令型 MCP 与 hook 的逐件运行准入归相关能力及租户治理。验证义务 V-WS09。

### INV-WS10 共享内容与私有材料分责

`.omne` 属工作区共享来源，每次变更须纳入该工作区所采用的共享同步范围，面向获准访问该工作区的租户共享，不能任意永久排除。同步沿管理类型的原生机制与策略，可以异步、按需；完成时机、冲突和失败处理不由此补定，不要求立即 push、更新其他实例或自动传播全部地址。`.omne.local` 不进入工作区共享上传或同步，也不能把两根有效求值结果整体上传。local 是实例本地而非租户私有保证，共用实例不自动共享租户私有资产、配值、凭据或所有者的私人输入。工作区配置不能放宽权限、落点、身份或治理锁定；外部读取和上传各自核验目的与授权。关系解除不销毁其他租户数据。验证义务 V-WS03、V-WS10、V-WS12。

### INV-WS11 目录指导与资产采用分开

AGENTS.md 社区规则、嵌套首次访问加载和文本上下文归 Context；工作区不设专属规范自动入口、不把规范文本纳入资产/设置合并。文件修改或资源同步不静默更新已采用装配；新的实际装配或显式 reload 才读取并校验。校验失败保持原采用记录，不发布半新半旧结果；这只保护采用的一致性，不延续已撤销的权限。后续准入、读取、结果交付及消费确认按当前资格核验，条件失效或无法取得时阻止依赖允许结论的新动作；验证通过后的运行切换遵守装配生命周期，不承诺任意外部副作用可回滚。验证义务 V-WS07、V-WS11。

### INV-WS12 选择竞争不改写原调用

Session 拥有当前选择和变更事实，工作区返回关联及版本依据，装配拥有受影响求值和交接。较新选择、取消优先于迟到候选；候选不得基于已失效条件暗换当前采用。已发调用保留原输入、实现、环境、工作区及工作身份，未消费结果仍属于原工作。新环境可用不代表旧执行转移或终止，环境负责真实落点及痕迹报告，Context 供给变化。旧建议尚未执行时按当前约定核验，不暗改参数或目标。验证义务 V-WS11、V-WS13。

## 提交、资源效果与恢复

### INV-WS13 确认、版本与工作归因可追溯

登记、关系、授权及不可重建的关联事实在对外确认前达到所声明耐久边界，满足普通进程/操作系统崩溃或断电后的读取与解释条件；外部资源效果另按其托管契约确认。实现须说明保存前提，不能把队列、进程缓冲或一次重启测试当耐久证据。同一关系及附带授权的变更不发布矛盾成功，跨拥有者多步提交留下可解释责任和恢复位置。

必要的原账号、租户、工作区、实例、Session/工作、操作目标及采用版本跨异步、重连、重启和交接保留。恢复不以最新来源替代历史采用依据，不以旧快照恢复已经撤销的当前权利。查询投影说明来源和新鲜度，资格判断不能只靠滞后展示；同一事实不生成两个独立权威来源。验证义务 V-WS02、V-WS13、V-WS14。

### INV-WS14 未知与取消不能伪装未发生

区分未获准、明确未执行、已经执行、部分完成、失败和效果未知。查询不可用、响应丢失、超时及取消等待不等于不存在、回滚或物理停止。保留原操作身份、已知效果和查询/恢复责任；有副作用的恢复先查询或核对原生状态，不盲目重新创建、同步、销毁或重放工具。取消后仍能承接原动作真实结果；已确认外部效果不会因 disposer、会话结束或取消而被称为撤销。验证义务 V-WS14、V-WS15。

### INV-WS15 资源操作反映实际目标与原生能力

具体管理类型复用其真实原生模型；Git 允许获准 agent 用通用工具自主按需同步、分支、worktree 与冲突处理，冲突不强制转人。非 Git 类型无需提供虚构 Git 能力。排队、开始、完成分别可观察，结果明确落在本地实例或具体远端，不宣称所有地址同步。超限或冲突保留原件与可判断状态，不截断、遗漏或静默写入新身份私有副本；不自动覆盖冲突目录，不承诺任意文件合并。验证义务 V-WS05、V-WS15。

### INV-WS16 撤权、解除关系与文件删除分开

撤回治理授权保留参与关系及其他合法权利；删除关系则解除附带授权，原子边界或恢复协议保持两者一致。成功解除后该租户后续装配不从原目录取得工作区或兼容来源，残留内容不自动恢复关系；再次使用须显式登记并重新核验。其他租户关系与本地文件不连带删除，已运行会话不推定即刻重装，但当前授权不得借本地残留复活。成员退出的私有保留/重入恢复归身份与资产，不与工作区退出混同。验证义务 V-WS12、V-WS14。

### INV-WS17 销毁确认后关系收敛

销毁须有所采用合法治理策略明确的本资源资格，并满足本次资源授权；不得仅凭管理员名号、工作区地址或历史准入放行。PF-020 的创建者/超管资格是可选具名策略，不能排除有合法授权的组织治理模型。外部参与登记不提供外部销毁资格。提交请求、一次访问失败或结果未知不能删除关系冒充确认销毁。资源确认销毁后所有关系不得继续作为有效授权或有效参与展示；关系清理未完成须可见并恢复，重启后只推进未完成清理，不重做已确认资源销毁。各节点本地文件保留，后续普通目录使用不自动创造替代工作区或加载工作区来源。验证义务 V-WS04、V-WS14、V-WS16。

### INV-WS18 可观测且披露守住授权

接受/拒绝、读取与求值、关系与授权变化、资源操作阶段、采用、取消、未知及恢复均有可定位事实或工程记录，关联原主体、工作、来源/提供者版本、目标与失败阶段。状态界面及诊断读取同一权威依据，观测查询不重做业务动作。秘密值、私有内容及地址中的敏感信息按目的与授权筛选，凭据不作为普通日志或遥测输出。必要记录故障及展示新鲜度缺口可见，不能制造假成功；具体事件和保存政策归技术采用，不在此钉死后端或 TTL。验证义务 V-WS17。

| V-WS08 同层求值 | 被禁/无资格 local 与可用共享同名；false 与缺值；完整 local 替换；共享配值和凭据不跨实现继承 | 来源与资产组合 |
| V-WS09 兼容准入 | 各开关独立，local 关闭覆盖共享；支持/未知格式；家目录不读取；原生优先；第三方冲突选择；重复 hook 不执行两次 | 兼容提供者、资产与对应类别 |
| V-WS10 共享同步界线 | 已采用共享同步的工作区中，`.omne` 每次变更均属于同步范围，不能只同步普通文件却永久排除共享资产或配置；同步可异步、按需，未完成不伪装 remote 完成；`.omne.local` 与合成有效值不上传，不同租户私有内容不泄露 | 来源与资源提供者、授权组合 |
| V-WS11 选择及 reload 竞争 | 文件变化不自动采用；连续更换/reload、迟到候选、取消竞争；旧调用仍归原工作区；Context 与资产处理不混合 | Session、装配、工作区、Context |
| V-WS12 授撤与退出 | 转授按所采用合法策略核验；未获授权不转授；撤权保留关系；关系删除解除附带权利；唯一所有者不单独退出；后续来源为空但文件保留；成员私有保留不被顺带删除 | 工作区、身份与资产组合 |
| V-WS13 原工作与落点 | 在途工具中更换工作区/环境，原输入、环境及归因保留，结果可接续；新环境可用不证明旧痕迹存在或已停止 | 工具、装配、环境、Context组合 |
| V-WS14 持久提交及未知恢复 | 保存前/后崩溃、确认丢失、读取不可用、取消等待、并发恢复；查原操作而不新建副作用，旧备份不复活授权 | 业务拥有者、存储/资源提供者及协调方 |
| V-WS15 资源目标和限制 | 只写一个 remote、排队/开始未完成、超容量、断网未知、原生冲突及取消后真实效果；原件和原操作依据保留 | 资源提供者、工具及交付面 |
| V-WS16 销毁故障收敛 | 未获准不改资源；未知不清理关系；已确认销毁但关系清理中断后只续清理；本地目录不删除、不自动替代 | 托管提供者、工作区治理 |
| V-WS17 观测与披露 | 凭记录辨别正常/拒绝/未知/恢复及原目标；观测故障和滞后可见；无权读取与秘密输出被阻止；查询不执行动作 | 各提供者及真实交付组合 |

V-WS14 的进程终止测试只能支持对应故障范围；断电耐久须核对存储前提并取得相称证据，介质损毁及灾备不因该测试获保证。恢复不要求调用恰好一次或任意异构热迁移；如提供者不能查询或证明安全重试，则保留未知并隔离依赖推进。

## 技术交接与边界

公开类型、身份匹配、来源快照、路径匹配、重复来源判定、配置 Schema、提供者能力结果和原操作查询协议须由具名成员设计补足。本规格没有选择数据库、Git 托管、LFS、进程拓扑或 Cordis 布局，也不把这些缺项包装成用户产品问题。实现前需要相应已接受承诺与构建计划；本稿及其检查不构成实施准入。
