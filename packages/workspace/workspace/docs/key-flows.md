## F-WS04 两根来源发现与材料求值

对应 J-WS04；守护 INV-WS02、INV-WS03、INV-WS06、INV-WS07、INV-WS08、INV-WS10、INV-WS11。

```mermaid
flowchart TD
    E[明确候选选择、有效参与与实例条件] --> R[核验当前来源读取资格]
    R -->|拒绝或未知| X[未采用，保留原采用记录]
    R -->|资格成立| C[读取候选两根 workspace.json 及一致依据]
    C --> Q{配置是否有效或缺失}
    Q -->|已存在但无效| X
    Q -->|有效或缺失| D[发现约定位置及明确扩展范围]
    D --> L[排除软链接与经过链接的路径]
    L --> P[候选保留类别、name、实现和来源]
    P --> F[资产拥有者过滤禁用、资格、锁定及受限配值]
    F --> N[同身份可用原生 local 优先于共享]
    N --> V[完整实现与声明项设置分别求值]
    V --> A[校验及采用与交接条件成立后正式采用]
    E --> G[目录指导访问事实交 Runtime Context]
```

来源缺失是空，配置缺失不是格式错误。候选读取无须先完成装配，未经校验及采用与交接不生效；首次没有原采用时，失败后工作区层仍为空。被过滤 local 不遮蔽共享；显式 false 不按 OR 合并；替换实现不拼接共享文件或继承其凭据。此流程只读取和求值，实际启动由相应能力准入控制，规范文本不进入设置合并。
