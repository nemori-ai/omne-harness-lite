# 身份组的成员与协作

状态为待审技术设计。正式维护位置不授予本组操作规格的技术接受、实施或支持。合法身份与时间点的纯值已经采用，精确形状归[共同纯表示](../../common/README.md)。本组操作的公开形状仍待定义。

## 目标成员与依赖

| 目标成员 | 拥有的事实与保证 | 消费的依据 |
| --- | --- | --- |
| `identity/identity` | 账号、组织、租户、成员、治理模型、邀约、认证接入、登录与当前租户选择；创建及身份变更不变量 | 明确的治理和认证契约、有效配置、可信时间、耐久能力 |
| `identity/authorization` | 资源与动作的授权建模、表达解释、适用范围、决定绑定、撤回与消费、当前准入及可追溯结果 | 可信身份资格、合法权限结果、实际操作参数、范围拥有者的依据及人工决定 |

两份[长期规格](../README.md)分别维护公开行为，不据此固定插件、服务、线程、数据表或进程数量。共享身份和结果引用同一公开定义，不在消费者复制同名类型。

identity 不依赖 Session、HITL、工具或模型的业务生命周期。authorization 消费相关能力的公开事实和契约，不依赖其私有实现，也不拥有资源类型的业务含义。身份与授权请求所用主体、对象和范围显式声明，不能采用没有说明的“当前身份”。

## 状态与共同完成

身份、成员关系、登录、授权表达及消费结果是业务事实；运行实例、订阅和连接是临时资源。通知帮助消费者重新读取，不代替唯一的持久事实。

下列后果须共同成立，具体事务、协调或提交协议由随包设计确定：

- 默认开通方案激活成功时，账号、个人组织和个人租户均成立。
- 默认团队方案创建成功时，组织、创建者租户与首位超级管理员均成立。
- 更换凭据成功时，新凭据成立，本账号全部旧登录失效。
- 默认团队方案调整成员或角色成功时，至少保留一位有效超级管理员。
- 邀约接受事实与对应关系结果一致。已经是有效成员时，返回无成员变更，不新建租户或改写角色。
- 批准、消费与原操作的允许范围一致，重复请求不能增加许可。

共同完成不要求所有参与者位于同一进程。回执丢失保留结果未知，调用方按操作契约认回或查询原结果，不能自动再执行。登录每次成功签发独立状态，其重试不能套用其他操作的去重规则。

普通进程或操作系统崩溃、断电后，已确认持久事实按系统耐久保证恢复。0.0.0 -> 0.1.0 不提供介质或整机物理损毁后的重新打开，具体阶段边界归[身份安全架构](../../../docs/architecture/security/identity-and-authorization.md#本阶段不提供的打开路径)。旧备份中的角色不授予重新开放权。

## 独立使用与 Cordis 装配

两个成员的公开能力独立于 Cordis。提供者将其按[IC 集成约定](../../../docs/architecture/cordis-integration-conventions.md)装配，负责依赖获取、资源拥有、绑定、替换及退出交接。Cordis 作用域不是租户隔离、事务、持久存储或远端身份凭证。

提供者撤除后，尚未完成的身份查询、判断、提交和通知都有明确收口责任。收到清理请求不等于原调用已经终局，通知失败不回滚已经成立的业务事实。精确撤除及接续协议由提供者设计和验证承接。

公共 SDK 与接入适配器通过[分层契约](../../../docs/architecture/layers-and-dependencies.md)访问公开能力。跨进程或节点传递声明的数据与可信依据，不传活的 Context、闭包或物理句柄充当身份契约。

## 后续技术义务

### T01 公开契约承接

identity 与 authorization 分别形成操作公开类型、结果和语义错误。接入拥有者形成可信材料、治理和认证扩展、配置接口。合法身份与时间点的纯值形状已经采用，不能从旧 core 签名迁入。本组操作的公开形状仍未定。

### T03 共同完成与提交关联

身份创建、邀约竞争、授权消费和实际资源提交必须兑现各自不变量。identity 负责自身事实，authorization 与原操作拥有者定义许可消费及资源提交关系；具体提供者及协调者须补原操作身份、提交查询和恢复协议，通知不能代替共同完成。

### T05 来源、秘密与缓存

接入、identity、authorization 及提供者分别形成传输认证、凭据派生、秘密保管、缓存有效性和跨进程来源验证。未知来源不授予允许，本设计未选择实现。

### T06 验证资源与尺度

实际成员承担 SPEC 的持久验证义务，系统集成拥有者形成真实组合、故障及性能验收资源。尚无可运行资源或尺度，本页不作通过声明。
