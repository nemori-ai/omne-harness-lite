# verification

<!-- documentation:placeholder -->

本目录承载本包的持续验证资源：模型、论证或证明。

## 允许的内容

<!-- documentation:placeholder -->

`models/` 下的形式模型，`proofs/` 下的论证或证明，以及说明文件。

## 边界

<!-- documentation:placeholder -->

每份资源说明所验证的性质、前提、运行命令、覆盖与限制。单次运行的原始输出留任务 tmp，不进本目录。

## 维护

<!-- documentation:placeholder -->

被验证的承诺变化时，同步模型、证明与本目录 `index.md`。

## 本包事实

<!-- documentation:placeholder -->

本目录尚无本包专有的可运行形式模型或证明，models/proofs 保持缺项；持续行为用例见[测试](../tests/README.md)。不得把目录存在或源码测试通过当成形式验证完成。适用的机制证明和目标介质证据继续按 SPEC 承担。
