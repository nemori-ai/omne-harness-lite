# 日历函数、全化与证明义务

本说明细化 [SPEC](../SPEC.md) 的计算、覆盖、版本及失败语义，不新增公开字段。公开形状以 [calendar-contract](../../calendar-contract/README.md) 为准。模型、源码映射和执行方法见 [verification](../verification/README.md)。

## 计算器与有状态领域

固定不可变事实版本、计算规则语义及查询后，日历计算是偏函数 `C_b: Query ⇀ Answer`。`b` 是这次计算的依据。供应、发布、健康与读取资格仍是有状态责任，不能因计算纯化而删除。

日历身份、事实版本、供应插件、计算语义版本、服务地址是五个不同维度。更换供应适配器不得改写已发布版本；可替换计算提供者必须先满足同一计算契约。当前实现静态调用计算函数，没有通用算法插件协议。函数的部分应用是固定 `b`，与“部分输入无答案”的偏函数含义不同。

远程契约传递可序列化输入、依据及结果，不传闭包、插件实例或 Cordis 对象。受信读取资格属于调用边界，不因携带版本引用而获得。

## 定义域和成功值

设 `K` 为逐日覆盖集合，`W` 为一周七种星期取值的完整分类表，`O` 为每日期最多一个覆盖项的映射。覆盖内先取 `O(d)`，没有覆盖项时取 `W(weekday(d))`。`d ∉ K` 时分类未定义，不能猜为普通工作日。

| 函数 | 成功的充分依据及边界 |
| --- | --- |
| 分类 | 目标日已覆盖，覆盖项优先于星期表 |
| 计数 | 闭区间每一天已覆盖，计两端，按工作日谓词求和 |
| 增减 | 起始日在覆盖内；非零偏移严格从下一日或上一日数，零偏移返回起始日，即使它不是工作日 |
| 下 N 个工作日 | 起始日在覆盖内，从其后逐日推进，必要路径均已覆盖 |
| 区间第 N 个工作日 | 正序找到目标时，已检查的前缀覆盖足够；无需再检查目标之后的日期。返回 `null` 或求最后一个时，需足以排除未查看日期的完整区间依据 |

日期域溢出、缺覆盖、非法输入与搜索限制沿 SPEC 和公开结果表达。`null` 是“有充分依据而不存在”的成功值，不是失败、未知或预算用尽的代号。

P1 分类唯一性。固定 `b` 时，`O` 的日期键唯一且 `W` 完整，两个分支互斥，因此覆盖内只有一个分类。

P2 扫描正确性。扫描状态维持“命中数等于已覆盖且已扫描前缀内的工作日数”。初始空前缀为零；每一步只加入一个已覆盖日期，按其分类增零或一，保持不变量。达到 N 时该日期正是第 N 个工作日；扫描完完整区间仍不足 N 才能返回 `null`。反向和最后位置算法需要各自的扫描方向证明，不能直接引用正向实例覆盖所有算法。

这是抽象推导。源码对日期库、范围边界、时区与异常的实现仍需符合性测试，并未由这段推导自动证明。

## 精确全化与有界求值

设原偏函数 `f: X ⇀ Y`，定义域为 `D`。精确全化为：

```text
f̂(x) = Ok(f(x))                 x ∈ D
      = Undefined(reason(x))     x ∉ D
```

`reason: X\D → E` 必须对每个域外输入有定义且在固定实现中单值。若契约允许同一输入返回多个合法错误，规范描述的是结果关系，不能宣称跨实现完整错误值相等。

资源有界求值是另一个函数：

```text
Eval: ValidInput × NaturalFuel → Ok(Y) ⊎ Undefined(E) ⊎ Limited
```

合法且有答案的输入可能因预算不足返回 `Limited`，因此 `Eval` 不是原偏函数的精确全化。领域无答案、操作未算完、外部提供者故障和权限拒绝分别表达。隐藏受保护对象存在性的 `not_found` 规则保持，不因诊断细化而泄露事实。

终止状态必须与活动状态分开：

```text
run(n, Finished(r)) = r
run(0, Active(s)) = Limited
run(n+1, Active(s)) =
  match step(s):
    Done(r)     → r
    Continue(t) → run(n, Active(t))
```

`step` 是终止、确定且无隐藏 I/O 的全函数，不随外层初始预算改变。无工作可做的已终止结果在零预算下仍可返回。公共 API 的正预算约束不因数学模型允许剩余预算为零而改变。

| 义务 | 证明前提与结论 |
| --- | --- |
| T1 有限终止 | `step` 每步终止，活动状态递归时自然数预算严格减一；对预算归纳可得有限返回 |
| T2 成功可靠 | 每步保持独立建立的扫描不变量，`Done(Ok(y))` 具备成功见证；归纳得到成功不伪造答案。预算递减本身不能证明结果正确 |
| T3 足量完成 | 原输入经过 k 次 `step` 可成功或确定无答案，则预算至少 k 可取得同一结果；`Finished` 的 k 为零 |
| T4 组合终止 | 有限层数的全函数组合，失败短路；统一预算，或有界个数的有限子预算。不允许无限重试、无界候选展开或隐藏递归 |

## 提供者替换与服务边界

P3 条件替换。两个提供者在相同语义、事实版本与有效输入下都满足 P1/P2，且日程后续纯流水线相同，成功答案可替换。错误优先级、限额及可用性可能不同，不能据此宣称所有观察等价。日期库、时区数据库与计算语义的实际一致是前提；只增加一个版本字段不构成证明。

读取环境、版本或授权产生观察；固定观察上的选择与计算才是纯函数。网络超时只表示观察未完成，不能推断远端未提交。`Promise<Result>` 形状不保证终止；同一事件循环的计时器不能打断同步死循环。宿主资源隔离、关闭排空、取消与实际 deadline 需要独立运行证据。
