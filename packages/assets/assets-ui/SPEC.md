# @omne-harness/assets-ui 行为规格

本文件拥有设置的界面模块在公开类型以外的必要行为。公开形状是 `src/index.ts` 导出的 `SettingsPanel` 与 `SettingsPanelProps`，导航见 [docs/public-api.md](docs/public-api.md)。

## 范围与依据

- 依据：[RFC-0015](../../../docs/rfcs/RFC-0015-access-dynamic-registration.md) 第 9 节「设置」（概念、操作与答复的全化表、设置读写面的契约、八条规定、读写面的结果与 `assets/v1` 的结果怎样对应），第 10 节「四部分界面」的「设置」一段。契约是 `@omne-harness/assets-protocol` 的 `assets/v1` 第一版：`list-settings`、`describe-setting`、`set-setting`、`clear-setting`。
- 采用范围：第一条纵线（卡 #1265）。读写的是行事租户这一层的管理视图；一次运行实际选入的设置不在这里。
- 能改的值只有权限项的挑选：给每一档一个单选，再点「设置」。普通项的值与秘密项的状态只读显示，提案没有规定它们的输入控件。三类项都能「清除」：清除不带值，与类型无关。
- 对提案的暂时偏离：样式用普通 CSS 文件，不引入 Tailwind 与 Radix；组件直接收协议客户端。由统筹会话记入差异表。

## 结果与不变量

<a id="au-1"></a>**AU-1 结果不知道就是不知道。** 「设置」「清除」答 `unknown` 或本地 `uncertain` 时不发新的一次写入。原样再送同一次：同一个 `operation`、同一个消息编号、同样的修订号与值（契约规定 3：这就是认回）。认回之前这一项显示「结果未知，正在确认」，控件不可用。认回仍说不出结果时停在「结果仍未知」，由人点「再确认一次」，再原样送一次。界面从不把未知写成成功或失败。

<a id="au-2"></a>**AU-2 写入带读到的修订号。** 「设置」「清除」的 `expectedRevision` 取这一项当前视图的 `revision`。答 `conflict` 时不写入，显示一句原因，并用 `describe-setting` 重读这一项。

<a id="au-3"></a>**AU-3 显示的是服务端的事实。** 「设置」「清除」成功只带新的修订号，所以成功之后用 `describe-setting` 重读这一项，按读到的视图重画。清除之后这一层不再有挑选，显示的生效值是外层来的那一个。界面不在本地推算生效值。

<a id="au-4"></a>**AU-4 读不出来不显示成未设置或默认值。** 列表或一项读失败时显示一句原因和「重试」，不画值。列表有一页答 `partial` 时整张表标明「列表不全」。

<a id="au-5"></a>**AU-5 每项写明说明、生效的值、来源、能不能改。** 不能改时写出原因：被上层锁定、这一层不能配这一项、上层已经主动禁止。权限项另写本层的挑选与上层的允许集合；生效值是被主动禁止或允许集合为空时，照实写出。

<a id="au-6"></a>**AU-6 错误各有一句人话，不吞掉。** 每种拒绝一句，显示在出事的那一处（整张表、那一项）。`denied` 写「没有权限，或登录已失效」；登录门归外壳。

## 全化表

两层状态。整张表一条轴；读完之后每一项两条独立的轴：读（已读、读中、读失败）与写（没有、提交中、成功、被拒、结果未知）。结果未知再分「确认中」（认回在途）与「仍未知」。每格写转到哪与发出的作用；「不变」是这一格的确定答复；「作废」是旧读取编号、旧操作编号的迟到答复，一律不变。

整张表。列：**未读**、**读中**、**已读**、**读失败**。

| 行  | 事件                                                                                        | 未读             | 读中                                              | 已读   | 读失败             |
| --- | ------------------------------------------------------------------------------------------- | ---------------- | ------------------------------------------------- | ------ | ------------------ |
| L1  | 挂上                                                                                        | 读中，列出第一页 | 不可达                                            | 不可达 | 不可达             |
| L2  | 人点「重试」                                                                                | 不可达           | 不可达                                            | 不可达 | 读中，从第一页重读 |
| L3  | 列出答 `succeeded`，有 `next`                                                               | 作废             | 收下这一页，按 `next` 读下一页                    | 作废   | 作废               |
| L4  | 列出答 `succeeded`，`next` 为空                                                             | 作废             | 收下这一页，已读；有一页是 `partial` 就标「不全」 | 作废   | 作废               |

一项。列：**闲** 已读且写已了结（没有、成功、被拒）；**交** 已读·提交中；**认** 已读·结果未知·确认中；**疑** 已读·结果未知·仍未知；**重** 读中（写已了结）；**败** 读失败（写已了结）。读中与写在途不同时出现：写只从「闲」开始，重读只在写了结之后发起。

## 所有权、失败与生命周期

`SettingsPanel` 每次挂上建一个驱动器（`src/model/settings-driver.ts`）。驱动器持有状态，替状态机跑每个作用；卸下之后迟到的答复不再改变任何东西。它不持有登录、不认识宿主与身份；租户读不懂时组件直接显示一句话，不发任何调用。客户端只在发出之前抛错（契约写不出的消息体），驱动器把它当作本地 `unavailable`。一页最多 100 项，读到 `next` 为空为止。
