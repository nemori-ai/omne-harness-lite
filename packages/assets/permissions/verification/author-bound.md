# 作者权限上界的单调性

状态为源码级论证及公开边界验证，不是机器证明。动态注册、原动作资格与并发当前性沿其拥有者的模型，本论证不替代这些前提。

设当前权限定义的值全集为 V，其他已知约束的交集为 E。已成功解析的精确 Agent 定义对当前关口声明 B 时，投影取 B；没有匹配声明时取 V。若定义不可读或 B 包含 V 以外的值，投影为 unavailable，而不是 V。

消费通过 PermissionConstraint 的 bound 进入 evaluatePermission。有效集合为 E∩B，因此 E∩B⊆E。B 为空则交集为空，任何租户 pick 都不能产生允许。没有作者限制时 E∩V=E，不覆盖其他治理。来源不可用时必要约束不齐，求值不能产生有效允许；已知主动禁止仍依既有求值规则优先成立。

精确性前提是原动作拥有者认回 Adoption，AgentAdoptions.resolve 按该完整身份读取。应用投影不按名称回退，不自动升级发布。来源和修订保留该 Adoption，并绑定当前权限定义。未来生产装配仍须证明调用方使用的是原动作的采用及同次当前材料。

公开行为守护如下。

- Agent 契约的 permission-bounds.spec.ts 守护两个解析入口、唯一性、空集及冻结。
- 应用的 agent-permission-bound.spec.ts 通过真实采用服务守护空集禁止、无声明、不同关口、未知值和精确版本缺失。
- 原权限关系 oracle 的外界和必要来源缺失分区守护纯集合求值。该既有证据不自动证明新增来源适配器。
