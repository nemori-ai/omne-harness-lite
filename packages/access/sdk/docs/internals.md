# 客户端 SDK 内部设计

<!-- documentation:placeholder -->

本页预留完整 Harness 的客户端统一入口及客户端拥有的连接和句柄的内部结构说明。依据为[上层责任](../../../../docs/architecture/layers-and-dependencies.md)与[成员文档规范](../../../../docs/member-documentation.md)。当前没有成员源码或已接受的内部机制。

## 设计边界

SDK 不依赖服务端私有实现或 Cordis 装配树。内部设计须兑现[成员行为规格](../SPEC.md)，不得从目录或封存实现推断对外保证。

## 后续技术问题

技术拥有者先确认首批操作、客户端环境、连接与订阅生命周期、缓存同步、关闭及未知结果，再说明模块分工、状态和资源拥有者、依赖方向、故障处置与换代路径。实际协调者和客户端应用共同核对交接点。单次候选留任务证据，现行决定写回本成员唯一正文。

## 验证与维护

成员维护者把设计决定连接到实际测试、模型或组合验证，并列明前提与未覆盖。文档维护者核对来源、链接及登记。长期个人负责人尚未具名；目前没有可执行的内部设计验证。
