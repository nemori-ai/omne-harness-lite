# 客户端 SDK

与 [README.md](README.md) 是同一成员、同一份承诺。本页是摘要，导出清单和用法样例在 README.md。

SDK 提供会话客户端、治理客户端和基于 `fetch` 的 HTTP 传输适配。客户端再送和缓存规则在 [SPEC.md](SPEC.md)。结果含义在公开契约。路径、方法、状态码在承载绑定页。信任核验失败时不发送凭据或登录证明。

- 传输适配只接受 `127.0.0.1` 或 `localhost` 上的 `http:` 地址，不跟随重定向。
- 传输适配证明没有字节发出时，客户端自动再送一次。字节可能已经发出时不再送。
- 调用者只收到 `messageId` 相同的响应。没有可信答复时得到 `uncertain`。
- 任何错误文本都不含登录证明和凭据。
