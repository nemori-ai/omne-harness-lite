# @omne-harness/client-assembly 行为规格

本文件拥有本包在公开类型以外的必要行为。公开形状归 `src/` 的公开定义，公开定义的导航归 [docs/public-api.md](docs/public-api.md)。

## 范围与依据

依据是 [RFC-0015](../../../docs/rfcs/RFC-0015-access-dynamic-registration.md#6-客户端) 第 6 节「客户端装配」与第 13 节「客户端：树上的一个协议客户端」，交付卡 #1249（已定事项 21 到 24）。本包只依赖公开契约、SDK 的客户端核心与 Cordis，不依赖服务端接入。登录怎样发生不在本包：连接只转出 `LoginStateSource` 给的状态。

## 结果与不变量

### 连接

`connectionPlugin(options)` 装上服务 `connection`（类 `ConnectionService`）。它在自己的作用域里一直跟着可用性：

| 事件 | 连接做什么 |
| --- | --- |
| 装上 | 立刻订阅 `access/v1` 的 `availability` |
| 收到快照 | 视图换成快照 |
| 收到变化，修订号是视图的修订号加一 | 应用这一变化 |
| 收到变化，修订号对不上 | 不应用；关掉这次订阅，立刻重新订阅，等新快照 |
| 观察结束（断了、被拒、没发出、不确定） | 等退避给的时长后重新订阅；视图不动，协议客户端不收回 |
| 卸载 | 中止订阅，等它收场 |

退避策略是一个对象 `{ delayMs(attempt) }`。缺省值 `defaultBackoff`：第 n 次（从 0 起）等 `min(200 × 2^n, 10000)` 毫秒。一次订阅里收到过帧，次数从头算。

每次视图变了，连接对每个开放却没有协议客户端登记的协议记一条诊断 `protocol-client-missing`（同一个协议在它保持开放期间只记一次），然后通知订阅者。

### 协议客户端

`defineProtocolClient(protocol)` 的插件依赖 `connection`，登记自己的键，跟着视图：

| 事件 | 服务未提供 | 服务已提供 |
| --- | --- | --- |
| 视图说这个协议开放了 | 提供服务 `protocol:<名字>/v<主版本>`，值是这份协议的 `ClientOf`；依赖它的插件加载 | 不变 |
| 视图说这个协议开放了，树上没装它的协议客户端 | 不变；连接记一条诊断 | 不可达 |
| 视图说这个协议撤下了 | 不变 | 先标记已收回，再注销服务：服务立刻不可见，依赖它的插件随后卸载；进行中的观察结束 |
| 标记之后调用方法（含外部留着的旧句柄） | 不可达 | 本地答 `unavailable`；观察立刻以 `unavailable` 结束；不经过传输 |
| 在途调用遇到收回 | 不可达 | 本地结束：收回的标记并进这次调用的中止信号。字节没发出的答 `unavailable`，标记之后不再送；可能发出的答 `uncertain`，不等传输的答复 |
| 在途调用遇到连接断开 | 不可达 | 结果由传输给出：没发出的再送一次，仍没发出答 `unavailable`；可能发出的答 `uncertain`，不重发 |
| 连接闪断 | 不变 | 服务不收回。调用：连接没有接上时由传输答「没发出」，得到 `unavailable`；连得上时照常发出，由服务端回答。观察随传输结束，结束原因由传输给出，不自动重新打开 |
| 重连拿到新快照 | 按差异走第一行 | 按差异走第三行，或不变 |
| 换登录或换租户 | 不变 | 不变 |

插件卸载时注销服务，退出登记。

## 所有权、失败与生命周期

- 视图只归连接；协议客户端只读它。连接的作用域卸载时中止订阅并等它收场。
- 协议客户端的服务由它自己的作用域提供；注销返回的 Promise 在依赖它的插件卸载后完成。
- 收回不撤回任何外部效果：服务端已经做了的事不因为客户端收回而撤销。收回时在途的调用在本地结束，可能发出的答 `uncertain`，调用方按原操作认回。
