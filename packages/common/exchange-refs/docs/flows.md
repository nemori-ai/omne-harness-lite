# 关键流程

本包是 `module` 变体的纯类型包，只有三个类型，没有运行时代码。没有参与者之间的调用时序、数据流、状态变化、取消、恢复或资源释放。本文件写明不适用的理由，不编造流程，并在 `documentation.json` 里记为 `not-applicable`。

## 流程

不适用。值在各域之间的传递由铸造方和接收方的契约描述，例如 Agent 把 `ConsumerRef` 交给 Model 的 `admit`。本包不参与传递，也不核验值。使用示例见 [context.md](context.md)，含义与规则见 [SPEC.md](../SPEC.md)。

## 失败与生命周期

不适用。本包没有运行时代码，所以没有失败分支。值不合格时由接收域的判定拒绝，失败词汇归那个域。本包不创建需要释放的资源，也没有生命周期。
