# tests

本目录承载本包适用的持续测试。测试种类的责任与边界见仓库[包级测试责任与边界](../../../../docs/verification.md#包级测试责任与边界)。

## 允许的内容

`*.spec.ts` 等测试文件、测试辅助代码，以及 `fixtures/` 下的固定输入。

## 边界

说明每类测试用到的真实依赖与替身。测试通过不代替规格或验收。

## 维护

公开行为或 `SPEC.md` 条款变化时，同步对应测试与本目录 `index.md`。

## 本包事实

本目录有 `shapes.spec-d.ts` 与 `public-entry.spec.ts`，都从包名导入公开入口，不用替身，也没有真实外部依赖。`shapes.spec-d.ts` 是类型测试，在 `test:fast` 和 `typecheck` 中运行。它检查三个类型各有四个必需的只读 `string` 成员，缺成员、写成员或成员不是 `string` 时类型检查失败。`public-entry.spec.ts` 检查根入口没有运行时导出、`dependencies` 为空，并且只有 `.` 入口。集成测试与端到端测试不适用，本包没有存储、服务或用户旅程。负责人是本成员的维护者。当前没有已知缺口。
