# 对象模型

本文件描述本包内部对象的职责、身份、状态、关联、组合、继承与生命周期。本包是值包，只有两个类型和四个纯函数，没有 class、继承或持久状态，所以下面写实际的值模型和不适用项。

## 对象与关系

本包只有两种值，各是一个联合类型。

```text
Outcome<T, F> = { ok: T } | { failure: F }      带值成功，或失败
Ack<F>        = { ok: true } | { failure: F }   无值确认，或失败
```

两种结果不合并。`Outcome` 的成功分支携带调用方的载荷 `T`。`Ack` 的成功分支只表示「已经完成」，`ok` 固定为 `true`，不携带载荷。如果合并成一个信封，无值确认就要选一个占位载荷，调用方无法从类型上看出这个操作不返回值。分开以后，类型直接告诉读者这个操作有没有值。

`F` 归调用方。本包不规定共同的失败词汇，不是所有能力共用的统一信封。每个能力契约自己规定 `F` 的字面量，以及失败代表什么。

构造函数与守卫对应如下。

| 函数 | 返回 | 说明 |
| --- | --- | --- |
| `succeed(value)` | `Outcome<T, never>` | 带值成功。失败词汇为 `never`，因为它不会失败 |
| `ack()` | `Ack<F>` | 无值确认。`F` 默认为 `never`，调用方可显式给出 |
| `fail(failure)` | `Outcome<never, F>` | 失败。成功载荷为 `never` |
| `isSuccess(result)` | 类型守卫 | 对象带有 `ok` 时收窄为 `{ ok: T } | { ok: true }` |

值没有身份。两个结果相等当且仅当结构相等。值之间没有关联、组合或继承。

## 生命周期

值由调用方用构造函数创建，之后只读使用，没有变化和销毁责任。本包不持有任何已创建的结果，不缓存，不注册。结果对象随调用方的引用被回收。
