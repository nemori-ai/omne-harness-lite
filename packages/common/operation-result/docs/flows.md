# 关键流程

本包是 `module` 变体的纯值包，只有两个类型和四个纯函数。没有参与者之间的调用时序、数据流、状态变化、取消、恢复或资源释放。本文件写明不适用的理由，不编造流程，并在 `documentation.json` 里记为 `not-applicable`。

## 流程

不适用。调用方用构造函数产生结果值，再用 `isSuccess` 或检查键来读它。这是单次同步的函数调用，没有多方协作。使用示例见 [context.md](context.md)，形状与规则见 [SPEC.md](../SPEC.md)。以后如果本包加入有时序的行为，例如编码或重试，才建立流程。

## 失败与生命周期

不适用。失败是 `fail` 返回的值，不是流程分支。本包不创建需要释放的资源，也没有生命周期。失败词汇与处置归各调用方的契约。
