module 变体草稿。行为归 Issue #242。

## 职责与状态

本成员是共同的 JSON 文本读取器。已接受的契约在架构页「公共 JSON 文本读取」。叶子名 `json-text` 在本分支确定。#242 当时没有裁定名字，并禁止从旧目录猜测。

今天已经有的是 RFC-0003 的包文件、module 变体，以及一个空的公开入口。`readJsonBytes`、`readJsonText`、预算和失败结果还没有实现，归 #242。本包不导入 Cordis、身份、时间，也不导入两棵 legacy 树。

## 使用

现在没有可调用的示例。`src/index.ts` 不导出值。依赖为空。本包没有 Cordis 入口。

`files` 只发布 `dist`。`build` 先删除 `dist` 再编译。`tsconfig.build.json` 打开 `erasableSyntaxOnly`。源码条件没有写入导出，因为条件名尚未决定。

## 契约

行为拥有者是 `packages/common/README.md` 指向的架构节。本页不复制签名和失败种类。#242 实现该契约。读取成功不表示对象存在，也不表示调用方获得授权。

## 设计

内部模块还没有。读取器保持纯函数。字段 codec 留在形状拥有者，只在读取成功之后运行。

## 配置与运行

`limits` 没有默认值。本包不读环境变量，也不创建时钟、数据库或进程。

## 验证

适用的测试是单元测试、从公开入口做的契约测试，以及独立消费检查。集成测试和端到端旅程不适用。本包没有存储、服务或用户旅程。

这份草稿里没有测试文件。没有可观察结果的断言不算上述测试。#242 在实现契约时补上测试。届时在本目录运行 `pnpm test` 和 `pnpm build`。

## 维护

后续的配置读取、协议解码和持久记录读取是消费者。它们不在本包里实现。公开读取结果变化时，#242 和这些消费者一起改。
