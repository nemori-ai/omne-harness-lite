# tests

本目录承载本包适用的持续测试。测试种类的责任与边界见仓库[包级测试责任与边界](../../../../docs/verification.md#包级测试责任与边界)。

## 允许的内容

`*.spec.ts` 等测试文件、测试辅助代码，以及 `fixtures/` 下的固定输入。

## 边界

说明每类测试用到的真实依赖与替身。测试通过不代替规格或验收。

## 维护

公开行为或 `SPEC.md` 条款变化时，同步对应测试与本目录 `index.md`。

## 本包事实

本目录有四个测试文件：`modality.spec.ts`、`media-type.spec.ts`、`modality-types.spec-d.ts` 和 `public-entry.spec.ts`。前两个是单元与契约测试，第三个是类型测试，第四个检查公开入口的形状。测试从包名导入公开入口，不用替身，也没有真实外部依赖。集成测试与端到端测试不适用，本包没有存储、服务或用户旅程。负责人是本成员的维护者。当前没有已知缺口。
