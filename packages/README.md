# 产品包

**当前为空。**

这里放产品的可复用包，按 `packages/<能力族>/<职责包>/` 两层组织：第一层只组织相关能力，
**不是 workspace 成员**；第二层才拥有 `package.json`、`src`、依赖、公开入口和测试。
布局规则见[源码布局](../docs/workspace.md)。

## 为什么是空的

2026-09-20 回退到骨架。此前这里有一批从上游 fork 来的源码基线，以及每个包一份
「目标设计」文档——那些文档自己就写着「目标提供者尚未实现」，而它们兑现的那套契约
随旧设计链一并退役了。

[设计工作区](../.meta_harness/AGENTS.md)重构之后，正式设计**停在产品设计阶段**：
系统架构与规格设计尚未开始，更没有据以交付的实现。
**留着一批没有有效规格依据的代码和设计，只会让后来者把它们当成已经定下来的东西。**

原件都在 Git 历史里：

```sh
git log --oneline -- packages/session/session
git show <sha>:packages/session/session/design.md
```

## 什么时候会有内容

等 `.meta_harness/design/` 走完架构与规格设计、产出可实施的契约之后，实现从那里的
规格出发建立。**包的划分规则也在那时重新确定**——不沿用随旧链退役的那份包组织决定。
