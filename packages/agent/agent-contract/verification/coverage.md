# Agent 产品能力与设计覆盖

本页追踪[产品页](../../../../.meta_harness/design/product/agent-progression/design.md)的十项能力 CAP-AG01 至 CAP-AG10 和八条旅程 J-AG01 至 J-AG08 在设计中的去向。每行连接产品规则、旅程、领域对象、公开操作、Loop 节点、异常路径和验收场景。

本页追踪的设计已由[技术接受与产品采用决定](https://github.com/nemori-ai/omne-harness-lite/issues/384#issuecomment-6258475204)接受。本页不表示运行已验证。契约包的实现状态见下文“阶段与接受状态”。本页不复制产品规则，产品能力的定义只归产品页。
