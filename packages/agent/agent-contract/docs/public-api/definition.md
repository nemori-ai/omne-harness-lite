# AgentDefinition 与能力选择规格

状态为候选，待用户确认。[成员入口](../../SPEC.md)维护共同身份、持久和验证边界。本页拥有定义专有含义，装配清单和实际采用切换仍由 assembly 维护。

## 定义自身的行为

AgentDefinition 的身份是该资产类别与 name，不由模型、人格、语气、角色称呼或依赖内容组成。定义通过能力标识声明组合，不捕获具体提供者对象或运行句柄。

定义声明 master 或 non-master。master 只能 official 提供，三层自定义限于 non-master；official 定义不可由同标识自定义替换。定义类型不因为作用域、实例化方式或本次派发改变。non-master 的可用能力不由类型一刀切削减，具体限制须有具名规则。

master 类目取产品提供的 general-purpose、coding、office、research 或 personal-life。产品出厂增加类目；非官方来源不自创类目。类目与使用场景的映射、创建与派发规则由调用方所在的领域消费，不在此建立另一份规则。

默认模型、人格与语气、上下文策略、模型首内容和静默时限等取合法声明与共同设置求值。具体声明形状及公开校验未定，不补数值或私有字段。实例化和派发资格消费共同权限求值。

定义可引用具有已定组合关系的能力。Connector 的完整业务处于搁置范围，定义能引用 Connector 不表示 Connector 已经交付。组合关系不自动使所有定义引用都成为 Loop 的直接生命周期依赖。

## 必需身份与继承

Skill、Tool 和 MCP 的选入按下面的行为顺序成立。

1. 保留执行类型要求的必需身份。执行类型由调用方在采用时给出。
2. 加入生效定义显式需要的必需身份。
3. 自动继承开启时，加入开放来源提供的额外身份。
4. 只从第三项扣除定义继承排除和调用方允许移除的可选项。
5. 相同身份去重。任何来路必需，该身份即为必需。
6. 每个所选身份交给共同资产治理，在完整合法作用域内解析当前实现。

自动继承默认 false。开放到组织只选组织额外身份；开放到租户包含租户与组织；开放到工作区包含所选工作区、租户与组织。未选工作区时该来源为空，不造默认工作区，也不跨租户找材料。

范围决定额外身份的来源，不限制已选身份同标识实现的解析范围。组织中有 Tool A，租户中有合法同标识实现时，开放到组织仍可绑定租户 A；租户额外 Tool B 不由此自动选入。上级 immutable 锁定继续有效，工作区不能设置锁或突破锁。

继承排除按类别与 name。Skill A 与 Tool A 分别判断，排除实现版本不能代替排除能力身份。MCP 排除针对接入点，派生动作按 MCP 契约。排除不得移除前两项必需身份。

继承声明随生效定义完整采用，不属于组织或租户逐项配值的偏好设置。更具体来源替换可替换的自定义定义后，只使用新定义自己的开关、范围与排除。未声明仍关闭，不继承旧开关。

这些规则仅适用 Skill、Tool 和 MCP，不为其他 AgentDefinition、Slash Command、Plugin 或 Loop Extension 开放统一自动继承。

## 调用方可选声明与已知身份

调用方的可选能力移除声明须持久保留，并参加后续装配求值。重新添加当前声明允许的可选项只撤销对应移除意图，不新增越过定义来源范围的入口。必需项不能移除；新定义将原可选项改为必需时，必需来路优先。

合法纳入后，身份加入调用方的已知能力记录。后续实例、执行和装配不删除该身份。当前可用集合可缩小，身份记忆不冻结正文、schema 或实现。

移除某个实现来源时先解析其他合法同标识候选，仍有候选则更新采用绑定；没有候选才转不可用。定义排除或调用方的移除针对身份，不能用另一来源绕过。失去使用资格时仅保留最近合法身份及说明不能使用所需信息，不读取新内容。

当前不可用应答由 Tool 的逻辑调用契约承接。它不要求启动真实工具或执行环境，也不虚构真实运行用量。尚未合法纳入的身份不能为了返回替换件而凭空创建。

## 版本采用与实际变化

调用方固定定义身份。每个新的 execution 在采用时求值：没有写明版本的身份，采用当时的合法胜出者；写明版本的身份固定为该版本。合法胜出者是多层来源求值完成资格筛选和层序选择后，该身份的结果，规则见[装配与变更](../../../../../docs/architecture/runtime/assembly-and-change.md#定义清单与实例)。内容没有变化且旧清单仍有效时可复用。普通恢复使用当前已生效清单，不静默升级定义或工作区文件。

显式 reload 可更新依赖、继承声明、Loop 和 extensions，通过安全交接采用同身份新版本。调用方固定的执行类型和必需身份不变。定义身份、租户身份或调用方关联身份的变更不是合法 reload。

以下变化由拥有者分别处理。

| 变化 | 本成员约束 | 不得推断 |
| --- | --- | --- |
| AgentDefinition 版本、捕获 Loop 或 extension 结构 | 新候选校验并交接实例，保护原工作 | 改写原清单或原请求 |
| 稳定入口内的 Tool、Skill、MCP 数据与实现 | 合法更新当前采用，逐使用固定 | 自动更换执行挂接或重建全部 Loop |
| 模型、权限、模式、Context | 沿各自生效点消费 | 整段 Agent 实例冻结取值 |
| 工作区文件或 Git 改动 | 实际装配或显式 reload 后采用 | 文件写入即已生效 |
| 下游工具依赖消失 | 该能力不可用或执行失联按实际影响处理 | 整个系统或 Loop 必须重启 |

装配从未取得必需身份的合法定义，或自身必需入口无法建立时明确失败。已有合法定义但实际实现不可用时可以保留位置，必需绑定不承诺每次执行成功。必需 Skill 也不因此每次全文注入。

### 采用解析与交接

AgentAdoptions 有两个操作。resolve 把精确的 Adoption 解析为定义、求值器和扩展声明。handover 在显式 reload 时证明原 execution 的接续可以交给目标采用。类型形状见[公开接口页](README.md#托管协调与运行实例)，handover 的行为见 SPEC 的“[采用交接](../../SPEC.md#采用交接)”。下面两张表写这两个操作的要素。

| 操作 | 输入要点 | 成功返回 | 错误与未知 |
| --- | --- | --- | --- |
| AgentAdoptions.resolve | Access、精确的 Adoption（owner、name、revision、digest） | 定义、求值器、扩展声明 | denied；invalid（Adoption 不合法，或不是 AgentDefinition 的采用）；unavailable（来源不可读，或采用的 schema 没有可用的求值器）。不取最新版本。合法定义的某项能力实现暂不可用，不是 resolve 的失败，按实现不可用的规则保留位置 |
| AgentAdoptions.handover | Access、源采用、目标采用、完整的 ExecutionSnapshot、原 continuation | 转换后的 continuation 与证明 | denied；invalid（快照与原 continuation 不一致，或定义身份、执行类型、必需身份发生变化）；unsupported（目标不能解释活动经过的原采用）；unavailable（原解释器或材料不可用，保留原精确解释器收束，不自动重判） |

| 操作 | 授权 | 幂等身份 | 并发与竞争 | 事件 | 生命周期 |
| --- | --- | --- | --- | --- | --- |
| resolve | 租户核对。读取该采用所在作用域的资格由适配器核验 | 没有操作身份。同一精确 Adoption 得到同一结果，解析缓存可复用 | 只读，不加锁，不与其他操作排序 | 无 | 值。execution 只保存 Adoption 引用。解析缓存可丢弃重建。换代只影响尚未开始的经过 |
| handover | 租户核对。快照由调用方经 load 取得，读取资格已在 load 核验。handover 不授予推进权 | 没有操作身份。execution、revision、源采用、目标采用和原 continuation 的摘要相同，得到相同的证明 | 不读取活体 execution。并发的 handover 互不影响。唯一的裁定点是 attach 的条件提交，revision 变化时 attach 返回 changed | 无。reload 的效果由 attach 提交的事件体现 | 证明绑定 revision，revision 变化即失效，不持久保存。新采用只影响尚未开始的经过 |

handover 本身不返回 changed。调用方在 attach 返回 changed 之后，用 Journal.load 重读快照，再重新调用 handover，不重试旧证明。

## 交接结果与验证义务

本成员向 assembly 提供可解释的专有声明、必需与可选来路及冲突原因。assembly 提供合法采用依据；候选失败不能让本成员使用混合构成继续推进。运行数据、实现和直接结构绑定分别记录，不持久化内存句柄。

持续验证至少包括下面的反例。

| 场景 | 必须成立 |
| --- | --- |
| 关闭继承，定义显式 Tool A | A 仍是必需，不能被排除 |
| 组织范围继承，租户新增 Tool B | B 不自动选入；合法同标识 A 实现仍可解析 |
| 替换自定义定义，新定义不写继承 | 继承关闭，不混入旧开关 |
| 调用方移除可选 A，后续重装配 | 移除持续有效；新定义显式要求 A 时按必需绑定 |
| 禁用已知 Skill，之后开始新的 execution 或建立新的执行挂接 | 身份保留，不能读取被撤权的新正文 |
| 工具暂不可用但合法定义存在 | 不以可执行成功要求取代必需身份，按不可用应答承接 |
| official 或 immutable 覆盖冲突 | 不采用非法定义，也不发布半份新构成 |

定义校验的公开入口是 SPEC“声明判断”的 `judgeAgentDefinition`。采用解析与交接的形状见公开接口页的 AgentAdoptions。动态注册与来源版本机制留后续设计。共同组合、持有和权限规格仍从原拥有者消费，不由本页重写其上界。
