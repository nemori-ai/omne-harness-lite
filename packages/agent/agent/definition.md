# AgentDefinition 与能力选择规格

状态为候选，待用户确认。[成员入口](SPEC.md)维护共同身份、持久和验证边界。本页拥有定义专有含义，装配清单和实际采用切换仍由 assembly 维护。

## 定义自身的行为

AgentDefinition 的身份是该资产类别与 name，不由模型、人格、语气、角色称呼或依赖内容组成。定义通过能力标识声明组合，不捕获具体提供者对象或运行句柄。

定义声明 master 或 non-master。master 只能 official 提供，三层自定义限于 non-master；official 定义不可由同标识自定义替换。定义类型不因为作用域、实例化方式或本次派发改变。non-master 的可用能力不由类型一刀切削减，具体限制须有具名规则。

master 类目取产品提供的 general-purpose、coding、office、research 或 personal-life。产品出厂增加类目；非官方来源不自创类目。会话类型映射、创建与派发规则由相应领域消费，不在此建立另一份会话规则。

默认模型、人格与语气、上下文策略、模型首内容和静默时限等取合法声明与共同设置求值。具体声明形状及公开校验未定，不补数值或私有字段。实例化和派发资格消费共同权限求值。

定义可引用具有已定组合关系的能力。Connector 的完整业务处于搁置范围，不能从旧八类列表承诺本批已交付 Connector。组合关系不自动使所有定义引用都成为 Loop 的直接生命周期依赖。

## 必需身份与继承

Skill、Tool 和 MCP 的选入按下面的行为顺序成立。

1. 保留会话执行类型要求的必需身份。
2. 加入生效定义显式需要的必需身份。
3. 自动继承开启时，加入开放来源提供的额外身份。
4. 只从第三项扣除定义继承排除和本会话允许移除的可选项。
5. 相同身份去重。任何来路必需，该身份即为必需。
6. 每个所选身份交给共同资产治理，在完整合法作用域内解析当前实现。

自动继承默认 false。开放到组织只选组织额外身份；开放到租户包含租户与组织；开放到工作区包含所选工作区、租户与组织。未选工作区时该来源为空，不造默认工作区，也不跨租户找材料。

范围决定额外身份的来源，不限制已选身份同标识实现的解析范围。组织中有 Tool A，租户中有合法同标识实现时，开放到组织仍可绑定租户 A；租户额外 Tool B 不由此自动选入。上级 immutable 锁定继续有效，工作区不能设置锁或突破锁。

继承排除按类别与 name。Skill A 与 Tool A 分别判断，排除实现版本不能代替排除能力身份。MCP 排除针对接入点，派生动作按 MCP 契约。排除不得移除前两项必需身份。

继承声明随生效定义完整采用，不属于组织或租户逐项配值的偏好设置。更具体来源替换可替换的自定义定义后，只使用新定义自己的开关、范围与排除。未声明仍关闭，不继承旧开关。

这些规则仅适用 Skill、Tool 和 MCP，不为其他 AgentDefinition、Slash Command、Plugin 或 Loop Extension 开放统一自动继承。

## 会话可选声明与已知身份

会话的可选能力移除声明须持久保留，并参加后续装配求值。重新添加当前声明允许的可选项只撤销对应移除意图，不新增越过定义来源范围的入口。必需项不能移除；新定义将原可选项改为必需时，必需来路优先。

合法纳入后，身份加入 Session 的已知能力记录。后续实例、Run 和装配不删除该身份。当前可用集合可缩小，身份记忆不冻结正文、schema 或实现。

移除某个实现来源时先解析其他合法同标识候选，仍有候选则更新采用绑定；没有候选才转不可用。定义排除或会话移除针对身份，不能用另一来源绕过。失去使用资格时仅保留最近合法身份及说明不能使用所需信息，不读取新内容。

当前不可用应答由 Tool 的逻辑调用契约承接。它不要求启动真实工具或执行环境，也不虚构真实运行用量。尚未合法纳入的身份不能为了返回替换件而凭空创建。

## 版本采用与实际变化

会话定义身份固定。新 Run 从该身份取得最新合法发布内容；内容没有变化且旧清单仍有效时可复用。普通恢复使用当前已生效清单，不静默升级定义或工作区文件。

显式 reload 可更新依赖、继承声明、Loop 和 extensions，通过安全交接采用同身份新版本。会话固定执行类型和必需身份不变。定义 identity、Session 与租户身份变更不是合法 reload。

以下变化由拥有者分别处理。

| 变化 | 本成员约束 | 不得推断 |
| --- | --- | --- |
| AgentDefinition 版本、捕获 Loop 或 extension 结构 | 新候选校验并交接实例，保护原工作 | 改写原清单或原请求 |
| 稳定入口内的 Tool、Skill、MCP 数据与实现 | 合法更新当前采用，逐使用固定 | 自动更换 attempt 或重建全部 Loop |
| 模型、权限、模式、Context | 沿各自生效点消费 | 整段 Agent 实例冻结取值 |
| 工作区文件或 Git 改动 | 实际装配或显式 reload 后采用 | 文件写入即已生效 |
| 下游工具依赖消失 | 该能力不可用或执行失联按实际影响处理 | 整个系统或 Loop 必须重启 |

装配从未取得必需身份的合法定义，或自身必需入口无法建立时明确失败。已有合法定义但实际实现不可用时可以保留位置，必需绑定不承诺每次执行成功。必需 Skill 也不因此每次全文注入。

## 交接结果与验证义务

本成员向 assembly 提供可解释的专有声明、必需与可选来路及冲突原因。assembly 提供合法采用依据；候选失败不能让本成员使用混合构成继续推进。运行数据、实现和直接结构绑定分别记录，不持久化内存句柄。

持续验证至少包括下面的反例。

| 场景 | 必须成立 |
| --- | --- |
| 关闭继承，定义显式 Tool A | A 仍是必需，不能被排除 |
| 组织范围继承，租户新增 Tool B | B 不自动选入；合法同标识 A 实现仍可解析 |
| 替换自定义定义，新定义不写继承 | 继承关闭，不混入旧开关 |
| 会话移除可选 A，后续重装配 | 移除持续有效；新定义显式要求 A 时按必需绑定 |
| 禁用已知 Skill，之后创建新 attempt | 身份保留，不能读取被撤权的新正文 |
| 工具暂不可用但合法定义存在 | 不以可执行成功要求取代必需身份，按不可用应答承接 |
| official 或 immutable 覆盖冲突 | 不采用非法定义，也不发布半份新构成 |

公开类型和定义校验接口、动态注册与来源版本机制留后续设计。共同组合、持有和权限规格仍从原拥有者消费，不由本页重写其上界。


## 旅程与持续验证

本页承接 [J-AG01](../../../.meta_harness/design/product/agent-progression/design.md#j-ag01)、[J-AG07](../../../.meta_harness/design/product/agent-progression/design.md#j-ag07) 与 CAP-AG01、CAP-AG02，协作见 [F-AG01](docs/key-flows.md#f-ag01)、[F-AG07](docs/key-flows.md#f-ag07)。原选择反例继续保留，另验证以下贯通结果。

| 场景 | 可观察判据 |
| --- | --- |
| 初次、reload、后续装配分别缺必需合法定义 | 均拒绝该候选；只保留仍合法的旧采用，不发布混合构成 |
| 新 Run、普通恢复和显式 reload 读取同标识不同版本 | 新 Run 可采用合法发布版本，普通恢复不升级；合法 reload 经交接采用，标识不变 |
| 用户只选模型、模式或刷新稳定入口内数据 | 不因此切换 AgentDefinition 或新建 attempt，已发请求内容不改 |
| 合法候选交接时有原 Model、Tool 和扩展卡片 | 撤旧推进权后新实例认回原 Run、原调用与原语义；未发动作核当前参数和绑定 |
| 取消先成立后候选就绪，或旧候选迟到 | 不恢复已取消推进，不覆盖更新选择 |
| 已知能力撤权后恢复，再度合法可用 | 身份持续可解释，撤权期间无新内容读取，重新可用仍核当前选择与依赖 |

公开校验、版本读取和采用提交协议仍由定义、assets、assembly 与 Session 拥有者对齐。本文不把合法版本选择解释为任意在线升级，也不据文档场景宣称实现通过。
