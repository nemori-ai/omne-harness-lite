# Agent 定义与工作推进组的工程关系

本页在正式维护位置保存待审技术设计。领域分解已评审不等于成员技术接受、阶段选择或实现支持。具名目录只有文档，公开形状和实际验证仍待设计及补证。


## 成员分解与邻接协作

定义解释向 assembly 交专有声明；Session 供给原工作与当前资格；推进协调者向 Context、Model、Tool 和 HITL 请求能力并认回原位置。单成员内部流程由成员拥有，跨组资格和事实交接分别由原责任方维护。

本组不维护第二份状态机、错误集合或精确承接协议。完整机制见[成员内部设计](../agent/docs/internals.md)，责任与事实归属见[领域角色](../../../docs/domains/agent-progression/architecture.md)。
