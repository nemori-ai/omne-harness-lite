# verification/models

本目录承载本包的形式模型，例如 TLA+、Alloy 或 SMT 模型。

## 允许的内容

模型源文件、配置与说明。

## 边界

说明模型对应的 `SPEC.md` 条款、抽象前提与未覆盖的部分。模型通过不等于实现符合。

## 维护

承诺或实现结构变化时，复核模型的抽象是否仍然成立。

## 本包事实

[RequestBody](request-body/README.md) 检查请求正文的规则：持有请求材料的调用有完整的正文；没有受理在途时，没有无归属的块；调用方一直重做的受理最终有结论。建模对象、性质、四个具名负控、运行命令与模型到代码的对应在该模型自己的 README。模型不覆盖同一进程里同一租户的并发受理与多个写进程。
