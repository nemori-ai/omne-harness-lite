# 模型调用的待细化事项

本页维护技术义务和来源缺证，不授予新产品政策或默认机制。原问题ID保持；建议未获采用，既定边界继续有效。完整行为仍读成员SPEC及具名专题。

<a id="model-e01"></a>
## MODEL-E01 工具结果块集合与嵌套模态投影的依据未闭合

工具结果包含图片或嵌套块时，模型合法目标需要与实际可读内容相容。已有资料确认工具可产图，但未具名闭合允许块全集及嵌套遍历。

由工具和消息契约拥有者补齐实际允许块集合及嵌套投影的具名依据，随后Model和Context承接；目前不向用户索取技术事实。

已定边界如下。

- 模型不可见块不缩小候选
- 有transcript的块不增加历史模态约束
- 工具原结果不因转换失败删除
- 实际请求的模态相容仍须校验

建议尚未采用。继续查源并由原契约拥有者闭合，不自行把过程帧清单当全部最终结果许可。

影响范围。该局部不能声称完整覆盖；不阻止已经有明确依据的图片、文本及可见性分支。

<a id="model-m01"></a>
## MODEL-M01 输入和适配器的精确契约

已有档案能力、有限提供范围、首内容与参数不静默丢弃承诺，但尚未采用公开形状、具体数值及提供者。

后续成员与提供者设计落实Schema、参数词表、状态码映射、计量、余量和真实协议事件，不作产品方向访谈。

已定边界如下。

- 所有适用上限发前校验
- token估算须适用依据及明确余量
- 首内容后不重发
- 参数不支持须说明实际采用

建议尚未采用。以实际采用模型和传输证据设计并验证，不给所有模型填统一限额。

影响范围。实现及符合性仍缺精确输入；当前行为承诺完整保留。

<a id="model-m02"></a>
## MODEL-M02 可靠承接、独立策略与清理接续协议

消费者替换、整调用重试中断、ACK和真实读写并发、费用迟到及清理重启须按原身份恢复。

后续模型、存储与消费协调者明确稳定引用、提交未知、读写保护、费用去重、独立策略适配及可信自身失联判据。

已定边界如下。

- 整调用收场后当前合法消费者才ACK
- 已确认不回滚
- 清理由模型侧续做
- 独立调用不造Session
- 真实多次发出可能多笔费用

建议尚未采用。先定义共同完成与失败边界，保留可复跑并发和故障验证。

影响范围。未运行跨进程或存储验证；不降低耐久、结果保管和首内容限制。

<a id="model-m03"></a>
## MODEL-M03 已展示在途内容的恢复兑现

原规则要求用户已看见内容可追溯，部分旧说明把未收场内容留runtime内存，模型自身失联时尚需衔接。

由流式、Model、存储和交付面技术设计对齐展示与保留责任；仅技术确需改变用户可见保证时另行提出具体决策。

已定边界如下。

- 不默认允许已展示内容丢失
- 不以收场ACK证明逐片耐久
- 不默认指定逐片同步落盘
- 首内容后自身失联不重发

建议尚未采用。先完成技术兑现调查，保留已有可见承诺及局部未覆盖。

影响范围。尚不能声称已验证该故障范围无丢失；不重问整套流式设计。

<a id="model-m04"></a>
## MODEL-M04 新接入方式的凭据具体形状

旧单通道一个秘密值的形状不能成为所有未来模型接入的数量与通道约束。

实际接入采用时由契约拥有者设计所需通道、键、数量与选择，当前不凭迁移补新政策。

已定边界如下。

- 档案不存秘密
- 租户合法绑定及实际调用归属
- 本阶段不提供组织共用凭据
- 官方部署默认只在既有例外适用
- 存在但不可读绑定不退默认

建议尚未采用。保留通道无固定全局约束和现行租户秘密边界。

影响范围。当前候选不定义通道字段和数量；独立提供者实施前仍须精确设计。

<a id="identity-neighbor-diagnostics"></a>
## 供应商尝试诊断的披露与保留

Model、诊断接入与存储拥有者须补足供应商尝试诊断的读取资格、可披露内容及保留范围与条件的精确契约。原问题的产品影响和责任见[Model 产品承接位置](../../../../.meta_harness/design/product/model-invocation/design.md#identity-neighbor-diagnostics)。

已有[数据保护与异常](consumption-and-cost.md#数据保护与异常)、[费用和账目边界](consumption-and-cost.md#真实费用和账目边界)及[清理范围](consumption-and-cost.md#清理范围与读写保护)继续有效。成本账目资格不替代诊断披露资格，秘密及无权披露信息不能先写入普通持久记录再靠界面遮挡；最终成功不覆盖真实尝试，诊断也不能成为永久保留无关全文的理由。

尚未选择诊断字段、保留时限、存储或运行机制。实施依赖该诊断入口时须先补足契约，不能声称完整诊断已可查询；其他已有行为、保管责任及阶段范围保持。需要改变既定产品边界的具体取舍交 Model 产品拥有者，不由技术设计补定。
