# 档案与模态的长期行为候选

状态：候选，待用户确认。本专题属于[model/model 长期规格](../SPEC.md)，维护档案、模态和转换契约的必要行为，不独立授予采用。

本专题承接 CAP-MD01..06、CAP-MD12、CAP-MD13；产品旅程与流程见[主规格对应表](../SPEC.md#能力旅程与持续验证入口)。Session 拥有列表选择与切换保存；本域维护合法档案及相容依据。

## 身份、修订及撤回

档案身份为所在范围加不可变路由名，来源产生时确定不可改。同一范围只能有一行同名档案，在册与撤回均占该身份。再次需要已撤回名字时恢复原行，不另建重复身份。不同范围可同名。

允许供应商有序且非空，回退声明显式，输入输出模态分别为非空能力集合。输入窗口为正的有限值，输出上限为正值。图片输入档案还须有正的有限单图字节上限。参数以统一业务含义声明，不猜 TypeScript 字段或上游词表。

有资格者修订参数、供应商、模态与限额；撤回保留身份、历史可查询及恢复资格。恢复者具备撤回该范围档案的资格。官方档案由发布供给，组织超级管理员和租户分别维护自身层自建档案，不从这些规则授予跨层编辑资格。Agent 不自行建改、撤回或恢复档案，不配置或解绑凭据；代表用户执行明确合法切换不等于拥有这些配置权。

修订和撤回不改原请求采用记录，恢复同名也不把原失败或取消改成成功。确认保存档案变更后，普通进程、操作系统崩溃及断电恢复仍识别原身份与新状态。并发同名创建不能形成两行；恢复与修订、撤回的顺序须由拥有者裁定，不靠时钟排序证明。

## 同名求值、选择及列表

求值的输入是当前范围链、档案状态、配置规则和所选路由。先去掉已撤回及当前范围配置排除的候选，再按租户、组织、官方取最具体。模态不相容、凭据缺失或不可读不触发重新向外找同名行。

范围资格与允许配置分别沿既有身份和设置契约。组织锁定路由名，不能据此锁定档案物理行。请求前扩展若获准改写候选，仍须满足有效锁定、身份、模态与外传条件，并保留实际改写依据。

会话保存的选中值与每次求值出的有效档案分开。未有会话取值时沿既有设置规则得初值；后续切换改变会话值并追加事实。真正生效以保存确认为边界，未知提交可按原操作核实。合法切换不因窗口小或系统认为模型差而拒绝，不取消原在途调用；下一请求使用重新求得的有效档案。

链上全部同名档案撤回时具名已下架。仍有在册而全部被配置排除时表示配置排除；资料不可取得时保留未知，未知名字不能伪装成已下架。外层同名按既定筛选胜出不算暗换路由。因缺凭据或模态不符改换外层才违背固定求值。

合法目标先满足范围和锁定，再按胜出档案输入模态覆盖会话模态投影。缺调用凭据不剔除合法目标，提供缺失标注。列表包含合法名字、当前选择及它们所带被覆盖同名条目；被覆盖条目只作来源说明，不能单独选择。当前选择失效也不消失，原因与来源可见。

列表、点查询及请求发起读取须识别投影覆盖范围和当前配置。允许展示延迟不允许以过期资格作为正确性依据。投影缺失或不可读不能当作空历史从而放行。精确一致读取、版本及更新协议由协调者设计。

## 上游限制与提供上限

上游限制由证据声明，未知与已知无限、已知有限、不适用分开。本档案提供上限必须明确有限，不能把本地提供值冒充上游能力，也不能将总量事实冒充单图事实。

适用提供上限缺失、非正、无限或超过已知上游限制时，禁止使用该档案发出任何请求；不能用本次只有文本绕过图片档案缺项。所有适用上限共同满足，不以模态支持替代大小或总量检查。

字节、图数及精确可计量限制按最终实际表示检查。恰好达到上限可通过该项，超过不发。token 有适用准确计数或可靠上界时使用它；否则按模型适用方法对完整请求估算并纳入明确配置余量。计量输入包含提示词、消息、提醒、工具定义和所有实际模态。

缺适用方法、必要配置或遗漏组成时拒绝发出。估算加余量超过限额时说明估算不通过，不伪称测得上游实际超限。估算通过不保证上游接受或计数相同，实际用量和费用按真实响应取得，不能拿估算填账。

上游实际限制变化后须复核档案和适配器。一次接受只证那次请求成功，不能证明未知无限；上游拒绝保留原发出和原因。具体数值、方法、余量、输出参数和校验资源按供给及真实协议设计，不用通用固定数填所有模型。

## 模态投影与实际表示

模态由内容媒体类型识别，文件块不是另一种模态。思考和工具调用是用途，不因此新增模态。非模态文件附件只交引用；能处理文本引用不意味着取得或理解附件正文。文字、图片和语音是本候选的原生支持目标，视频的既有文件表达不新增阶段交付范围。

新会话的初始模态约束为文本，只有实际支持文本且满足其余准入条件的档案才进入合法集合。会话模态投影仅从原历史中模型可读、无 transcript 的块累积模态。只给人看的块不算，派生 transcript 在原接纳时固定后不改。投影可重建且结果与同范围历史一致，压缩排除不改变原块标记、原内容或这项历史事实。

在固定档案能力及范围规则时，历史新增无 transcript 模态会收紧合法目标。配置、在册状态、档案模态都可变化，当前合法集合不保证只减。不能仅据历史投影单调推出必须新建会话才恢复候选。

实际表示选择与组装归 [request-context 的 RQ-04](../../../context/request-context/SPEC.md#rq-04-模态与可追溯表示)。本域提供以下相容及档案约束，不另定义组装算法。请求上下文按实际能力取原件或适用派生，均取不到时取已有 transcript，最终仍检查模型接纳该文本表示。多个表示都可读时，采用具名组装策略并留下实际表示依据；不静默丢不兼容块。原件超大小上限时同样必须取得合规表示，未能取得就明确失败，不能按模态错误归类。

模型实际读取派生内容时，交付面能标明读的具体表示。转换损失不能隐藏；原件保持可按其资格读取。图片、语音、链接及 transcript 同样受读取与外传限制，转换不获得额外授权。

## 转换件的共同契约

转换件由系统装配按模态或文件媒体类型键选择，同键只一件生效。文件同时命中具体媒体类型和一般模态时，只采用媒体类型件，形成一份确定派生及 transcript。未采用本次具体件之前不得任意并行调用两件后拼合输出。

输入是一个模型可读非文本模态块或文件块。输出包含至少一个不同模态的非文件块及纯文本 transcript。只有 transcript、无 transcript、文件派生块或执行报错都不合约。结果挂在原块上，不进入消息主块序列、不改原块，不形成另一独立业务对象。

转换在消息接纳前完成。转换件不根据当前模型决定是否转换，因为该处可能没有活着的 Run；有件且适用就按契约转换，模型取哪份属于随后组装。已接纳原块的派生与 transcript 不随转换件更换更新，不以转换更新改历史。

本候选的转换边界为本地完成，不主动发模型请求，transcript 来自本地识别。转换件不成为资产，组织或租户不取得按持有或分享替换它的权力。装配生命周期及自身资源释放仍由集成契约负责。

未登记适用件时，原块依消息准入可原样接纳，无 transcript 则参与相应模态约束。已登记但不可用按失败，不当成未登记默默原样通过。仅供人读的块不触发面向模型转换。

| 原消息来源 | 转换失败的共同结果 | 保留责任 |
| --- | --- | --- |
| 输入 | 拒绝此次接纳并通知发送方，会话投影不改变 | 输入入口保留真实拒绝及原因，不伪称已受理消息 |
| 模型回复 | 原回复不成为消息，原调用照常收场，记录否决；Loop 退避后另起调用，既定次数上限仍有效 | Model 保留原结果，Agent 维护新调用及否决位置，不算供应商内部重试 |
| 归属仍有效、尚未终结 Run 的工具结果 | 使该消费契约指定的 Run 失败，指出转换件及块 | Tool 保存全文、执行和效果，不因未成为消息删除或自动重做 |

后台、Run 外或原 Run 已终结的结果按原消费契约处理转换失败，不修改原终态、不默认挂到后继 Run。没有有效 Run 不造一个，已取消业务不得凭本条恢复推进或取得新入队资格；未定旁路后果仍由原消费拥有者明确。

不存在失败后改成没有 transcript 而放行的补偿分支。拒绝消息与删除真实执行结果不同，转换失败不撤销实际工具副作用。独立程序未走消息接纳时仍消费真实原模型结果；不能硬造会话转换分支。

## 验证与待闭合输入

验证覆盖同范围并发建档、撤回与恢复身份、同名最具体筛选、锁名字且合法同名覆盖、缺凭据不退层、合法小窗口切换、动态配置扩大候选，以及未知来源不放行。

限额验证包含缺值、非正、无限、低于已知上游、恰好上限、单图通过但总量超限、仅文本绕缺图片上限、估算无依据、遗漏工具声明和扩展后再校验。使用真实采用模型及证据检验适配，不用本地估算替代正式费用。

转换验证包含媒体类型优先、无件与不可用区分、错误派生、transcript 缺失、本地无模型调用、原件不变、失败不接纳，以及模型和工具真实结果仍保留。投影须增量维护，单个会话某模态是否存在的点查询为常数代价；更新与历史重建一致，增长点查询不反复扫描全部历史。列表开销按当前候选量及实际输出分别评价。

工具可产图片和模型不可见块不影响模态已有依据。完整工具结果允许块集合与嵌套遍历尚未闭合，不能自行把过程帧清单当最终结果许可。由 tool 和消息契约拥有者补来源，Model 与 Context 按真实允许内容共同检查。该局部未定不授权跳过已知实际模态相容性。
