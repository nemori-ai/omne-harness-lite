# verification/models

本目录承载本包的形式模型，例如 TLA+、Alloy 或 SMT 模型。

## 允许的内容

模型源文件、配置与说明。

## 边界

说明模型对应的 `SPEC.md` 条款、抽象前提与未覆盖的部分。模型通过不等于实现符合。

## 维护

承诺或实现结构变化时，复核模型的抽象是否仍然成立。

## 本包事实

不适用。本包没有自己的形式模型，也没有登记形式任务。共同协议的模型性质与前提记在 [model-contract](../../../model-contract/verification/models/index.md)，那里也没有可执行模型。
