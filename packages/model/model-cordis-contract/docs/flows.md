# Model Cordis 登记流程

1. 宿主装载本包的唯一定义及所需目录，再提供业务实现。
2. 受信贡献者携带固定身份及采用登记。目录按 [SPEC](../SPEC.md) 核当前资格、冲突与幂等条件。
3. 成功登记返回关联原贡献的 token，并将撤除责任绑定原 caller fiber。
4. 消费者沿唯一键取得能力，操作仍核业务主体及租户。查询目录不创建新调用。
5. 释放时只撤原 token 对应贡献。转换贡献退役停止新取得，已取得资源按原采用完成和释放。

通知是重新查询的提示，不是事实副本。事件载荷和监听失败行为归 [SPEC](../SPEC.md#配置通知和撤除)。具体发送、恢复及宿主依赖换代见 [model 装配设计](../../model/docs/cordis.md)。
