# examples

本目录承载面向真实公开入口的使用示例。

## 允许的内容

可运行的示例代码与说明。

## 边界

示例只用公开入口，并写明运行前提。示例不代替测试或规格。

## 维护

公开入口变化时，同步示例并确认它仍能运行。

## 本包事实

本包不另写示例代码。可运行的消费示例就是角色夹具：`tests/fixtures/consumers/<角色>/` 下的小工程，各自只依赖已打包安装的公开制品，演示一个角色怎样只靠本包的公开契约完成消费。五个角色是独立调用者、编排协调者、Context、结果消费者和通用提供者作者，登记在 `tests/fixtures/consumers/roles.json`。

运行全部夹具：

```sh
pnpm --filter @omne-harness/model-contract run fixtures
```

夹具的写法和限度见[夹具目录说明](../tests/fixtures/README.md)与[角色夹具](../verification/README.md#角色夹具)。夹具里的替代提供者与替代传输由脚本给出结果，不证明任何生产提供者。夹具兼作持续消费示例：它们每次运行都对已安装制品重新编译，所以公开入口变化而示例没有同步时，运行会失败。

需要学习真实 runtime 的受理、观察和原终局收场时，运行 model 的[四个独立教学脚本](../../model/examples/README.md)。这些脚本使用本包公开类型和脚本传输，内存装配仍不是生产提供者证明。
