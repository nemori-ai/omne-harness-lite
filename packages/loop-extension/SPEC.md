# Loop Extension

## 总体架构

本组实现拓展件这一类资产的专有部分：包与声明，租户启用的拓展件这份视图，以及实现的取得与运行。

| 成员 | 回答的问题 |
| --- | --- |
| `loop-extension-contract` | 一件拓展件的包是什么样，声明怎样从包里取出，向资产登记什么，供给的块长什么样，命令型实现的输入输出是什么形状。纯数据与纯函数 |
| `loop-extension` | 视图怎样从资产事实算出，一个位置的成员怎样筛出并排序，一次命令型运行观测到的事实怎样归成调用结果。不依赖 Cordis 与存储 |
| `loop-extension-cordis-contract` | 这套系统里的服务定义：视图，内建实现的登记表 |
| `loop-extension-host-local` | 单机的提供者：视图的缓存与失效，租户级作用域里的那一块，扩展实现的提供者，命令型经执行环境运行，耐久账本 |

依赖只朝内：四个成员依赖 Agent、资产、Runtime Context 与执行环境的契约；这些契约都不认识本组。

## 领域边界

本组拥有：拓展件包的格式与校验；拓展件的类别契约；租户启用的拓展件这一块的声明与值；内建实现的登记；命令型实现的协议、运行、时限与收场；命令型调用的账本。

本组不拥有：

- 扩展位置、维度、干预力、位置输出表、声明的字段与判断规则、扩展链的顺序与归约、一次经过的记录。它们归 [Agent](../agent/SPEC.md#扩展与卡片)。
- 持有、版本、发布、禁用、层级求值、设置的配值与锁定。它们归[资产](../assets/SPEC.md)。
- 谁有资格读这一块。读取资格归租户级作用域的持有者与应用的装配。
- 子进程的落点、租约与停止。它们归[执行环境](../execution/SPEC.md)。
- 输出合不合法、结论是什么。本组交回调用结果，由 Agent 裁定。

本组只认通用角色：访问身份、能力标识、精确版本、经过的身份、不透明的作用域引用。它不导入会话或工具的类型。

它为别人实现的端口：

| 端口 | 对方 | 对得上的一句话 |
| --- | --- | --- |
| 扩展实现 | Agent | Agent 需要按精确版本取得一个成员的实现并调用；本组提供 |
| 类别契约 | 资产 | 资产需要校验一个包、取出声明与设置声明；本组登记 |
| 块的声明与供值 | Runtime Context | Runtime Context 需要这一块的语义与当前值；本组把它贡献给租户级作用域 |

它声明、由别人实现的端口：

| 端口 | 对方 | 对得上的一句话 |
| --- | --- | --- |
| 层的来源、包的读口与本机目录、设置的读取、变化信号 | 资产 | 本组需要租户在持的拓展件、各层候选、胜出版本的声明、「运行」设置的值，以及它们变了的信号 |
| 环境面与命令设施 | 执行环境 | 本组需要一个落点、一份租约、启动与停止一个进程 |
| 运行位置 | 应用装配 | 本组需要一次调用的作用域、落点与工作目录；它不认识会话 |
| 耐久存储 | 存储 | 本组需要一份跨进程存活的账本 |
| 环境授权与恢复授权 | 应用装配 | 本组作为执行环境的集成方，需要装配为它的访问身份授权 |

## 心智模型

拓展件有三样互相分开的东西。定义是资产里的包与声明，只是数据。视图是此刻把名字绑到胜出版本上的结果，随时可以丢掉重算。实现是登记着的函数或一次子进程运行，可以回收，可以重建。

视图不是事实。事实是资产的持有、版本、设置。视图只回答「这个租户此刻哪些拓展件会运行，各是哪一版」，谁来问都现算或取缓存。

本组不知道循环走到了哪里。Agent 带着成员的精确版本与输入来调用，本组只负责把这一次调用做完并如实说出结果。

## 应然设计

### 包与声明

- 一件拓展件是一个目录，里面有一份声明文件与实现要用的文件。声明经 Agent 契约的声明判断，判断不过的包不合法。
- 声明的名字必须等于能力名。
- 实现有两种：内建，声明只写内建实现的名字；命令型，声明写解释器的名字、包内的入口文件与时限。入口文件必须在包的清单里。
- 命令型的声明不能声明模型调用的需要。
- 版本记录的正文是从包里投影出的声明。读视图与取实现时读这份正文，不重新解析包文件。
- 每件拓展件带一项「运行」设置，布尔，缺省为关，由类别契约声明。这份设置定义的版本只由它的内容推出，同一件拓展件的每个版本是同一份定义：换版之后人设的值保留，不用迁移。
- 类别契约给每个版本一份摘要：标题是名字，一句话说它在哪个位置、能做什么，事实列出位置、干预力、实现（内建的名字，或解释器、入口与时限），声明了报错处置时再列一条。摘要只读声明，不读运行时的事实。
- 类别带一段写法说明，给要写一件的人与 agent：一份完整的最小声明与脚本、九处位置的名字、脚本从标准输入读什么、往标准输出写什么、发布之后要打开「运行」。

### 租户启用的拓展件

- 一件拓展件进入视图，要同时满足：租户持有它且持有没有被禁用；层级求值有胜出版本；胜出版本的声明读得到；「运行」设置求值为开。
- 视图的成员带能力名、资产引用、精确版本与声明。
- 任何一层的来源、任何一件的声明或设置读不到时，整份视图答不可用。不交出部分清单。
- 一个位置的成员从视图里按位置与维度筛出，按能力名升序排列。筛选与排序是本组导出的纯函数。
- 视图按租户缓存。资产或设置的变化信号到达时，这个租户的缓存作废，下一次读取时重算。缓存只是性能手段：作废之后到重算完成之前的读取，等重算的结果。
- 视图的答复带它计算时所依据的修订。
- 这一块是租户一级的事实，不分会话。它登记在 [Runtime Context 的租户级作用域](../context/SPEC.md)里，由本组贡献声明与供值函数；会话的创建与会话的作用域都不登记它。每次读取现取，不进快照，不产生变化提醒。它是必需块：没有贡献或来源不可用时读取方得到缺项或不可用，不得到无值。

### 实现的取得与调用

- 取实现按成员记下的精确版本，不按当前胜出版本。
- 内建实现按名字从登记表取。登记是一份贡献，撤回只撤自己那一份。登记表里没有时答不可用。
- 全新调用取实现时，这份持有已被禁用或移除，或者版本的材料不可用，答没有开始的不可用。重放时取不到原实现，原调用保持原状态，结果是未知，不改答不可用。
- 一次调用的结果是输出、报错、没有开始的不可用、未知之一，分类规则归 [Agent 的作者协议](../agent/SPEC.md#扩展与卡片)。本组不把判不明的情形归成不可用或报错。

### 命令型的运行

- 一次运行只经执行环境的命令设施启动。本组不自己起子进程。
- 命令型的实现在运行当中不取得任何回调系统的能力。
- 解释器的名字由宿主的解释器表解析。表里没有这个名字，答不可用。
- 运行位置由应用装配给出。子进程只得到白名单里的环境变量，不继承服务进程的环境。
- 输入经标准输入交付：经过的输入、调用模式、按声明的需要读到的值。重放时带已有的卡片轮次与答复。
- 输出从标准输出读回。退出码是零且输出是一份形状合法的输出时，结果是输出。输出超过上限、被执行环境丢弃过字节或形状不合法，结果是报错。标准错误不进任何记录，只留字节数。
- 时限由声明给出，本组计时。到时限先请求停止，再强制停止。超时是报错，不证明进程已经停止。
- 启动意图先写进账本，再向执行环境请求启动。结局写进账本之前，本组不释放这次调用的责任。
- 宿主启动时先结清账本里登记了启动意图而没有结局的调用，再接新的调用。这些调用的结果仍是未知。
- 推进失效时，本组请求停止，交回的结果不被采纳。

### 失败、未知、取消与恢复

- 资产、设置、Runtime Context、执行环境、存储任一依赖答不可用或未知，本组把它原样带出，不改成空或失败。
- 同一个经过的再次调用带重放模式。本组不为它保证只运行一次：作者以经过的身份给自己的副作用去重。
- 本组的服务卸下时，不再接新的调用，在途的调用各有结局。

### 在资产页里的样子

- 本组不带界面模块，也不开对客户端的协议。拓展件在资产页里用通用的窗格：栏里的一项、资产的行、新建的表单与一份资产的页，照[资产的规格](../assets/SPEC.md#资产页与设置页的样子)。
- 行上的简介是摘要的那一句话；一份的页上，「运行」是设置里的一行，用布尔的开关；摘要的事实在「详情」里。禁用、启用、移除用资产页的动作。
- 页面不显示一件拓展件此刻在不在视图里，也不显示它调用过什么。这两样是运行时的事实，要显示就得由本组开一个读它们的协议，现在没有。

### Cordis 装配

- 类别登记、内建实现的登记、扩展实现的提供，都绑在本组插件的作用域上，随卸载收回。块的贡献由应用的装配放进租户级作用域的登记面，随那一行卸下撤走。
- 依赖的资产、Runtime Context、存储齐了才启动。执行环境不在时，命令型答不可用，内建实现照常。

## 原则与约束

- 类别的差别由类别契约表达。资产的成员里不出现拓展件的分支。
- 本组不写会话日志。视图、缓存与内建实现的登记都可以丢掉重建。本组唯一的耐久事实是命令型调用的账本：它是执行环境要求集成方提供的资源账本，另记每次物理调用的启动意图与结局。设施守卫也由本组提供。
- 视图的规则只有一处：进不进视图、怎样筛、怎样排，都在领域实现的纯函数里。提供者与适配成员不重写这些规则。
- 读不到不变成空。
- 每次调用带租户。视图、缓存、账本都按租户分域。

## 不变式

| 编号 | 永远成立的性质 | 违反的后果 | 由什么守 |
| --- | --- | --- | --- |
| LX-1 | 视图只含持有未禁用、求值胜出、声明读得到、「运行」为开的成员 | 没启用的拓展件在租户的执行里运行 | `loop-extension` 的视图用例 |
| LX-2 | 任何来源读不到时视图答不可用，不交出部分清单 | 一道守卫在读不到时被当成没装 | `loop-extension` 的视图用例 |
| LX-3 | 一个租户的视图、缓存与账本不含另一个租户的条目 | 跨租户运行或探测 | 租户身份的类型；`loop-extension-host-local` 的隔离用例 |
| LX-4 | 取实现按记下的精确版本 | 一次经过里成员的版本中途改变 | `loop-extension-host-local` 的取实现用例 |
| LX-5 | 命令型的启动意图先于启动落盘；判不明开始或收场时结果是未知 | 重复的全新运行，或把运行过的调用说成没运行 | `agent/verification/position-pass` 的 `FreshOnce`、`UnavailableNeverRan`；`loop-extension-host-local` 的崩溃用例 |
| LX-6 | 子进程只经执行环境启动，不继承服务进程的环境 | 秘密泄漏给租户的脚本；进程没有人承接 | 依赖检查；`loop-extension-host-local` 的运行用例 |
