# verification

本目录承载本包的持续验证资源：模型、论证或证明。

## 允许的内容

`models/` 下的形式模型，`proofs/` 下的论证或证明，以及说明文件。

## 边界

每份资源说明所验证的性质、前提、运行命令、覆盖与限制。单次运行的原始输出留任务 tmp，不进本目录。

## 维护

被验证的承诺变化时，同步模型、证明与本目录 `index.md`。

## 本包事实

动态贡献和生命周期的有限模型由 [governance-local 的 verification](../../governance-local/verification/README.md) 维护；组织来源保留由 Settings verification 维护。本目录不复制模型。真实 SQL、Cordis 生命周期和重启符合性仍由提供者验证，尚未取得本成员完整组合的接受证据。
