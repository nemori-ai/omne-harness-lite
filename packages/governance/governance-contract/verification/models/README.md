# verification/models

本目录承载本包的形式模型，例如 TLA+、Alloy 或 SMT 模型。

## 允许的内容

模型源文件、配置与说明。

## 边界

说明模型对应的 `SPEC.md` 条款、抽象前提与未覆盖的部分。模型通过不等于实现符合。

## 维护

承诺或实现结构变化时，复核模型的抽象是否仍然成立。

## 本包事实

本成员不复制跨域模型。动态贡献的性质和负控沿 [governance-local 的 verification](../../../governance-local/verification/README.md) 的入口运行；实现验证不能用模型通过替代。
