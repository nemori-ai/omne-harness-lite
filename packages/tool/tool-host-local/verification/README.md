# tool-host-local 持续验证资源

[环境准备有限模型](models/README.md) 记录本地预占、原发送、查询、首次采用和释放的有限性质，以及原提供者前提和源码对应缺口。driver 的追加 prepare 与 E 缓存条件由独立子模型检查。

[启动围栏与推送退避](formal-mapping.md) 记录启动排序域（G5、P04）和结果推送退避与退避表（R2-D273、R2-D282、R2-D327）的性质、模型、源码对应与机读守卫。运行记录见 [formal-runs.md](formal-runs.md)，手写证明见 [proofs](proofs/README.md)。

有限模型、内存 fixture、真实后端和完整组合属于不同证据范围。模型资源存在不代表检查已执行，规格配置通过也不能替代当前源码符合性。单次命令、原始输出和反例保存在任务 tmp。

公共验证义务归契约包的 [verification](../../tool-contract/verification/index.md)。本提供者的契约见 [SPEC](../SPEC.md)，目录导航见 [index](index.md)。
