# tool-cordis-contract 持续验证资源

本包的验证义务是键与类一一对应、定义入口不导入 Tool 实现、事件名以包名为范围。这些义务由[成员测试](../tests/index.md)持续检查。登记语义与撤除范围的验证义务归 [cordis](../docs/cordis.md#验证义务)，由实现登记的包承担。公共验证义务归契约包的 [verification](../../tool-contract/verification/index.md)。

本目录不授予设计接受。单次运行和评审证据归任务 tmp。

契约范围见 [SPEC](../SPEC.md)，目录导航见 [index](index.md)。
