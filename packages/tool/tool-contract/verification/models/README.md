# Tool 协议模型

本目录保存可执行的协议模型及其性质、假设、有限状态边界和运行命令。每个子目录是一个模型，带自己的 README、TLC 配置和运行入口 `check.py`；运行输出写到任务 tmp，不进入本目录。子目录清单见 [index](index.md)，契约范围见 [SPEC](../../SPEC.md)。

正控配置列出模型的全部性质，要求 TLC 完成检查且没有错误。负控配置只列一个具名性质，要求 TLC 以该性质的反例结束。模型检查只证明列出的有限状态和假设，不证明实现，也不代替部署验收。持续验证义务见[设计覆盖与验收规范](../README.md#设计覆盖与验收规范)和[旅程验证场景](../README.md#旅程验证场景)。
