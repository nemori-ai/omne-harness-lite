# 工具执行的内部设计

本页在正式维护位置保存待审技术设计。领域分解已评审不等于成员技术接受、阶段选择或实现支持。具名目录只有文档，公开形状和实际验证仍待设计及补证。

领域角色读[责任交接](../../../../docs/domains/tool-execution/architecture.md)，工程邻接读[组设计](../../docs/architecture.md)。本页与[SPEC](../SPEC.md)及原具名行为专题分别维护机制与行为，不据当前实现降低承诺。

## 发起与排队的共同边界

发起、排队、真实执行和 dummy 分支见 [TL-F02](key-flows.md#tl-f02)；定义与动态可用性见 [TL-F01](key-flows.md#tl-f01)。

图中的真实执行和 dummy 是可辨的分支，不要求 dummy 建立环境、进程或执行资源。环境准备顺序适用于真实动作，已知不可用分支直接交付具体原因，不因图中阶段凑齐虚构事实。

会话同工具并发限制合计前后台，超额按发起次序排队。准入、环境准备和排队事实不证明实际启动。队列等待跨越撤权、归档或 reload 时，实际发起须重核原操作及当前条件。参数、定义、实现和批准不匹配时不盲发；无关变更不机械重问。

发起与当前资格检查需要共同成立的范围由发起协调者和权限、存储契约明示。目录相邻、同租户或相同数据库不能证明原子性。提交未知保留原操作身份对账，不能直接产生另一次外部效果。

## 状态、关系与资源分别维护

执行提供者维护真实运行、内部等待和实际终局。调用方维护前台依赖、转后台占位及后续结果位置。取消意图、控制受理、物理停止、业务不再等待和资源回收分别可辨。

前台和后台不会分成两套 Tool runtime。转后台改变原调用的等待关系和结果交付方式，不重建执行、不改归属，也不要求移动线程或进程。内部等待与前后台正交，本候选的需答复等待仅开放前台；没有声明不能转后台，Ask 无超时或默认答案。关系只从前台向后台转换，不能回到前台或再次转换，转后台不释放仍运行的名额。具体关系图见 [TL-F03](key-flows.md#tl-f03)，内部 HITL 等待见 [TL-F04](key-flows.md#tl-f04)。

调用身份、原用途、适用租户和组织、工作区及已有 Session、Run、attempt、step、动作关联是接续依据。独立调用使用自身调用方与工作身份；不存在的关联不补造。等待者、连接、订阅和句柄是可重建资源，不是这些事实的唯一保存位置。

提供者保留本次匹配的采用依据。后续定义、MCP 清单或环境策略更新影响后续调用，不改已发原输入。稳定入口内部数据更新不自动要求 Agent 重建；真实结构绑定换代沿明确交接，不承诺失效资源无限存活。

## 收场与消费的责任移交

原结果保管、先保管或先完成处理的两条交接路径见 [TL-F05](key-flows.md#tl-f05)，卸载与全文读取见 [TL-F06](key-flows.md#tl-f06)。

Tool 在可靠交接前保管结果。原消费者保存后续所需内容和处理位置，或完成处理并保存必要完成事实，才解除对应交付关系。确认响应丢失时按原身份核对，不重复逻辑承接、不重发原工具。执行后扩展须在可靠保管之后消费结果，不能先扩展失败再丢原结果。

卸载由会话路径的执行后单结果扩展协调，Tool 提供结构化原文、摘要和附件依据。消费者保留全文有效引用及原附件地址，实际存储承担字节耐久与可取回责任。工具全文没有采用的删除期限，Model ACK、压缩、Run 结束或归档不释放这项义务。

消息或模态转换否决不撤销原执行。仅消费契约指定仍有效且未终结 Run 时，否决使该 Run 失败。后台、Run 外和原 Run 已终态的消费不能套用该简写，不能改旧终态、默认挂后继或造 Run。业务取消也不产生新的入队资格。其余旁路后果由实际消费者定义。

## 控制、失联和故障交接

Session 保存 Run 取消或归档业务事实，撤销相应新推进资格，再向目标调用传播控制。Run 取消控制前台关联，后台不自动停止。归档在业务上取消全部原未完成请求和等待，不以实际物理停止为完成前置。Tool 提供者继续控制、真实收场、全文和账目责任，迟到事实不复活工作。

Agent 换代只改变当前推进者。接手方先查原调用，运行则认回句柄，已收场则取原结果，已交接则从消费侧保存位置继续。查询不可用保持未知，不能当成丢失。只有工具自身确认连续性丢失，才报告失败和异常中断，系统不自动重放未知外部效果。

环境重建和计算恢复不证明原执行停止、数据已恢复或外部效果未发生。执行域终止不自动终止已准入的宿主调用；宿主桥接和调用拥有者须承接迟到结果。控制能力无法确认时记录实际缺口，不用 disposer 声称外部效果可逆。单次、Run、Session 控制及接续分支见 [TL-F07](key-flows.md#tl-f07)。

必要结果保存失败，原交付责任不解除。必要准入或存储服务不可用，依赖其允许或保存的新动作受限，不能默认为成功。错误上交保留身份、阶段、分类及责任，不默认携带正文、附件或秘密。可选观察帧故障不使真实工具执行失败，但必要生命周期记录缺口须按明确契约处置。

## 组合验证与明确未覆盖

Tool 验证逻辑调用、真实启动、等待、控制、收场和效果；协调者验证资格与发起、原位置交接、取消和恢复；提供者验证环境及传输实际边界。必要组合覆盖 dummy 不启动原工具、排队撤权、后台与 Run 终态竞争、归档迟到、提交未知、消费者替换、工具自身丢失和全文长期读取。

已确认事实的耐久验证覆盖进程崩溃、操作系统崩溃和断电，不能只凭进程重启证明。真实外部效果测试缺环境时报告无法验证。资源上限和超长会话读取按实际规模验证，不自定统一数值。

最终块许可与嵌套投影继续沿 MODEL-E01 证据缺口核对，已确认图和可见性分支不暂停。已展示过程内容与在途内存丢失的技术衔接待流式拥有者完成，不宣称每片落盘或允许丢失。精确 API、控制和提交协议等缺项见[成员 SPEC](../SPEC.md)及[问题登记](../../../../.meta_harness/design/product/tool-execution/design.md#未决问题与待定事项)。
