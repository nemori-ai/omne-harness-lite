# 结果、过程与保管

状态：候选、待用户确认。本页是 [SPEC](../SPEC.md) 的必要行为专题。原工具结果、会话消息采用、模型输入、执行账及费用是不同事实。

## 两种作者返回与一种消费形态

普通函数返回的整个值作为文本使用，在上报时统一转换为 ToolResult。结构化 ToolResult 提供面向消费者的内容，以及可选卸载原文和附件地址。只有结构化返回提供这些附加能力，普通返回不通过猜字段暗中取得卸载或附件语义。

返回值的精确 Schema、非字符串值的文本转换及兼容规则待公开定义拥有者明确。本稿保留两种写法和统一上报语义，不猜 JSON、序列化库或函数签名。普通返回也须能被明确消费，不能因尚未采用精确格式把未经转换的任意对象当消息正文。

完成、失败、不可用、转后台、被中断和等不到应答带具体原因正常返回。真正的运行事实与效果确定性另行说明，“失败”不能自动推出“没有效果”。转后台只交前台占位，最终结果仍归同一原调用。当前后台最终收场不能再次是转后台或 dummy 不可用，也不开放需答复等待。

原结果可以是多块，已确认工具可产图。公开最终允许块全集及嵌套投影仍有 MODEL-E01 来源缺口，不把过程帧的块种表自动当成全部最终许可。已确认的文本、图片、原件可见性和实际模态相容检查继续有效。

## 过程帧的观察契约

工具发帧是可选运行原语，不在定义中增加“发不发”的许可项。未发帧正常，发送失败不单独导致执行失败。工具作者根据当次执行决定内容，系统按实际收到的协议处理，不凭定义猜帧。

会话路径同一次工具执行的过程形成一条 ToolInternalMessage 的到达增量，块可以很多，过程消息不是一串独立工具结果。它给人观察，不进入模型上下文。没有实际交付块时不虚构过程消息；已有块时，无论工具如何收场，都保留已交付过程并独立标明真实收场。

开块时固定填充方式，追加片段保留各片内容，整体替换只替换同一块当前值，不覆盖其他块或历史消息。进度状态可以整体替换，已发生过程可以追加。工具可在同次调用先发日志，再开整体替换的面板，不声明全工具仅一种模式。

封块交付完整块。分次到达组装与一次性取得相同内容；重连观察者先读已到当前快照，再接后续增量。快照包括已封块、开着的追加内容及整体替换最新值，不等于完整增量历史。帧的封口结果和执行终局分别表达，过程播报不能替代最终返回。

输出、快照和观察者资源有边界。节流可合并相邻增量，不能默丢内容；裁剪多少、为什么裁剪须可见。长期历史保存最终过程内容，不要求回放每个增量及当时屏幕。已展示但未收场内容的故障保留与运行内存快照失联之间尚需技术衔接，不能用收场保存或 Model ACK 声称逐片耐久，也不能默认允许丢失。

独立入口可以提供等价过程观察，不强制形成 Session 消息。访问和导出各核对当前权限。Frame 故障与必要生命周期记录故障不同，后者不能因“发帧可丢”无声取消其记录义务。

## 执行账与真实成本

每次逻辑调用都能辨认实际处理和真实执行事实。完成时上报实际运行时长、计算用量等执行账，不直接装入 ToolMessage 或模型上下文。dummy 不启动真实原工具，不虚构其用量；替换件处理确有开销时按事实保存。

原调用的真实时长、用量、费用及各次真实尝试可追溯。消费者重读、通知重投、接续 attempt 或解除交付关系，不重复记录原成本。真正的新合法调用可有自己的开销，不为了“去重”抹掉真实重复收费。

收场、消费、费用结算分别可查。费用未知保留待核实责任，不能填零，取消、归档和消费者失权不删除费用。迟到账目归原调用及原工作，在适用时归原 Run；不当普通消息触发新 Run。独立调用使用真实归属，不造 Run 来记账。

每个租户可查自己的成本明细；组织管理员可查本组织所有租户账目明细。组织边界不能扩成该账号其他组织。账目资格不授予正文、原文、附件、凭据或秘密权限。遥测估算和采样不冒充完整财务事实，具体金额、字段、费率和成员位置尚待成本契约设计，不增加额度、预算或超限拦截。

## 可靠交接与处理的两条路径

Tool 先可靠保管真实原结果、归属和原消费位置，直到合法消费者按自身协议可靠接下或完成处理。执行后扩展、卸载或消息准入期间，原结果仍须有保管者，失败不能先销毁结果。消费者先认回原调用及原用途，不从新 attempt 或当前等待实例重新生成身份，再按适用协议选择以下路径。

先保管后处理时，消费者保存后续需要的内容或在所需期限内可恢复的引用、所属租户、适用工作关联、原位置和待交付责任。取得普通进程崩溃、操作系统崩溃和断电耐久确认后，消费者可依工具协议解除对应待交付关系，再从原位置执行后续扩展、卸载和消息采用，记录各自结果。

先完成处理时，Tool 在处理期间继续可靠保管原结果，消费者从原位置执行后续扩展、卸载和消息采用。消费者完成处理并可靠保存必要完成事实后，才依工具协议解除对应待交付关系。此路径不强制消费者再保存一份不需要的原结果全文；完成事实须足以恢复已完成结果及责任，不能重复已完成的逻辑处理或外部效果。处理失败、处理中断或完成事实保存未知时，原交付责任保持，按原身份和原位置对账。

通知、展示、读到内容或开始处理均不构成可靠交接。解除关系及保存承接依据须可恢复一致，未知提交先按原身份核对。双方不能同时放弃保管，也不能重复逻辑承接。两条路径均保护仍有效的全文保留责任。协议不要求所有工具统一 Model ACK，更不授予按 Model 清理工具全文。

消费者可以独立处理或保管结果，无须先落聊天。消费者退出或失权不释放原交付责任；有合法替代者时从相应位置接续。结果保存失败或引用无法达到所需保留时，生产方继续承担未交付责任，报告缺口，不能声称已经消费。确无当前合法读取者也不授予不合法者内容。

## 卸载与全文读取

工具作者在 ToolResult 提供卸载原文时，消费方使用作者构建的摘要作占位。系统兜底处理单条结果超限时保留首尾、标明机械截断，不编造语义摘要。实际限额和计量尚待协调契约明确，不从这里造一个统一数字。

占位包含够用内容、原始大小及取回方式。原结果、摘要和原附件地址能相互关联，完整字节或有效可恢复引用达到必要耐久和保留条件后，才声称已经卸载。存储失败不留下声称可取回的空占位；结果卸载扩展不可用须可见，不能伪造已卸载或自行丢原文。

卸载与前后台、内部等待正交。结果大不自动转后台，也不改变终局。整个会话超预算的压缩不是单条结果卸载，不能靠压掉刚返回内容掩盖单条超限。

历史一开始追加占位，不先记录全文再覆盖。取回是新的工具调用，分页返回新内容，原占位不改。会话模型发起的取回沿实际 Assistant 调用和新 Tool 返回追加，不重计原工具费用、不重做原效果。独立消费者也按原调用查询，不能要求知道存储内部文件路径。

全文取回不因卸载、消费、压缩、Run 结束或归档过期。当前没有采用工具全文到期回收规则，存储提供者可实现分层和去重，但不能自行删唯一原文或缩短承诺。Model ACK、旧句柄释放和订阅结束也不授权删除。原附件地址不能因消息摘要处理被抹掉或暗换。

读取核对当前资格，权限撤销可以拒绝当前读者，不能因此删仍承担保管责任的内容。地址失效、存储不可用和对象不存在分别表达；临时失败不冒充不存在。确认过的多媒体内容及引用须共同耐久，不把临时沙箱文件地址当永久保管。

## 模型采用、否决与终态边界

会话消费原结果时，Tool 的可靠保管事实先成立，再沿上述任一合法路径进行消息准入和模态转换。先完成处理路径不强制消费者在处理前另存一份原结果。转换只能追加派生表示，不伪造或覆写原件。实际模型可读块仍须满足目标模型及转换能力，模型不可见过程内容不缩小候选，有 transcript 的块不增加历史模态约束。最终块许可和嵌套投影未闭合的部分保持具体未覆盖，不跳过实际可读图片校验。

消息入口否决工具结果或模态转换失败时，保留真实原结果、原因和原调用，不重跑工具制造另一份可采用结果。只在消费契约指定该结果回到仍有效、未终结的 Run 时，该否决使该 Run 失败，终态由 Session 与 Agent 治理写入。

后台、Run 外、原 Run 已终态或已取消业务的结果，不能沿无条件“工具结果否决则 Run 失败”修改原终态。 正常后台结果仍具合法后续投递资格时，由 Session 按其准入及工作规则承接；本节的否决分支不禁止该正常路径，也不授予否决结果新的任务资格。不能默认挂到后继 Run、造新 Run 或恢复普通入队资格。原结果和账目仍保存，未规定的旁路消息后果交实际消费拥有者明确，不因本规格写满而填默认失败、成功或丢弃政策。

一条会话历史与原工具结果不是同一个权威源。历史是否采用不改变真实执行是否发生；转换或扩展失败也不自动回滚工具操作。执行后位置没有否决真实动作的能力，只能处理已经存在的结果和允许的后续候选。

<a id="tl-v05"></a>
### TL-V05 观察与原结果采用

实际组合须验证无帧、追加、替换、封块和重连快照，过程不进模型上下文且帧失败不单独令执行失败。构造保存失败、确认丢失、扩展否决和消费者替换，分别走先保管后处理及 Tool 仍保管时先完成处理的两条可靠交接路径；原结果始终有责任者，不重复逻辑承接或效果。 另构造原 Run 正常完成且 Session 未归档的后台成功结果，核对仍合法的投递可经 Session 形成后继工作，保留原调用且不复活原 Run；与已归档、投递资格撤销及转换否决分支分别验证。实际模型不可读图片或转换失败须保原件与原因；仍有效未终结 Run 和原 Run 已终态分别验证失败后果，不能修改旧终态或造后继 Run。

<a id="tl-v06"></a>
### TL-V06 全文与真实账目

验证作者摘要与机械首尾占位、保存失败、原附件地址、分页新返回和读取资格收窄；归档、压缩、消费及 Model ACK 后仍可在合法资格下取原文，旧占位不改。分别构造暂时不可读、地址失效和不存在，不混成删数据。重复通知和换 attempt 不重计原账，新取回调用记录真实新成本；迟到、未知费用和 dummy 实际处理分别表达。组织账目读取不授成员正文或其他组织明细，独立调用不造 Run。

MODEL-E01 的最终块全集和嵌套投影，以及 TOOL-M04 已展示在途内容故障保留均继续缺项。TOOL-M03 的引用、承接、分页与费用协议未采用、真实存储故障与断电未验证前，不能声明这些边界已实现。
