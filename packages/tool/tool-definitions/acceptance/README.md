# 独立验收

本目录由独立验收者维护跨 Files、Shell 及真实宿主的场景。当前没有本成员独立执行脚本或已通过的验收结论。作者映射的单元用例位于 [tests](../tests/README.md)，不能替代真实执行环境与 Tool 运行时组合验证。

## 允许的内容

独立场景使用公开作者入口及真实消费者，固定输入放在 [fixtures](fixtures/README.md)。实施者可以运行已接受场景，不自行改动验收判据或固定输入来消除失败。

## 边界

当前波由线负责人组织 Windows 同提交组合验证，Linux 最终组合归 Reduce C1。这里不把测试替身、目录存在或类型检查写成后端已通过。

## 维护

首个可执行场景进入本目录时，验收拥有者同时加入成员的验收配置及执行脚本，给出平台前提、真实输出与未覆盖范围。

## 本包事实

当前验收资源为空，尚无可执行 acceptance 配置。已实现行为与限制归 [SPEC](../SPEC.md)，验证准备不改变该状态。
