# 关键流程

## 流程

### 文件修改

参数解析取得已验证字段。作者依路径读取全部原文和版本，计算唯一且互不重叠的范围，然后一次写入或 commitBatch。结果分别渲染设施确认和计划 diff。发生未知时宿主继续观察原批次，作者不重发。

### 命令执行

作者选择 command 或精确 terminal 路径。设施交出 ProcessHandle 后，作者订阅当前 signal，逐流增量解码并持续排空。结果终结后报告原终局与停止确认，移除 signal 监听。终端关闭只在 close_session 明确请求时发生。

## 失败与生命周期

author 在返回前限制整个文本的 UTF-8 字节数。Tool 的独立包装器执行返回屏障。生产结果接收与保管由 Tool 和宿主装配承担，见 [SPEC](../SPEC.md#组合与验证)。
