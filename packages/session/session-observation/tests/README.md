# tests

本目录承载本包适用的持续测试。测试种类的责任与边界见仓库[包级测试责任与边界](../../../../docs/verification.md#包级测试责任与边界)。

## 允许的内容

`*.spec.ts` 测试文件、测试辅助代码 `ports.ts`，以及 `fixtures/` 下的固定输入。

## 边界

`observation.spec.ts` 对着端口的假实现测领域面与定位，不用真实的会话或模型；时间用假的 `wait`，日志用内存里的假日志。两个入口的测试只核对导出面。在正式装配上的用例不在本目录，在服务端应用的测试里。测试通过不代替规格或验收。

## 维护

公开行为或 [SPEC.md](../SPEC.md) 条款变化时，同步对应测试与本目录 `index.md`。全化表里的用例名前缀写在 SPEC 的对照表里，改用例名要同步它。

## 本包事实

现有三个测试文件和一个辅助文件，见 [index.md](index.md)。流这一侧没有用例（第 2 块，未实现）。
