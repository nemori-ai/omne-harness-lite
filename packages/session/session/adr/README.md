# adr

本目录承载有持续消费者的实现取舍与必要理由。

## 允许的内容

每项取舍一份 Markdown 文件。

## 边界

只保留现行理由。单次评审、提案过程与执行日志归任务 tmp，不进本目录。

## 维护

取舍被替换时，更新或删除对应文件，并同步引用它的设计正文。

## 本包事实

现在为空。命令处理器、协调器、调度器、缓存与策略的取舍与理由写在[内部架构](../docs/architecture/README.md#机制与设计理由)与[机制说明](../docs/architecture/mechanisms.md)，行为写在 [SPEC](../SPEC.md)。实现进入后，出现一项有持续消费者、又不属于架构页的取舍时，才在这里加文件，例如缓存条目的淘汰顺序或每会话串行队列的实现方式。
