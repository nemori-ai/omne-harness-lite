# examples

本目录承载面向真实公开入口的使用示例。

## 允许的内容

可运行的示例代码与说明。

## 边界

示例只用公开入口，并写明运行前提。示例不代替测试或规格。

## 维护

公开入口变化时，同步示例并确认它仍能运行。

## 本包事实

现在为空。工厂已进入根入口，但可运行的示例需要一个真实的存储提供者与应用的会话存储组合，两者现在都没有可用的组合。夹具里的 `node:sqlite` 测试提供者不是公开入口，不能当示例。装配与独立使用的职责伪代码在[使用与定位](../docs/context.md#使用方式)里。

示例进入后放在这里：一个不装配 Cordis 的可运行例子，运行前提是本机可用的 SQLite 提供者。它完成：声明组合并执行迁移，构造事务端口，提交一条命令，用 `queryOperation` 认回，再用历史分页读回。示例不用内存替身。
