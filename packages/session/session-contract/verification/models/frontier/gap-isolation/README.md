# GapIsolation

DiscoverGap 关闭共享门而故意不增加 root。旧准备、新解释者和新命令不能仅凭匹配根继续发布。原日志、尾部和修复责任保留。

## 有限前提

一个 Session、两个 execution、一个正常原事实、一个权威缺口、两个正常解释者、一个新命令和一次独立 custody。正常解释、命令、保管及隔离各最多一次。

模型假定原日志不可变、连续，目录完整可验证，单个发布动作原子成立。配置没有搜索深度截断，并关闭 deadlock 检查。进展需要有限相关历史、材料最终可读、公平调度与最终提交机会；本资源不证明无条件活性。

## 覆盖边界

诊断读取及查询仅在原授权有效、答案可读时成立。没有持久隔离、重启、修复、解除权限或完整命令面的证明。

源文件 [GapIsolation.tla](GapIsolation.tla)、[cases.json](cases.json) 与 cfg 保留采用字节或明确的元数据分区映射。具名负控、见证及正控的精确目标见[配置目录](../case-catalog.md)。复跑参数、测量自检和证据含义见[总入口](../README.md)，实现接续义务见[动作映射](../mapping.md)。
