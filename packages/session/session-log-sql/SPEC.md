# SQL 会话日志提供者

本包实现 [Session Log 公共承诺](../../core/session-log/SPEC.md)。公开形状归根入口；Cordis 装配归 `./cordis`。本页仅约束提供者的存储、并发和资源行为。交付评审尚未完成。

## 存储与当前授权

工厂必须收到同一 `AtomicStorage` 实例、绑定该实例的 `LogAuthorityOperations` 和正安全整数 `operationLimit`。迁移通过 `sessionLogMigrations` 安装。存储由应用拥有；本包不关闭它。Cordis 装配时，提供者在真实 atomic unit 中核验注入 Storage 面与授权源的稳定 Storage 身份属于同一实例，再以该稳定身份建立物理拥有者；不同代理本身不构成不同存储，服务键或数据库文件相同也不构成同实例。该实例核验每次挂载执行一次空写事务，使用原存储写队列、锁和COMMIT；它可能因锁等待或存储不可用而延迟或拒绝ready，不写业务行、不发通知、不进入逐次日志操作热路径。每次启动等待结束后、发布服务之前必须核验 fiber 和本行代际资格；撤除或停止后的旧 setup 不得发布服务或成功兑现 ready。同一存储实例至多一个存活的物理日志拥有者。

普通受权借用固定 tenant、session 与物理 ownerGeneration。每次操作在真实 StorageUnit 内核当前授权，拒绝跨租户或跨会话访问。恢复枚举使用独立恢复资格。可信根句柄与 backing 属于应用装配面，不能作为用户授权入口。

journalGeneration 持久保存在日志记录中。提供者重载产生新的物理 ownerGeneration，不改变原日志的 journalGeneration。日志位置按精确整数递增，排序不能先转换为 JavaScript Number。源坐标与固定前缀必须来自同一已提交范围；按键片段不能冒充完整前缀。

## 追加与事务参加

每个会话的写者使用同一存储锁顺序。在锁内核当前授权、尝试栅栏、重复键和提交条件后追加。重复键命中返回 alreadyRecorded；这只说明没有写入本次批次，不证明原完整批次等值。认回原批次须核全部位置、顺序、键、租户和正文。

`appendIn` 仅参加本实例尚可用的 StorageUnit，不独立提交、不发外部 IO。日志与其他参与者由外层统一提交或回滚。可选 expectedSource 必须与锁内读取的完整来源坐标相等。外层提交回执未知时，本包保留原批次身份与全文；调用者也必须保留自己的业务责任。

未知追加不凭一次缺席或最新尾号认定未写。确有原完整批次的持久等值证明才可认回。不能用另一批次、重复键拒绝或物理停止来替代该证明。

## 容量与释放

operationLimit 显式限制各句柄及拥有者的操作数、未决批次和借用数。异步开始之前预留相应名额；达到上限拒绝，不建立无界隐式队列。

借用 release 同步停止该句柄准入，等待已登记操作，并核验未知批次。失败保留责任，重复 release 可继续核验。`drainRaw` 仅排空可信根句柄，后续恢复借用仍由存活物理拥有者提供。

close 先停止物理拥有者准入，再等待已接纳工作。未知提交未认回或借用未释放时必须失败，不能关闭依赖存储或假报已排空。成功后移除该存储实例的存活拥有者登记。存储拥有者必须在所有直接消费者和日志借用排空后才能关闭存储。

StorageUnit 的 observeCompletion 只观测本地提交操作的结束与已知结果。unknown 不证明远端数据库事务已经停止，也不授权重发。

## 验证义务

真实 SQLite 组合须覆盖同提交／全回滚、另一生产参与者、实例与失效 unit 拒绝、当前权限变化、跨租户、tail／fence 竞争、完整原批认回、并发容量、重载代际及借用排空。Cordis 组合须验证注入、服务生命周期与失败清理。有限模型与内存替身不能代替数据库或远端 COMMIT 断连的实际证据。

## 同单元固定前缀读取

participant.readPrefixIn使用原调用者StorageUnit，不另开事务，不独立提交。它与独立readPrefix共用固定代际、完整范围和解码实现，并在原单元核当前权限。后来追加不改变已选完整前缀；缺少范围、错误代际、归属或授权不返回部分成功。读取可以观测该单元的暂存行，这不证明提交。外层调用者保留单元的提交／回滚／未知责任。已接纳读取登记到日志拥有者的排空集合；关闭停止新读取并等原读取结束。
