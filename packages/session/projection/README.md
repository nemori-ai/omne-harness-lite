# @omne-harness-lite/session-projection

Session projection registration and folding.

This private source fork is a starting point for further development, not an implementation
of the accepted product capability contracts. Public entry: `@omne-harness-lite/session-projection/baseline`.

Build in the repository with `pnpm --filter @omne-harness-lite/session-projection... build`; tests use compiled
artifacts. Dependencies belong to this manifest; consumers use exported package entries.

The accepted baseline implementation design is maintained in [design.md](design.md);
the target provider remains unimplemented.

[package layout](../../../docs/proposals/core-capabilities/fork/package-layout.md),
