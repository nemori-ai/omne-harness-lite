# verification/models

本目录承载本包的形式模型，例如 TLA+、Alloy 或 SMT 模型。

## 允许的内容

模型源文件、配置与说明。

## 边界

说明模型对应的 `SPEC.md` 条款、抽象前提与未覆盖的部分。模型通过不等于实现符合。

## 维护

承诺或实现结构变化时，复核模型的抽象是否仍然成立。

## 本包事实

现在为空，也没有立项。本成员的性质是装配与生命周期的次序，例如撤除的四步、换代时新旧实例可能并存、每租户只绑定一个扫描者。它们依赖 Cordis 的具体行为，用真实 Cordis 上的测试验证比抽象模型更直接。

将来要换成多实例、为每租户一个扫描者定义租约协议时，那份协议适合用模型检查，模型随协议的拥有者放置（[SPEC 的明确缺项](../../SPEC.md#明确缺项)）。具名维护者由负责人指定。
