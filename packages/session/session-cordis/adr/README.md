# adr

本目录承载有持续消费者的实现取舍与必要理由。

## 允许的内容

每项取舍一份 Markdown 文件。

## 边界

只保留现行理由。单次评审、提案过程与执行日志归任务 tmp，不进本目录。

## 维护

取舍被替换时，更新或删除对应文件，并同步引用它的设计正文。

## 本包事实

现在为空。只 inject 事务端口、用本插件 Context 现取端口、本成员派发提交通知、扫描者在首次见到租户时绑定、撤除限时等待，这几项取舍与理由写在[内部架构的关键机制与理由](../docs/architecture.md#关键机制与理由)，行为写在 [SPEC](../SPEC.md)。实现进入后，出现一项有持续消费者、又不属于架构页的取舍时，才在这里加文件，例如跳过本插件自己派发的通知用什么判据。具名维护者由负责人指定。
