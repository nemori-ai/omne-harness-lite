# examples

本目录承载面向真实公开入口的使用示例。

## 允许的内容

可运行的示例代码与说明。

## 边界

示例只用公开入口，并写明运行前提。示例不代替测试或规格。

## 维护

公开入口变化时，同步示例并确认它仍能运行。

## 本包事实

现在为空。两个入口都没有导出，没有可运行的示例。插件树里的一行与独立使用的写法在[使用与定位](../docs/context.md#使用方式)里，只说明形状，不能运行。

插件实现之后，在这里加一个最小装配示例：装载一个事务端口的替身、一份内部主体与本插件，以一个调用方类调用一个面，再卸载插件观察撤除顺序。具名维护者由负责人指定。
