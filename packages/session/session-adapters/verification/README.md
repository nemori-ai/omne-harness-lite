# verification

本目录承载本包的持续验证资源：模型、论证或证明。

## 允许的内容

`models/` 下的形式模型，`proofs/` 下的论证或证明，以及说明文件。

## 边界

每份资源说明所验证的性质、前提、运行命令、覆盖与限制。单次运行的原始输出留任务 tmp，不进本目录。

## 维护

被验证的承诺变化时，同步模型、证明与本目录 `index.md`。

## 本包事实

现在为空，`models/` 与 `proofs/` 都没有资源。本成员的验证义务列在 SPEC 的[组合与验证](../SPEC.md#组合与验证)，都按场景由测试承担，见 [tests/](../tests/README.md)，目前没有测试覆盖这些义务。表中没有要求哪条义务必须用模型或证明验证。共同提交、认回与恢复的行为模型归 Session 契约的验证义务，不在本成员。
