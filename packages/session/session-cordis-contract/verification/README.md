# verification

本目录承载本包的持续验证资源：模型、论证或证明。

## 允许的内容

`models/` 下的形式模型，`proofs/` 下的论证或证明，以及说明文件。

## 边界

每份资源说明所验证的性质、前提、运行命令、覆盖与限制。单次运行的原始输出留任务 tmp，不进本目录。

## 维护

被验证的承诺变化时，同步模型、证明与本目录 `index.md`。

## 本包事实

现在为空，`models/` 与 `proofs/` 都没有资源。本成员的验证义务列在 SPEC 的[实现与验证](../SPEC.md#实现与验证)和 Cordis 说明的[验证义务](../docs/cordis.md#验证义务)。这些义务由测试承担，见 [tests/](../tests/README.md)。本成员没有并发或故障语义，所以现在不需要模型或证明。Cordis 机制读数的依据在 Cordis 说明的[机制读数与假设](../docs/cordis.md#机制读数与假设)，不在本目录。
