# 进程这一层装配的三个模型

规则归包组规格的[应然设计](../../SPEC.md#应然设计)与[不变式](../../SPEC.md#不变式)。模型在 `models/`，每份配置的预期登记在 [models.json](models.json)，由 [check.py](check.py) 判读，命令是成员目录下的 `pnpm run verify:formal`（要 `TLA2TOOLS_JAR`）。只跑一个模型时加 `-- --models MCSwap` 这样的入口模块名。

有限检查是模型检查，不是归纳证明，也不是源码符合性。每个模型是一个小世界，上界写在它的入口模块（`MC` 开头的那一份）与各配置里。活性都带着弱公平的假设：能一直做的一步终会做。环境捣乱的次数用 `MaxLoss`、`MaxSwitch` 界住。

配置的名字里带 `bad-` 的是负控：故意破坏一条规则，预期命中写明的那条性质。其余是正控，预期跑完没有错误。

## Swap：一行的换代

小世界：一行的三代，其中第 2 代启动就失败；两次调用。规则对应[行的换代：一代的全化表](../../SPEC.md#行的换代一代的全化表)。

| 性质 | 规格规则 |
| --- | --- |
| `OneServing` | AS-14：同一时刻至多一代在服务 |
| `NoGap` | AS-14：有过一代进入服务之后，总有一代在服务；新的起不来时旧的照常 |
| `NoLateAdmit` | AS-13：新的调用不落到不在服务的一代上 |
| `NoOrphan` | AS-13：在途的调用钉着的那一代还在服务或正在撤下 |
| `Settles`（活性） | 正在撤下的一代终会撤完；备着的一代终有结局 |

| 配置 | 规则 | 预期 |
| --- | --- | --- |
| `swap-holds` | 新的启动成了再一步换；只进在服务的一代；等在途的做完；新的起不来旧的照常 | 通过 |
| `swap-bad-break-first` | 先撤旧的再升新的 | `NoGap` 违反 |
| `swap-bad-admit-retiring` | 正在撤下的也接新调用 | `NoLateAdmit` 违反 |
| `swap-bad-drop` | 不等在途的就撤完 | `NoOrphan` 违反 |
| `swap-bad-fail-drops-old` | 新的起不来时旧的已经撤了 | `NoGap` 违反 |

## Supervise：一行坏了之后

小世界：三行一条依赖链（会话行依赖存储行，接入行依赖会话行）；运行中至多没了两次；连着起不来两次到上限。规则对应[监督与期限](../../SPEC.md#监督与期限)与[监督者](../../SPEC.md#监督者)。

| 性质 | 规格规则 |
| --- | --- |
| `NoHang`（活性） | AS-16：总会回到全部在服务，或明确地停在那里 |
| `NoZombie` | 一行在服务时，它依赖的行都在服务；一行回来的次序跟着依赖走 |
| `OnlyDeclaredRerun` | 没声明能重跑的行不被重跑，只能换进程 |
| `HeldAfterLimit` | 停下只发生在连着起不来到了上限之后 |

| 配置 | 规则 | 预期 |
| --- | --- | --- |
| `supervise-heals-or-restarts` | 存储行与会话行会没了；只有接入行声明能重跑；启动失败带原因退出 | 通过 |
| `supervise-all-rerun` | 同上，会话行与接入行都声明能重跑 | 通过 |
| `supervise-broken-version-held` | 会话行这一版启动就失败 | 通过：到上限后停下 |
| `supervise-bad-hang` | 会话行启动就失败，启动失败挂着不退 | `NoHang` 违反 |
| `supervise-bad-rerun-any` | 不看声明都重跑 | `OnlyDeclaredRerun` 违反 |

## Versions：版本目录与指针

小世界：三个版本，第 1 版出厂即装好并起稳过，第 2 版起来就倒；连着倒两次退回；至多切三次。规则对应[版本目录、指针与戳](../../SPEC.md#版本目录指针与戳)。

| 性质 | 规格规则 |
| --- | --- |
| `PointerComplete` | AS-20：指针只指向一份完整装好的版本 |
| `PrevSettled` | AS-20：退路总是一份起稳过、装完的版本 |
| `Recovers`（活性） | AS-20：一份坏的版本不会让系统永远起不来 |

| 配置 | 规则 | 预期 |
| --- | --- | --- |
| `versions-recover` | 只切到装完的；连倒到上限退回上一份起稳过的 | 通过 |
| `versions-bad-switch-partial` | 装到一半的也切 | `PointerComplete` 违反 |
| `versions-bad-no-rollback` | 不退回 | `Recovers` 违反 |

实现比模型记得少，两处不同，都在安全的一侧：

- 模型给每一版记「起稳过」；指针文件只记上一份定下的那一版。一版以前定下过、现在既不是指针指着的也不是退路，实现里再切到它时算试用中。
- 模型里一份起稳过的版本倒了可以一直再拉（`Recovers` 的前提是起稳过的版本不是坏的）；实现里监督者对它也数连着倒下的次数，到上限就停下并写明。
