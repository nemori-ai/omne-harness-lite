# Trying a Skill

Try the Skill right after you publish it, in the same session. A try answers three questions.

1. **Is it found?** Search with two or three ways that a user would ask for this task. The Skill should be on the first page each time. When it is not, change the description: add the words that the user used.
2. **Is it followed?** Do a real task with it. Read the body and follow it as written, step by step. Each place where you had to guess is a gap in the body.
3. **Is the result right?** Compare the result with what the user said a good result looks like. When they differ, find the step that led away and fix that step.

## What to note

For each try, note:

- the request you tried
- whether search found the Skill, and its place in the results
- each place where you hesitated, guessed or went wrong
- what you changed because of it

Show these notes to the user with the result.

## When to stop

Stop when two tries in a row need no change. Stop also when the user says the Skill is good enough. A change after that is a new version: publish it with a new id.
