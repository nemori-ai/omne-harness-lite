# tests

本目录承载本包适用的持续测试。测试种类的责任与边界见仓库[包级测试责任与边界](../../../../docs/verification.md#包级测试责任与边界)。

## 允许的内容

`*.spec.ts` 等测试文件、测试辅助代码，以及 `fixtures/` 下的固定输入。

## 边界

说明每类测试用到的真实依赖与替身。测试通过不代替规格或验收。

## 维护

公开行为或 `SPEC.md` 条款变化时，同步对应测试与本目录 `index.md`。

## 本包事实

测试是单元与契约测试，经包名从 `dist/` 导入本包，所以先运行 `pnpm run build`。端口套件对 `./testing` 的内存替身运行，替身通过不证明真实来源或读取权。`conformance.spec.ts` 还对故意泄露身份的替身在进程内跑套件，核对恰好无披露用例失败。测试与 SPEC 义务的对应见 [SPEC「持续验证」](../SPEC.md#持续验证)。
