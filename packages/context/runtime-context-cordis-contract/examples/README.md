# examples

本目录承载面向真实公开入口的使用示例。

## 允许的内容

可运行的示例代码与说明。

## 边界

示例只用公开入口，并写明运行前提。示例不代替测试或规格。

## 维护

公开入口变化时，同步示例并确认它仍能运行。

## 本包事实

现在没有独立示例文件。两个入口已实现；真实 Cordis 的可运行装载与调用示例在 tests 中。依赖方的写法片段在[使用与定位](../docs/context.md#使用方式)里。提供者 runtime-context-cordis 进入后，这里可以放一个可运行示例：装载提供者，一个生产者插件登记，一个消费者插件 `bind` 并读取。
