# adr

本目录承载有持续消费者的实现取舍与必要理由。

## 允许的内容

每项取舍一份 Markdown 文件。

## 边界

只保留现行理由。单次评审、提案过程与执行日志归任务 tmp，不进本目录。

## 维护

取舍被替换时，更新或删除对应文件，并同步引用它的设计正文。

## 本包事实

现在为空。撤除写在一个 effect 里、作用域每次调用时读取、策略选择失败即加载失败、渲染结果随登记一起撤除、不为每次请求开运行对象，这几项取舍的理由写在[内部架构](../docs/architecture.md#关键机制与理由)。实现进入后，出现一项有持续消费者、又不属于架构页的取舍时，才在这里加文件，例如插件导出的形式或策略实现的登记方式。
