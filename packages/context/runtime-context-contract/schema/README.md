# schema

本目录承载本包对外的 Schema、稳定身份与发布消费说明。

## 允许的内容

JSON Schema 文件与说明。

## 边界

没有 Schema 文件就表示没有发布 Schema。Schema 的身份不随目录搬迁而改变。发布范围由对应责任明确声明。

## 维护

Schema 变化时，同步消费者、示例与验证资源。

## 本包事实

现在为空，本成员不发布 Schema。公开形状由 `src/` 的 TypeScript 类型表达。块的值、参数与需要的形状用 Standard Schema 表达，校验器由语义拥有者或消费者在自己的包里给出，不在本目录。

独立入口的字节编码现在未定（[RC-01](../SPEC.md#rc-01-消费者身份与范围)）。编码确定并决定对外发布 Schema 时，本目录才会有内容。
