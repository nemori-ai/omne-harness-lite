# Runtime Context 源码

根入口 [index.ts](index.ts) 重导出值类型、三面八操作的操作类型、两个权威端口的类型、恢复会话的类型与八个纯操作。模块和阅读路径见 [index.md](index.md)。

`testing/` 提供框架无关的用例列表（核心、扩展、权威、恢复四组）、可编排的权威端口替身与非耐久替身。只有测试辅助持有状态。非耐久替身按世界状态、持有者面、生产者面、读者面与恢复会话分文件，`memory.ts` 只做组装。根入口不导入 Cordis、存储或生产机制。

精确公开签名归源码，行为归 [SPEC](../SPEC.md)。修改导出时同步公开接口页和导出清单。
