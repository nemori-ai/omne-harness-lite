# adr

本目录承载有持续消费者的实现取舍与必要理由。

## 允许的内容

每项取舍一份 Markdown 文件。

## 边界

只保留现行理由。单次评审、提案过程与执行日志归任务 tmp，不进本目录。

## 维护

取舍被替换时，更新或删除对应文件，并同步引用它的设计正文。

## 本包事实

现在为空。服务只承载登记面、作用域由装配声明、事件只做失效提示、策略选择是配置，这几项取舍的理由写在[内部架构](../docs/architecture.md#关键机制与理由)，登记协议写在 [Cordis 说明](../docs/cordis.md#登记与撤除协议)。实现进入后，出现一项有持续消费者、又不属于这两页的实现取舍时，才在这里加文件。
