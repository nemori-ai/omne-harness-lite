# request-context 长期行为候选

状态：候选、待用户确认。目标成员为 `context/request-context`，不是实际包。本规格拥有派生输入、模态与预算的必要行为，不选择签名、Provider、存储、压缩算法、协议或数值。

产品输入归[运行感知与一次请求](../../../.meta_harness/design/product/runtime-context/design.md)，供给保证归[runtime-context](../runtime-context/SPEC.md)，跨成员交接归[领域架构](../../../docs/domains/runtime-context/architecture.md)。

## RQ-01 调用方与计算边界

主流程、压缩、扩展及独立调用可以消费本能力，每次给出明确用途、合法输入范围与原消费位置。Session 路径保留适用租户、Session、Run、attempt 及原调用关联；独立消费不创建隐式 Session 或 Run。

本能力派生候选请求，不直接修改原历史、原块、注册或当前权限，不拥有 Model 执行寿命与外部效果。最终发起协调者负责一致读取、发出前资格、接收方、实际绑定与固定采用。本能力成功表示按明确输入完成计算，不表示请求已发出、结果已承接或动作已获准。

一次请求的固定采用写在调用登记上，不另建一条上下文事实。压缩只追加压缩消息，不改原历史。发出之后的寿命归模型调用。系统提示词每次求值，不进入会话历史。

纯计算可以只处理调用方提供的数据。读取系统托管历史、引用、模型档案或其他资源时，实际集成方按原来源契约兑现身份、资格及保留责任，不因未运行 Cordis 而绕过。公开独立入口与支持范围尚待形状设计。

## RQ-02 组装的前置输入

一次组装取得当前合法系统提示词规则、适用可靠历史、工具声明及匹配绑定、模型可读 Runtime Context、有效 ModelProfile、参数和适用模态表示。各项来源、范围及实际采用依据可追溯，不从当前连接或最新消息反推归属。

系统提示词每请求求值，单独计量，本候选只含文本，不保存为历史 SystemMessage，也不靠压缩删除固定要求。Skill 取用和命令展开沿自己的原路径进入历史，不偷换为长期系统设定。

这次需要承接的普通新输入与相关历史消息先完成可靠保存，再组装。确认持久边界含进程崩溃、OS 崩溃和断电；内容引用也满足所需可恢复性。只在内存队列到达或读到未确认消息不满足前提。

工具声明与实际合法绑定一致，ModelProfile 及参数属于明确有效采用范围。来源并发更新时不能拼旧档案、新 schema、旧实现成从未合法成立的请求。需要共同版本边界的部分由最终协调者保护，精确快照与复核机制未选定。

来源不可用、无权、缺项、格式不受支持及提交未知可辨。依赖未满足时不生成冒充完整合法输入的空白成功，不为方便改用其他租户内容或秘密。必要数据恢复资格不足时仅暂停依赖部分。

## RQ-03 历史与块投影

模型侧只取明确标为模型可读且满足当前资格的块，再按有效压缩关系计算派生排除。人侧与模型侧标注独立，常态消息类型表不代替实际块标注。缺失或不明确标注不进入模型请求。

ToolInternalMessage 始终在模型请求前排除，不提供配置绕过。未收齐工具参数不解析执行，残缺调用可按原规则留历史备查，但派生请求剔除该调用，不改原件或原消息。

用户叫停且已有交付内容，按原消息形成规则保留标为中断的消息，模型侧剔除不完整调用。无内容不造空回复。出错已交付内容沿原调用记录可查，不冒充完整回复；正常达到输出上限的消息沿实际收场形成。中断原因提醒由原消费路径追加，不能凭缺少回复让 Agent 猜原因或重做效果。

消息来源不用正文标记解析，状态和事件提醒均追加且保留实际感知链。未经过合法压缩，不能先按“同一块只取最新提醒”再筛一道。首次及压缩后纳入当前合法完整 Context，工具或扩展私有块不因补全路径进入模型。

人侧历史查询及实时交付由会话与交付面承接，复用同源块标注规则。最近一段、按最早点向前追加与按最新点接新内容分别可辨，读者加载进度不写回历史。模型预算不删人侧原件，本成员不凭本规格新增分页公开操作。

## RQ-04 模态与可追溯表示

文字、图片和语音为当前明确支持目标，不要求每个模型支持全部。实际媒体类型决定内容模态，文件块是引用载体，不自动代表模型可读的文本。图片、语音、附件及派生表示全部按真实发送内容处理。

选用有效模型可接纳的原件、派生表示或 transcript。多种表示都可用时消费明确策略，不静默丢弃不相容内容。转换件保留原块关联与来源，不覆盖原始内容或原可见性，也不绕过原权限。模型未提供的内部推理不能补造。

必要转换的缺少能力、执行失败与表示不存在分别报告。消息准入失败不删除原结果，不能用空文本或猜测 transcript 当成功。带模型读取标注的非文本块或文件参与该转换，包括同时供人和模型读取的内容。纯文本及只供人读取而没有模型读取标注的块，不受不适用转换件否决。适用转换在消息准入前完成，不因当前模型能读原件而跳过。准入后派生表示及 transcript 固定，不随转换件更换改写。请求只消费这些表示；具体操作边界沿实际契约设计，纯派生请求本身不暗写原历史。

转换件的选择键、媒体类型优先、合法输出、原块关联及本地转换范围消费 [Model 转换件共同契约](../../model/model/docs/profile-and-modality.md#转换件的共同契约)，本规格不另定转换件协议。接纳路径依该契约区分未登记与已登记但失败，并保存接纳时固定的表示及来源；Request Context 只读取其合约结果。未登记而准入的无 transcript 原块仍参与相应历史模态约束。

转换不承诺无损，交付面须能说明本次模型读取的是哪份表示。实际模型不支持文本等必要表示时仍按真实能力判断，不能从 transcript 存在推出所有在册档案都可选。

历史模态约束只纳入模型可见且无 transcript 的相关历史块，文件按实际媒体类型判断。约束在固定候选及能力条件下只收紧，不推出动态配置下合法模型永不扩大。压缩排除不改原可见性，也不据此声称历史模态约束消失。Model 拥有合法候选与切换判断，本成员消费其有效档案及检查实际可读输入。

Tool 可以产图。最终允许块全集及嵌套投影缺源延续 MODEL-E01，不能把过程帧列表当最终语法或发明递归协议。实际读到的模型可读模态仍检查，未知分支不冒充兼容或已完整闭合。

## RQ-05 完整预算与候选完成

预算计入全部系统提示词、适用历史、提醒、工具定义和最终选择的实际模态内容，含完整 Context 及实际提供者映射的必要表示。不能只计最新用户文本或忽略工具 schema。

ModelProfile 提供已知有效上下限。字节、图片数等精确约束实际检查，token 使用适用计量与明确余量估计。未知上游限制报告未知，不伪造数值或默认通用 SLO。实际物化、模态读取和转换成本不能因缓存命中而从资源计量消失。

候选交回时符合目标模型限制，或明确失败并解释原因。固定部分超限与合法压缩后仍超限分开，必要档案或限制未知与确实超限也分开。具体失败类型由后续公开契约维护，不以一个成功布尔隐藏缺项。

## RQ-06 压缩共同结果与保护边界

是否压缩、如何压缩及能否装入窗口由请求计算承接。Agent Loop 消费装得下或明确失败，不额外拥有预算策略。硬限额先满足，再兼顾前缀一致、信息保留与长度，不将前缀优化当任意变化后逐字不变保证。

压缩只处理允许的会话历史内容，追加 CompactionMessage，共同保存摘要及被排除原块身份名单。它不覆写块、不改人侧或模型侧原标注、不删任何原历史。摘要与名单不能分别提交成无法解释的半份压缩事实。

上次模型请求之后未读新输入不压，未结人工等待与后台执行占位不被排除。什么属于未结工作由 Session 与原执行拥有者判断，请求计算不能凭界面不可达或查询失败认定已经结束。

已有摘要可以再次进入合法压缩，保护上界仍以原模型读取依据判断。相关全部有效压缩记录共同决定可读集合；较早未排除块仍可纳入，不能机械截取最后摘要之后。缓存可保存派生集合，但输入范围与失效必须完整。

压缩成功后补入完整合法 Runtime Context，再计全部输入限制。该当前数据不是可删旧历史提醒的替代源，也不在摘要与排除名单的原消息处理范围内。补入后仍超限必须失败，不能只检查摘要长度就声称成功。

压缩内部模型调用有独立原调用身份、真实结果和费用，回到原压缩消费位置，不直接形成主流程 AssistantMessage。Agent 换代认回原调用，按 Model 契约先完成处理，或先可靠保存结果或有效引用及接续位置，再确认消费；Model ACK 清理不使接续依赖已释放全文。

## RQ-07 扩展修改、发起与固定采用

模型前扩展作用于尚未发出的候选，改内容、参数或日志后，必要重组装或重新校验预算、合法绑定、资格及实际接收方。同一次经过不再次触发这个扩展位置，避免改写后无限自触发。

最终发起协调者固定实际模型、参数、历史范围、Context、工具声明与绑定及足以解释输入的采用依据，发出前确认当前发起条件。发起之后的定义、权限或 Context 变化不回写该请求；未来动作独立判断当前资格。

派生完成不等于发出成功。发出或提交未知回原协调与 Model 调用身份对账，查询不可用不证明原执行丢失。本成员不自动重发、不新建相同调用、不因恢复重记原费用。

## RQ-08 失败、否决与消费位置

固定部分超限或合法压缩后仍超限，返回明确失败及原采用范围。会话路径按消费契约指定的仍有效未终态 Run 失败并上交，保留 Session、历史、设置和已有结果。原 Run 已终态时不能反转，条件不变不无限新建 Run 重做。

独立计算或调用向其调用方返回失败，不暗造 Run 或 Session。不默认分叉、删历史或换模型。合法条件后来改变时，新工作沿现有入口判断，不复活失败原 Run。

外部输入准入或转换否决告知发送方，不形成该会话消息。模型回复否决保留真实收场及否决原因，不交模型故障重试策略；仍有效原工作按适用退避继续。连续否决不设次数上限，不因此使 Run 失败。具体设置与推进由 Agent 拥有。不能以此修改终态或取消后的工作资格，独立或旁路结果沿自己的原消费契约。

Tool 结果准入或转换否决前，Tool 与原合法消费方可靠保管原结果及消费关联。否决使明确消费契约指定的仍有效未终态 Run 失败。后台、Run 外和原 Run 已终态时，不能改旧终态、挂无关后继、造 Run 或恢复取消后的入队资格。旁路具体后果缺项交原拥有者，不填默认。

原结果保留后，重试派生或转换不等于重跑外部工具。已有扩展判断、模型调用及副作用按原身份接续，不能简单重跑有副作用函数。合法消费者失去资格后停止新交付，保管与未结责任仍由原生产方或获准接手者承担。

## RQ-09 取消、恢复与迟到

取消组装结束其待处理计算和订阅，不证明压缩内部模型已经物理停止，不撤销已提交摘要或外部效果。业务取消沿原 Run 或独立调用控制协议传播；释放本地资源不等于取消原执行。

归档使会话业务取消生效并解除等待。原独立执行仍可能收场与收费，迟到结果回原身份及消费位置，不恢复入队或推进。撤销归档不重启旧请求。成本未知保留未结责任，不编零。

已确认保存的普通事实、压缩共同结果、固定采用及承接位置跨进程崩溃、OS 崩溃和断电保留。恢复区分原采用、当前条件与派生缓存；缓存失效可重建，但不能用最新值假装原请求，也不能照搬旧允许。物理损毁及恢复开放政策不在本规格补定。

已展示在途内容的故障保留机制仍缺项。收场后 ACK 与持久确认不能证明在途每片耐久，本规格不授权丢失，也不要求未经决定的逐片同步落盘。

## RQ-10 性能、缓存与观测

派生可读集合、历史索引和稳定前缀可缓存。每份缓存标明日志范围、有效压缩记录、模型与表示条件、注册、权限及全部影响结果的输入，随相应变化失效。相同明确规则及输入派生结果一致，不把纯计算解释为禁止缓存。

超长历史不能让每次当前准备重扫全部历史；按需要建立可重建索引与增量计算。结果物化、全文、模态读取、转换和发送成本仍与实际读取量有关。冷加载、连续追加、压缩、Context 变化与模型切换分别度量，不编规模、延迟或算法。

诊断可追踪来源、采用范围、被排除身份、表示选择、实际预算、失败位置及恢复责任。遥测不默认发送原正文、秘密、图或附件地址。实际接收方、目的和外传资格单独核对，脱敏失败与发送缺口可辨。

## RQ-11 持续验证与未覆盖

后续成员及真实组合至少持续验证以下行为。

| 场景 | 必须检查的结果 |
| --- | --- |
| 新输入可靠保存后组装 | 采用范围能恢复，未保存内容不提前发模型 |
| 混合标注与 ToolInternalMessage | 私有、未标注及过程内容不外发，原件保持 |
| 混合模态及不同模型 | 原件、派生与 transcript 选择可追溯，全预算含实际内容 |
| 最后摘要以前仍有有效块 | 不因位置截断丢块，全有效压缩关系参与 |
| 未读输入、未结等待与后台占位 | 压缩保护仍在，原事实和全文不丢 |
| 压缩后完整 Context | 当前合法全量重新纳入并再次计量 |
| 模型前扩展改变参数、内容或日志 | 重组装或复核最终结果，同次位置只触发一次 |
| 固定部分或合法压缩后仍超限 | 原因分别可查，历史保留，不换模型或造 Run |
| 后台结果转换失败且原 Run 终态 | 原结果保留，不改旧终态，不挂后继，不复活资格 |
| 压缩结果交接、ACK、清理失败和 Agent 换代 | 原消费位置接续，已释放模型副本不再被依赖，不重发调用或重计原账 |
| 变更与读取、固定、撤权竞争 | 一致合法采用可解释，旧缓存不扩大外传 |
| 普通故障与超长历史 | 持久声明有相称故障证据，缓存与无缓存同输入一致，实际成本可测 |

MODEL-E01、在途耐久兑现、精确类型、模型限制计量、余量、表示策略、压缩算法、同提交与一致读取、公开失败集合及旁路消费协议尚待设计。依赖这些缺项的实现和完整闭合声明受限，既有保证继续约束。

本规格没有运行实现或性能测试，不证明真实接口、隔离、断电耐久、模型兼容或外传正确。候选、自检、独立审阅和实施接受分别判断。

#### RQ-VJ04 两侧历史及中断

对应 [RC-J04](../../../.meta_harness/design/product/runtime-context/design.md#rc-j04)及 [RC-F04](docs/key-flows.md#rc-f04)。用人侧与模型侧四种标注组合、未标注块、ToolInternalMessage 和残缺工具调用核对派生集合，原件保持。中断分别覆盖已有交付内容及无内容，核对中断事实、没有空回复、残缺调用不执行。由 Session 与交付面验证最近段、向前读取与新记录到达不改变历史，取消翻阅或播放不取消原业务。已展示在途故障的保留验证仍受 CONTEXT-M03 限制，不能标为已通过。

<a id="rq-vj05"></a>
#### RQ-VJ05 转换接纳与来源失败

对应 [RC-J05](../../../.meta_harness/design/product/runtime-context/design.md#rc-j05)及 [RC-F05](docs/key-flows.md#rc-f05)。复用 Model 共同契约样本，核对文本和仅人侧块跳过不适用转换，适用非文本即使模型可读原件仍先转换，准入后表示固定且原件不变。区分无件、已登记不可用、不合约输出及准入否决，检查输入拒绝、模型回复有界否决及 Tool 原结果保管三种后果。后台 Tool 结果在旧 Run 终态后失败，不挂后继或造 Run。取消与接续不重跑外部效果。MODEL-E01 的最终块全集和嵌套样本未闭合前，不能宣称全结果覆盖。

#### RQ-VJ06 完整组装、扩展与发出未知

对应 [RC-J06](../../../.meta_harness/design/product/runtime-context/design.md#rc-j06)及 [RC-F06](docs/key-flows.md#rc-f06)。在可靠保存前阻止会话新输入进入组装，核对逐请求文本系统提示词不写成历史消息。交错档案、工具声明、绑定和 Context 更新，采用范围不能出现从未合法成立的拼接。扩展分别改参数、内容及接收方，复核完整预算和当前资格，同次扩展位置只触发一次。精确限额与 token 估算及余量分别检查，缺依据不能通过。发出结果未知按原调用查询，不重发；纯独立计算不创建 Session 或 Run。取消计算不冒充原 Model 已停止。

<a id="rq-vj07"></a>
#### RQ-VJ07 压缩保护、全预算与内部调用接续

对应 [RC-J07](../../../.meta_harness/design/product/runtime-context/design.md#rc-j07)及 [RC-F07](docs/key-flows.md#rc-f07)。构造最后摘要前仍有有效块、未读新输入、未答等待及未结后台占位，核对全有效压缩关系及保护集合。摘要和精确原块 refs 共同保存，模拟中间失败不能暴露半份有效压缩事实。补全合法 Context 后再计完整预算，分别覆盖固定部分超限、压缩后仍超限和限制未知。失败只作用于原消费契约指定的有效未终态工作，历史保留且独立路径不造 Run。内部模型接续验证先处理后 ACK、先保管后 ACK 两条合法路径，清理后不依赖已释放全文，不重发、不重计账，不把压缩结果当主回复。

<a id="rq-vj08"></a>
#### RQ-VJ08 固定采用、取消与恢复

对应 [RC-J08](../../../.meta_harness/design/product/runtime-context/design.md#rc-j08)及 [RC-F08](../docs/key-flows.md#rc-f08)。已确认的历史、共同压缩、固定采用和消费位置分别取普通故障证据。恢复时最新值不能替代旧采用，旧允许不能替代当前授权，失效缓存重建后与同输入无缓存结果一致。取消、归档、旧 Run 终态后迟到内容与费用保留原关联，不恢复推进，撤销归档不重启旧调用。已展示在途内容继续保留待兑现及待验证边界。

<a id="rq-vj09"></a>
#### RQ-VJ09 成本与诊断依据

对应 [RC-J09](../../../.meta_harness/design/product/runtime-context/design.md#rc-j09)及 [RC-F09](../docs/key-flows.md#rc-f09)。冷加载、连续追加、压缩、Context 变化与模型切换分别核对缓存输入范围、覆盖和失效，记录历史扫描、模态读取、转换、物化及发送的实际成本。诊断能关联原块、表示、排除身份、预算及失败位置；账目资格不带正文资格，遥测和接收方变更不绕外传检查。规模和性能目标未采用前只报告测量条件及缺项，不宣布达到目标。
