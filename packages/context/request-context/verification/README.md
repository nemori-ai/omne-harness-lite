# verification

本目录承载本包的持续验证资源：模型、论证或证明。

## 允许的内容

`models/` 下的形式模型，`proofs/` 下的论证或证明，以及说明文件。

## 边界

每份资源说明所验证的性质、前提、运行命令、覆盖与限制。单次运行的原始输出留任务 tmp，不进本目录。

## 维护

被验证的承诺变化时，同步模型、证明与本目录 `index.md`。

## 本包事实

现在为空，`models/` 与 `proofs/` 都没有资源。本成员的持续验证场景列在 SPEC 的[组合与验证](../SPEC.md#组合与验证)，由测试承担，见 [tests/](../tests/README.md)。有缓存与无缓存同输入同结果、按组失效只重算对应层，这两条覆盖的输入组合很多。只靠测试不能覆盖足够的组合时，才在这里加入模型或论证。
