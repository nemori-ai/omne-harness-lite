# tests

本目录承载本包适用的持续测试。测试种类的责任与边界见仓库[包级测试责任与边界](../../../../docs/verification.md#包级测试责任与边界)。

## 允许的内容

`*.spec.ts` 运行测试、`*.spec-d.ts` 类型测试、测试辅助代码，以及 `fixtures/` 下的固定输入。

## 边界

本成员与 Cordis 无关，测试直接调用工厂，不装载 Cordis。历史源读口、计量端口与转换件结果端口用测试内的替身，因为它们的真实实现归历史持有者与 Model。替身要能前进修订、返回「epoch 已变」与不可用，才能覆盖失效与失败的场景。持久化、共同提交、模型发送与真实协调者、持有者的端到端组合不在本目录。测试通过不代替规格或验收。

## 维护

公开行为或 SPEC 条款变化时，同步对应测试与本目录 `index.md`。工厂进入根入口时，同一次修改要更新导出测试。默认值改变时，同步核对默认数值的测试。

## 本包事实

现在只有 [public-entry.spec.ts](public-entry.spec.ts)。它断言根入口没有导出。没有 `*.spec-d.ts` 类型测试。

运行方式：在仓库根执行 `pnpm turbo run test --filter=@omne-harness/request-context`，或在本包目录执行 `pnpm test` 与 `pnpm typecheck`。

当前缺口：SPEC [组合与验证](../SPEC.md#组合与验证)列出的十个场景都还没有测试，随实现进入。复杂度场景需要测量，不只是断言。具名维护者由负责人指定。
