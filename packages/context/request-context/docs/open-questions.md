# 请求协调的待细化事项

<a id="context-m02"></a>
## CONTEXT-M02 派生请求、表示、预算与最终采用的精确协议

模型档案、工具实现或 Context 在组装期间变化，扩展又修改参数，压缩内部调用跨消费者换代后须接续。

后续 Request Context、Model、Tool 和原协调者明确公开输入失败集合、表示策略、完整计量、余量、压缩共同提交、一致采用及旁路消费协议。

已定边界如下。

- 普通新输入可靠保存后组装，工具声明与合法绑定一致。
- 全预算含所有实际内容，精确限额实际检查，token 可有明确估计和余量。
- 扩展改参后重新组装或复核，同次经过不重触发扩展位置。
- 压缩只追加摘要与排除名单，不改原可见性、不压未读输入与未结占位。
- 失败限于明确消费契约仍有效未终态工作，不默认挂后继、造 Run 或复活取消资格。

后续处理。用正常与撤权、扩展改参、超限、原 Run 终态后转换失败的反例校验协议，不在本批选算法或数值。

影响范围。真实组合及完整性能接受仍缺输入，当前规则和局部失败责任继续。
