# @omne-harness/runtime-context 行为规格

状态：机制实现成员，`draft`，没有运行实现。本成员实现 Runtime Context 的供给机制：注册表、生产者表、需要绑定、当前投影、观察链、资格核对与翻译。公开行为归 [runtime-context-contract SPEC](../runtime-context-contract/SPEC.md)。本页只写实现真实承担的本地行为，不重复契约条款。

## 范围与依据

本成员与 Cordis 无关（[IC-4](../../../docs/architecture/cordis-integration-conventions.md#ic-4)）。它导出一个工厂，输入是契约的端口与配置，输出是实现契约三面操作的对象。Cordis 绑定、isolate、intercept 配置和唤醒事件归 [runtime-context-cordis](../runtime-context-cordis/SPEC.md)。

本成员不持有任何耐久状态。注册、自有值与步提交的耐久保存归作用域持有者；供给块的 `persisted` 值由生产者在重启后重新发布。本成员的全部表都是进程内副本，重启后由持有者重新注册、生产者重新登记来重建（[IC-19](../../../docs/architecture/cordis-integration-conventions.md#ic-19)）。

## 结果与不变量

### 表与投影

| 表 | 键 | 内容 | 谁改 |
| --- | --- | --- | --- |
| 注册表 | 作用域加块键 | 需要绑定、参数值、是否必需、注册修订 | 持有者面 `prepareRegistration` 核对，持有者提交后 `applyCommit` 写入 |
| 生产者表 | 块键 | 生产者句柄、代际、最近一次发布的值与修订 | 生产者面 |
| 当前投影 | 作用域加块键 | 该作用域读到的当前值与修订；状态块的值来自最近一次步提交 | 发布、步提交 |
| 观察链 | 作用域 | 视图修订序列与每个绑定读者的游标 | 每次投影变化 |

当前投影按作用域链查找：先本作用域，再父作用域，同键子级遮蔽父级（[RC-03](../runtime-context-contract/SPEC.md#rc-03-当前读取资格与缺项)）。查找一个块键的成本与链长成正比，不随历史长度增长。

### 本地行为

- 注册变更按注册修订做比较后写入。依据的修订不是当前修订即拒绝，不用后写覆盖先写（[RC-02](../runtime-context-contract/SPEC.md#rc-02-块声明注册与参数)）。
- 发布带代际。代际小于生产者表里当前代际的发布被丢弃并记录诊断，不改投影，不前进修订（[RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复)）。
- 使当前值失效不改投影，不前进修订，只向观察链写一次唤醒。
- 每次读取先核读取资格：作用域、消费者类、允许的键、注册修订。资格被撤销后的读取返回拒绝。资格签发时的注册修订落后于当前修订时，读取仍按当前注册进行，但结果带上两个修订，供持有者判断是否重新签发。
- 必需块没有当前值时返回缺项，带块键。可选块没有当前值时返回「不在场」。两者都不是失败。
- 带翻译的绑定在读取时执行翻译。翻译抛出即按读取失败返回，带来源块的修订，不返回部分结果。
- 快照只含该读者资格允许且当前有值的块，带视图修订与游标。`changes(cursor)` 返回游标之后的变化；游标早于观察链保留下界、授权范围变化、生产者换代或进程重建时游标作废，读者重取完整快照（[RC-04](../runtime-context-contract/SPEC.md#rc-04-读取时点观察与变化材料)）。
- 观察链有保留上限。超过上限时最老的变化被丢弃，持有旧游标的读者在下一次 `changes` 得到游标作废，须重取完整快照，不得到残缺的增量。上限是配置初值。
- `per-request` 块不进快照，也不进观察链。
- 变化材料只为模型可读块生成，前值按读者资格过滤。生成是纯函数 `diffForReminder` 的调用，本成员不保存变化材料。
- `reduceStep` 的结果写入当前投影只发生在 `applyCommit`，也就是持有者提交之后。本成员不在提交前改投影。

## 所有权、失败与生命周期

| 事物 | 拥有者 | 失败时 | 结束 |
| --- | --- | --- | --- |
| 四张表 | 本成员实例 | 进程失败即丢失，由持有者与生产者重建 | 实例关闭 |
| 生产者句柄 | 生产者 | 旧代发布被丢弃 | `dispose`：等本代在途读取结算后撤除；在途读取用的是撤除前的值与修订 |
| 绑定读者 | 建立它的集成方 | 资格撤销后读取拒绝 | 读者结束或实例关闭 |
| 读取资格 | 持有者签发 | 撤销立即对下一次读取生效 | 持有者撤销 |

实例关闭：拒绝新的注册与登记，使全部绑定读者结束，等在途读取结算，然后释放表。关闭不撤回已经交给持有者的变化材料，也不撤回任何外部效果。关闭前未结算的读取在关闭时返回未知。

进程崩溃后，本成员没有东西可恢复。重建顺序是：持有者重新注册并重新签发资格，生产者重新登记并发布，读者重新 `bind` 并取完整快照。`persisted` 的供给块在生产者重新发布之前读到缺项，本成员不用旧值填充。

## 组合与验证

| 承诺 | 位置 |
| --- | --- |
| 三面操作、读取结果种类、缺项语义 | [runtime-context-contract SPEC](../runtime-context-contract/SPEC.md) RC-01 至 RC-07 |
| 登记寿命、消费者类声明、唤醒 | [runtime-context-cordis-contract SPEC](../runtime-context-cordis-contract/SPEC.md) |
| 持有者的耐久保存与步提交 | 持有者的契约，不在本组 |

持续验证义务，随实现一起进入 `tests/`：

| 场景 | 必须检查的结果 |
| --- | --- |
| 注册修订落后的变更 | 拒绝，当前注册不变 |
| 旧代发布 | 丢弃，投影与修订不变，有诊断 |
| 撤权后的读取 | 拒绝；撤权前已返回的值不收回 |
| 必需块无值 | 缺项带块键；可选块无值为不在场 |
| 翻译抛出 | 读取失败带来源修订，无部分结果 |
| 游标早于保留下界 | 游标作废，不返回残缺增量 |
| 子作用域遮蔽 | 同键读到子级值；子级无值时读到父级值 |
| `per-request` 块 | 不进快照，不进观察链 |
| 关闭时在途读取 | 结算后返回关闭前的值与修订；关闭后新读取拒绝 |
| 当前点读取成本 | 与块数和链长成正比，与历史长度无关 |

本成员不覆盖：持久化、跨进程一致性、租户隔离的端到端证据。这些归持有者与装配的真实组合验证。
