# @omne-harness/runtime-context 行为规格

状态：机制实现成员，`draft`，没有运行实现。本成员实现 Runtime Context 的供给机制：注册表、生产者表、资格表、需要绑定、当前投影、观察链、资格核对与翻译。公开行为归 [runtime-context-contract SPEC](../runtime-context-contract/SPEC.md)。本页只写实现真实承担的本地行为，不重复契约条款。本页的本地设计还没有按契约的[通用权威端口](../runtime-context-contract/SPEC.md#通用权威端口)、按租户的生产者槽（[RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复)）与[作用域结束和恢复会话](../runtime-context-contract/SPEC.md#rc-09-作用域结束恢复会话与恢复后供值)重新设计，冲突处以契约为准，见[明确缺项](#明确缺项)。

## 范围与依据

本成员与 Cordis 无关（[IC-4](../../../docs/architecture/cordis-integration-conventions.md#ic-4)）。它导出一个工厂，输出实现契约三面操作的机制实例。这个工厂是 Runtime Context 唯一的机制工厂。[runtime-context-cordis](../runtime-context-cordis/SPEC.md) 的根入口不导出任何东西；不装配 Cordis 的独立调用方直接从本成员取工厂。Cordis 绑定、isolate、intercept 配置和唤醒事件归 [runtime-context-cordis](../runtime-context-cordis/SPEC.md)。

工厂的输入如下：

| 输入 | 内容 |
| --- | --- |
| 配置 | 观察链保留上限；来源调用与生产者回调的超时。默认值只是配置初值。经 Cordis 时两项由 [runtime-context-cordis 的配置](../runtime-context-cordis/docs/cordis.md#配置)给出，独立路径由调用方作为工厂参数给出 |
| 变化出口 | 回调 `onChange(scope, revision)`，见[变化出口](#变化出口) |

本成员不持有任何耐久状态。注册修订的唯一权威是作用域持有者的耐久提交，本成员的表是按提交顺序应用的投影（[注册修订与提交顺序](../runtime-context-contract/SPEC.md#注册修订与提交顺序)）。供给块的 `persisted` 值由生产者在重启后重新发布。本成员的全部表都是进程内副本，重启后由持有者重放、生产者重新登记来重建（[IC-19](../../../docs/architecture/cordis-integration-conventions.md#ic-19)）。

## 结果与不变量

### 表与投影

| 表 | 键 | 内容 | 谁改 |
| --- | --- | --- | --- |
| 注册表 | 作用域加块键；另按作用域记一条 | 需要绑定、参数值、是否必需、注册修订；状态块的块声明。按作用域记：所属租户、当前注册修订、已应用提交的记录（提交身份到结果，注册决定与步提交都记） | 持有者面 `prepareRegistration` 核对，持有者提交后 `applyCommit` 应用 |
| 生产者表 | 块键（登记）；发布的值按作用域加块键 | 生产者身份、代际、供给块的块声明、作用域无关块的按作用域供值回调、本代在途调用；每个作用域最近一次写入的值、修订与写入序号 | 生产者面 |
| 当前投影 | 作用域加块键 | 该作用域读到的当前值与修订；供给块的值来自该作用域的发布或回调，状态块的值来自最近一次步提交 | 发布、回调、步提交 |
| 观察链 | 作用域 | 视图修订序列 | 每次投影变化 |
| 资格表 | 资格身份 | 作用域、消费者类、主体与租户、块键集合、需要绑定集合、签发时的注册修订；状态：有效、被取代（记取代者身份）、已撤销；引用该资格的绑定读者，每个读者带自己的游标 | 持有者面 `issueEligibility`、`revokeEligibility`；读者面 `bind` |

绑定读者引用资格身份。游标挂在绑定读者上，指向本作用域观察链上的位置。

运行时的块声明目录不单独成表：供给块的声明随生产者表的登记保存，状态块的声明随注册表保存。按块键查声明时两处合起来查（[RC-02](../runtime-context-contract/SPEC.md#rc-02-块声明注册与参数)）。

`per-request` 块不存值，生产者表只存它的登记与取值回调，当前投影与观察链里都没有它的条目。它的值在每次读取时向生产者取得（见下一节）。

当前投影按作用域链查找：先本作用域，再父作用域，同键子级遮蔽父级（[RC-03](../runtime-context-contract/SPEC.md#rc-03-当前读取资格与缺项)）。查找一个块键的成本与链长成正比，不随历史长度增长。

### 本地行为

注册与提交：

- `applyCommit` 按提交身份应用。同一提交身份重试返回原结果。注册决定依据的注册修订等于当前注册修订时，应用并前进注册修订。依据不等、提交身份又没有见过时，返回无效，原因是「顺序不符」，带本成员的当前注册修订。步提交按提交身份幂等应用，不与注册修订比较（[注册修订与提交顺序](../runtime-context-contract/SPEC.md#注册修订与提交顺序)）。
- 一个作用域第一次注册时，本成员记下注册材料带的作用域所属租户。之后的注册带不同的租户即拒绝（无效）。
- 生产者登记带来的供给块声明与持有者注册带来的状态块声明，与同一块键已有的声明比较摘要。摘要不同即拒绝（无效）。
- 持有者先于生产者注册供给块时，注册只核与声明无关的部分：块键的形状、作用域所属租户、绑定的结构。生产者带声明登记时，本成员按声明核对该块键已有的注册。不相容的注册记录诊断，该块在这个作用域读到缺项，直到持有者重新注册。

发布、回调与代际：

- 发布带作用域引用加块键，只写该作用域的值。生产者表与当前投影都按作用域加块键存值，不按块键只存一个值。作用域无关的供给块由本成员驱动供值：持有者注册该块时，本成员对这个作用域调用生产者登记时给出的回调；生产者在持有者注册之后才登记，或调用「使当前值失效」时，本成员对每个已注册该块的作用域调用回调。回调取得的值按该作用域的发布写入。生产者不需要知道作用域列表（[RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复)）。
- 每个作用域加块键有一个写入序号。回调发起时与直接发布到达时各取一个序号。结果写入前比较序号：小于该作用域加块键已写入的序号时，结果不写入，记录诊断。所以晚到的旧回调结果不覆盖新值。
- 持有者注册时触发的回调不阻塞 `applyCommit`。注册先应用；回调结果到达之前，该块读到缺项（可选块标「无值」）。回调失败时记录诊断，该块保持缺项。
- 代际由本成员在每次登记时新取，单调递增。生产者身份是登记时给出的名字，独立于代际。同一块键已有另一身份的登记时，登记被拒绝。同一身份再登记时取新代际，替换旧一代。撤销登记只移除本代的登记；这一代已被替换时，撤销不改动任何登记。
- 代际小于生产者表里当前代际的发布被丢弃并记录诊断，不改投影，不前进修订（[RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复)）。
- 使当前值失效把该作用域的投影条目变为缺项（可选块标「无值」）。这是值的变化：视图修订前进，调用变化出口。作用域无关的块另外按本节第一条重调回调，回调取回值时视图修订再前进一次，变化出口再调用一次。
- 来源调用与生产者回调都有超时，超时值来自工厂的配置。超时的调用按未知结算，取不到的值按契约的[读取结果](../runtime-context-contract/SPEC.md#读取结果)表落位。

资格与读取：

- `issueEligibility` 先核读者的消费者类（[RC-06](../runtime-context-contract/SPEC.md#rc-06-需要绑定与读者形状)），不满足即拒绝签发（无权）。通过后写入资格表，状态为有效。带「取代的资格身份」时，旧资格转为被取代并记下新资格的身份，引用旧资格的读者改为引用新资格，它们的游标作废。`revokeEligibility` 把资格转为已撤销，在下一次读取生效。
- 每次读取按契约 [RC-03](../runtime-context-contract/SPEC.md#rc-03-当前读取资格与缺项) 的顺序核对：资格状态为有效；资格的租户等于作用域所属租户；作用域、块键集合或需要绑定集合；读者的消费者类按当前注册仍合乎块允许的类。按块原形状读，要求块键在块键集合里。读带翻译的需要，要求这条绑定在需要绑定集合里，被翻译的块不必在块键集合里。任一项不满足返回拒绝（无权）。读取结果的种类以契约的[读取结果](../runtime-context-contract/SPEC.md#读取结果)表为准，本成员不返回表外的结果。资格签发时的注册修订落后于当前修订时，读取仍按当前注册进行，但结果带上两个修订，供持有者判断是否重新签发。
- 必需块没有当前值时返回缺项，带块键。可选块没有当前值时，该项标「无值」，读取仍是成功。「不在场」只用于生产者不在场。
- 带翻译的绑定在读取时执行翻译。翻译抛出即按缺项返回，带来源块的修订，不返回部分结果。
- 快照只含该读者资格允许且当前有值的块，带视图修订与游标。`changes(cursor)` 返回游标之后的变化；授权范围变化、生产者换代、进程重建、持有者重签该读者的资格、游标早于观察链保留下界，这五种情形下游标作废，读者重取完整快照（[RC-04](../runtime-context-contract/SPEC.md#rc-04-读取时点观察与变化材料)）。
- 观察链有保留上限。超过上限时最老的变化被丢弃，持有旧游标的读者在下一次 `changes` 得到游标作废，须重取完整快照，不得到残缺的增量。上限是配置初值。
- `per-request` 块不进快照，也不进观察链。每次读取（完整快照或变化）时，本成员按读者资格过滤出它可读的逐请求块，向生产者取当前值：`recompute` 的块调用生产者的取值回调，`reread` 的块向来源重读。取得的值随这次读取另行交给读者，不写入当前投影，不前进修订，不产生唤醒。取不到值时按契约的[读取结果](../runtime-context-contract/SPEC.md#读取结果)表落位：必需块记缺项，来源读取未知记未知，可选块标「无值」（[RC-04](../runtime-context-contract/SPEC.md#rc-04-读取时点观察与变化材料)）。
- 变化材料只为模型可读块生成，前值来自持有者保留的上一份快照。生成是纯函数 `diffForReminder` 的调用，本成员不保存变化材料，也不保存旧值。
- `reduceStep` 对每条更新给出接受或拒绝（无权、不合形状），只合并接受的更新。它的结果写入当前投影只发生在 `applyCommit`，也就是持有者提交之后。本成员不在提交前改投影。`applyCommit` 收到含被拒更新的步提交时整笔拒绝（无效），投影不变。

### 变化出口

工厂接收回调 `onChange(scope, revision)`。某个作用域的视图修订每前进一次，本成员在写入完成之后同步调用它一次，传入作用域引用与新的视图修订。回调抛错时只记录诊断，不回滚已经完成的写入。[runtime-context-cordis](../runtime-context-cordis/docs/cordis.md#按作用域过滤的唤醒) 用它派发唤醒事件。独立调用方自己决定怎样接这个回调。

## 所有权、失败与生命周期

| 事物 | 拥有者 | 失败时 | 结束 |
| --- | --- | --- | --- |
| 五张表 | 本成员实例 | 进程失败即丢失，由持有者重放与重新签发、生产者重新登记来重建 | 实例关闭 |
| 生产者句柄 | 生产者 | 旧代发布被丢弃 | `dispose`：先取消本代在途调用，再在超时内等待在途读取结算，然后移除本代登记；在途读取用的是撤除前的值与修订，被取消的调用按未知结算 |
| 绑定读者 | 建立它的集成方 | 资格撤销后读取拒绝（无权） | 读者结束或实例关闭 |
| 读取资格 | 持有者签发，本成员保管在资格表里，带资格身份 | 撤销对下一次读取生效；被重签取代后，引用它的读者改引用取代者，游标作废 | 持有者撤销，或被重签取代；实例关闭时释放 |

实例关闭：

1. 拒绝新的注册、登记与签发。
2. 使全部绑定读者结束。
3. 取消在途的来源调用与生产者回调。
4. 在同一超时内等待在途读取结算。被取消的调用按未知结算。
5. 释放五张表。

关闭不撤回已经交给持有者的变化材料，也不撤回任何外部效果。关闭时在途的读取先结算，结算后返回关闭前的值与修订。

进程崩溃后，本成员没有东西可恢复。重建顺序如下：

1. 持有者按耐久顺序重放全部注册提交（[注册修订与提交顺序](../runtime-context-contract/SPEC.md#注册修订与提交顺序)）。
2. 持有者经 `applyCommit` 交回每个 `checkpointed` 状态块最近一次步提交后的全值，带原提交身份。
3. 持有者重新签发资格。本成员不从任何地方恢复资格。
4. 生产者重新登记并发布。
5. 读者重新 `bind` 并取完整快照。

规则来自契约 [RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复) 的恢复段。各恢复方式的本地行为如下。

| 恢复方式 | 谁触发 | 本成员调用什么 | 恢复前读到什么 |
| --- | --- | --- | --- |
| `persisted` | 生产者重新登记后重新发布原值 | 不调用，只接收发布 | 必需块记缺项，可选块标「无值」。本成员不用旧值填充 |
| `reread` | 作用域无关的块：持有者重放该块的注册，或生产者在持有者重放之后才重新登记 | 对各已注册该块的作用域调用生产者的按作用域供值回调，回调向权威来源重取并按当前资格取得 | 回调取得值之前，必需块记缺项，可选块标「无值」 |
| `recompute` | 同 `reread` | 对各已注册该块的作用域调用同一回调，回调从当前事实重算 | 同 `reread` |
| `checkpointed` 状态块 | 持有者交回最近一次步提交后的全值 | 按提交身份应用，写入当前投影 | 交回之前，必需块记缺项，可选块标「无值」 |

`per-request` 的 `reread` 与 `recompute` 块没有要恢复的值：重建后的每次读取都按上一节向生产者取值。

明确缺项：

- 不经按作用域供值回调的 `reread` 与 `recompute` 块（按作用域发布的块）在重启后由谁触发重取或重算，契约没有写。本成员只等生产者重新发布，发布之前按上表读到缺项或「无值」。

## 组合与验证

| 承诺 | 位置 |
| --- | --- |
| 三面操作、读取结果种类、缺项语义、注册修订与提交顺序 | [runtime-context-contract SPEC](../runtime-context-contract/SPEC.md) RC-01 至 RC-08 |
| 登记寿命、消费者类声明、唤醒 | [runtime-context-cordis-contract SPEC](../runtime-context-cordis-contract/SPEC.md) |
| 持有者的耐久保存、步提交与重放 | 持有者的契约，不在本组 |

持续验证义务，随实现一起进入 `tests/`：

| 场景 | 必须检查的结果 |
| --- | --- |
| `applyCommit` 同身份重试 | 返回原结果，注册表不变 |
| `applyCommit` 顺序不符 | 依据的修订不等且提交身份未见过时返回无效，带当前注册修订；按耐久顺序重放后注册表与持有者一致 |
| 步提交重复交回 | 按提交身份幂等，投影只写一次，不与注册修订比较 |
| 作用域所属租户 | 第二次注册带不同租户时拒绝（无效）；资格租户与作用域租户不同时读取拒绝（无权） |
| 资格状态 | 被取代的资格沿取代者读取，游标作废；已撤销的资格读取拒绝（无权）；撤权前已返回的值不收回 |
| 签发核类 | 块键集合含不允许该消费者类的块时拒绝签发 |
| 声明摘要冲突 | 同一块键带来不同摘要的声明时拒绝（无效） |
| 先注册后登记 | 注册只核与声明无关的部分；生产者登记后不相容的注册记诊断，该块在该作用域读到缺项，持有者重新注册后恢复 |
| 使当前值失效 | 当前值变为缺项，视图修订前进，变化出口被调用；回调取回值时再前进、再调用 |
| 旧代发布 | 丢弃，投影与修订不变，有诊断 |
| 生产者身份 | 同一块键另一身份登记被拒绝；同一身份再登记取更大的代际；旧一代撤销在已被替换后不改动登记 |
| 回调乱序 | 晚到的旧序号结果不写入，有诊断 |
| 注册时的回调 | `applyCommit` 不等回调；回调返回前该块读到缺项；回调失败后保持缺项并有诊断 |
| 超时 | 来源调用或回调超时按未知结算 |
| 必需块无值 | 缺项带块键；可选块无值时该项标「无值」，读取成功 |
| 翻译抛出 | 缺项带来源修订，无部分结果 |
| 游标早于保留下界 | 游标作废，不返回残缺增量 |
| 子作用域遮蔽 | 同键读到子级值；子级无值时读到父级值 |
| `per-request` 块 | 不进快照，不进观察链，不存值；每次读取向生产者取当前值，取不到时按读取结果表落位 |
| 变化出口 | 每次视图修订前进后同步调用一次；回调抛错只记诊断，写入不回滚 |
| 关闭时在途读取 | 先取消在途调用，再在超时内等待结算；结算后返回关闭前的值与修订；关闭后新读取拒绝（服务已关闭） |
| 重建顺序 | 重放注册、交回 `checkpointed` 全值、重新签发资格之后，读者取完整快照得到恢复后的值 |
| 当前点读取成本 | 与块数和链长成正比，与历史长度无关 |

本成员不覆盖：持久化、跨进程一致性、租户隔离的端到端证据。这些归持有者与装配的真实组合验证。

### 明确缺项

本页的本地设计早于契约的三组新条款，实现之前要重新设计，届时以契约为准：

- 访问经调用方提供的可信绑定来源与权威端口核对，带同步的 `current()`（[通用权威端口](../runtime-context-contract/SPEC.md#通用权威端口)、[当前授权前提](../runtime-context-contract/SPEC.md#当前授权前提)）。本页的资格核对与生产者核对没有这两个端口。
- 生产者槽是租户加块键，句柄带租户，另有按租户失效（[RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复)）。本页的生产者表仍按块键登记。
- 作用域结束、恢复披露围栏、`beginReplay` 与 `finishReplay`、恢复后的待刷新供值（[RC-09](../runtime-context-contract/SPEC.md#rc-09-作用域结束恢复会话与恢复后供值)）。本页的重建顺序（逐条重放注册、交回检查点全值）已被契约取代。

这些缺项不影响契约的 `./testing` 非耐久替身；那份替身已经按新条款实现，只作测试用。
