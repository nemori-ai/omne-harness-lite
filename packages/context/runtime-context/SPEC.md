# @omne-harness/runtime-context 行为规格

状态：机制实现成员，`draft`，没有运行实现。本成员实现 Runtime Context 的供给机制：注册表、生产者表、需要绑定、当前投影、观察链、资格核对与翻译。公开行为归 [runtime-context-contract SPEC](../runtime-context-contract/SPEC.md)。本页只写实现真实承担的本地行为，不重复契约条款。

## 范围与依据

本成员与 Cordis 无关（[IC-4](../../../docs/architecture/cordis-integration-conventions.md#ic-4)）。它导出一个工厂，输入是契约的端口与配置，输出是实现契约三面操作的对象。这个工厂就是 Runtime Context 唯一的机制工厂；[runtime-context-cordis](../runtime-context-cordis/SPEC.md) 的根入口只重导出它，不另写工厂。Cordis 绑定、isolate、intercept 配置和唤醒事件归 [runtime-context-cordis](../runtime-context-cordis/SPEC.md)。

本成员不持有任何耐久状态。注册、自有值与步提交的耐久保存归作用域持有者；供给块的 `persisted` 值由生产者在重启后重新发布。本成员的全部表都是进程内副本，重启后由持有者重新注册、生产者重新登记来重建（[IC-19](../../../docs/architecture/cordis-integration-conventions.md#ic-19)）。

## 结果与不变量

### 表与投影

| 表 | 键 | 内容 | 谁改 |
| --- | --- | --- | --- |
| 注册表 | 作用域加块键 | 需要绑定、参数值、是否必需、注册修订 | 持有者面 `prepareRegistration` 核对，持有者提交后 `applyCommit` 写入 |
| 生产者表 | 块键（登记）；发布的值按作用域加块键 | 生产者句柄、代际、作用域无关块的按作用域供值回调；每个作用域最近一次发布的值与修订 | 生产者面 |
| 当前投影 | 作用域加块键 | 该作用域读到的当前值与修订；供给块的值来自该作用域的发布或回调，状态块的值来自最近一次步提交 | 发布、回调、步提交 |
| 观察链 | 作用域 | 视图修订序列与每个绑定读者的游标 | 每次投影变化 |

`per-request` 块不存值，生产者表只存它的登记与取值回调，当前投影与观察链里都没有它的条目。它的值在每次读取时向生产者取得（见下一节）。

当前投影按作用域链查找：先本作用域，再父作用域，同键子级遮蔽父级（[RC-03](../runtime-context-contract/SPEC.md#rc-03-当前读取资格与缺项)）。查找一个块键的成本与链长成正比，不随历史长度增长。

### 本地行为

- 注册变更按注册修订做比较后写入。依据的修订不是当前修订即拒绝，不用后写覆盖先写（[RC-02](../runtime-context-contract/SPEC.md#rc-02-块声明注册与参数)）。
- 发布带作用域引用加块键，只写该作用域的值。生产者表与当前投影都按作用域加块键存值，不按块键只存一个值。作用域无关的供给块由本成员驱动供值：持有者注册该块时，本成员对这个作用域调用生产者登记时给出的回调；生产者在持有者注册之后才登记，或调用「使当前值失效」时，本成员对每个已注册该块的作用域调用回调。回调取得的值按该作用域的发布写入。生产者不需要知道作用域列表（[RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复)）。
- 发布带代际。代际小于生产者表里当前代际的发布被丢弃并记录诊断，不改投影，不前进修订（[RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复)）。
- 使当前值失效不改投影，不前进修订，只向观察链写一次唤醒。作用域无关的块另外按上一条重调回调。
- 每次读取先核读者当前的读取资格：作用域、消费者类、允许的块键、允许的需要绑定、注册修订。按块原形状读，要求块键在块键集合里。读带翻译的需要，要求这条绑定在需要绑定集合里，被翻译的块不必在块键集合里。两项不满足都返回拒绝（无权）。资格被撤销后的读取返回拒绝（无权）。资格被重签取代后，读者按新资格核对，游标作废。读取结果的种类以契约的[读取结果](../runtime-context-contract/SPEC.md#读取结果)表为准，本成员不返回表外的结果。资格签发时的注册修订落后于当前修订时，读取仍按当前注册进行，但结果带上两个修订，供持有者判断是否重新签发。
- 必需块没有当前值时返回缺项，带块键。可选块没有当前值时，该项标「无值」，读取仍是成功。「不在场」只用于生产者不在场。
- 带翻译的绑定在读取时执行翻译。翻译抛出即按缺项返回，带来源块的修订，不返回部分结果。
- 快照只含该读者资格允许且当前有值的块，带视图修订与游标。`changes(cursor)` 返回游标之后的变化；授权范围变化、生产者换代、进程重建、持有者重签该读者的资格、游标早于观察链保留下界，这五种情形下游标作废，读者重取完整快照（[RC-04](../runtime-context-contract/SPEC.md#rc-04-读取时点观察与变化材料)）。
- 观察链有保留上限。超过上限时最老的变化被丢弃，持有旧游标的读者在下一次 `changes` 得到游标作废，须重取完整快照，不得到残缺的增量。上限是配置初值。
- `per-request` 块不进快照，也不进观察链。每次读取（完整快照或变化）时，本成员按读者资格过滤出它可读的逐请求块，向生产者取当前值：`recompute` 的块调用生产者的取值回调，`reread` 的块向来源重读。取得的值随这次读取另行交给读者，不写入当前投影，不前进修订，不产生唤醒。取不到值时按契约的[读取结果](../runtime-context-contract/SPEC.md#读取结果)表落位：必需块记缺项，来源读取未知记未知，可选块标「无值」（[RC-04](../runtime-context-contract/SPEC.md#rc-04-读取时点观察与变化材料)）。
- 变化材料只为模型可读块生成，前值按读者资格过滤。生成是纯函数 `diffForReminder` 的调用，本成员不保存变化材料。
- `reduceStep` 对每条更新给出接受或拒绝（无权、不合形状），只合并接受的更新。它的结果写入当前投影只发生在 `applyCommit`，也就是持有者提交之后。本成员不在提交前改投影。`applyCommit` 收到含被拒更新的步提交时整笔拒绝（无效），投影不变。

## 所有权、失败与生命周期

| 事物 | 拥有者 | 失败时 | 结束 |
| --- | --- | --- | --- |
| 四张表 | 本成员实例 | 进程失败即丢失，由持有者与生产者重建 | 实例关闭 |
| 生产者句柄 | 生产者 | 旧代发布被丢弃 | `dispose`：等本代在途读取结算后撤除；在途读取用的是撤除前的值与修订 |
| 绑定读者 | 建立它的集成方 | 资格撤销后读取拒绝（无权） | 读者结束或实例关闭 |
| 读取资格 | 持有者签发，带资格身份 | 撤销立即对下一次读取生效；被重签取代后，按它建立的读者沿新资格继续，游标作废 | 持有者撤销，或被重签取代 |

实例关闭：拒绝新的注册与登记，使全部绑定读者结束，等在途读取结算，然后释放表。关闭不撤回已经交给持有者的变化材料，也不撤回任何外部效果。关闭时在途的读取先结算，结算后返回关闭前的值与修订。

进程崩溃后，本成员没有东西可恢复。重建顺序是：持有者重新注册并重新签发资格，生产者重新登记并发布，读者重新 `bind` 并取完整快照。三种恢复方式的本地行为如下，规则来自契约 [RC-07](../runtime-context-contract/SPEC.md#rc-07-生产者句柄并发撤除与恢复) 的恢复段。

| 恢复方式 | 谁触发 | 本成员调用什么 | 恢复前读到什么 |
| --- | --- | --- | --- |
| `persisted` | 生产者重新登记后重新发布原值 | 不调用，只接收发布 | 必需块记缺项，可选块标「无值」。本成员不用旧值填充 |
| `reread` | 作用域无关的块：持有者重新注册该块，或生产者在持有者重新注册之后才重新登记 | 对各已注册该块的作用域调用生产者的按作用域供值回调，回调向权威来源重取并按当前资格取得 | 回调取得值之前，必需块记缺项，可选块标「无值」 |
| `recompute` | 同 `reread` | 对各已注册该块的作用域调用同一回调，回调从当前事实重算 | 同 `reread` |

`per-request` 的 `reread` 与 `recompute` 块没有要恢复的值：重建后的每次读取都按上一节向生产者取值。

明确缺项：不经按作用域供值回调的 `reread` 与 `recompute` 块（按作用域发布的块）在重启后由谁触发重取或重算，契约没有写。本成员只等生产者重新发布，发布之前按上表读到缺项或「无值」。

## 组合与验证

| 承诺 | 位置 |
| --- | --- |
| 三面操作、读取结果种类、缺项语义 | [runtime-context-contract SPEC](../runtime-context-contract/SPEC.md) RC-01 至 RC-08 |
| 登记寿命、消费者类声明、唤醒 | [runtime-context-cordis-contract SPEC](../runtime-context-cordis-contract/SPEC.md) |
| 持有者的耐久保存与步提交 | 持有者的契约，不在本组 |

持续验证义务，随实现一起进入 `tests/`：

| 场景 | 必须检查的结果 |
| --- | --- |
| 注册修订落后的变更 | 拒绝，当前注册不变 |
| 旧代发布 | 丢弃，投影与修订不变，有诊断 |
| 撤权后的读取 | 拒绝（无权）；撤权前已返回的值不收回 |
| 必需块无值 | 缺项带块键；可选块无值时该项标「无值」，读取成功 |
| 翻译抛出 | 缺项带来源修订，无部分结果 |
| 游标早于保留下界 | 游标作废，不返回残缺增量 |
| 子作用域遮蔽 | 同键读到子级值；子级无值时读到父级值 |
| `per-request` 块 | 不进快照，不进观察链，不存值；每次读取向生产者取当前值，取不到时按读取结果表落位 |
| 关闭时在途读取 | 结算后返回关闭前的值与修订；关闭后新读取拒绝（服务已关闭） |
| 当前点读取成本 | 与块数和链长成正比，与历史长度无关 |

本成员不覆盖：持久化、跨进程一致性、租户隔离的端到端证据。这些归持有者与装配的真实组合验证。
