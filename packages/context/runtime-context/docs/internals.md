# 当前块供给与恢复的内部设计

本页在正式位置维护待审细化，只有文档目标，没有真实包、公开形状或实际运行验证。产品既定规则保持原确认范围，阶段支持仍待用户选择。

## 3. 当前读取、变化与恢复的链

变化感知见 [RC-F01](key-flows.md#rc-f01)，注册失效见 [RC-F02](key-flows.md#rc-f02)，目录指导见 [RC-F03](key-flows.md#rc-f03)，恢复见 [RC-F08](../../docs/key-flows.md#rc-f08)。

1. Session 提供当前注册、会话自有值和适用身份，Agent 在每次执行开始或挂接建立时取得当前合法快照。原来源不可用与无权分别报告。
2. 运行期间的模型可读变化由原协调消费路径追加提醒。状态提醒表达会话实际感知的前后值，事件提醒保留发生事实。
3. 空闲状态推送可以丢弃，下次执行开始或挂接建立时从当前来源补齐。可靠业务输入仍先保存及受理，不能走可丢通知路径。
4. 模型首次与压缩后取得完整合法 Context，平时请求保留变化链。工具和扩展私有块不向模型提醒或投影。
5. 注册增删和自有不可重算值的变更跨普通故障恢复。移除意图不复活，共享源不被删除，当前权限重新取得。

该链的业务边界已定，提交、通知补查、并发读取和前值关联的协议仍须设计。

注册当前值与其恢复事实需要保持一致，更新成功不能只留一份无法解释的缓存。确认已保存之后，适用事实须跨进程崩溃、OS 崩溃及断电保留。实时或外部可重读值不统一复制到 Session log；历史采用值用于解释原执行，不能代替当前授权。

## 6. 生命周期、权限与资源

独立消费者可以使用公开计算或供给能力，不需启动 Cordis 或创建隐式 Session。纯计算只使用调用方输入；读取托管数据或发送请求时，集成方须承接身份、授权、资源及可靠结果责任。

取消组装、释放缓存或订阅只结束对应计算资源，不自动取消原工具效果或清理原数据。会话归档按已决定的业务取消传播，不等所有独立执行物理停止。迟到结果与费用归原调用，不能重开会话推进。Model ACK 只清理获准模型侧副本，不是本域统一清理协议。

可读与可外发分别复核。权限失效后缓存不提供新内容，提醒、转换、摘要、链接和遥测都受原限制。实际接收方变更须重判。Cordis 只负责集成，不提供恶意代码隔离证明。

长期读取须分别计量当前注册与点查询、变化供给、历史扫描、表示读取、转换、请求物化和发送。指定当前值的读取不随历史长度重扫全量；返回列表和全文成本仍随实际输出量增长。缓存声明容量、失效、来源范围及覆盖进度，不能省略资格复核。规模、时限和算法不在本批选定。


## 采用限定

必需感知清单中的 ModelProfile 消费关系、压缩设置以及后台、子会话、待办供给包含原产品推导的候选项，仍以待审表达，不借物理落位升级为已接受事实。固定身份、源归属、空工作区、结构化授权私有、语义授权范围和不虚构进度继续保留。完整快照前值可选，变化提醒保留获准实际前后关系；精确表示与关联仍待设计。
