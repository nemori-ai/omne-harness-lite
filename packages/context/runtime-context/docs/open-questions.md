## CONTEXT-E02 工作区指导采用版本与首次访问协议

AGENTS.md 已明确在嵌套目录首次访问时加载，具体社区规范版本、访问判据及合并协议仍未采用。

后续 Context 拥有者核实具名规范版本，再落实首次访问、路径适用、内容合并和恢复协议；本次不把未经核验的惯例写成采用。

已定边界如下。

- 未访问目录不因资产发现而预加载。
- 首次访问加载适用指导，来源、资格及采用内容可追溯。
- 不走普通资产 reload，不保证远端文件即时同步。

后续处理。行为保持既有边界，版本与精确协议作为来源和机制交接，不作产品访谈。

影响范围。精确指导读取实现仍缺必要输入，不影响其他块的供给和组装规则。

<a id="context-m01"></a>
## CONTEXT-M01 注册、当前读取和恢复的一致协议

注册变更、源更新、撤权与读取并发，提交未知或通知丢失后，当前值、恢复事实和实际采用仍须一致。

实际成员与协调者落实公开形状、授权提交、并发顺序、当前读取范围、未知对账、变化身份与补查、前值关联、恢复输入和缓存失效。

已定边界如下。

- 生产者原数据、Session 注册、自有不可重算值、提醒、采用值和缓存分别可辨。
- 可选移除不删共享源、不复活，必需注册不能绕过。
- 执行开始或挂接建立时当前 pull，空闲状态推送可丢但可靠业务输入不丢。
- 确认后普通耐久含进程、OS 崩溃和断电，历史不能提供当前权限。

后续处理。先明确共同成立的事实和交接责任，再选公开类型与机制，不从旧实现倒推。

影响范围。实施前仍缺精确协议，已有供给和恢复保证不因此降低。
