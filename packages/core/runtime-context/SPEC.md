# runtime-context 行为契约

采用依据：2026-10-04 用户授权采用经审阅的 Tool Runtime r10 设计并实施第二阶段。本期增量沿2026-10-06用户授权的PR1交付，由主会话在选择／表达无剩余阻断后作技术采用；不据此接受产品故事或声明后端已完成。公开形状归 `src/index.ts`；本页只约束类型不能保证的行为。分阶段兑现范围由实际验证证据报告，不以本页存在宣称全部实现。

RC-1 注册是会话属性。读取、注册、更新、移除必须核验绑定的 tenant/session 与可信消费者，不能凭角色字符串授权。

RC-2 注册与内容独立演化。移除本会话注册不删除共享源，也不删除其他会话的注册；恢复不能重新加入已移除项。必需注册不能由普通移除操作删除。

RC-3 返回的数据是调用者独占的不可变副本。模型、工具和拓展点只取得其被允许的块；仅工具／拓展点消费的内容变化不生成模型提醒。

RC-4 持久内容恢复，共享来源重取，实时块重算。环境引用可以保存，活体服务、函数、进程和句柄不得保存为 context 数据。历史采用值不证明当前授权。

RC-5 并发修改使用修订条件，失败不部分修改。生产者失联明确不可用，不用最后值冒充本次已重取。当前值与逐次采用依据分别保存。

RC-6 注册表修订与块内容修订分开。registrations 返回会话注册集的修订；register/remove 比较该修订；update 比较该块内容修订，新修订由提供者产生。输入值不得自行重写身份、修订和观察时刻。

RC-7 `required` 是声明的读数，不由提交者自行决定。写入须与会话必需 meta 声明核对，不允许把 true 改成 false 后绕过移除限制；消费者范围须同时受来源声明和访问绑定约束。

RC-8 来源注册归调用方 effect；重复同名拒绝，撤除仅撤本代来源。会话注册不随来源插件删除。多块读取不得以部分结果冒充完整成功；初始修订为 absent，更新和移除须比较拥有者当前修订。

RC-9 当前授权读口或日志不可用统一回 unavailable；sourceUnavailable 只用于来源缺席／来源读失败。不得以 notAuthorized 冒充依赖故障，也不在操作结果联合之外抛出业务异常。

RC-10 会话创建者一次性初始化必需注册及固定身份值；其持久声明是该会话必需性的权威。来源 requiredKeys 只核对该声明，不能提升或削弱它；注册须满足持久要求、来源声明与提交 required 三者一致。来源缺席不解除移除限制。初始化缺席或版本不明不能当作空声明。固定身份值约束内容更新及动态来源读取。初始化批自身原子，不据此声明它与其他存储中的会话创建同成同败。本条的实施闭包经 ic3 独立选择复核，无阻断；原 RC-2/6/7 保证不变。

RC-11 快照包含绑定读者当前有权消费的全部注册投影与值，不包含来源名称、来源配置或其他消费者的授权信息。完整管理注册仍由 configure 权限取得。viewRevision 只由该读者可见的注册投影与值产生，不由不可见配置派生，也不能作为任何管理或内容修改的 expectedRevision。多块成功基于同一持久注册／内容前缀；外部来源分别标明其观察时刻，不宣称跨来源原子事务。读取前后核当前授权、注册修订和来源代／失效线索；发生相关变化明确拒绝，不能部分成功或借旧快照扩大权限。

RC-12 游标只属于产生它的绑定读者和已核授权范围。变化是可见注册及值的 added／updated／removed，不是来源内部事件流。伪造、跨读者、进程重建、参与视图的来源换代或授权范围变化的游标要求完整重取，不暴露原读者内容。撤权、来源不可用和读取失败不当作空增量；首轮、压缩后以及重置要求仍取得完整快照。游标不得令已释放的历史永久强引用。

RC-13 来源失效提示显式携带 scope／keys，核对本次注册确实属于原来源代。提示不写正文、不删除注册，也不授予读取权。旧 handle、晚读返回或旧 dispose 不影响新代。广播只作无载荷唤醒提示，模型消息和 Run 生命周期由上层消费者负责；工具的指定键耐久读口不因此新增未记账的旁路。

RC-14 dispose调用先撤除本代资格，禁止新来源调用；返回的Promise在该代已经进入的read／invalidate全部结算后完成。同一handle重复或并发dispose等待同一排空义务；不靠取消或旧晚回执冒充排空。正在读取的消费者不采用已撤代的返回，明确sourceUnavailable。原来源读取及提示任务由该来源登记闭包保有到结算，新代不接管它们。
