# 可读块与压缩名单的有限模型

行为归[公共SPEC](../../SPEC.md)。Readable.als检查同一日志内块路径的合取取用、压缩名单与后台工具占位的结构关系。模型只取有限消息/块，不表示当前完整Session/Tool生命周期。

模型按构造吸收不存在的块、SystemMessage不落日志等条件，这些条件不是被检查得到的实现性质。请求输入范围上界、未回答卡片占位、真实授权、字节编码、日志耐久与外部工具停止未建模。块形状归content-blocks；调用工具的前后台不改变执行身份。

用Alloy Analyzer逐条执行文件末尾的run/check；正控须区分可满足见证与无反例，负控须命中目标性质，工具错误不算反例。单次命令、scope、结果与输入摘要留工作树tmp。模型注释中的条款号是内部说明，不是另一份现行契约或登记源。
