# Messages 验证职责

公开形状与类型外行为分别归公开入口和[薄 SPEC](../SPEC.md)。规范 JSON／Markdown 输入、精确拒绝期望、摘要向量与原资源校验由 [tests](../tests/fixtures/README.md) 维护。这里只列方法与责任，每次执行结果留 tmp。

| 范围 | 必须观察的性质 | 方法／真正责任 |
|---|---|---|
| 单消息及技术记录 | 原规范行、块层拒绝、唯一首个拒绝、当前 Attempt 来源边界、复制后不可变 | 公开值／文本边界及类型测试；Schema 转换守卫 |
| 可读性与压缩 | 五消息场景及三变体、祖先／visibility／silenced、完整前缀、卡片／最近请求缺源为 undetermined、前向引用拒绝 | prefix／compaction 场景；真实追加／导入者另核完整日志 |
| 配对与真实来源 | 七条日志唯一／配对规则、后台占位与唯一收场、工具中断、当前感知状态、派生消息不改原回复 | 纯关系测试不能代替 Session 日志及消息写入者 |
| 请求留痕 | 完整固定绑定、原请求参数、实际发送处置、真实 ResponseId、ready／final 原值一致、迟到按原归属 | 单记录准入；跨记录关系由模型运行时／日志组合验证 |
| 精确图 | 所有 53 定义及原9份资源闭包、缺每个资源均报其精确 URI、公开 retained 6／3／2、无旧执行入口 | 独立固定资源摘要、完整 F0 转换、缺资源负控及制品消费 |
| 语义摘要 | 20 原向量、4 等值与6异值、UTF-16 次序、巨大指数、角色域分隔、无损数、accessor 不执行 | 独立固定编码／SHA 向量，不能声称密码学证明 |
| ACK 见证 | 15 原形状正反例、小账是原账、释放后锚点和只读引用边界、不按 priority 遮矛盾 | 本包值测试；实际权限／保留权／停止／耐久／自动清理见 [runtime](../../model-request-runtime/verification/README.md) |

创建 payload 保 MP6，dispatched 保 MP5；本包不反向依赖 runtime。有限模型归实际生命周期拥有者，不为纯消息包造状态模型。形状通过不证明当前权限、租户、原回复、完整日志、正文摘要、物理删除或真实提交。
