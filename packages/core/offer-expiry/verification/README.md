# 邀约验证义务

`pnpm --filter @omne-harness-lite/offer-expiry build`、`typecheck`、`test` 核对纯函数、Schema 原字节、配置时长与不可用次序。共同提交、授权与真实对象消失由组织治理／资产消费者在其原子域内验证。清理停运不能改变读时过期。

[有限模型](models/README.md)拥有终结不覆写、非pending不首次终结及不重复接受效果的相称义务。模型与正／负配置成套保留，不证明 SQL、授权、网络或真实组织删除。运行 TLC 时从 models 目录传具体 cfg；原始输出留任务 tmp，不入库累计绿测。
