# 验证职责

公开形状归类型与必要校验，类型外行为归[本包 SPEC](../SPEC.md)。每次执行结果留工作树 tmp，本页不维护运行台账。

| 范围 | 必须验证的方法与责任 |
|---|---|
| 本包值与纯函数 | 能力／记录／持有／配值、正文端口、唯一声明、manifest、血缘与准确首拒绝。原规范输入／拒绝期望／类型测试保持；Schema形状不代替完整纯关系判断。 |
| 资源与真实消费 | 固定原资源与每个缺资源负控；真实五提供者链及 Connector 缺失边界；shared／organization 来源、发布顺序、配值历史、owner／血缘同提交、授权与保密由资产治理／流转／求值者核。 |
| 制品与边界 | 实际 tarball 的公开类型／JSON入口、精确私有路径拒绝和真实组合见 [core-verification](../../../../tools/core-verification/README_ZH.md)；外部责任不能仅以fixture或Schema判完。 |

固定图构建生成、首次实际消费加载；缺资源、定义、生成物或 helper 明确失败，不回退。纯数据无独立状态模型，不为目录完整补空模型；真实并发、恢复、授权及跨节点完整性归其效果拥有者。
