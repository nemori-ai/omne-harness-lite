# 组合根正文的窄投影

[公开根](src/index.ts)拥有纯校验／投影函数，[Schema](schema/agent-definition.schema.json)拥有结构。只解释 `agent_definition` 正文的 `references` 与 `attributes` 两槽位；不定义完整 Agent、委派、sub-agent、master、上下文或运行时功能。本窄规则不授予读取或版本选择权限。

## 来源与完整性

两个必填槽位同时来自调用方选中的同一份已发布、不可变 AssetVersion.content.body；不拼接不同版本、不读草稿、不临时改成最新版本。body 是对象，两槽位可以合法空数组，缺席／null 不能当作空数组。正文其他成员保持不透明，无损保存和回读，不删除、改写、解释或据此形成身份。

取不到选中版本是调用能力的失败，不交出空数组伪造成功。投影不另带 id、name、version 或运行时身份。先完成通用资产壳与跨字段验证，再应用本窄规则；仅有通用壳校验或一份样例不足以允许读取槽位。

## 引用集合

references 按集合解释，数组次序无装配次序含义。同一 capability 至多一条，resident 不同也不能并存。resident 仅适用于 tool／skill；缺席表示未标，不补 false。原样交出全部引用，不判断目标可用、不丢掉求不出的目标。自身引用／环由组合求值负责，值层不替它作判定。

AssetReference 与资产求值的共享形状保持一致；CapabilityId 的精确相等和八类词法归资产模型。需要执行顺序的消费者须从顺序拥有者取得显式输入，不能把此数组存储次序变成执行依据。

## 声明集合与规范域

attributes 按集合解释，同一正文确定地交出相同声明，内容不改写，不读持有、租户、时间或环境。只允许 first_token_wait_limit、post_first_token_stall_limit、model，每项至多一次；可以不声明任一项或全部三项。只声明 setting，category／domain／作者 default 必须明确。disabled、usableBy 由通用资产规则提供，不在正文再声明或复制。

两项时限 category 为 preference，domain 的确切 JSON 值由 Schema 定义：工具定义 Duration 加严格正值约束。全零时长拒绝，合法正时长无本数据域数值上界；不能引入浮点或计时器范围限制。PT60S 与 PT1M 语义相等，保留作者合法原文，不改单位或规范化。消费者无法调度合法时长时，沿自身承诺明确失败，不截断、溢出或当无限等待。

model category 为 binding，domain 的确切 JSON 值引用公开保留的 model-profile RouteName 资源。default 是作者的设置默认，不是已解析模型档案；不查目录、不补来源／范围、不判断能否调用。声明可缺席，但声明后 default 不得缺席、空串或 null。

规范域比较按确切 JSON 值，不要求序列化字节相同，也不接受任意语义等价 Schema 拼法。不能解析作者额外远程 Schema 替代规范域，不能借校验器忽略未知关键字放行替换域。所需旧 Schema URI 是公开数据身份，物理移动不改其 URI 或精确依赖。

## 缺席、失败与纯函数边界

缺席声明不补项，不从示例、宿主、上次调用、适配配置或另一版本补默认。表示拒绝、取不到正文、合法空数组是三个不同事实；投影成功不证明设置求值成功或可发出请求。

整个正文含不透明成员沿严格无损 JSON 规则：任一层重复成员名拒绝；十进制数读入／保存／回读保持精确，不舍入超安全整数；true 不等于 1，对象顺序不影响相等，数组顺序影响值相等。

通用校验沿资产模型的闭合拒绝值与次序；通过后本窄规则只有 malformed。失败不返回局部成功集合，无写入、提交、外部状态、恢复或事件，不修改输入／已保存版本。相同 body 得相同结果。调用方保留来源和选中版本，不把表示拒绝解释成引用目标不存在、无权限或求值结果。

## 验证与未实现范围

Schema 不独自检查解析前重名 JSON 键、同 capability 不同 resident、同名 item 不同声明、错误来源、浮点舍入或未知字段丢失。[规范实例及四个真实消费者场景](tests/fixtures/agent-definition-examples.md)与窄拒绝由本包 tests 验证，真实选中版本读取与两集合交接归资产注册表／装配清单／求值消费者。

完整 Agent Definition 正文及根以外正文规则仍由 PF-004 与后续正文拥有者定义；本页不关闭这些未实现责任，不以窄校验冒充 Agent Runtime。模型档案公开精确依赖的采用已成立，但形状或数据文件存在不证明目录／模型调用实际可用。本包没有共享状态或生命周期，不建立空行为模型。
