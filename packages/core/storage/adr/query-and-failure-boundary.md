# 存储协议的查询与失败边界

采用 Kysely 作为统一查询类型，方言由提供者选择。协议不自造查询 DSL，也不持有业务表；换查询层会改变公开协议，不能只当驱动替换。

锁是显式 lockRow／lockSentinel，不能让调用方依赖 SQLite 下不会取得行锁的 forUpdate。空行不被锁，唯一约束及冲突后同事务可用保证空行竞争的收场。

唯一约束使用迁移控制的显式索引名，主键统一成 <table>_pkey；调用者能跨方言区分具体约束。匿名或不可映射的名字是迁移缺陷，不是瞬时不可用。

缺陷单列 StorageDefect，避免坏 Schema 被重试策略无限重扫。mapStorageError 只折瞬时 StorageUnavailable，其他值原样重抛。PG 的逐语句 SAVEPOINT 用于保证约束失败后事务仍可用，成本不能以性能名义删除该语义。

显式共同事务与普通独立提交分开；ALS 只限定本地活跃帧，不授予租户资格、不提供跨进程协议或裸 SQL 沙箱。回调 runner 由测试进程提供，以免产品闭包装载 Vitest。

若查询层、支持方言、物理线程模型或提交边界改变，重新核验[行为规格](../SPEC.md)及[符合性义务](../verification/README.md)，不能只靠类型同形。
