# 为项目判断保存事实与局限

这里保留能影响需求理解、候选比较或决定复议的事实证据，解释观察到什么及其
适用边界。研究提供判断依据；采用哪项政策由对应选择负责。
准入正文见[组织规范](../maintenance/organization.md#持久化知识的准入)。

## 准入与转出

有具体项目问题、可核对来源或实验，以及需要长期保留的结论与局限时进入这里。
固定版本，区分观察、推断、假设与未覆盖；协议、原件和日志只保留支持复现或
判断所需的部分，并说明它们的身份。

无项目问题的资料收藏、未整理检索、临时实验过程归 tmp；候选取舍按 proposals
准入；已确认目标归 requirements；开发模型与防御辅助实验按 evaluation 协议归属。

## 按任务进入

从[研究索引](README.md)复用仍适用的事实。新观察挑战有效决定时按
[知识流转](../maintenance/knowledge-flow.md)记录因果影响；上游事实不能自动
接受本项目政策。Cordis 原语核对使用对应权威资料 skill。

只修正来源或补充观察时，保留旧结论的版本范围，按本次问题停止检索。
