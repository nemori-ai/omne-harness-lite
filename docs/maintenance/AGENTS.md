# 知识与研发交付的维护规则

这里拥有本仓库跨任务复用的组织、版本、验证、workspace 和交付维护规范。
它管理知识如何保持一致、被消费和演进，不选择产品运行时的业务政策。

## 准入与转出

具有跨任务价值、明确治理依据及维护对象的规则进入所属正文；含义首先由
[组织与准入](organization.md#持久化知识的准入)定位。一次任务的计划、进度或
命令输出归 tmp；具体自动化实现归 tools/scripts；产品保证归其需求、设计和 spec。

新增治理取舍按 proposals 准入并保留接受范围，不能借修改指南或 AGENTS 暗中
接受未决产品协议。命令引用实际实现，不在多份规则中维护同义格式。

## 按任务进入

从[规范索引](README.md)定位唯一拥有者。提案到决定看
[知识流转](knowledge-flow.md)，承诺及消费者演进看[规格维护](spec-maintenance.md)，
计划方法看[交付规划](delivery-planning.md)，证明与执行证据看[验证规范](verification.md)。

修改拥有者后同步必要入口、skills 和角色；普通局部修正按相称检查完成，不展开全部治理。
