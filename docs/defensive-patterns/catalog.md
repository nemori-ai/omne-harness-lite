# 防御指导的身份与适用记录

[当前指导](../defensive-patterns.md) · [演化规范](../../.meta_harness/agents/evaluation/developer-model/README.md)

此表为现有指导提供稳定引用身份，供后续开发模型评估精确说明在比较哪一条提醒。
正文仍由当前指导页维护；系统保证来自所属契约与决定。本次没有添加任何模型特定
的强制步骤，也没有证明任何提醒已被某个模型内化。

## 来源与当前状态

这些条目来自[迁移前防御文档](../research/project-baseline/defensive-patterns-before-migration.md.txt)
及其参考资料；本轮结合[框架研究](../research/framework-governance/README.md)重新限定语义。
它们是设计经验，未伪装成本项目生产事故或实测模型弱点。当前使用方式均为**按需设计提醒**，
适用风险出现时从 skill 导航读取，不要求每次任务加载全部条目。

| ID | 正文与保护结果 | 适用范围及限制 | 主要复核触发 |
|---|---|---|---|
| DP-01 | [独立事实分别报告](../defensive-patterns.md#独立事实分别报告)：区分失败与完成事实 | 执行结果与外部进程；简单返回值不因此强制引入通用结果框架 | 新结果协议、误报成功 |
| DP-02 | [公共契约两端一致](../defensive-patterns.md#公共契约两端一致)：边界语义一致 | 适配与公开 API；不要求纯内部函数模拟公共协议 | 边界或适配层变化 |
| DP-03 | [异步状态不可混同](../defensive-patterns.md#异步状态不可混同)：状态与结果归属可解释 | 长期/异步工作；同步操作无需机械扩充状态机 | 新调度、排队或恢复机制 |
| DP-04 | [释放以可观察终态为准](../defensive-patterns.md#释放以可观察终态为准)：释放承诺可核查 | 拥有存活任务或资源的对象；终态依契约确定 | 资源泄漏、取消实现变化 |
| DP-05 | [回调故障有边界地隔离](../defensive-patterns.md#回调故障有边界地隔离)：失败可见且不破坏隔离承诺 | 独立观察者；授权/校验失败不可按“捕获继续”处理 | hook/listener 契约变化 |
| DP-06 | [所有权必须可追踪](../defensive-patterns.md#所有权必须可追踪)：资源有负责者 | effect、注册、任务、句柄；普通不可变数据不需专门生命周期对象 | 热替换或所有权转移 |
| DP-07 | [外部输出不声称普遍可逆](../defensive-patterns.md#外部输出不声称普遍可逆)：恢复承诺真实 | 外部可见写入/发送；纯局部逆操作按自身契约处理 | 外部协议、幂等/补偿变化 |
| DP-08 | [不把环境交给不可信执行](../defensive-patterns.md#不把环境交给不可信执行)：授权边界清晰 | 子进程、插件与工具；不能从目录或动态装载推导安全隔离 | 新执行环境、权限改变 |
| DP-09 | [失败阻止假状态提交](../defensive-patterns.md#失败阻止假状态提交)：装配失败可解释 | 重载、替换、刷新；不承诺已释放旧实例自动复活 | 提交边界或恢复条件变化 |
| DP-10 | [规格实现与证据对齐](../defensive-patterns.md#规格实现与证据对齐)：证据与承诺对应 | 设计和行为变更；不要求文字修正重跑无关模型 | 规格、模型、实现或假设变化 |

模型或工具升级、样本中的失败复发、提示冲突、明显执行负担也是共同复核触发。
每次具体评估把这里的 ID、所用文本版本/哈希、实际注入位置与未覆盖任务范围一起记录。
新增故障应补证据，退出应附限定范围的采用决定和替代机制；退出内容从当前路由撤下，
其原始证据仍可沿历史记录回查。现阶段没有退出记录或真实模型对照结果。
