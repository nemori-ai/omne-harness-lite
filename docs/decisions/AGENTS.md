# 已接受选择及其历史

这里记录有明确接受依据、需要长期追溯的选择、理由、范围和取代关系。
它回答当时为何采用某方案，不保存全部候选讨论或持续变化的实现说明。
准入边界见[组织规范](../maintenance/organization.md#持久化知识的准入)。

## 准入与转出

只有已经明确接受的选择进入决定正文，并关联来源提案或研究、接受依据和适用范围。
待接受的决定草稿留在对应 proposal；用户目标归 requirements；事实与运行证据
回到所属记录。执行授权和只读评审结果不自动成为新的接受决定。

接受目标、语义范围、机制选择或其他对象应可区分；有必要证明未完成时，不能
同时接受依赖它的机制。详细边界归[接受与交付](../maintenance/knowledge-flow.md#接受与交付怎样闭合)。

## 按任务进入

新增或复议决定先读[版本与取代规则](../maintenance/versioning.md#决定与提案)，
字段形状查[元数据](../maintenance/metadata.md#决定-front-matter)。原理由、前提
和未受取代范围保留，不靠原地改写或改状态隐藏新选择。

普通索引、链接修正只检查相应引用；没有新观测不重新评判有效决定。
