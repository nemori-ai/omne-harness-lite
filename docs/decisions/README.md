# 有效决定与历史

在适用范围内且没有新观测时，有效决定是研究、提案和决定三者中的最终权威。每份决定必须关联至少一份提案或研究；取代必须提供可复现、可验证、可因果解释的强理由。详细规则见[知识流转](../maintenance/knowledge-flow.md)。
