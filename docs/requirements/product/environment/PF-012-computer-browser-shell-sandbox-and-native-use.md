# PF-012：Computer、Browser、Shell 能力与沙盒／本机使用

[环境维度](README.md) · [执行环境来源核对](../../../research/computer-browser-shell-environment-sources.md)

主维度：环境，关注能力作用于怎样的操作环境。副维度：智能体、用户，分别
关联三类 use 能力，以及与用户共享电脑时的授权、观察和控制。

## 已确认要求

2026-09-12 用户明确：computer use、browser use、shell use 都是 Agent 的
能力要求；三者均须支持沙盒使用，以及直接在 **Agent 运行时当前所在的操作
系统** 上使用。后者可能就是用户日常使用、与 Agent 共享的电脑环境。

同日用户进一步明确：某个部署可使用沙盒、本机或两者，由模型能力等级、部署
装配配置、部署时配置的默认权限及用户授权共同作用；此补充计入 C2 的直接
确认范围。

C1/C2 记录直接要求；C3–C7 结合本轮要求、已确认的工具/授权要求及原系统
有效产品条款补充边界。来源中沙盒路径“不接触宿主”的条款仍约束沙盒，不能
据此排除用户本轮明确要求的本机直接使用路径。

- **PF-012.C1：Agent 具备三类 use 能力。** Computer use 支持观察计算机
  视觉界面并通过点击、输入、滚动、拖拽等操作完成工作；browser use 支持
  浏览器导航、页面观察及元素交互；shell use 支持执行命令、取得输出和结果，
  并支持有明确生命周期的终端工作。三者都是 Agent 可以在任务中持续使用的
  能力，不能仅提供一个环境入口或菜单就视为满足。精确动作目录与工具形态
  留待建模，三类能力不因共享一个工具实现而合并授权或结果语义。
- **PF-012.C2：系统支持两类环境，部署有效范围共同决定。** 以下六种组合
  均属于系统整体的产品目标；某个部署支持使用沙盒、本机还是两者，是**模型
  能力等级、部署装配配置、部署时配置的默认权限和用户授权**共同作用的效用
  结果，不要求每个部署都同时开放两类环境。四项依据及实际生效结果须可辨认，
  精确组合、覆盖与优先关系留待设计。沙盒提供相应的隔离计算机、浏览器或命令
  环境；直接使用作用于 Agent 运行时所在操作系统中的获准真实目标，可以与用户共享桌面、应用、
  文件或浏览器环境。本机路径不能仅以另一份隔离副本模拟成功来兑现；沙盒也
  不因物理上运行在本机，就等于直接使用该操作系统的用户环境。
- **PF-012.C3：环境选择、目标与授权分别明确。** Agent 和用户能够辨认
  当前操作在哪个环境、对哪个目标生效；选择依据可来自适用设置、任务声明或
  授权策略，具体优先关系待设计。权限继续按 Agent 定义、当前组织/个人范围、
  目标环境和动作判定；直接使用不自动获得系统管理员权限或全部个人数据权限。
  沙盒不可用时不能静默改用本机，目标不明确时不能猜用当前用户的窗口、目录
  或浏览器。切换路径须有明确的适用依据与真实反馈，无需把已有有效授权一律
  重复询问，也不能把只覆盖沙盒的授权借给本机操作。
- **PF-012.C4：沙盒可取得、使用并可靠回收。** 系统能提供满足所需能力与
  隔离条件的获准沙盒，辨认其归属和当前可用性，并支持释放与失败清理。取得
  环境不等于取得所有动作权限；撤销使用权限也不应使资源无法安全清理。沙盒
  临时内部状态与耐久会话状态分别表达，未确认导出/保存的数据不能宣称可跨
  沙盒销毁恢复。物理上同机、跨机或使用不同后端不改变其隔离与归属义务。
- **PF-012.C5：共享环境中的操作和人类控制可协调。** Computer use 的
  画面读取、剪贴板/键盘访问与改变状态的输入须可分别治理；浏览器操作与像素
  级桌面控制也不互相授予。系统能辨认当前目标、焦点、控制归属以及用户是否
  接管；目标已变、画面过期或失去控制时，不能继续按旧状态操作并报告确定成功。
  沙盒浏览器保持隔离，不自动继承用户的登录和存储；本机路径可在获准范围内
  使用指定的真实浏览器环境，所用 profile、登录态、凭据及文件范围必须明确，
  不能从“运行在用户电脑上”推导任意使用权。
- **PF-012.C6：结果、数据交接与副作用如实可见。** 三类调用均适用
  [PF-003](../agent/PF-003-tool-execution-observation-and-control.md) 的状态、
  按需过程帧、单次中断及符合声明时的后台接续。命令、页面动作和视觉输入
  区分已应用、被拒、受阻、失败、部分完成与结果未知等适用情况；请求已发出
  不等于真实效果已完成。文件上传/下载、剪贴板或产物在环境间交接需明确来源、
  去向和权限，临时路径不等于持久保存。中断、断连和恢复不撤销已发生效果，
  不得盲重试可能已生效的动作；本机环境也不能套用“沙盒释放”去清理用户的
  共享环境或其它工作。
- **PF-012.C7：可用性与实际环境相符。** 系统能说明当前操作系统、目标
  环境和已装配能力是否满足本次使用条件；缺少桌面、浏览器、终端供给或所需
  模型能力时如实说明，不能伪装为空画面、空页面或成功空操作。需要视觉等
  模态的工具按自身声明与模型能力适配；异构装配、恢复和后台执行不自动使
  新环境继承旧环境的目标、权限或临时句柄。

## 能力与环境组合

| Agent 能力 | 沙盒使用 | 运行时所在操作系统直接使用 |
|---|---|---|
| Computer use | 操作获准的隔离桌面/视觉环境 | 操作获准的真实桌面和应用，可以与用户共享 |
| Browser use | 操作隔离的浏览器环境及其页面 | 操作本机上获准的浏览器环境及其页面 |
| Shell use | 在沙盒的工作环境中执行命令和终端工作 | 在当前操作系统获准的目录、进程与权限范围内执行命令和终端工作 |

这些是系统级产品组合，具体部署的有效子集按 C2 决定，不预先决定六套实现、
六个插件或同一个统一工具。Browser use 也不由普通 Web search/fetch 自动替代；
用户提到的既有编码助手仅用于说明
共享本机环境的体验，本轮不据此声称采用其技术机制。

## 可观察场景

| 场景 | 应有表现 |
|---|---|
| Agent 需要在隔离环境里运行命令或操作网页 | 获得符合要求的沙盒并在其范围内完成，用户能辨认隔离目标 |
| 用户授权 Agent 处理当前电脑上的文件、应用或网页 | 对指定真实环境生效，结果能在相应文件、应用或浏览器中核对 |
| 所需沙盒当前不可用 | 明确报告不可用；不悄悄把相同动作放到用户电脑执行 |
| 两个部署具有不同模型能力等级、装配、默认权限或用户授权 | 可以呈现不同有效环境范围，并能解释依据；一个部署支持两类不代表另一个也已开放 |
| 用户在 Agent 操作桌面时接管输入或切换目标窗口 | 控制与目标变化可辨，旧截图坐标不能继续被当作可靠输入依据 |
| 浏览器下载需要交给另一个工作环境 | 交接范围及实际结果可核对，不能仅返回本不可访问的临时路径却声称已保存 |
| 命令仍在后台运行，Agent 运行时重建 | 按 PF-003 重新关联已有调用，核对实际环境和结果，不自动重复启动命令 |

## 关联与待设计事项

[PF-006](../user/PF-006-user-settings-and-agent-definition-authorization.md) 拥有
用户设置和定义级授权，[PF-007](../user/PF-007-system-initiated-hitl.md) 拥有
需确认动作的系统拦截；直接使用可消费相应有效授权，不因此要求所有动作逐次
HITL。[PF-010](../user/PF-010-organization-personal-assets-and-permissions.md) 与
[SYS-TENANT](../../system/constraints.md#sys-tenant) 继续约束共享电脑上的租户
数据与操作权限，物理共享不能变成跨组织借权。
[PF-014](../agent/PF-014-runtime-tool-and-skill-discovery-and-loading.md) 约束工具/技能
按需装载与真实环境适配，[PF-015](../agent/PF-015-artifact-management-and-isolated-working-copies.md)
拥有制品向本机/沙盒的加载、隔离工作副本及持久保存，不以执行环境目录代替存储。

[SYS-RUNTIME-CONTINUITY](../../system/runtime-state-and-continuity.md) 拥有异构
装配与同构恢复目标，本项提供具体消费场景。操作环境、会话运行时和工具后台
执行的生命周期分别表达；后台不等于沙盒，本机直接使用也不等于只能前台执行。

待设计：各操作系统的支持矩阵、模型能力等级/装配/默认权限/用户授权的组合
与变更生效规则、沙盒隔离等级与供给、执行环境选择规则、桌面
接管和输入竞争、浏览器 profile/登录态使用方式、命令与文件的权限边界、环境间
交接、长期终端和故障恢复。共享本机支持不预先决定默认读取全部用户状态、
取得管理员权限或使用某个浏览器协议。

[当前候选](../../../proposals/agent-core/README.md#当前需求对应与缺口)尚未定义
这些能力及两类环境的完整语义。本次登记直接要求和来源映射，不采用旧沙盒
专用能力作为全系统唯一执行路径，也不选择容器、虚拟机、桌面后端或 shell。
