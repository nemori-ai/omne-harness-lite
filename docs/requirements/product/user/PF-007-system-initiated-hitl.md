# PF-007：系统发起的 HITL 与动作授权确认

[用户维度](README.md) · [来源核对](../../../research/user-governance-and-decision-pool-sources.md)

主维度：用户，关注系统向用户请求决定及其对行动的效力。副维度：智能体，关联
智能体的动作被系统拦截、等待或按声明形成暂行产物。

## 已确认要求

2026-09-12 用户明确继承系统发起的 HITL，包括依据编译后的需授权动作，在
执行前拦截并向用户确认。C1–C3 直接展开这一要求；C4–C7 结合原系统已确认
范围与有效补充登记。系统发起与 agent 主动提问是两个来源，不能只依赖智能体
自行决定是否询问来兑现本项。

- **PF-007.C1：系统能够主动要求用户决定。** 当实际动作命中需要人类确认
  的条件时，系统能够发起可辨认的 HITL 请求，说明触发原因、动作与对象、缺少
  的授权、影响及可选决定。内容根据实际动作和授权事实生成，不能只复述 Agent
  自称的行动意图。
- **PF-007.C2：需事先授权的动作在执行前受控。** 系统能依据编译后的动作
  及权限声明，结合用户对相应 Agent 定义的授权、当前会话权限模式和适用策略，
  在需事先授权的动作开始前拦截并取得确认。未经有效批准，不执行该受控动作。
  编译或装配时曾经通过检查，不等于执行时仍然获准；实际准入使用当前有效依据。
- **PF-007.C3：答复作用于被确认的具体工作。** 系统将答复可靠关联到该次
  请求及其动作，在用户有权授予的范围内决定放行、拒绝或明确的后续处理。
  含糊回复、等待超时或通知送达不构成批准；参数、对象或授权范围改变后不能
  静默沿用不适用的旧决定。系统的许可、拒绝、需询问三种结果须可区分，硬性
  拒绝不能靠弹出一次确认变成可由该用户放行的动作。
- **PF-007.C4：阻塞请求可长期等待并恢复。** 需事先取得用户决定的请求先
  耐久登记再呈现，没有自动超时或默认答案；等待与运行时资源寿命解耦，允许
  有界热宽限后回收。运行时重建后请求仍可定位，合法答复可驱动对应动作的
  后续处理；显式关闭、取代或工作终结后不能被迟到答复或恢复流程重新激活。
- **PF-007.C5：与主动请求汇入同一决策池。** 系统请求进入
  [PF-008](PF-008-unified-decision-pool.md)，用户可直接在池内回答，无需返回
  来源会话。系统仍负责判定动作是否获准；池只提供统一呈现和作答入口，不能
  绕过该动作自身的授权与结算规则。重复答复不重复形成批准或执行准入。
- **PF-007.C6：符合资格的动作支持暂行确认。** 继承原系统已承诺的未来
  路径：授权允许延后且已被显式登记的动作，可先形成耐久、受遏制的暂行产物，
  Agent 继续工作，用户再定夺。资格要求领域内的暂行承载和全函数撤销；暂行
  期间声明禁止的不可逆后果不能发生，依赖它产生的后续产物同样保持暂行关系
  或被正常拦截。缺少资格的动作仍走事前阻塞确认，不能凭“应该可撤销”的自述
  先执行。会话内呈现窗口到期只改变决定的呈现位置，永不默认批准或驳回。
- **PF-007.C7：暂行决定的后果明确且可追踪。** 同一个暂行产物在会话和
  决策池共享一个决定；首个合法定夺生效。批准使其正式生效，驳回执行完整撤销，
  沿暂行依赖关系级联撤销，失败明确暴露；不能把补偿笼统当成已经完全撤销。
  决定回传按动作预先声明的策略执行，可为仅改变产物、供下次运行感知、触发
  一次接续或触发补偿，用户可查看回传结果。此路径不降低原有授权判定要求。

## 可观察场景

| 场景 | 应有表现 |
|---|---|
| Agent 未主动请求批准，却调用了需事先确认的动作 | 系统在执行前拦截，向用户呈现准确动作及授权需求 |
| 编译时允许的动作在执行前被撤权 | 实际动作按最新依据处理，不能沿用旧快照放行 |
| 用户在决策池批准某个被拦截动作 | 决定回到那件工作，系统核对授权和请求后处理；重复提交不重复放行 |
| 合格动作形成暂行产物，用户暂时不在 | Agent 可继续，决定保持待定，呈现窗口到期不代用户裁决 |
| 用户驳回有依赖产物的暂行决定 | 依声明完整撤销及级联，真实结果和失败对用户可见 |

## 边界与待设计事项

[PF-005](../agent/PF-005-agent-initiated-human-input-and-approval.md) 拥有 agent
主动问题与一次性批准；[PF-006](PF-006-user-settings-and-agent-definition-authorization.md)
拥有用户设置及定义级授权；各请求的合法作答者由其自身授权语义决定，集中
呈现不能让任意会话 owner 代替设备 owner 或其它专用裁决主体授权。

待设计：编译产物与有效授权的映射、动作和请求身份、动态更新与执行准入边界、
阻塞/暂行路径的声明与验证、撤销依赖、结果回传和恢复模型。暂行资格的具体
动作目录继续逐项登记。本项不指定编译器、守卫类、权限引擎、数据库或消息框架，
原系统某条路径未实现也不缩小本轮已确认的产品范围。

本项受 [SYS-TENANT](../../system/constraints.md#sys-tenant) 等全局要求约束。
[当前候选](../../../proposals/agent-core/README.md#当前需求对应与缺口)尚未覆盖
完整系统 HITL 和暂行确认；接受要求不等于接受旧架构或证明这些流程已交付。
