# 文档与规格体系提案

## 接受记录

2026-09-12，用户明确授权构建此前讨论的组织与长期维护体系并迁移现有内容，补充决定最终权威及因果复议原则，并认可防御分类与主力开发模型切换前的评估要求。接受范围是组织和治理机制，不自动批准候选业务模型或具体服务切分。

原始讨论稿保存在 [v1](v1/README.md)，其中“proposed”和未来语态反映当时状态。当前有效规则以以下决定及其落实文档为准：

- [D-001：组织与维护](../../decisions/D-001-documentation-system.md)
- [D-002：决定权威与因果复议](../../decisions/D-002-decision-authority.md)
- [D-003：防御指导与开发模型评估](../../decisions/D-003-defensive-evaluation.md)

## 用户补充的直接依据

有效决定在没有新观测时是最终权威；每项决定至少关联提案或研究。决定允许被推翻，但必须提供事后可复现、可验证且能够因果解释的强理由。开发主力模型切换前，需要评估它是否仍需强制遵循特定防御模式。
