# 预算、供应方账务、工程观测与命令入口（候选）

本页补齐[能力图](capabilities.md)中的必要相邻能力，消费
[共享提交和身份](shared-contracts.md)。它们不因与 Session 共同部署而失去
独立状态权威。完整支付执行、客户端界面和 Connector 领域仍在本轮之外。

## 计量与预算

**BG-01**：ChargeAttempt 关联 tenant、StepRef/WorkRef、模型/工具 request/
call/attempt、原 Session/Run、定义、因果派发关系、供应方和价格依据。每笔
计量以 sourceId/externalFactId/revision 去重；同一回执重放不增费用，供应方
实际两次计费不得因相同逻辑请求而合并。迟到费用归原 Step 及原账期依据，
不得因 Run 已完成、Agent 已回收或当前用户换租户而丢失。

金额用十进制定点整数与 scale、currency 表示，不用二进制浮点累加。数量
带 unit，金额质量 actual/estimated/reserved/unknown 分别表达；缺失价格
或回执不是确认零。实际调整以修订/冲销关联保存，不覆盖原估算证据。
不同币种分别汇总，转换须有独立汇率事实及转换时间；首版不自动转换预算。
无法归因共享费用在租户账目列出 unallocated 差额，不平均分摊伪造精确性。

**BG-02**：Budget 具有 tenant、scope（tenant/definition/Session/Run）、currency/
单位、额度、周期、mode、阈值和 revision。首次启用计费来源必须有明确预算
立场，不隐藏 unlimited。mode 为 observe、soft、hard：observe 记录消耗；
soft 记录阈值和告警后果；hard 在下一计费准入检查并预留当前暴露。
多个适用预算分别成立，子 Agent 的新身份不重置租户预算或脱离因果归集。

**BG-03**：reserve 在调用受理共同提交中，为精确 attempt 同时检查所有适用
预算/额度的剩余量及修订，原子增加预留；任一拒绝不留下已准入调用或漏记
预留。预留和动作权限分别成立。start 前取消且可确认从未发出时释放预留；
已发出/unknown 时保留暴露直到实际对账，不能因连接关闭归零。结算时将
相同 attempt 的预留转换为实际/估算与未决差额，重复提交不扣第二次。

**BG-04**：可核实的单次费用上界来自实际价格/单位限制和 provider 的可兑现
约束，不从 token 估算自称严格封顶。事后计费上界未知时，hard 默认拒绝该
来源的新准入；获准用户可在配置中明确选择 allow_unknown_exposure，该来源
仍按已知预留和触顶规则限制新工作，但对外必须显示总超额上界未知，不能
宣称严格财务封顶。该选择不由 Agent 或普通批准工具隐式授予。

迟到收费或预算下调可使剩余量为负，不自动强杀在途调用，不改写供应方
账目；后续按新值拒绝/告警。预算周期切换记录精确周期身份，旧预留及迟到
结算留在原周期，不通过重建或午夜重置抹去。告警送达失败独立于超限事实。

## 订阅、授予额度与账单

**BG-05**：SubscriptionLink 由租户管理能力拥有本地关联和变更意图；供应方
拥有其实际订阅/账期/状态/结算。操作 list/get/requestChange/requestCancel/
reconcile 保留当前外部版本、期望变更、生效时间和 pending/applied/rejected/
unknown 结果。相同变更意图重试认回来源操作，不能重复购买；未知期间先
核实，不把本地按钮成功当供应方已修改。实际支付、税务发票和代扣未由此
接口授权或实现。

**BG-06**：授予额度有具名签发者、受益 tenant、单位、周期/重置规则、来源
事实版本和有效状态；本地未被授权的管理者不能生成供应方额度。使用资格
消费当前授予依据，不以剩余预算替代订阅。额度重置/暂停/撤销影响下一
准入并与预留协调；在途实际消耗和历史周期保留。来源权威不可达时明确
资格 unknown，只有来源保证仍有效的依据可使用，不沿用普通缓存越权。

**BG-07**：Invoice/Statement 读面保留供应方文档身份、账期、行项目、币种、
金额、结算状态与修订。它和本地 Step 计量以证据关联对账，差异分别显示
matched/unmatched/disputed/unknown；本地估算汇总不冒充正式账单。财务
管理者可看有权金额/范围和关联 ID，不据此取得私人会话正文或秘密值。
提供者卸载不删除账目与待核实意图，重新绑定必须认回相同供应方身份。

## 工程观测

**OB-01**：每项业务能力在本身的操作/提交边界生成受理、拒绝、开始、等待、
答复、控制、终态、失败、unknown 与动态变更依据，带 CD-02/CC-07 的关联。
工具过程披露与这些工程事实不同；未形成调用即被拒绝的入口也必须有
可定位 operation/主体/阶段及被裁剪目标，不能只统计成功调用。

观测采集与读面拥有采集 cursor、处理版本、来源水位、保留策略、索引、
导出任务和 gaps；关键业务记录仍由原权威拥有。工程事件非授权或执行
命令，不允许观测 listener 改变已经成立的结果。度量至少覆盖队列/等待/
执行延迟、请求/错误/拒绝计数、资源使用、依赖就绪、写入/交付水位和费用
质量；它们不是供应方账单。

**OB-02**：关键生命周期/审计随所属耐久提交或可核实 outbox 保存，不受
普通诊断采样丢弃。非关键诊断允许有界缓冲/采样/保留期，但记录缺口类型、
来源范围、水位和丢弃计数。采集/传输/存储/索引故障和积压对读面可见，
无需伪造覆盖全链路。关键记录不能保存时拒绝依赖它的新效果；入口拒绝
自身也无法耐久记录时返回 audit_unavailable 并保留可用的最小诊断，不能
声称审计完整。诊断故障不通过递归记录制造无限任务。

**OB-03**：query/export 使用当前身份、tenant、内容分类和对象权限；原
记录内容按秘密引用、敏感参数与正文权限裁剪。关联 ID 不等于全文读取
能力。导出固定快照/水位，保留期结束或缺失显示 gap/gone；不从若干成功
span 推导整体已完成。观测插件卸载先排空必要记录，失败保留责任及
剩余 cursor；采集恢复认回原水位，不重放业务效果。

## Slash、技能与键盘控制

**IN-01**：SlashCommand 是独立定义资产，绑定精确 Skill/Prompt 及参数
Schema、作用域和效果类型；来自所选 definition/plugin 版本的命令目录
按当前权限披露。命令词法仅作用于输入开头，命令名为 ASCII 字母起始、
后续字母/数字/下划线/连字符，最长 64 字符；多命令以显式 ` /` 起始的
下一命令分隔，参数用一个完整 JSON 对象表示，后续 ` -- ` 后为普通正文。
JSON 对象按标准 JSON 解析其字符串/括号，不靠空格猜测边界。最多命令数
为可查询有界配置，缺省 8；该数为候选实施默认，不是来源产品要求。

例如 `/review {"depth":"short"} /style {} -- 请检查此文` 产生两个有序
上下文装载意图和一份普通正文。未知命令、非法参数、数量超限、失效引用
整份输入在受理前拒绝；用户显式选择 literal 模式可原样发送以 `/` 起始的
文本，错误解析不自动回退聊天。上下文装载型意图随同一普通输入耐久
排队／取批，固定定义和内容引用；实际使用仍重检，禁止从命令执行任意代码。
系统控制/有序命令按自身已登记操作进入 SR 协议，不把所有 slash 限定为
上下文装载。语法不等于模型的多命令工具参数范式。

**IN-02**：keyboard binding 归全局用户账号设置，客户端按平台能力读取。
绑定一个具名控制及精确目标，服务端使用当前授权和 SR-10，不能从按键
获得权限。冲突／不支持／系统保留键明确呈现，不自行改键；输入法和文本
选择上下文优先按客户端声明处理，等价显式按钮仍可用。键盘输入不自动
变成宏、slash 或复合任意脚本。UI 渲染和捕获实现属于后续应用装配。

## 具体计量来源核对

2026-09-13 的 OpenRouter [Usage Accounting](https://openrouter.ai/docs/cookbook/administration/usage-accounting)
说明响应/最后 SSE 可携带用量和费用，也可沿 generation ID 查询。adapter
保留该 ID、原始计量单位及来源；连接在最后帧之前中断仍可能缺失费用，
不能将文档的正常响应路径当无条件完整账务保证。[Generation 查询](https://openrouter.ai/docs/api/api-reference/generations/get-generation)
是核实入口，不是任意用户 Run 的外部幂等重试证明。具体单位到金额的映射
须由实现固定 API 样例验证，不能把 credits 和不同币种数字直接相加。
