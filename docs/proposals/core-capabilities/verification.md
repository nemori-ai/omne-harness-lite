# 设计验证与未完成的实现义务

形式工件与 [Schema](../../../spec/data/core-work/v1/schema.json) 已迁入
精确规格版本，接受依据为 D-008。实际配置、工件哈希、命令、返回码和日志见
[运行记录](evidence/model/results.json)，可由 [replay.py](evidence/model/replay.py)
重放，须提供 JAVA_BIN 和 TLA2TOOLS_JAR。

| 模型 | 规范映射 | 有限范围与刻意未覆盖项 |
|---|---|---|
| Admission | AU-03–06、HD-06、TL-08、CC-03；C04–08/C15 | 一个冻结动作、一次工具换代/成员撤销，三模式、一个决定、开始/停止送达交错；准入存当前授权见证，不要求后来的撤权抹去历史合法性；不证明真实解析器/远程 fencing |
| Decisions | HD-01/03/08、SR-09；C06/C10/C11 | 两个独立问题、owner/admin、逐次原子接续及其完成；公平调度下已答问题可独立接续；全局中断/关闭解除活性义务，不承诺人一定回答；原子接续抽象实际串行驱动 |
| QueueControl | SR-07/12；C12/13/15/16 的部分交错 | 三个预置输入含一个命令、一次编辑、领取/清除/强停/hold；safe 是当前停止的已验证回执抽象，不建模具体进程隔离、新输入到达、重排、批量领取、重试或 interrupt_then_run；C14 整体留待实际组合验证 |
| Budget | BG-03；C18 | 两 attempt、一单位已知上界及计费；原子预留/回执去重；无货币转换、未知上界、价格变更或实际供应方行为 |
| Provisional | HD-10–12；C25 | 父子两节点的批准/拒绝/finalize/逆序撤销；不证明实际撤销函数完整或任意 DAG 的结构正确 |
| ModelSelection | MC-08–10；C20 | text/image、支持/不支持/unknown、窗口三态与一次压缩；不覆盖完整模态编码或真实 OpenRouter 请求 |
| Recovery | DR-02–04/CC-03；C09 | 一个 envelope、完整/尾部/坏行、同步/回执/一次重启；恢复 full 重新同步再认回，bad 保留 unknown；不证明磁盘、文件锁或 OS 的实际耐久性 |

正向模型要求 TLC 完整探索退出 0。负向配置要求对应的指定不变量反例（退出 12）
或 IndependentProgress 的活性反例（退出 13）；语法错误、未赋值状态、超时
不算有效反例。初跑发现的模型运算符优先级错误已修订后重跑，不作为产品缺陷。
故障配置覆盖跳过授权、提前效果/回执、迟到启动、管理员代答、全答屏障、提前
Run 完成、越过 hold/安全停止、超额准入、重复计费、跳过暂行父项和模态检查、
重复压缩。检查是有限状态证据，不是全部产品、无界系统或跨模型 refinement 证明。

[组合场景](../../../spec/compositions/core-work-coordination/v1/scenarios.md)列出其它提供者验收条件。真实 JSONL 同步与
损坏恢复、授权屏障、租户隔离、模型/工具网络效果、媒体 GC、预算账务和应用
答复投影仍待后续实现验收。本轮源码 fork 只检验选定来源的可构建消费起点，
不会以 fork 测试替代这些目标验收。
