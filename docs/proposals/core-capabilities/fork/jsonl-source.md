# 普通 JSONL 文件机制源切片

来源为固定 `c291e796` 的 `packages/session/session-persistence-jsonl/src/index.ts`。
本切片保留其文件打开/写入/同步/关闭、目录同步、失败后截回及首行分块读取算法。
完整入口原件只供来源比对，不编译；不导入 format catalog、历史 generation
迁移、压缩、native 锁或 Windows 桥。完整后端和项目 envelope 编码仍未实现。

语言无关前提：调用者已拥有受信路径和对文件的独占写入责任；同一文件写入
串行发生。单个操作打开并拥有文件句柄，在成功或失败时尝试关闭。新建使用
排他创建，已有文件不得覆盖；写完同步内容。追加保存原始长度，写入/同步失败
时关闭句柄并尝试截回原长度、同步。截回失败同时报告原故障及恢复故障，不
声称没有追加。目录同步是独立步骤，不从内容同步推断目录项已经耐久。

首行读取在每次异步读取前后检查 caller 的取消信号，按块读取到换行；EOF
没有完整首行返回 undefined。它不解析 Session 格式，也不验证整个日志；单行
总长度未额外限定，调用者仍须提供准入/容量约束。取消读取不删除文件。

本地适配：原方法的 Session 路径/事件编码参数改为受信 filePath 和 bytes，
新建函数由调用者提供路径，不隐式产生无人追踪的随机临时文件。提取过程中
保留写/同步与 rollback 顺序，关闭失败与原错误同时保留。Windows 的目录
同步具名拒绝，Linux 临时文件测试是本轮实际平台范围。

目标 DR v1 还要求写入权/epoch、完整 envelope 与原子提交域、目录发布、
损坏/截断区分、unknown 隔离和恢复核实；这些不能由本组文件函数单独兑现。
故只公开 baseline/jsonl I/O 原语，不将它登记成 SessionPersistence 服务或
可用于生产的目标 JSONL 提供者。并发写入权和用户路径授权也不由此赋予。
