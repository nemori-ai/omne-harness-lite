## 目标与范围

在 `design/dsh-core-adoption`、基线 `c3563c9` 上完成下列能力族的设计：
会话/状态/持久化，工具，租户，模型/多模态。识别独立状态权威与可替换能力，
明确 Cordis 的服务、插件贡献、受限运行对象、依赖和事件映射；包数量不由能力
清单预定。完整设计包含身份/数据、操作/提交、授权、所有权、失败/未知、撤除、
恢复与未来独立部署边界，以及可执行模型和真实实现验收场景。

范围包括这些能力不可缺少的最小相邻契约：输入/Run 控制、定义与设置、使用权益、
预算、HITL、媒体内容及模型上下文装配。不会顺带设计完整管理 UI、支付渠道、
插件代码分发平台或每一种 shell/browser/computer/sandbox 后端；明确其接入义务。

## 工具声明驱动的系统 HITL

2026-09-13 用户在承接 session `01a0989d-024f-73d2-bc15-cfa624e3515e` 时补充：
工具在定义时自行声明需人类批准的动作，装载时自动识别、解析并登记；调用时
结合当前会话运行的权限模式及用户已有授权，判定是否拦截，让对应工作等待
用户放行或拒绝。这是 [PF-007.C1–C5](../../requirements/product/user/PF-007-system-initiated-hitl.md#已确认要求)
的系统发起流程。以下作为本轮必须完成的设计与验收范围；具体数据和操作在
专题契约中定稿，不把计划当作已经发布的规格。

| 环节 | 设计义务 | 必须验证的结果 |
|---|---|---|
| 定义与声明 | 工具定义承载命令/动作级授权声明，能由实际参数解析出目标、范围、影响和确认需求；多命令工具不能仅按顶层工具名授权 | 同一工具的不同命令、对象和参数得到正确的授权需求；帮助/skill 阅读状态不构成人类批准 |
| 装载与登记 | 随工具贡献的装载自动解析、校验并登记声明；定义身份/版本、贡献代次、租户与作用域可追踪。明确注册表是工具声明的受管索引及解析能力，不另建一份授权事实权威 | 工具可调用时具有匹配的有效声明；非法声明、登记失败或冲突不会留下可调用但未受控的工具；新增工具无需手工另写一份审批规则 |
| 当前授权判定 | 工具执行准入必经系统授权门，使用实际动作、当前 Agent 定义授权、会话权限模式、用户配置及适用约束，明确 `allow` / `deny` / `ask` 与判定依据 | 已有有效授权允许时直接准入；需确认时执行前拦截；硬拒绝不能通过询问升级，装载时的许可不替代执行时重检 |
| 耐久等待 | `ask` 在受控效果开始前耐久登记请求及对应 Session/Run/调用的等待关系，再呈现到会话及统一决策池；明确暂停范围与仍可处理的控制/答复 | 等待不依赖活体 Agent 或内存 Promise；关闭界面、回收、重启后仍可恢复，无自动超时或默认答案；拒绝、取消、强停和取代各有可观察出口 |
| 答复与接续 | 按同一请求身份验证作答者、动作绑定及当前授权；首个合法决定生效，批准后的执行准入仍须校验，接续受耐久幂等和工作终态约束 | 会话与池内竞态/重复答复不重复决定或准入；拒绝不执行；迟到批准不复活已关闭工作；参数、对象或授权范围变化不能沿用旧批准 |
| 动态变化与恢复 | 设计工具更新、卸载、重载与声明登记/撤回的共同可见边界，区分新调用、待批调用和已准入调用；保留历史请求和精确绑定 | 旧声明或旧版本的批准不能自动授权替换后的动作；等待期间撤权或模式变化按当前规则处理；声明提供者失效不成为绕过授权门的路径 |

授权事实与设置生效由 [PF-006](../../requirements/product/user/PF-006-user-settings-and-agent-definition-authorization.md)
约束，统一池按 [PF-008](../../requirements/product/user/PF-008-unified-decision-pool.md)
提供同一请求的呈现和答复入口；工具声明、授权求值、请求/决定、Run 等待各自
只有一个状态权威。系统拦截必须独立成立，不能依赖 Agent 主动调用批准工具。
原设计要求明确具体权限模式词表、配置优先关系、声明解析接口与等待后接续协议，不能把旧系统字段或某个库的 registry API 直接当作已接受接口。

[PF-007.C6/C7](../../requirements/product/user/PF-007-system-initiated-hitl.md#已确认要求)
的暂行确认保留独立资格和撤销义务；仅声明“需批准”不授予先执行资格。
普通事前审批不得因超时、转后台、通知送达或“可补偿”的自述而放行。
