# 拓展件领域交接设计

已接受职责沿[领域入口](README.md)，本页只维护事实拥有者和跨领域交接。工程细化与成员分工见[包组规格](../../../packages/loop-extension/SPEC.md)。

## 责任与消费者

| 责任 | 事实拥有者 | 交接及拒绝边界 |
|---|---|---|
| 包的格式、声明的判断、类别的登记 | 本领域；声明的字段与判断规则归 [Agent 推进](../agent-progression/README.md)的作者协议 | 给资产一份可校验的类别契约。不合法的包不发布，不记版本 |
| 包的内容、读口与本机目录 | [资产与规则](../assets-and-rules/README.md#内容的存放与包的读口) | 本领域按能力标识与版本取读口或本机目录，不认目录布局。摘要对不上答材料不可用 |
| 持有、版本、禁用、求值 | [资产与规则](../assets-and-rules/README.md) | 本领域消费求值结果，不重做层级求值。出局的候选不进视图 |
| 「运行」设置的声明 | 本领域经类别契约声明 | 配值、锁定与求值归资产的设置规则 |
| 变化信号 | [资产与规则](../assets-and-rules/README.md)的写入者 | 信号只说明变了，不带值。本领域重读 |
| 租户启用的拓展件这份视图 | 本领域 | 经 Runtime Context 供给。任何来源读不到时答读不到 |
| 这一块在租户级作用域里的登记与读取资格 | [Runtime Context](../runtime-context/README.md) 的租户级作用域与应用的装配 | 这一块没有贡献时读者得到缺项，按读不到处理，不按没有成员处理。会话的作用域不登记它 |
| 一次经过的扩展链、调用请求、结论 | [Agent 推进](../agent-progression/README.md)，经会话日志的写入者保存 | 本领域不写会话日志 |
| 实现的取得与一次调用的结果 | 本领域 | 交回输出、不可用、报错、未知之一。不替 Agent 裁定输出合不合法 |
| 子进程的启动、停止与资源 | [执行环境](../execution-environments/README.md) | 本领域是它的集成方之一，自带耐久账本与守卫 |
| 这次调用在哪个作用域与落点运行 | 应用装配的适配成员 | Agent 与本领域都不认识会话；适配成员按访问身份取得 |

责任分解不决定包、插件、进程或部署数量。

## 端口与实现方

本领域为别人实现的端口：

| 端口 | 需求方 | 对得上的一句话 |
|---|---|---|
| 扩展实现 | Agent | Agent 需要按精确版本取得一个成员的实现并调用；本领域提供 |
| 类别契约 | 资产与规则 | 资产需要校验一个包并取出声明；本领域登记 |
| 块的声明与供值 | Runtime Context | Runtime Context 需要一块的语义与当前值；本领域把这一块贡献给租户级作用域 |

本领域声明、由别人实现的端口：

| 端口 | 实现方 | 本领域需要什么 |
|---|---|---|
| 层的来源 | 资产与规则 | 按类别列出一个租户在持的资产；按能力标识取各层候选 |
| 包的读口与本机目录 | 资产与规则 | 一个版本的声明与文件 |
| 设置的读取 | 资产与规则 | 一件拓展件「运行」设置的当前值 |
| 变化信号 | 资产与规则 | 资产或设置提交之后的一条信号 |
| 环境面与命令设施 | 执行环境 | 落点、租约、启动一个进程、停止、结局 |
| 耐久存储 | 存储 | 命令型调用的账本 |
| 运行位置 | 应用装配 | 一次调用的作用域、落点与工作目录 |

## 组合保证由谁承担

| 保证 | 参加者 | 承担者 |
|---|---|---|
| 租户启用一件拓展件之后，它从下一次经过起运行 | 资产、本领域、Runtime Context、会话、Agent | 发行应用的装配 |
| 同一次经过里扩展链不变 | Agent、会话日志 | Agent |
| 命令型的一次调用，启动意图先于启动落盘；宿主重启后先结清未停的进程 | 本领域、执行环境、存储 | 本领域的本机宿主 |
| 一个租户的拓展件不进入另一个租户的执行 | 资产的求值、本领域的视图、每次调用携带的租户 | 各自守自己的一段；整体由发行应用的装配验证 |
