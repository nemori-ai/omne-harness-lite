# 拓展件

## 范围与边界

拓展件是挂在一处 Loop 扩展位置上的一段判断或动作。Agent 不知道它存在：它不进系统提示词，也不进工具声明，由系统在固定位置调用。本领域维护拓展件这一类资产的专有知识：一件拓展件的包与声明，一个租户此刻启用了哪些拓展件，以及一件拓展件的实现怎样取得、运行和收场。

本领域不拥有扩展位置。位置、维度、干预力、位置输出表、扩展链的归约和一次经过的记录归[Agent 推进](../agent-progression/README.md)，规则见[Loop extensions](../../architecture/runtime/loop-extensions.md)。本领域依赖 Agent 的契约，Agent 不认识本领域。

定义、持有、版本、发布与设置复用[资产与规则](../assets-and-rules/README.md)。拓展件不组合任何资产，也不被 Skill 或 Tool 组合。

## 模块角色与事实归属

| 模块角色 | 拥有的知识 |
| --- | --- |
| 包与声明 | 一个目录是不是合法的拓展件；从目录到声明的投影；向资产登记的类别 |
| 租户启用的拓展件 | 按当下事实算出的一份视图：这个租户此刻哪些拓展件会运行，各是哪一版 |
| 实现的取得 | 按精确版本找到一件拓展件的实现；找不到时答不可用 |
| 内建实现 | 随发行登记的函数，按名字取得 |
| 命令型实现 | 包里带的脚本，由子进程运行；一次运行的启动、时限、收场与未知 |

租户启用的拓展件是视图，不另存一份事实。它由资产的持有、版本、求值结果和每件拓展件的「运行」设置算出。任何一项来源读不到时，这份视图答读不到，不答空。

## 协作与依赖

一件拓展件从租户资产到在循环里生效，经过下面这些拥有者。每一项只有一个拥有者。

| 问题 | 谁答 |
| --- | --- |
| 包是不是合法的拓展件 | 本领域 |
| 是谁的，哪一版，禁没禁用，「运行」设置是什么 | [资产与规则](../assets-and-rules/README.md) |
| 这个租户此刻启用了哪些 | 本领域算出，经 [Runtime Context](../runtime-context/README.md) 供给 |
| Agent 定义组合了哪些 | [装配与交接](../assembly-and-handoff/README.md)，记在采用依据里 |
| 一次经过运行哪些、什么顺序、输出许不许、怎样归约 | [Agent 推进](../agent-progression/README.md) |
| 实现怎样取得、运行和收场 | 本领域，经 Agent 声明的端口 |
| 子进程在哪里运行 | [执行环境](../execution-environments/README.md) |
| 卡片的唯一有效答复 | [人工介入](../human-intervention/README.md) |
| 一个动作许不许 | [身份与授权](../identity-and-authorization/README.md)的官方动作准入 |

「此刻启用了哪些」是租户一级的一个事实，走 Runtime Context 的租户级作用域：本领域贡献这一块，Agent 一侧的适配成员是读者。它不登记在会话的作用域里，会话的创建不为它付代价。「调用这一件」是一次调用，走 Agent 声明的端口。两条路互不决定。

## 主路径与交接

1. 租户发布一个拓展件的包，并记成自己的持有。本领域校验包并投影出声明，发布本身归资产。
2. 租户把这件拓展件的「运行」设置打开。
3. 资产或设置的写入者在提交之后给出变化信号。本领域据此作废这个租户的视图，下一次被读到时重算。
4. Loop 走到一处位置，读到这个租户此刻启用的拓展件，确定并记下这次经过的扩展链。
5. Agent 对链上每个成员先提交调用请求，再经端口调用。本领域按记下的精确版本取得实现并运行。
6. 本领域交回输出，或者交回不可用、报错、未知之一。Agent 按位置输出表与干预力裁定，并记下结论。

租户停用或移除一件拓展件之后，它不再进入新的经过。已经开始的调用照常收场。本领域的服务被卸下时，视图答读不到，实现答不可用；在途的子进程由本领域按自己的账本结清，不随卸载默认消失。

## 命令型拓展件

命令型拓展件的实现是包里的一个入口文件，由声明里写明的解释器运行。解释器是一个名字，由宿主的解释器表解析成本机的路径；表里没有这个名字时，这件拓展件不可用。

一次运行只经执行环境的命令设施启动。子进程不继承服务进程的环境，只得到白名单里的环境变量。输入经标准输入交给它，输出从标准输出读回，时限由声明给出。

命令型拓展件在运行当中不能回调系统。它需要的运行数据在声明里写明，由系统在启动之前读好并记下，随输入交付。需要模型调用的拓展件不能用命令型实现。

起不来、已经开始后失败、判不明是否开始或是否收场，是三种不同的结果，规则见[Loop extensions](../../architecture/runtime/loop-extensions.md#不可用报错与系统扩展)。
