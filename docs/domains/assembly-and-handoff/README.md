# 定义求值与装配交接

本页维护已接受的应然模块分工与公开协作，采用范围见[领域入口](../README.md#维护与状态)。引用的上游约束保持原采用范围；正文接受不表示当前代码已实现。

## 范围与边界

本责任把获准定义、实现、设置、权限及运行条件求值为可采用的执行配置，协调结构变化与旧新实例交接。组织/租户/工作区求值和进程发行的Cordis装配不同，不能合成一份全局配置树。

来源身份和规则归共同治理，推进资格归原工作，实际调用和结果归各runtime及消费者。

## 模块角色与事实归属

| 模块角色 | 拥有的决定 |
| --- | --- |
| 定义求值 | 按合法来源选择组合与依赖，保留采用依据 |
| 采用协调 | 校验同次使用的定义、参数与资格，形成执行条件 |
| 绑定集成 | 将独立能力与提供者接入Cordis等装配机制 |
| 换代交接 | 新旧绑定、推进和未完成责任的交接关系。工具除外：工具实现的结构绑定换代由 Tool 的换代协调者承接，见[工具执行](../tool-execution/README.md) |
| 实例提供者 | 明确就绪、撤除、资源和在途行为 |

单个实例不能成为原工作与原执行的唯一恢复依据，定义更新也不等同已有实例更新。

## 协作与依赖

消费[治理规则](../assets-and-rules/README.md)、[工作](../sessions-and-work/README.md)及依赖能力条件，按公开契约装配。不把工作区来源当授权，不从服务键/Context推断业务身份。

必需与可选依赖明确，缺必需不能宣称就绪。独立能力根与集成入口分别维护；业务不读取产品装配入口或依赖宿主私有表示。

内核辅助是同组的另一个成员，名字是 `kernel-basis`。它提供 Cordis 插件辅助和测试装配。操作结果归 `packages/common/operation-result`。它不是求值、采用和交接成员 `assembly`。业务成员可以依赖 `kernel-basis` 的公开入口。业务成员不读取 `assembly` 来取得全局服务或隐式依赖。目录和封存路径归[产品包组织](../../package-organization.md)。

进程级的应用装配（插件树、运行时对象与桥接）不是本责任的定义求值；单机首条租户路径的应用装配见[应用装配](../../architecture/runtime/application-assembly.md)。

## 主路径与交接

1. 取得合法定义/来源、所需依赖及工作条件，求值候选组合。
2. 校验本次采用依据与资格，建立结构绑定及实例的明确就绪条件。
3. 结构发生变化时确定受影响贡献及未发动作，准备新条件并协调推进交接。
4. 原责任按原身份由当前合法拥有者收尾。已发调用的观察、保管与消费不依赖原实例存活。

允许重装配和重新实例化，但不能造成系统性停机。重装配完成不证明原结果已接手或旧推进权失效；数据变化也不一律要求重建。

## 契约与验证导航

求值/采用契约拥有一致依据及失败，绑定提供者拥有装配生命周期，原工作与换代协调者拥有认领/推进交接。工具实现的换代协调者在 Tool 宿主，装配只给候选。精确服务定义、公开类型及协议随这些成员。

上层沿[采用与换代](../../architecture/runtime/assembly-and-change.md)、[Cordis与部署生命周期](../../architecture/deployment/cordis-and-lifecycle.md)、[系统分层](../../architecture/layers-and-dependencies.md)。当前产品责任候选见[Agent 定义与工作推进](../../../.meta_harness/design/product/agent-progression/README.md)及[资产与规则](../../../.meta_harness/design/product/assets-and-rules/README.md)，两者仍为草案，不代替既有技术接受。验证见[组合入口](../verification.md)。

## 后续设计与维护

快照、版本复核、结构绑定换代、同提交和跨进程交接由实际协调者细化。工具的结构绑定换代已由 Tool 的换代协调者细化，见[工具规格](../../../packages/tool/tool-contract/SPEC.md#342-契约缺口决定)的 G7。服务定义随能力的契约拥有者就近维护，目录和工具适配范围沿[产品包组织](../../package-organization.md)；装配组不集中拥有全部能力的Service定义。

改独立提供者只读其契约/绑定即可；涉及来源或推进权才展开对应责任。新的组合产品规则待确认不阻塞已接受生命周期边界。
