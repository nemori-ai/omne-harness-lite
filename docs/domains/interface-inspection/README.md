# 界面检视

## 范围与边界

[界面检视](../../../.meta_harness/design/ubiquitous_language/terms/interaction-and-dispatch.md#ul-interface-inspection--界面检视--interface-inspection)回答一个问题：一个客户端的某一页，在某种模式下长什么样。问的是 agent，答的是一个连着的客户端。

本领域不回答的：

- 有哪些页、一页画什么。那归外壳契约与各领域的界面模块，见[共用界面的规格](../../../packages/frontend/SPEC.md#外壳契约)。
- 怎样画出一张不打扰人的图。那归宿主应用，桌面应用见[它的规格](../../../apps/desktop/SPEC.md#看界面的窗口)。
- 服务端那台机器的屏幕上是什么。那归[执行环境](../execution-environments/README.md)的屏幕设施。
- 图怎样存、怎样进模型的输入。那归[工具执行](../tool-execution/README.md)与[媒体](../media/README.md)。
- 许不许看。那归放行判断。

## 它和谁怎样来往

| 对方 | 来往 | 方向 |
| --- | --- | --- |
| agent 的工具 | 问一次，得到一张图的引用，或做不到的原因，或客户端不在 | 工具调本领域 |
| 客户端的界面模块 | 经一条观察收到请求，经一个提交交回结果 | 本领域的公开协议 |
| 宿主应用 | 照模式画出点名的那一页 | 本领域声明端口，应用实现 |
| Tool 的产出与图像预算 | 把图存成一份产出 | 本领域声明端口，应用接上 |

一次检视没有效果：人正在看的页面、本机记着的选择、服务端的事实都不变。所以结果不知道时再问一次是安全的。

精确的契约、一次请求的每一步与不变式归[包组规格](../../../packages/interface/SPEC.md)。
