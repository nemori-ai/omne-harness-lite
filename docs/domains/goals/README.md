# 目标

## 范围与边界

目标让人把一件事交给一个会话里的 agent，并说清三件事：做到什么算完，怎样量，什么时候停。它管四件事：一份目标怎样成立、怎样修订；agent 干活时怎样知道还差多少；它想收工时怎样判；判完走哪条路。

目标是接在核心系统上的插件。核心域的成员不依赖它；去掉它，会话、agent、模型与工具原有的流程不变，只是会话没有目标，agent 手里没有工具 `Goal`。

三件事互相独立，各有各的拥有者：

| 问题 | 归谁 |
| --- | --- |
| 什么时候算完，什么时候该停 | 目标 |
| 什么时候再推进一轮 | 会话与 Agent |
| 能做什么 | 身份与授权。目标不授予权限 |

目标不是会话的一部分。它跨好几轮，比会话短，一个会话先后可以有很多个；它的规则跟着「怎样把目标写好、判准」变，不跟着受理与循环变。目标也不是日程的一部分：日程每次到点交出一份带目标的 Job，目标本身是一次有限的委托。

## 模块角色与事实归属

| 模块角色 | 责任 |
| --- | --- |
| 目标登记 | 正文的数据、修订与来历；状态与结局；已用的轮数 |
| 读数 | 每条判据与每个指标最近的读数、从哪来；差距表 |
| 进展清单 | agent 维护的那一份：每条判据的状态、证据引用、阻碍、交付物、笔记 |
| 判定 | 打包材料、出题、解释答案；转移函数 |
| 查验 | 要等的判据成批交给独立的一方；任务书；交回的读数；一批的身份 |
| 对账 | 结果不知道的步骤按原身份重做 |
| 会话 | 一轮开不开、输入怎样受理、会话日志、值守 |
| Agent | 一轮怎样推进；终态前的位置 |
| Model | 决策调用的发出、登记、记账与结果保管 |
| 查验的一方 | 怎样动手：它的会话、它的一轮、它的工具与落点。目标只认识交一批、收读数这个端口 |
| 人工介入 | 确认卡片与人的答复 |

这是逻辑分工，不裁定成员的划分。成员见 [Goal 规格](../../../packages/goal/SPEC.md)。

## 协作与依赖

目标认识会话、Agent 的扩展契约、Model 的决策调用、人工介入的等人契约与命令的入口来源，它们都不认识目标。认识每一个邻居的各只有一个适配成员。

目标以系统主体给会话送提醒：开始、恢复、接着干。送进去的输入作者角色是系统提醒。它不写会话的日志，目标的事实存在自己的存储里，按引用指到会话。

一份目标有一个主人。[会话](../sessions-and-work/README.md)有人值守时主人是那个人，无人值守时是建这个会话的一方。设、改、暂停、恢复、取消都要追得到主人的一个动作；agent 只能看、起草与记进展。

[日程](../schedules-and-jobs/README.md)是使用方：交给 agent 的 Job 带一份冻结的目标，Job 的结局照目标的结局。日程认识目标，目标不认识日程。

## 主路径与交接

1. 人用自己的话说目标。会话里的 agent 对齐之后起草正文，调 `Goal` 的 `propose`。
2. 工具出一张确认卡片，上面是渲染出的整份正文。人确认，目标凭这张卡成立。
3. agent 干活，维护进展清单。它每跑一次正文里声明的命令，目标记一笔读数。
4. agent 想收工时，Agent 走到终态前的位置。目标打包三层材料，发一次决策调用，转移函数裁决。
5. 还没完：否决这次收工，给会话送一条提醒，这一轮接着干。该收场：放行，落结局。有人值守而判定发现得停下来：放行，目标暂停，告诉人。
6. 当场读的都成立，只剩要等的判据：放行，目标仍在进行中。目标把这一批交给查验的一方；它动手查完，用 `Goal` 交回每条的读数；目标再裁决一次，达成就落结局，还差就送提醒叫 agent 接着干。

无人值守的会话没有第 1、2 步：建会话的一方带着自己的资格直接交来一份合格的正文。

## 失败、未知与取消

| 发生了什么 | 目标 | 那一轮 |
| --- | --- | --- |
| 人在判定期间改了目标 | 这次判定的结论作废，按新修订重判 | 不放行，重新观察 |
| 决策调用没有应答 | 不重发同一个请求，另起新的，至多两次；仍不行，有人值守时暂停，无人值守时收场 | 放行 |
| 记了一轮，提醒有没有被受理不知道 | 按同一个身份再送，不另计一轮 | 不变 |
| 进程重建 | 状态不变，下一次完成候选照常判 | 按 Agent 的恢复规则 |
| 人停了这一轮 | 有人值守时不变；无人值守时由建会话的一方发中止 | 被取消 |
| 人取消目标 | 已收场，不算成功也不算失败 | 不停；停一轮是另一个动作 |
| 查验还没回来，agent 又写了文件 | 那一批回来时不算数；下一次想收工时交新的一批 | 不变 |
| 查验的那一轮没交读数就结束了 | 这一批每条记成判不了 | 不变 |
| 交出去的一批，交没交到不知道 | 按同一个身份再交，不另起一批 | 不变 |

## 验证责任

- 结局只落一次、达成来自当期观察、同一轮只计一次、轮数有界、没有人的会话不暂停、状态变化不来自 agent、过期的卡片不生效；达成凭的查验读数是新鲜的、一批只交一次、查验的次数有界、读数只来自查验的一方：模型 `Goal`，随成员保存。
- 正文的校验与渲染、转移表与裁决表逐格、材料的上限、答案的解释：成员的契约测试。
- 判定判得准不准、查验查不查得出：评测台上的门槛。
- 终态前的位置与扩展的输出：[Agent 规格](../../../packages/agent/SPEC.md)。决策调用：[Model 规格](../../../packages/model/SPEC.md)。问询卡：[人工介入规格](../../../packages/human-intervention/SPEC.md)。
