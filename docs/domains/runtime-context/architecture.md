# 运行感知与请求的事实归属

本页在正式位置维护待审细化，只有文档目标，没有真实包、公开形状或实际运行验证。产品既定规则保持原确认范围，阶段支持仍待用户选择。

## 2. 事实拥有者与派生范围

| 数据或计算 | 唯一语义拥有者 | 本域责任 |
| --- | --- | --- |
| 原块与读取资格 | 身份、设置、工作区、执行等原生产者 | 经其公开保证供给，不复制成共享权威 |
| 本会话注册、选择及不可重算值 | Session 及实际值的业务拥有者 | 提供合法注册读面、提交与恢复协作，不代定修改资格 |
| 当前块快照 | 由有效注册与原来源共同求值 | 说明来源与覆盖范围，不能当成长期授权 |
| 变化提醒与原业务输入 | 原消费协调者提交到 Session 追加历史 | 区分状态推送和可靠业务输入，保存实际感知关系 |
| 历史内容及块标注 | 消息生产者与 Session 历史 | 只读取合法投影，不回写原件 |
| CompactionMessage | 原压缩协调消费路径形成的追加事实 | 请求计算决定适用排除与摘要，Session 保存共同结果 |
| 派生表示与 transcript | 原内容及转换责任拥有者 | 保留来源、资格和原件关系，按实际模型选用 |
| 请求输入及本次采用依据 | 发起协调者与 Model 原调用 | 交付明确输入范围及计量结果，协作固定采用 |
| 派生集合、索引、缓存 | 原事实的可重建读面 | 标明输入范围、覆盖进度、失效与重建责任 |
| 原结果、真实费用与交接位置 | Model、Tool 及各自合法消费者 | 沿原用途继续，不以 Context 通知替代消费 |

来源及边界由原数据与消费拥有者公开契约维护。同数据库不能证明同提交，实例或连接不决定数据归属。
