# 管理租户

<!-- documentation:placeholder -->

本页服务租户管理者。目前仅提供可核对的来源与停止点，尚无经本页验证的新操作流程。

## 当前入口

先确认任务针对封存的 0.0.1 实现，还是新树中的目标能力。封存实现的步骤、结果与失败处置从[封存版 CLI 命令说明](../../apps.0.0.1.legacy/cli/README.md#commands)读取。操作前核对调用身份、授权及作用范围。目标架构和文档目录不表示当前产品已经支持该操作。

封存说明中部分仓根命令仍采用旧目录坐标。按[当前 workspace](../workspace.md)核对真实路径、构建及依赖后再操作；本页未核实可运行制品或部署环境，不能原样套用历史命令证明当前支持。

## 后续承接

治理应用与权限契约拥有者确认真实消费面和支持范围后，与文档维护者在此补全任务步骤、预期结果、失败处置与相称操作验证。长期个人负责人尚未具名。来源无法回答任务时，在该拥有者处停止，不推断命令或可用性。源变更按[维护指南](../maintenance.md)同步。
