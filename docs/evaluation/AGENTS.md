# 开发 agent 与防御辅助的评估

这里保存开发模型及防御辅助选择所需的评估协议、输入、格式和可复现报告。
对象是参与研发的 agent；其结论不直接评价产品运行时 agent。
范围来自 D-003 及[本目录协议入口](README.md)。

## 准入与转出

比较特定模型、推理设置、harness、工具和提示条件下防御辅助的保留、简化或移除，
且遵循相应协议的实验材料可以进入这里。输入、留出、重复运行、版本和局限
应可核对，不能把报告字段齐全当作采用结论。

普通测试输出归所属验证记录或 tmp；产品运行时评测的目标、研究和能力设计
回到对应拥有者；模型相关网页摘抄按 research 准入，不因出现 benchmark 一词入库。
完整目录准入见[组织规范](../maintenance/organization.md#持久化知识的准入)。

## 按任务进入

开展或审阅实验使用[评估协议](protocol.md)，改变指导沿
[防御演化](../maintenance/defensive-evolution.md)。系统保证和用户约束不是实验
可以移除的辅助，采用与模型切换也不由结构检查自动批准。

只修改格式或链接时核对相应拥有者，不隐式调用模型或扩展实验范围。
