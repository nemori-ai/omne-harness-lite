# 当前系统架构的投影

这里解释系统当前采用的边界和关系，以及已有设计、实现和证据尚未覆盖的部分。
它把要求、决定和精确契约连成系统视图；准入依据见[组织规范](../maintenance/organization.md#持久化知识的准入)。

## 准入与转出

需要持续维护的系统或跨能力视图，有已确认要求、有效选择或精确契约依据时进入
本目录。保留需求导出的不变量、责任关系和当前缺口，并引用其权威定义；已接受
方向与实际实现状态分别表达。

待选架构和取舍理由按 proposals 准入；可重复使用的建模方法归 architecture-guide；
包的提供者映射和应用装配细节归所属成员。系统视图不重新定义业务规则，也不因
引用候选就接受它。

## 按任务进入

更新视图从[当前架构入口](README.md)及关联决定/规格定位依据。新增边界或改变
保证时使用[架构设计 skill](../../.meta_harness/agents/skills/harness-design-handbook/canonical/SKILL.md)，先从
目标与需求导出适用性质，再作机制判断。

仅同步已接受选择的导航时按受影响范围检查，无需重做无关设计。
