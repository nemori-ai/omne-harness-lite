# 本次派发说明

把以下内容作为任务消息提供给角色，避免只写“继续上面的事情”。

- 任务身份、目标与预期交付：{{task}}
- 仓库/worktree 与采用的基线：{{workspace}}
- 角色版本/正文位置：{{role_source}}
- 允许的读、创建、修改、删除路径；外部动作权限：{{scope}}
- 需要的规格、实施计划、决定与证据位置及版本：{{inputs}}
- 已确认事实与已接受决定：{{knowns}}
- 假设、未知和已有待答问题：{{unknowns}}
- 本次可自主决定什么，哪些决定保留给谁：{{authority}}
- 遇到哪项缺口暂停哪项动作；澄清联系人/返回方式：{{stops}}
- 真实预算、截止时间或重试限制（如有）：{{limits}}
- 成果位置、必要验证和交接接收者：{{return}}

这些内容可以引用可访问文档；不要求重复其正文。引用是否可读、当前版本是否正确
由接收者核对。待答问题只在收到有权作答者的明确回复后解除，不以经过时间代替。
