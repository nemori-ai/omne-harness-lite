# Subagent 编写任务说明

这是可填模板；省略不相关维度，不用猜测补齐关键空白。

- 角色名称与一句话职责：{{role}}
- 由谁派发、谁消费/接受结果：{{parties}}
- 必须交付的结果及完成标准：{{outcome}}
- 可自主决定的范围：{{decision_authority}}
- 允许读取/创建/修改/删除的对象与路径：{{action_scope}}
- 明确禁止的行为及本角色不承担的相邻职责：{{exclusions}}
- 必需输入及其权威、版本、接受状态：{{required_inputs}}
- 实施角色的实施规格和实施计划：{{implementation_inputs_or_not_applicable}}
- 缺失输入、歧义、冲突、环境不足时暂停什么、向谁澄清：{{stop_contract}}
- 目标宿主、版本、精确模型/继承策略、推理设置：{{targets}}
- 所需工具/skills 及能够实际强制的权限：{{capabilities}}
- 是否需要长程恢复记录、允许保存位置：{{continuity}}
- 允许的生成位置、发布范围与验证方式：{{delivery}}

给定任务足以确定的项直接填写；重要未知保持未知并说明影响。仅提供中性草稿时，
精确模型可以待定；不能把待定草稿报告为经过某个目标模型验证的成品。
