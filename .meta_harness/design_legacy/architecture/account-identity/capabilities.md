# 能力责任与投影

## 独立责任

| 能力 | 权威事实与保护责任 | 不拥有的事实 |
|---|---|---|
| 账号身份 | 不复用的产品 `UserRef`、注册生命周期、认证主体映射、登录态有效性与撤销 | 租户、成员、资产授权、预算及用户设置值 |
| Tenant | 个人租户唯一 claim、个人 owner 成员、组织成员资格与租户状态 | 凭据、会话 token、账号注册政策 |
| 设置/资产/授权 owner | 各资源的 owner/scope、有效值或权利 | 由本机文件路径推断的账号身份 |

CLI 装配持有本机凭据槽和当前目标选择，但不成为身份或成员关系的权威。同一现实人可持有多个账号，产品不建立现实人去重关系；同一账号可加入多个组织，切换目标不改写其 `UserRef`。

## Cordis 投影

账号插件提供受限的注册状态解析、可信会话验证和当前会话撤销服务；认证 provider 作为可替换实现持有凭据/会话资源。依赖账号身份的消费者只取得带验证边界的主体，不因知道 `UserRef` 或持有客户端自报字段而获得权限。Tenant 插件继续提供个人/组织资格；资源 owner 在每次准入按自身 scope 和当前资格裁决。

账号插件停止或换代先封闭新认证/注册，再将未决注册和撤销结果交给可恢复的持久 owner；卸载运行实例不删除账号、已发布租户、旧会话的审计事实或外部效果。真实服务键、Cordis 生命周期顺序、库版本及关闭策略归提供者设计，当前尚未锁定。

本地磁盘上的 skills/settings 也按资源声明的账号级或租户级范围定位。账号级事实不因组织切换复制到组织范围；租户级资源须同时核验可信账号、目标 tenant 与对象资格。物理路径、OS 用户与 CLI 目录不是授权依据。
