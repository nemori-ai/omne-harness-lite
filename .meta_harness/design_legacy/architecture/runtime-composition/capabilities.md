# 运行时共同能力地图

| 能力/提供者 | 自己裁决的事实 | 向组合交接什么 |
|---|---|---|
| Session | 长期身份、定义关联、资格、历史与持久状态 | 精确 attachment、资格修订和释放结果 |
| live-agent | 活体占位、AgentRef、阶段、工作账目与资源退出 | activation/work permit、当前阶段和真实排空事实 |
| 访问验证 | 当前主体对目标操作的允许/拒绝 | 覆盖一次明确提交的可撤销 guard |
| Factory/驱动 | 私有准备、实际绑定、业务静止 | 准备资源、退役受理、静止与释放事实 |
| 资源/贡献 provider | 精确 use 关系和资源存续 | acquire/retire/release 的真实结果 |

Run、工具、模型和上下文装配继续拥有自己的业务事实；本视图不把它们并入 Agent 内核。
