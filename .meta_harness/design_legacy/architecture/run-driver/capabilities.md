# 能力边界

RunDriver 是推进者：取得精确 claim，在安全切点调用模型、裁决工具批、等待、settle 或 Yield。它不拥有 Session 队列、Run 状态机、工具调用或人类决定，只通过当前能力端口推进。

## Cordis 投影

候选插件实例绑定 Run epoch、Agent WorkPermit 与 driver binding；撤除先封闭新 claim，在安全边界 Yield 并结算许可。

Context、服务引用或 AgentRef 只提供定位，不构成授权、执行权或耐久事实。每次使用仍核对
tenant、精确代次、当前资格与撤销屏障；运行插件缺席不得删除其长期 owner 的责任。
