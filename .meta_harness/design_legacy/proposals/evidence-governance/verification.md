## 目录入口的交付说明

这些入口常驻知识性质、准入方向、少量高代价边界及展开/停止条件：它们在该
目录多数任务中都决定材料归属，且不能仅由链接检查器裁决。九个 CLAUDE 只
引用同级 AGENTS；详细规则仍由组织规范和对应拥有者维护。

| AGENTS 位置 | 相对父级增加的认知职责 |
|---|---|
| `docs/` | 从文档总图路由到持久化准入和局部入口 |
| `docs/requirements/` | 辨认已确认目标/要求及消费基础，阻止候选冒充需求 |
| `docs/architecture/` | 识别当前系统视图与有效依据，区分候选、覆盖与完成 |
| `docs/architecture-guide/` | 辨认跨设计复用的方法及判断，具体系统选择转给拥有者 |
| `docs/research/` | 保留版本化观察、来源和局限，区别推断与接受选择 |
| `docs/proposals/` | 判断持久候选及取舍价值，拒绝任务排期和无筛选会话入库 |
| `docs/decisions/` | 辨认接受对象、依据与取代范围，保持决定简短可解释 |
| `docs/maintenance/` | 识别长期维护机制，区分机制正文、系统政策和一次操作状态 |
| `docs/defensive-patterns/` | 维护指导身份、范围和复核记录，指向同级目录外的当前指导正文 |
| `docs/evaluation/` | 限定为开发模型及防御辅助评估，区分协议、测量和接受 |

本轮没有从既有目录入口删去未迁出的硬规则。完整准入表归组织规范；推导方法、
证明门槛和规划步骤归对应方法正文，skills/角色只投影任务判断。一次施工计划
移入 tmp，研究事实与持久取舍各留其拥有者；通用命令、模型字段和排期不进入
九份局部入口。审阅发现的来源表述歧义按拥有者消解，没有留下需靠提示词选边的
已知归属冲突。

九份局部 AGENTS 各 21–24 行，根→docs→局部的完整继承链为 180–183 行、
9692–9757 字符。长度仅说明常驻成本；以下推演提供有限的认知效果证据。

## 独立任务探针

独立普通 agent 读取实际入口与原始情境，未提供预期答案；每项返回心智、
拥有者、必要输入/性质/证据、负责者及继续/停止范围。根 agent 根据已定义的
验收范围核对返回：14 项均作出相应区分，未把缺证明、缺契约或缺组合负责人
报告为已经完成。这是同次阅读推演，不是原生角色调用或跨模型行为测量。

| 情境 | 实际判断及到达的拥有者 |
|---|---|
| 普通失效链接 | 局部文档维护及相称检查，不生成提案或架构审阅 |
| 一次数据库任务的分派/进度/日志 | tmp 或任务系统；只有后续持久观察/取舍才提炼入库 |
| 共享注册表示的跨包选型与丢条目实验 | 提案保存选择依据，研究保存可复现事实；反例不证明另一候选 |
| 消费精确版本的既有受控 API | 核对适用前提与实现映射，复用证据，不重复证明提供者 |
| 新交换性保证支撑租户隔离并首次省略冲突检查 | 触发机器检查证明；两实例模型不足，依赖消费受阻，研究可继续 |
| 无实现的全称恢复安全要求 | 可以表达/接受语义并保留未证明状态，全称措辞不单独触发新增门槛 |
| 关闭连接但外写结果未知 | 资源关闭不足以支持整体结算，需生命周期契约及实际接续责任 |
| 工具退出成功但目标仍为假设 | 记录目标未证明，验证规范拥有结论边界 |
| 删除独立条目改为恢复旧快照 | 提供者表示变化须重判旧证明适用性，签名不变不足为据 |
| 三组件通过但真实组合无人负责 | 计划负责人补齐组合责任和判据，plan-reviewer 核对安排 |
| 多租户在线更新设计只列服务键/成功路径 | 从需求补推性质和保护位置，architecture-reviewer 查覆盖遗漏 |
| 既定代际撤除行为只有 Schema | 规格维护者补行为表达，spec-reviewer 核对给定设计，不重选政策 |
| 实现允许全租户撤除但契约只授权当前租户 | 修复实现及相关证据，不通过改文档降低既有保证 |
| 为少写适配代码直访另一包内部注册表 | 沿公开边界判断并简化；需要新能力时由提供包拥有者演进接口 |
