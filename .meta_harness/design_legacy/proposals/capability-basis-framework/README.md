# 从需求到 Cordis 的设计框架

[提案索引](../README.md) · [方案与交付计划](plan.md) · [方法正文草稿](method.md) · [提案决策形状](proposal-shape.md) · [调研：开源提案与决策流程](../../research/proposal-processes/README.md)

本提案由 2026-09-15 的 HUB 会话起草，用户确认理解无偏后决定**移交实施**：接手者按
[plan.md](plan.md) 的交付物清单与五波计划推进，方法正文以 [method.md](method.md) 为起点，
提案的决策形状（每个决定点 ≥3 真候选 + 基线、同一把尺、否决理由与复议条件）以
[proposal-shape.md](proposal-shape.md) 为锚，调研证据在 research。三个待用户确认的点已在
plan.md §5 列出（能力基地图是 catalog 的投影而非新登记表；≥3 候选作为 docs-check 硬门；
既有提案候选不足时如实标注不补造）。
