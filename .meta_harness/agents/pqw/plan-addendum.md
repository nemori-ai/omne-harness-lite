# plan 的本项目附加节

pqw 的 plan 模板照用。本项目只加两处。

## 进度总览加的一行

在「圈外发现」一行之后加：

`轨道：起点 <短提交号> · 轨道头 <短提交号> · PR <#号或未开>`

同步轨道头后改这一行。轨道头前进了而起点没动，进轨道前先合并。

## 最后一片的收口加的三项

- [ ] 同步轨道头后，改动成员的合入检查与 `pnpm run preflight` 通过
- [ ] 最终 head 上 `pnpm run admission` 退出 0，准入日志的摘要与哈希贴在卡评论里
- [ ] PR 已开，gate 已确认，卡的看板已写 delivered
