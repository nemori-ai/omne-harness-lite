# spec 的本项目附加节

pqw 的 spec 模板照用。本项目在抬头的起点一行之后加下面几行，在「验收标准」之后加「风险级别」一节。

## 抬头加的行

- 卡：<#卡号，交付修订 n>
- 起点：<`integration/mainline` 上的完整提交号；同步轨道头后改这一行，并在修订记录里写原因>
- PR：<开出后填链接；没开写「未开」>

## 风险级别

- 级别：L<n>。取卡上写的与改动路径推出的两者中高的那个。级别的含义与人审数见 `docs/engineering/quality.md`「按成果和风险验证」。
- L3 时写热点：<租户隔离、凭据、同一提交的状态、gate 与验收目录、契约破坏性改动中本程碰到的>，收口按 `omne-card` 的 L3 热点清单核。
