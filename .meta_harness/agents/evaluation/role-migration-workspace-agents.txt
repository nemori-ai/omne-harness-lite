# Meta Harness 工作区

这里提供从需求到 harness 设计的独立方法与资产空间，目录职责见 [README](README.md)。

按 C 方案区分可复用方法、系统设计、研发 agent 源与发布边界：
`method/` 维护方法，`design/` 维护待设计系统的完整需求与设计链，
`agents/` 维护 skills/角色源，`publication/` 维护对外产物与采用关系。

设计上下文从工作区内部材料及本次明确输入取得；位置规则与缺失处理见
[工作区上下文](agents/skills/harness-design-handbook/canonical/references/workspace-context.md)。
不从父目录推断所设计的系统，也不把承载仓库的需求、契约或流程自动接为设计权威。
骨架与候选不表示迁移或接受完成；材料不足时保留缺口，独立分析仍可继续。

新 skills 与角色源归 [agents](agents/README.md)，编译结果留在本目录的宿主目录中；
通过 [tooling](tooling/README.md) 了解生成与检查边界。
审阅方法草稿只展开相关依据，不顺带启动产品设计、安装或发布流程。
