# 工作区 AGENTS.md 的重写与验证

## 常驻职责与归属

角色句：给进入私有工作区的 agent 建立自包含心智、能力设计方向、权威边界及按任务展开的地图。
使用迁入的 [write-agents-md](../skills/write-agents-md/canonical/SKILL.md)；方法和家族规则先在拥有者处明确，再投影到入口。

| 旧入口的信息 | 重写后的归属 |
|---|---|
| 私有工作区与方法/设计/agent/发布分工 | 常驻心智及职责地图；细目录和当前迁移状态归工作区 README |
| 不从父目录推断产品事实，材料缺失只阻止依赖工作 | 工作区边界及末尾停止点；具体输入导航归 handbook 的 workspace-context |
| 候选、骨架不等于接受或迁移完成 | 权威边界及四层就绪导航；实际状态继续归对应正文 |
| 资产以源生成，产物留在内部 | 生成边界；命令、依赖与链接保护归 tooling |
| 审阅方法不顺带启动产品设计/安装/发布 | 按当前任务收口、角色行动边界与工具/发布授权分别导航 |

新增的常驻内容包括“现有能力覆盖 → 剩余责任 → 演化 → 契约/插件投影”的短模型、topic 信息包心智、
少量有来源的品味，以及直接通向 skills/roles/家族拥有者的触发入口。没有复制工具命令、完整模板、
模型清单、当前数量或产品业务政策；CLAUDE.md 仍只引用同级 AGENTS.md。

## 继承与源冲突

本次物理父链有主检出和当前工作树两份相同的仓库 AGENTS.md，各 140 行；局部入口由 16 行骨架展开为 75 行。
物理文件合计 355 行，不据此推断宿主一定重复加载两份父文件或模型的实际上下文量。
局部入口增加独立设计世界的含义，不撤销对明确执行仓库实际操作所适用的约定。

重写前发现 decisions 家族允许未接受草稿直接建主题，与该 family 的已接受选择归属矛盾；
已先修家族入口及模板，未接受文案留在提案。用户新增的三个实质候选准入同样先落到
proposals 与 handbook，AGENTS 只导航拥有者。尚未迁入的具体治理格式/工具继续按真实缺口处理，
本轮没有新建 design/AGENTS.md 或声称已经完成全部 family 的治理细则。

## 实际任务导航试用

独立普通 agent 从新 AGENTS.md 进入，接收[五个原始任务](meta-agents-cases.json)，没有预先收到预期答案；
按实际需要加载页面，结果由主 agent 核对，摘要和输入/入口哈希见[试用记录](meta-agents-probes.json)。

| 任务 | 观察到的方向与停止点 |
|---|---|
| 普通错链 | 仅凭入口和明确任务判断为局部修正，不加载手册，不追加提案/升版/评审 |
| 新批准消费语义 | 从能力覆盖推导剩余责任，比较扩展与独立能力，给出插件/交接边界，未决政策留为候选 |
| 实现与已发布契约冲突 | 沿规格演进定位实现违约，保留契约版本，提出消费者与验证影响，不让注释成为权威 |
| 应用读取私有状态并复制状态机 | 沿开发者契约和应用职责守住公开边界；接口不足只暂停依赖部分，交回拥有者 |
| 三个改名候选与未接受决定 | 识别为一个实际方案，回到研究/探索补齐选择空间，不把候选登记为决定 |

普通问题无需额外导航；规格演进、提案准入和角色契约在一至两次拥有者跳转内可达，
完整新边界设计才继续展开相关契约/投影专题。试用未执行编辑、产品操作或委派；只读动作依据返回报告，
未独立记录完整工具轨迹，也不是原生宿主加载、长程或所有模型行为保证。
