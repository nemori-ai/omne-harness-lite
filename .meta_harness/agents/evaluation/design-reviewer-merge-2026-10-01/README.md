# 三个设计评审角色合成 design-reviewer（2026-10-01）

本记录保存一次角色集调整的依据、对照结果与验证范围。角色的现行定义以[角色源包](../../roles/README.md#按判断对象选择-reviewer)为准，
判据以手册 `references/review/` 的三页为准；这里不是第二份定义。

## 改了什么，为什么

architecture-reviewer、spec-reviewer、plan-reviewer 三个角色共用同一套只读纪律、输入规则与报告格式，差别只在判据。
负责人 2026-10-01 定：合成一个 [design-reviewer](../../roles/design-reviewer/role.md)，**一次派发只做一种判断**（选择／表达／计划），
判据各一页放手册、按需读；能机械算的核对搬进工具，评审者只对工具输出逐条判断；**用预置缺陷对照，不退化才采用**。

| 退役 | 去向 |
|---|---|
| architecture-reviewer | design-reviewer 判「选择」，判据 `references/review/choice.md` |
| spec-reviewer | design-reviewer 判「表达」，判据 `references/review/expression.md`；机械核对由[设计评审报告](../../../tooling/README.md#设计评审报告)先算 |
| plan-reviewer | design-reviewer 判「计划」，判据 `references/review/plan.md` |

评审者仍然不能写、不能执行：Claude Code 一端只给 Read、Glob、Grep 与联网读取，Codex 一端是只读沙箱。
工具由派发者跑，输出附进简报。

## 对照怎么做的

[分析计划](analysis-plan.md)在任何一次运行之前写定，连同缺陷清单、简报与运行器的哈希记在 [frozen.sha256](frozen.sha256)。
三份材料取自同一个小领域（一次执行尝试的两件事实），各预置若干已知缺陷，清单与真值在 [suites/seeds-v1.json](suites/seeds-v1.json)。
同一种判断的两组用同一个模型（旧角色当天钉的那个），只有角色正文不同；新组的简报多一行「本次判断」，
「表达」那一种另附设计评审报告在该副本上的原始输出。每次运行是一个新的 `claude -p` 进程，只放行 Read、Glob、Grep。

冻结的角色定义（`--agents` JSON 的 SHA-256 前 8 位）：architecture-reviewer `fc296d92`、spec-reviewer `68ae4ffa`、
plan-reviewer `b4fa0261`、design-reviewer `358419fd`。原始轨迹、简报与最终消息在主检出
`tmp/design-reviewer-merge/runs/<判断>/<组>-r<次>/`，各带一份 `run.json`。

## 对照里看到的、与判定无关的事

- **E3 在这份契约上工具判不了。**缺陷清单把 E3 标成「工具核得出」，但 `capability.run-attempt-facts/v2` 有操作表而没有九件事定义表，
  工具认不出哪一格是失败集合；对照当时的报告只在「未能判定」里列了九件事一项，对失败集合没有说话。新组两次都照判据页
  「未能判定的由你用眼睛补上」手工补了九件事并抓到 E3。这处沉默事后已修：工具现在另列一条「失败集合是否闭合没有核」
  （提交 `7bbee15ee`，**晚于全部对照运行**）。缺陷清单与分析计划没有改。
- **产品依据的 rev。**这份契约把那一项写成「设计依据」，工具只认「产品依据」，归了「未能判定」；新组两次都手工补判出 rev 过期
  （契约写 rev 14，当前 rev 21），并指出可据此收紧工具。全部契约里写成别的标签的有 44 份，工具没有改，留作改进候选。
- 两组都把「v2 被改回 candidate、原地修订」报成阻断——那是为了让契约可以受审而做的种入手段（改登记、去冻结），不是预置缺陷，不计分。

## 这次对照说明不了什么

每组一两次运行，量不出小差异，只能发现明显的退化。预置缺陷是主会话写的，比真实待审稿里的问题更显眼；
材料只有一个小领域；判定由主会话一人做，没有第二人复核。没有 Codex 一端的行为对照（那一端只做了加载与派发探针）。
「表达」那一种比的是新的一整套（角色加工具输出）对旧角色单独，分不出角色正文与工具各自的贡献。
结果**不构成「新角色更好」的证据**，只支持「没有看到退化」。
