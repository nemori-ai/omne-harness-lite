# 开发 agent 防御辅助评估协议

## 单位与比较

一次报告比较固定基线模型的 `retain`，以及一个候选模型的 `retain`、`simplify`、`remove`。
四组使用同一任务集、正整数重复次数和可比环境；报告只覆盖一个候选、一个基线、一个任务集版本和一个环境快照。

公开任务可用于调优。真实检验还须有未参与辅助或 prompt 调优的冻结 `heldout`，保存路径、SHA-256 和防污染声明；
材料暴露后改变分析计划须建立新的实验修订，不能反复尝试同一留出直到通过。

## 比较前固定

`analysis_plan` 在运行前固定辅助身份及文本、保护机制、主指标、关键约束、可接受退化、重复次数依据、重试预算、
环境重置和停止条件。模型、推理、harness、工具与 prompt 的精确版本和配置均须可回查。

每次运行保存任务、split、arm、重复序号、产物或轨迹及 hash、关键约束的实际观察，以及 token、耗时、工具调用和人工干预。
不能用 agent 自述代替产物与副作用观察，也不能用总分掩盖关键约束退化。

## 结果与采用

每个关键约束标为实际满足、违反或未观察。违反是可审阅的负面证据；未观察、重复不全、证据缺失或条件不可比使结论不完整。
结构检查器只能检查字段、覆盖和本地 hash，不能认证轨迹真实性、留出未泄漏、样本充分或因果归因。

人工审阅同时比较失败类别、相邻任务回归、成本和干预。采用记录为 `undecided`、`adopt` 或 `do_not_adopt`，
并写明选中 arm 与限定范围；选中组不得违反关键约束。证据完整不是统计结论、采用授权或模型切换动作。

## 复核

模型、推理、工具、prompt、任务分布改变，故障复发、保护边界变化或成本显著改变时复核。
删除辅助不撤销系统保证；外部效果、取消、恢复与资源释放仍由各自产品契约定义。
