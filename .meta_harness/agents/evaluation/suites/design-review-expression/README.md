# design-reviewer表达用例

本套局部材料量表达判断：能否报告形状、授权、生命周期、依赖和证据范围的已知缺陷，并保持只读及判断种类。判据归手册references/review/expression.md；不再调用中央规格报告或读取中央登记。

当前版本2，尚未取得本版用例及判定方法签字，不允许据旧版签字派发或宣称角色性能等价。当前host配置归flow.json；本PR只执行静态准备和判定器测试，不运行模型基线。
