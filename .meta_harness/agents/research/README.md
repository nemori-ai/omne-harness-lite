# 方法的事实依据

这里保存研发方法仍采用的上游事实、适用版本和局限。当前方法归 canonical skills、roles 和所属规则正文；
本目录不保存本项目的讨论、迁移、决定形成过程或每次运行结果。这些过程材料放执行工作树 tmp。

| 主题 | 事实范围与消费者 |
|---|---|
| [proposal-processes](proposal-processes/README.md) | 上游 PEP、RFC、KEP、EIP、TC39 与 ADR 的候选比较要求；本地方法不能把调查统计当上游强制数量 |
| [framework-governance](framework-governance/README.md) | 外部框架的知识与防御规则演化；供[防御指导](../../../docs/defensive-patterns.md)核对适用性 |
| [agent-system-evaluation](agent-system-evaluation/README.md) | 外部项目的评估方法、边界及固定样本；本项目评估方法归 evaluation |
| [Cordis 证明边界](cordis-proof-boundaries.md) | 论文命题、机制事实与组件责任；不代替实际提供者验证 |
| [装载清理来源](design-spec-maintenance/effect-cleanup-sources.md) | 固定上游文档中的效应、撤除与异步清理事实 |
| [harness-design-decisions](harness-design-decisions/README.md) | 六个上游项目的设计治理事实与限制；不要求本项目永久保存决定事件 |

上游修订限定事实的适用范围，不是本项目的开发提交账本。方法改变时复核实际消费者与事实前提；
无消费者的旧项目正文、迁移快照和形成史不保存在这里。来源中的政策仅描述外部项目，不能冒充本地指令。
