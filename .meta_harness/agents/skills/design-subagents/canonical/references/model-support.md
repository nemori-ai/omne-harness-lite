# 先确认宿主支持，再收录模型指导

## 已记录的核对范围

[支持记录](model-support.json)保留其日期与版本下的核对结果。Codex CLI 0.159.0 的目录缓存
（2026-10-01 读取）可见 GPT-6.1 Sol、GPT-6 Astra/Sol/Luna、GPT-5.6 Sol/Terra/Luna、GPT-5.5；
GPT-6 没有 Terra，6.1 一代目录里只有 Sol。
本记录来自本地宿主模型缓存，保存读取时间、缓存时间、客户端版本和摘要哈希。
隐藏的内部条目不作为可选 subagent 模型。**新模型可能要求新客户端**：GPT-6 Sol 在 0.154.0
上被服务端拒绝、目录也不列出，升到 0.156.1 后才可见、可调用；GPT-6.1 Sol 在 0.155.0 的目录里没有，
0.159.0 才列出。目录缺某个已公布的模型时先核客户端版本。

**缓存归最后运行的那个客户端**：同一台机器上装着几个版本的 Codex（命令行一个，编辑器扩展自带一个）时，
谁最后跑谁重写 `models_cache.json`。读缓存前先看其中的 `client_version` 是不是目标客户端；
取证时先用目标客户端跑一次，随即复制一份再算哈希，不对着会被别人改写的原文件记哈希。

Claude Code 2.1.280 对照[官方宿主模型配置](https://code.claude.com/docs/en/model-config#available-models)
确认 Opus 5.5（最低 2.1.280）、Fable 5.1、Fable 5、Opus 5、Opus 4.8、Sonnet 5，以及提供方映射中的
Opus 4.6、Sonnet 4.6/4.5 和 Haiku 4.5。2026-09-29 在 2.1.284 上对照同一页补记 Sonnet 5.5（最低 2.1.284）；
该次只复核了这一项，Claude Code 其余条目仍是 2026-09-23 的结果。这证明所记版本的宿主支持，不声称本机
账户或网关已开通全部模型；提供方的别名映射可能不同。**别名会随宿主版本漂移**：
2.1.280 起 `opus` 在多数提供方解析为 Opus 5.5，此前为 Opus 5；需要可追溯的角色写精确 ID。

## 核对方法与证据等级

1. 读取目标宿主实际版本。查其官方支持页与最小版本要求；配置接受一个任意字符串
   不算支持证据。读取精确模型、提供方和组织限制，不输出凭证、完整配置或私密地址。
2. Codex 可用 [App Server `model/list`](https://learn.chatgpt.com/docs/app-server#list-models-modellist)
   查询可见模型和 effort，并处理分页。不能运行实时查询时，可用当前版本的本地目录
   缓存作有时间边界的证据，明确它不是本次实时运行结果。隐藏/内部模型不能自动纳入。
3. Claude Code 对照官方支持与当前版本；当前账户可见项需用该会话模型选择器或
   受支持的只读枚举核对。查询不能暗中改变默认模型或触发一次收费生成。
4. 记录：宿主已支持、当前账户/提供方可用、当前会话可派发、模型实际运行成功。
   不将它们合并成一个 `supported: true`。
5. 确认宿主支持后，才收录这个模型的提示指导/引用；指南未找到则保留缺口，不从
   模型名字、参数规模、其他代际或另一个提供方推导专属提示。

记录里 `account_execution` 写着 `ok` 的条目各做过一次最小的真实调用（回一个词），并用一个
编造的模型名做了对照，确认服务端不是来者不拒；其余条目未调用。目录可见不保证未来可调用，
官方支持也不保证账户权益。`inherit`/未指定 model 的模板可以保持中性，不能带未经确认的模型专属段。

## 长期维护

新增模型、修改目标宿主版本、切换提供方、目录变化或支持失败时重新核对；模型
材料的维护先更新支持证据，再更新指导。旧模型不再受目标宿主支持时移出当前适配
范围，不为凑齐历史代际保留一套不可用模板。

支持记录是有日期的事实快照，不是运行时路由或永久模型白名单。生成器以它进行
保守准入，新增精确目标需先核对并更新证据，不绕过检查。若离线材料过旧
而无法确认目标支持，明确暂停该模型的专属适配，不用“应该支持”填补证据。

## Cursor

Cursor 的实际 CLI 目录及角色请求标识记录在 model-support.json 的 cursor 项。原生字段、项目与插件差异、实际模型及权限资格按 [Cursor 适配](cursor.md) 核对。CLI 目录不证明 IDE、Cloud 或某次 Task 的后端模型。
