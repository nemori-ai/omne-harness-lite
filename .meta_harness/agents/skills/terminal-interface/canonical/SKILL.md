# 终端界面

本技能分三节：[实施](#实施要守的规则)、[验收](#验收要过的关口)、[取证](#出了异常怎样取证)。按这次在做的事读对应的一节。验收与取证共用[观察环境与证据层](#观察环境与证据层)。

## 实施要守的规则

### 职责

- 消费已定义的应用操作与结果，实现终端输入、导航、列表、表单、确认、结果呈现及错误反馈。
  人读、机读与终端界面共享业务操作。渲染器不另造认证、授权、租户选择或业务状态转换。
- 显示动作所属的账号与范围。界面仍显示旧身份时，不改变命令的预期身份来追随后台切换。
  按服务端结果呈现权限失效、身份冲突、不可达和结果未知，不自动把失败动作重新提交。
- 消费已选终端框架和精确版本。在交互规格内自主安排组件、排版与键位。
  框架缺少所需能力时给出反例，不以改产品语义或另建通用渲染框架补洞。

### 开工核对

开工时核对终端矩阵、TTY 与非 TTY 行为、编码与尺寸边界、人读／机读输出契约、秘密输入方式，以及所用真实或替身后端的范围。

### 生命周期与还原

- 原始输入模式、光标、粘贴与键盘协议、尺寸订阅和渲染循环各有所有者。
- 部分启动失败、正常退出、可捕获信号与异常退出均按规定还原。
- 不用无条件退出绕过清理。不承诺 SIGKILL、终端断连或断电时仍能执行还原代码。

### 内容与尺寸

- 覆盖中文宽字符、组合字符、emoji、换行、长内容、窄窗口、resize、粘贴与取消。
- 终端尺寸与能力不足时给出规定的结果，不改成另一种输出协议。
- 后端返回的名字、错误与内容按不可信文本呈现，避免控制序列改写终端。

### 秘密输入

- 密码和登录出示物不进入 argv、普通输出、调试日志、截图或回归录制。
- 取消秘密输入时清理临时状态。

### 人读与机读通道

- 机读 stdout 只承载约定的数据。诊断走独立通道。
- 非 TTY 不接管 raw mode。
- 状态刷新不是用户动作，不为保持画面新鲜续期登录或重复业务写入。

### 结果未知不说成功

- 关闭界面与退出账号登录是不同动作。取消确认不提交。
- 已提交但回执未知时，不显示「已撤销」。
- 本地临时状态只服务交互，不成为中心事实或授权依据。

### 实施的验证与交接

- 不为通过而修改验收场景、golden 或判据。取证留下的复现脚本作为输入保留。
- 按给定环境实际运行交互。保留程序版本、终端类型、尺寸、locale、命令与可重跑步骤。
- 分别说明组件测试、伪终端驱动、真实终端观察和真实组合验证的覆盖。
- 测试必须能观察业务结果和退出后的终端状态，而不是只断言显示文字。

## 验收要过的关口

每次验收都过下面八关。结果进逐条对照表。没条件过的写进「未覆盖」，不静默跳过。

| 关 | 判什么 | 怎么判 |
|---|---|---|
| 1 终端矩阵 | 至少在两种终端程序、两种尺寸下结果一致 | 同一场景各跑一遍，结构层 golden 逐一对比。只在某一种下挂的标「终端差异」 |
| 2 非 TTY | 被重定向或没有屏时明说不行，并指出机读那一份 | 用管道起一次。不静默降级 |
| 3 宽字符 | CJK、emoji、组合字符不错位、不溢出行尾 | 场景输入里放一段中文与 emoji |
| 4 resize | 中途改尺寸不丢内容、不残留 | 场景里插一次 resize |
| 5 退出还原 | 正常退出、Ctrl-C、被杀三种收场后，终端模式、光标、echo、替代屏都还原 | 每种收场后抓一次终端状态 |
| 6 scrollback 卫生 | 退出后 scrollback 里没有界面残骸。替代屏进出配对 | 看退出后的屏幕与原始写日志 |
| 7 输入法与粘贴 | 中文输入、多行粘贴不被拆成多次提交 | 伪终端整段喂一次、逐字节喂一次 |
| 8 机读通道纯净 | 机读输出里没有进度、提示、诊断混入 | 解析每一行，并逐条过 Schema |

观察按[证据层](#观察环境与证据层)的序号从前往后取。证据另加写到伪终端的原始字节，以及打开输入录制的终端录像。

## 出了异常怎样取证

### 假设账本

每条形状如下。只追加，不删改。

```
H-n  <一句话假设>
预测：若成立，<实验>应观察到 <X>。若不成立，应观察到 <Y>
实验：<脚本 / 命令 / 证据文件>
结果：<观察到什么>
判定：证实 | 证伪 | 不足以判定
置信：高(>80%) | 中(50–80%) | 低(<50%)
相悖证据：<必填。没有就写「未发现」并说明找过哪里>
越界发现：<可空>
```

### 取证顺序

按[证据层](#观察环境与证据层)的序号从前往后取。上一层足以判定，就不下到下一层。

### 先排除的终端变量

把一条假设指向程序逻辑之前，先逐项排除。排除过程写入账本。

| 变量 | 怎么排除 |
|---|---|
| 终端尺寸与 resize | 固定尺寸复现一次，再在 resize 序列下复现一次 |
| 宽字符与 emoji | 把同一行换成纯 ASCII 再跑 |
| 输入法与粘贴 | 开关 bracketed paste。逐字节喂与整段喂各一次 |
| 同步输出与替代屏 | 查写日志里同步输出括号和替代屏进出是否成对 |
| 终端类型 | 换 `TERM` 与终端程序各一次 |
| locale 与编码 | 显式设 `LANG` 与 `LC_ALL`，写进证据 |
| 非 TTY | 确认被测程序在伪终端里，不是管道 |
| 信号与作业控制 | 退出后抓终端状态。`stty sane` 前后各抓一次 |
| shell 集成 | 用素 shell 重跑 |
| 终端复用器透传 | 直接在真实终端下复现一次对照 |

### 时序

- 等条件，不等时间。谓词写在脚本里。超时也是证据，记超时值。
- 复现命中率不是 100% 时，先按交错记录每次结果，再谈假设。
- 瞬态故障事后抓不到时，在故障窗口内起录制，再触发故障。由别人触发时，请他在录制开启后触发。

### 证据分层

| 层 | 内容 |
|---|---|
| 语义层 | 机读记录序列、结构化日志 |
| 结构层 | 无头终端解析后的屏幕快照 |
| 原始层 | 写到伪终端的原始字节、终端录制 |
| 截图 | 只在同一环境内作旁证 |

## 观察环境与证据层

验收与取证都按下面的环境观察：

- 被测程序起在你自己所在终端之外的伪终端、独立终端复用器 socket 或另一个窗口。
- 你自己的 shell 必须素：固定提示符，不加载会往终端发控制序列的集成。
- 终端类型、尺寸、locale 显式设置并写进证据。

证据层按序号从前往后取：

| 序 | 手段 | 能证明 | 不能证明 |
|---|---|---|---|
| 1 | 被测应用自带的机读记录与结构化日志 | 语义层发生了什么、顺序、在哪个进程 | 画面长什么样 |
| 2 | 同一输入走机读通道与走界面，比两条记录序列 | 问题在渲染，还是在界面与后端之间 | 需要 oracle 定义「相同」 |
| 3 | 无头终端，解析成逐行文本与单元格属性 | 渲染结构、颜色、光标、宽字符占位 | 真实终端的同步输出与输入法差异 |
| 4 | 被测程序写到伪终端的字节流 | 转义序列是否成对 | 单独看不出语义 |
| 5 | 真实终端里的终端复用器，独立 socket | 真实 tty 上的复现 | 注入按键没有回执，必须等屏幕谓词 |
| 6 | 终端录制 | 给人回放 | 默认不录输入，会压缩空闲时序。取证时两个都关掉 |
| 7 | 终端窗口截图 | 人眼确认 | 不可断言 |
