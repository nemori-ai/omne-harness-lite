# P1 方法、准入与模板对齐

本轮把长期知识准入从散落的目录描述收敛成同一判断：持续消费者、唯一语义拥有者、最低可消费信息、
真实状态与停止位置。handbook 新增便携式信息包地图；工作区 family README 拥有具体门槛，`.templates/`
在 topic 入口要求先完成准入核对。三层只做方法、工作区策略和写作资源的投影，不复制产品正文。

旧维护文档中仍有效的知识流转、需求确认、规格版本、验证边界、交付规划与防御辅助演进已压缩进入
`method/governance/`。旧方法 proposals 与历轮 review 未机械迁入：其有效结论已由当前规则拥有，过程原件
只在来源修订中追溯。现有 harness 设计治理研究继续支撑三候选规则，同时明确这是用户要求的本地门槛。

开发模型评估协议、Schema 和公开 suite 已迁入 `agents/evaluation/developer-model/`，移除对外部产品决定和
路径的运行依赖。当前只采用证据协议，不继承旧采用授权；Meta Harness 尚无自带报告 CLI，Schema 通过
只能说明结构，这一提供者缺口保持显式。

本轮不迁产品需求、能力 topic、契约或一次性交付计划。完整来源处置和供集成消费的目标列表保存在本次
任务 `tmp/docs-spec-v1/p1/`；真实试用与检查结果在该任务完成时写回对应证据。
