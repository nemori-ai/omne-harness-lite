# 评审收敛规则修订

用户明确：同一块交付通常最多接受三轮迭代优化；三轮仍不收敛时，应停止局部修补，
从全局视角诊断结构问题和盲区，必要时可委派更强模型作为 advisor 提供指导。

本轮将唯一详细规则放入
[交付与反向核对](../canonical/references/handoff.md#三轮未收敛时升级结构诊断)：

- 以同一交付对象、同一需求/接受基线下的可识别 revision 和独立评审结果计算实质轮次；
- 实质修订后旧阻断仍未闭合也计轮；只豁免无实质修订的重复核对、纯机械修改后的核对或已无阻断的复查，且“机械”服从语义影响判断；
- 第三轮后仍有阻断时冻结三轮证据，暂停接受及依赖实施，转向完整设计链的结构诊断；
- advisor 是宿主支持时的独立只读诊断手段，不绑定模型、不形成固定角色，也不取得代写或接受权限；
- 只有根因、owner、修复范围、消费者和基线均明确并形成新快照后，才恢复相称评审。

入口和 topics 只提供按问题加载的路由，不复制计数、升级或恢复细节。
本次不改变 reviewer roles、proposal 模板、design family 或产品契约，也不增加常驻 AGENTS 内容。
