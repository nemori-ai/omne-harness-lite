## 可用性与发布

生命周期描述一个实例在什么条件下存在、可使用和失效。创建、初始化、发布、依赖就绪和正在接纳工作可能是不同阶段；需要分别说明各阶段允许哪些操作。[概念定义](../foundations/concepts.md)区分了定义与实例。

可以先完成内部准备，再把可用实例发布给消费者。若允许发布后仍处于等待状态，查询结果和调用行为必须明确表达等待，不能把“已找到实例”隐含当作“可以执行”。初始化失败时，已取得的资源也必须有清理归属。

状态集合按实际行为选择。没有被行为区分的状态无需人为添加；存在不同权限、清理责任或失败响应的阶段，也不应压成一个模糊的布尔值。

## 装载效应与撤除责任

设计可装卸的插件时，把装载建立的效应与卸载所需的撤除、清理或交接一起说明。
这里的效应是实例在明确作用域内建立的注册、关系、资源或状态改变；“逆效用”
首先指对这些受控贡献的撤除义务，不表示任意业务行为都存在数学意义的逆操作。
官方 effect/disposer 机制及待设计系统采用范围的区别见
[来源核对](../../source-check.md)。

按实际产生的效应辨认建立条件、所有者、消费者可见时点、撤除动作及其完成判据，
同时说明哪些状态应保留或交给其它所有者。可以用说明或对应表表达，不要求每个
插件手写统一的 load/unload 接口；框架已纳管的注册直接引用其机制，没有资源的
纯计算也无需制造空 effect。

局部清理应撤除本次实例拥有的贡献，保持其它合法贡献和已经明确保留的事实。
不能简单恢复“装载前的系统快照”，因为期间其它组件可能已经合法改变共享状态。
借用或共享的资源只释放本实例持有的使用权，最终释放由其所有权协议决定。

若装载只完成一部分，已建立的效应仍需收口；卸载时尚有消费者或工作，必须按
契约完成拒绝、排空、终止或交接，不能只删注册就宣布工作结束。具体并发窗口、
重复清理、异步顺序和失败残留沿下文说明，不能从 disposer 存在推断全部成立。

持久事实、独立工作和外部写入是否保留、撤销、补偿或恢复，由所属业务契约决定。
卸载可以使能力入口消失，同时保留合法业务结果；不能为追求表面可逆而删除它们。
声称卸载完成时，应能观测到承诺范围内的贡献已撤除、资源已释放或合法交接，
以及未完成部分的真实状态。

验证按风险观察装载、部分失败、卸载及再次装载后的实际关系；还应覆盖会影响
保证的并发贡献和在途使用。只断言清理回调被调用，不足以证明撤除正确。语义上的
前后条件归能力/组合契约，具体 effect 与 disposer 对应归提供者设计，运行证据
绑定实际采用版本；不为这一检查方面创建第四种规格或统一清理引擎。

局部逆关系不能独自说明交错撤除正确；共享操作和控制省略/放宽的证明要求沿
[组合性质](../assurance/composability.md)判断。前提应能定位负责它的接口提供者、
消费者或装配，不能从回调名称、相同签名或单实例测试推导。

## 资源所有权

每项注册、监听、任务、计时器、子实例和句柄都应能回答：谁建立、谁有权撤除、谁负责等待、何时失效。共享资源需要说明共同使用与最终释放的关系；“大家都可以用”不能意味着无人负责释放。

资源建立和所有权登记之间存在重入或并发时，应防止初始化尚未返回，拥有者已开始撤除而遗漏刚建立的资源。失效后的实例不得通过晚到回调重新发布能力或创建无主任务。

需要独立销毁权时，可以通过受约束句柄表达。一般查询得到的引用不应自动拥有所有管理权限，见[身份与作用域](../modeling/identity-and-scope.md)。

## 停止与静止

停止请求表达意图；停止接纳关闭新的入口；排空等待已接纳工作到达规定终态；释放结束对资源的占有。契约应明确停止操作的返回值对应哪个阶段，以及哪些等待是有界的。

例如，一个写入服务退出时，可以先拒绝新写入，再等待已接纳写入结算，最后释放后端。若底层不能完成，应按明确的超时或故障政策报告未完成状态，不得返回没有依据的“全部关闭”。

清理顺序由依赖确定。只有相互独立的清理才能安全并发；后端必须晚于使用它的写入任务关闭时，应显式表达这个等待关系。清理动作被逆序发起，不足以证明所有异步动作按逆序完成。

## 失败和外部副作用

重复停止和并发停止需要有一致、可解释的结果。单个清理动作失败时，应说明哪些其他清理继续、错误如何汇总、哪些资源仍未释放，避免一个回调阻断整个退出过程。

局部监听和注册可以通过清理撤除；模型调用、外部发送或持久写入通常已经留下独立效果。幂等、补偿、撤销和恢复各自需要业务协议，不能从 disposer 的存在推导。

实例退出后的晚到结果，要按原调用和代际归属处理。不得把旧任务的成功投递给新实例，也不得为了隐藏迟到响应而丢失已经发生的外部事实。相关交互规则见[操作与事件](interaction.md)。
