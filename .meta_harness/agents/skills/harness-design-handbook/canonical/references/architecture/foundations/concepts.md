## 能力与运行

| 概念 | 定义与边界 |
|---|---|
| 能力 | 系统可以提供的一项有明确含义的行为，例如执行命令、解析模型或保存记录。 |
| 能力维度 | 需求分解时可独立解释并演化的一项能力责任，经明确契约与其他能力组合；其边界由承诺和变化依据确定。 |
| 能力基 | 当前已定义的能力维度及其契约、版本和组合关系，用于解释新需求；候选、已接受与已实现范围分别记录。 |
| 能力覆盖 | 在明确前提下，一项或几项能力的契约与组合能否兑现某项要求；需给出对应操作、保证与交接依据。 |
| 能力契约 | 对能力的操作、输入输出、失败、状态关系和可观察保证的约定；接口签名只是其中一部分。 |
| 提供者／消费者 | 分别承担实现能力契约、依赖该契约完成工作的角色；同一组件可以同时承担两种角色。 |
| 插件定义 | 可以交给运行时装配的组件定义，包含实现及其配置、依赖等声明。 |
| 运行实例 | 一次装配产生的活跃对象，具有本次生命期内的身份、资源和状态；定义可以对应多个实例。 |
| 服务 | 经约定名称或标识可解析、可调用的能力表面；其内部可以是具体提供者，也可以管理多个贡献。 |
| 注册表 | 管理一类声明或贡献的命名、查找、冲突和撤除规则的能力；注册表存在不代表每个条目存在。 |
| 注册贡献 | 某个所有者向环境加入的条目、实现或处理器，具有可见范围、注册身份和撤除条件。 |
| 包／部署单元 | 分别承载代码分发与独立部署边界；与能力、服务、插件实例不要求一一对应。 |

分解方法见[能力覆盖与演化](../../decompose.md)，正交性与依赖见[能力边界](../modeling/capabilities.md)。
这里“维度/基”表达可组合责任，不假设线性叠加、零依赖或任意组合均合法。

## 关系与身份

| 概念 | 定义与边界 |
|---|---|
| Context | 介导当前组件访问服务、参与交互、登记受管资源的运行环境；不同于模型请求中的上下文文本。 |
| 作用域 | 决定贡献可见性、名称解析或事件接收范围的边界；继承规则必须由相应协议声明。 |
| 依赖 | 某项行为成立所要求的外部能力或条件，包括缺失和变化时的响应。 |
| 绑定 | 一次解析把消费需求关联到具体提供者、条目或版本的结果，具有有效范围和失效条件。 |
| 所有权 | 对某项资源或状态的创建、变更、释放承担责任并具有相应控制权的关系。 |
| 句柄 | 对某个对象或资源的受约束引用，携带可用操作、有效期或控制权；知道标识不等于持有句柄权限。 |
| 身份 | 区分并关联对象的依据；持久业务身份、运行实例身份、调用身份不可混用。 |
| 租户身份 | 确定数据归属与访问授权范围的业务身份，必须显式跨越有关边界。 |

具体关系与授权规则见[身份与作用域](../modeling/identity-and-scope.md)。

## 交互与状态

| 概念 | 定义与边界 |
|---|---|
| 操作 | 具有接纳条件、输入输出、状态影响和失败语义的一次交互；命令请求变化，查询读取状态。 |
| 事件 | 参与者之间按协议传递的发生或阶段信息；须另行说明它是事实通知还是允许参与决策的信号。 |
| 状态 | 在指定时刻、指定观察范围内影响未来行为的信息。 |
| 事实 | 已在声明的提交边界成立的业务记录；其成立不必等同于已经写入可抗崩溃的介质。 |
| 权威来源 | 对某项事实或状态具有最终解释权的定义或数据源。 |
| 投影／缓存 | 分别是按明确规则从权威来源导出的视图、为读取或计算保留的可替代结果；都不得自行重定义事实。 |
| 持久化 | 按契约让数据跨越指定故障或重启边界保留的能力；必须说明什么操作完成后获得何种保证。 |

交互的阶段与并发含义见[交互协议](../runtime/interaction.md)；权威、保存与重建见[状态与存储](../modeling/state-and-storage.md)。
上表的“投影”特指事实读面；需求到能力的承载映射、能力契约到 Cordis 插件的实现映射分别由
[分解](../../decompose.md)与[运行时投影](../../project.md)说明。

## 变化与约束

| 概念 | 定义与边界 |
|---|---|
| 受管 effect | 实例向环境建立的资源或关系，其建立与清理由明确所有者管理。 |
| 清理动作 | 撤除某项受管资源或关系的操作；有序性、等待和失败保证由契约规定。 |
| 外部副作用 | 超出局部受管环境的可观察改变，例如发送请求或提交外部写入；不因实例销毁自动撤回。 |
| 静止 | 在明确范围内，相关工作不再继续产生该范围所禁止的新行为；范围和判定条件必须写清。 |
| 契约版本 | 一组语义承诺的身份；内容版本标识定义内容，运行代际区分替换前后的实例，数据格式版本标识保存的表示。 |
| 安全性质 | 要求不发生某类非法行为的性质；状态不变量描述每个规定观察点都应成立的状态关系。 |
| 进展性质 | 在明确前提下要求某件事最终发生的性质；与“从未观察到非法状态”不同。 |
| 强制约束／运行时检查 | 分别在拥有操作的边界阻止非法行为、通过观察发现违约；检查器可撤除不意味着规则随之失效。 |

生命周期细节见[资源释放](../runtime/lifecycle.md)，版本变化见[动态演化](../runtime/evolution.md)，约束描述见[不变量](../assurance/invariants.md)。
