# 信息包准入与停止条件

**何时读：**准备落盘、迁入旧材料，或不确定该进哪个 design family。
**读后留下：**持续消费者、唯一语义拥有者、准入结果和受阻时的临时落点。
**返回：**[工作区上下文](workspace-context.md)选择实际模板，或[交付](handoff.md)记录缺口。

## 先过统一准入测试

只有任务结束后仍需消费的当前要求、承诺、必要理由或可复跑资源，才进入长期设计链。执行仓库明确保留的正式RFC及Issue最小记录按其文档治理判断，不把这些例外扩展为全部开发形成史。
指出唯一语义拥有者，并确保来源、范围、状态、未知与下一步消费足以接续。尚未形成正式要求，
但需求语义仍未确认时，交流与候选留本次 `tmp/`。确认后的规则归现行产品正文。
观察、候选、评审、接受、发布、实现和验证不能因换目录而升级。

**下表用通用语义名**，因为手册可被单独迁出；
**它们在本工作区落到哪个实际路径，见[工作区上下文](workspace-context.md#现行源)**。

| family           | 最低可消费信息                                           | 不满足时停止                                           |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------------ |
| requirements     | 观察者、触发、所需/禁止结果、来源与确认范围              | 留在 intake；不补造确认或机制                          |
| research         | 持续问题、精确对象/版本、取得方式、观察与局限            | 一次检索留 `tmp/`；不可核实则只留待验证命题            |
| basis            | 跨多次设计被反复依赖的上游机制语义，带 symbols 与**一个在该语义消失时会失败的 probe** | 只在本次用到的读数写进本次分析产物；给不出 probe 就记为待核对主张 |
| 共享公开形状     | 多方共享且必须一致的数据含义、身份、版本和消费者         | 单方内部表示回能力/提供者；归属不明先停止              |
| 单项能力行为     | 可独立解释和演化的能力责任、操作/状态/失败及精确依赖     | 现有能力仍能拥有时不新增；语义未定保持候选             |
| 跨能力整体行为   | 不能归于单项能力的整体性质、参与版本、保护者与失败交接   | 只汇总依赖不准入；关键责任未定不发布                   |
| providers        | 精确能力契约到插件/服务、源码修订、资源/装卸与符合性映射 | 只有机制设想回 proposal；无实现只记缺口                |
| assemblies       | 实际应用、提供者选择/版本、配置、动作链与集成证据        | 选择未发生保持候选；局部通过不等于整体完成             |
| views            | —                                                         | **不手写、不手改**；缺内容说明上游缺或生成器缺         |

**公开形状、模块行为、提供者与装配材料归实际成员。**公开入口、行为契约、必要ADR、Schema、models与verification按执行仓库包模板归位，多个提供者消费同一共享承诺。系统级预期归[工作区上下文](workspace-context.md)指定的系统架构拥有者。包群与完整成员文档沿执行仓库两层规则，不由SPEC限制文种或篇幅。

架构视图从实际源码及明确系统预期派生，不另写一份能力/绑定权威。迁移对照、计划、派发和进度留任务tmp；终态只保留新的实际拥有者与当前消费者。

**`views` 那一行的破折号不是漏填**：派生物没有自己的准入，它的内容全部来自上游。
**它不得被引为依据**——需要引用时引上游那份手写的家；与上游不一致时以上游为准，重新生成。

## 模板与形式工件

topic 是入口加按需现行正文与可复跑资源的信息包，不是单份固定表。先读实际 family README，
从相邻 `.templates/` 复制整包，再删除不适用文件并同步入口；模板占位不能冒充实际承诺或已接受状态。

规格中的 Schema、TLA+、Alloy、场景或证明按性质需要选择。optional 表示不为每个 topic 预造空工件；
契约或设计已经触发的行为、结构或证明义务必须完成或显式阻断相应发布与消费。

**停止判据：**正文只有一个拥有者，消费者能按入口找到必要信息；临时施工材料没有混入长期 family，
未满足的准入项保留在可恢复任务输入并指出闭合条件。

正式保存例外按执行仓库治理判断。其余候选、逐轮讨论和评审、原始运行结果落各自工作树`tmp/<task>/`。长期正文保留当前选择、必要理由、精确采用范围与未决，不要求形成史台账。
