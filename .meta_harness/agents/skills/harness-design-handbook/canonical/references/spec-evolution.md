# 规格落地、修订与变更传播

**何时读：**把已设计的语义写成可消费规格，或修改既有契约、实现映射及证据。
**读后留下：**语义归属、精确采用关系、受影响消费者及规范/映射/证据各自的变更。
**返回：**[定义](define.md)或[交付](handoff.md)；实际文件、包模板和工具从[工作区](workspace-context.md)取得。

## 按语义确定承诺拥有者

| 语义由谁拥有 | 适合落在哪里 | 不应放入的内容 |
|---|---|---|
| 共享身份、值和关系的含义 | 共享公开类型与必要校验 | 每个消费者各自复制的同义类型 |
| 对消费者的操作、权限、状态和失败承诺 | 拥有者旁的行为契约 | 内部类层次、具体服务键与库调用细节 |
| 无法归属单一能力的整体性质及交接 | 整体责任拥有者旁的行为契约 | 只为联调再抄一遍各方契约 |

候选比较留工作树tmp。正式终态使用唯一公开入口及模块旁行为承诺，明确采用范围和未决事项；当前理由按需写所属成员ADR，不要求永久采用形成史。
SPEC 是避免重复形状的行为契约，必须完整表达适用条件、失败、生命周期及验证义务。成员的使用、内部设计与维护文档不受其篇幅或文种限制。
公开接口、行为契约、模型和规范场景由同一语义拥有者持续维护。目录或文件存在不表示已接受，提供者选择及装配不复制共享承诺。

Schema、结构模型、行为模型与规范场景按[规格表达](architecture/assurance/specification.md)选择。
它们表达同一契约的不同方面；自然语言不能暗改行为权威模型，模型也不能靠省略已有要求取得通过。
语义冲突先解决权威和适用范围，不能默默采用更便于实现的一份。

## 精确引用与发布边界

区分身份、修订和文件位置；移动目录不自动改变语义身份。规范依赖按契约身份与条款引用，并记下「核对于哪一次修订」；
背景链接只供理解。**条款号不复用**：删掉的条款留着号，新条款取新号，引用才不会悄悄指到另一个意思上。
实际 Schema 的标识、引用解析和解析后的内容需相符，链接文件存在不足以说明数据引用正确。

**每份承诺只留当前终态。**被取代的正文及时删除，旧字节留Git历史。语义修订须有授权/接受依据，同步公开类型、Schema、行为契约、模型、规范场景及真实消费者；不能靠重新算哈希把未接受改写合法化。

模型及配置在实际拥有者models/，验证义务和可复跑方法在verification/。单次输入快照、输出和评审结果留工作树tmp，绑定实际修订及范围；不新增中央登记、冻结或版本目录。

公开Schema身份不因移动改变。检查实际声明闭包、打包消费及真实读取路径；不能用空清单、兼容包装或删断言求通过。数据身份与兼容政策由执行仓库的现行要求决定。

## 先判断改变的是哪层

| 观察到的变化 | 应回到哪里 | 需重新核对什么 |
|---|---|---|
| 结果、授权、状态、失败或生命周期承诺改变 | 语义拥有者及接受依据；已发布时出新修订 | 依赖契约、消费者、实现与证据 |
| 库、服务键、公开接口、绑定或清理映射改变 | 提供者/装配设计与公共接口；只有语义改变才改契约 | 实际调用者、作用域、时序与符合性 |
| 状态表示、交错、观察关系或环境前提改变 | 对应设计及性质论证 | 旧证明/模型的适用条件、实际组合证据 |
| 实现违反有效契约 | 先在契约内修复实现 | 违反的性质、相称回归与真实结果 |
| 增改已接受契约的规范模型或场景 | 修订现行源，过接受门 | 同一语义的表达一致性和消费者采用范围 |
| 仅更新执行结果或覆盖记录 | 规范之外的证据记录 | 输入、工具、环境、实际结果及局限 |
| 普通导航或局部表述修正 | 对应正文；语义变化须明确授权 | 链接/含义与受影响引用，无需无关全套审阅 |

具体服务键未定，未必是行为规格缺失；提供者失效后无人结算工作，则不能用映射表代替语义设计。
新证据与旧结论冲突时，按[设计复议](design-decisions.md#前提改变时怎样复议)报告，不为维护进度降低有效要求。

## 变更沿消费者传播

从所改条款/公共表面出发，跟踪依赖规格、数据使用者、提供者、装配、应用调用者和验证设施。
文字检索帮助发现引用，动态注册、配置解析和运行时选择还需查实际装配关系，不能以“搜不到”断言无消费者。

为受影响消费关系留下：它核对于哪一次修订、差异、负责修改的产物/拥有者、完成证据及闭合时点。
**修订不留旧版给消费者停靠**：消费了被改条款的人要复核——仍成立就把「核对于」改到新修订，不成立就跟着改；
不复核就批量改号，等于把这道检查关掉。没迁完的消费者是一笔显式的债，在任务tmp及当前拥有者处明确未完成范围，不靠保留旧版把它藏起来。
逐项核对语义、公共接口、数据解释及实际组合，不能只比较方法签名。
现有证据保留其原范围，只有前提与映射仍成立的部分可复用；迁移中的工作、持久事实和失败恢复也需有归属。

**停止判据：**规范、实现映射与证据的变化分别有落点，相关消费者可判断继续采用、迁移或等待什么。
四层就绪状态在[交付页](handoff.md#区分四层就绪状态)汇总；完成规格表达不等于实现或验证完成。
