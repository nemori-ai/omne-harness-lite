# Agent

## 它是什么

管一轮 Run 实际怎样往前推的领域。它回答的是「下一步做什么」：

- 准备一次模型请求，发出去。
- 读模型的回复，决定是结束，还是发起工具调用。
- 发起工具调用，接结果，再决定下一步。模型一次给出几个动作时，谁先谁后由它定：按原动作顺序发起；一个动作要等排在它前面的每个都填满了槽位，除非两者都标了可以同时进行。这个标记由受信的请求来源给出，Agent 不解释它从哪来。
- 在循环的每个拓展点上，让挂在那里的扩展运行。官方动作准入是每条扩展链末尾的受信系统扩展，不可替换、不可禁用；作者的扩展只能增加限制。
- 为程序发起的嵌套动作答许不许。一段程序在一个还在等待的工具调用之下发起动作时，Agent 用父动作那一批记下的扩展链与同一道官方准入判它；发起、等待与结果归程序的调用方。
- 接手只有一种方式：会话开一次新的执行尝试，新的协调者从检查点接着走。会话为重装请求交出时，Agent 按这一轮此刻在哪答：睡在保存的等待上，马上交出；在一步的中间，这一步求值之后、下一次模型请求之前交出；正在收尾，拒绝。交出时在途的模型与工具调用不取消、不重发。

它是 Model 和 Tool 的调用方，是它们的结果的接收方。对它来说，Model 和 Tool 是被远程调用的服务，见 [cross-domain.md](cross-domain.md)「调用是远程调用」。

## 它不是什么

- 不是会话的主人。它不决定收不收输入，不决定会话的生命周期，不拥有会话的业务状态。它对会话的了解，只有交到它手里的工作和推进资格。
- 不是事实的存放处。它的执行记录写进会话日志。Agent 的实例没了，换一个从日志接着推。
- 不认识 Context 的内部。它声明自己需要什么（准备一次模型请求），由适配成员翻译成对 Context 的调用。

## 扩展的装配归谁

| 事 | 归谁 |
| --- | --- |
| 循环上有哪些拓展点，扩展在拓展点上怎样被调用 | Agent |
| 这一轮用哪一份组合：哪些工具、哪个模型、Agent 定义组合了哪些扩展 | 装配与采用。在采用点上求值，结果是一份采用依据 |
| Agent 定义从哪来 | 资产类别 `AgentDefinition`，一份定义是一个目录。三层候选：官方的照部署的配置；租户在持且生效的一份；这一轮采用的工作区里的。后两种只能是 non-master，官方的不被同名的顶替。每一轮开始时采用当时胜出的一版 |
| 采用点在哪 | 只有两个：新的一轮开始时；人显式要求重装时。一轮在跑时的重装，按上面「接手」一条说的时机交出 |
| 常驻能力怎样进一轮 | 定义引用的 `tool`、`skill`、`mcp` 都可以标常驻。常驻的工具与 MCP 接入点进工具声明，常驻的 Skill 把简介放进系统提示词，在采用点定下。常驻的 Skill 与 MCP 接入点在采用时拿不到不挡会话 |
| 租户此刻启用了哪些扩展 | 拓展件领域。它按当下事实算出一份视图，经 Runtime Context 供给，见 [loop-extension.md](loop-extension.md) |
| 一次走到拓展点，这一次运行哪些扩展 | Agent。它在走到拓展点时读一次，把这一次的扩展链记进日志，这一次里不再变 |

拓展点是 Agent 的。扩展链的成员有三个来源：定义组合的在前，租户启用的居中，受信系统扩展在后。定义组合的是装配在采用点上定的，一轮里不变。租户启用的不进模型的上下文，所以不等采用点：Agent 每次走到拓展点现读，读到什么就记什么。受信系统扩展由装配经一个可选的端口供给，和租户启用的一起读。

## 拿它量一个设计

- Agent 发起一次调用之后等着对方的对象活着：不对。它保存调用的引用，结果交到登记的消费者引用上。
- Agent 的实例换了，就重新发一次调用：不对。先凭引用认回原来那次。
- Agent 在一轮当中发现有新的常驻工具，或定义组合的扩展变了，就立刻用上：不对。等到采用点。
- Agent 在一轮的开头读一次租户启用的扩展，整轮都用这一份：不对。每次走到拓展点现读。
- Agent 在一次经过的中途重新读，或者恢复之后重新读：不对。这一次经过凭已经记下的扩展链走完。
- 读不到租户启用了哪些扩展，就当作没有：不对。读不到是读不到。
- Agent 需要知道一个治理领域的事实，于是导入那个领域的类型：不对。那是 Runtime Context 的一块，经适配读。
- 一批动作里有先后的两个改动同时发给 Tool，让 Tool 的排队去定谁先：不对。先后是 Agent 的事，轮到了才交出。
- 一条规则只在某个扩展装着的时候才成立：把它写成那个扩展的规则，不写成循环的规则。
- 主模型调用答不可用，Agent 自己再发一次：不对。要不要再发由 Model 在同一个调用里决定；不可用让这一轮失败，带着成因。
- 人在作者扩展出的卡上同意了，就跳过官方准入：不对。官方准入照样对这个动作判断。
- 重装要交出时，Agent 打断正在进行的模型请求，或取消在途的工具调用：不对。它等到这一步求值之后再交出，在途调用留给下一次执行尝试。
