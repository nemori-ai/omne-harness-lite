# 设置与权限：配值与求值

## 它是什么

设置回答：一项可配置的东西现在的值是什么、来自哪一层、谁能改、改了怎样保证当下的事实仍成立。权限回答：一个权限关口的允许范围与生效值是什么，哪些限制下层永远解不开。两块各自拥有自己的求值规则，不合成一套通用覆盖算法。

- **含义归声明方，配值与求值归设置。** 功能或资产类别拥有每项设置的含义、类型、合法值、默认或无默认、清除后果与采用时点。资产设置随当前合法定义派生；独立设置从它自己的固定定义与配置目标投影，不伪造资产持有。
- **声明经治理交给一个逻辑服务。** 一个功能或一份资产在运行中把自己的设置项与权限关口声明交给 Governance；装配者一次整份定下当前采用。Governance 不碰配值、许可与身份资格。
- **值配在一摞层上。** 普通值按默认、组织、租户、工作区、会话的层序取最具体的合法值；有效的外层锁阻止更具体层覆盖。禁用按「任一层为真即禁用」合并，这条规则不推广到其他设置。
- **权限是另一种有自己合并规则的设置值。** 适用来源是默认、组织、租户、会话；工作区不提供权限配值。锁定集合取交集，内层不能突破外层上界；未锁值只是挑选，从最具体来源向外取第一个落在界内的挑选。拥有者提供的约束（如 Agent 定义的权限上界）与四层配值共同构成上界。
- **外层的锁、上界与主动禁止钉穿内层。** 组织、租户或会话主动配置「不允许该操作」时，下层挑选、会话模式、自然语言批准或人工介入都不能把它放宽成允许。
- **求值交出胜出的值和依据。** 有效值报告保留最终值、采用来源、被过滤或锁定的原因与本次依据。权限结果保留实际采用范围、允许集合、有效值与依据。
- **三种「没有」分开。** 本层没配，沿外层往下求；显式配成 false 或空，是一个值；读不出来，是故障，不是空也不是默认。清除只撤回本层覆盖，不等于 false。
- **写入看提交那一刻的当前事实。** 一次写入能不能成立，看的是目标拥有者在同一事务里给出的当前事实，不是之前读到的页面、一次准入结论或调用方的断言。结果不知道按原操作身份认回。
- **秘密设置项的值只在秘密保管里。** 它不进入配值、求值来源、提交记录或回执。秘密按范围、目标与用途绑定，替换后的新实现取不到原实现的秘密。

## 它不是什么

- 它不是授权。权限求值给出有效值与依据；一次具体的动作许不许，由授权每次回答。值的「允许操作」为真只表示结构上没有禁止，之后仍可能要人工、环境或别的检查。
- 设置保存成功不代表运行已经改变。值求出来不代表绑定对象可用、Agent 已装配或动作获准。
- 它不解释授权表达，不保存许可与消费回执。那归授权。
- 它不拥有配置目标的生死。目标归目标拥有者，资格归身份。
- 它不认识具体类别。Tool 与模型供应商的设置定义都经类别契约投影，Settings 不认识任何具体类别。
- 工作区不能授予更高权限。工作区的权限配值在加载时过滤，不允许放宽。
- 单次与会话授权不经它改持久权限。卡片上的「始终放行」「始终禁止」走同一条租户层写入，服从组织上界与主动禁止。

## 拿它量一个设计

- 设置和权限共用一个合并算法：错了。
- 某一层的来源读不出，求值当成「这一层没有」或回退到默认：错了。读不出是不可用；已有合法禁止时，禁止仍成立。
- 把设置合并出的单个有效值交给权限求值：错了。集成方把各层原配值交给权限求值。
- 权限求值放行之后不再经授权就执行动作：错了。
- 下层挑选、会话模式或一次人工批准解开了外层的主动禁止：错了。
- 写入凭之前读到的目录页或一次准入结论成立：错了。在提交那一刻核当前事实。
- 资产换了新版，同名的项直接继承旧值：错了。一项的声明一字不差才算没变。
- 秘密值出现在配值、回执、日志或诊断里：错了。
- 需要秘密的目标在这一层缺秘密，就改用另一层的：错了。停止依赖它的动作。
