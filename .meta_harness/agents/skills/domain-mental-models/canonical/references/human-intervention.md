# 人工介入

## 它是什么

人工介入把「要人决定」的那一件事交给人，再把人的答复交回去。

- **卡片有三种：问询、放行、通知。** 问询由 agent 经 `Ask` 发起，问的是信息或选择；放行卡由 Agent 的准入在放行判断答「问人」时发起，问的是许不许；通知只告知，不等答复。
- **卡上的字各有作者。** 放行卡的壳由系统固定；「这一次会做什么」由工具作者的描述函数从这次调用的参数算出，界面按种类画，画不了就画条目。
- **答复交回原来的地方。** 问询的答复交回 agent，它接着想；放行卡的答复交给授权，成为一笔授权表达或一项租户设置，不经 agent。
- **一张卡只产生一次有效决定。** 答复者要有当前资格。普通消息不自动回答卡片。

## 它不是什么

- 它不判许不许，那是放行判断。
- 它不保存授权。授权表达在会话日志里，持续的授权在租户设置里。
- 它不是工具自己出确认卡的地方。工具不出确认卡；要人确认内容，就是对带着完整内容的动作的放行。
- `Ask` 不是要授权的口。agent 不拿问询向人要许可，人在问询里答的话不产生许可。

## 拿它量一个设计

- 一个工具或一个领域自己出确认卡、自己问人：错了。走放行卡，由准入发起。
- 把问询的答复当成许可：错了。
- 放行卡的答复经 agent 转交给授权：错了。它直接交给授权的拥有者。
- 同一张卡产生两次有效决定，或答复者没有当前资格也算数：错了。
- 卡上「会做什么」由准入或界面自己拼：错了。它由工具作者给，系统只画壳。
