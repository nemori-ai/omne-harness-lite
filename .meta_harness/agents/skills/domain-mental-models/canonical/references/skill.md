# Skill

## 它是什么

一个 Skill 是一个目录。目录里有一个入口文件 `SKILL.md`，还可以有参考资料、模板和脚本。它教 agent 怎样做一类事。

它按三层披露，一层比一层多，用到才读下一层：

| 层 | 是什么 | 什么时候到模型面前 |
| --- | --- | --- |
| 一 | 名字和一句说明，取自 `SKILL.md` 的头部 | 常驻时一直在；不常驻时出现在搜索结果里 |
| 二 | `SKILL.md` 的正文 | 模型决定用这个 Skill 时读 |
| 三 | 目录里别的文件 | 正文指到了、模型需要时，按目录里的路径读 |

- **Skill 领域拥有的是「这个目录是不是一个合法的 Skill，以及怎样把它读给主体」。** 包的格式校验、三层的读取、读取时带的来源与版本，归它。脚本怎样运行不归它。
- **agent 经一个入口用它：`Skills`。** 入口有五个命令：搜索给第一层，读入口给第二层，按路径读给第三层，列目录看有哪些文件，提交发布一个目录。前四个只读，没有执行命令。入口是稳定的；背后有多少个 Skill，入口不变。
- **脚本是目录里的文件，运行它的是 Shell。** 脚本和参考资料、模板一样，按路径读，读到不运行。资产一定先加载到本地。单机装配下，Skill 的目录就在本机的文件系统里，`Skills` 的读取结果告诉 agent 它在本机的位置，agent 用 Shell 直接运行。这是一次普通的 Shell 工具调用，准入、环境、等待、取消、结果全照工具执行与执行环境的规则。
- **登记一个 Skill 的最小办法是交出一个目录。** 人交、agent 交，走的是同一个发布操作，发布到一个租户名下。
- **元技能是一个普通的 Skill。** 它教 agent 怎样写 Skill，由官方层提供，常驻。它没有特殊的机制。

## 它不是什么

- 它不是工具。它没有参数契约，没有执行体。读一个 Skill 的结果是文字。
- 它没有运行时，也没有「已启用」这个状态。读正文是一次返回，读完系统不记任何东西。
- 它不认识材料从哪来。发行自带的、租户登记的、以后工作区里的，对它是同一种东西：一个待校验的目录。
- 它不决定同名的几份听谁的，不决定许不许用。那归资产与规则、身份与授权。
- 它不决定哪些 Skill 的简介常驻在系统提示词里。那在采用点由会话的声明和 Agent 定义决定。
- 能读一个 Skill，不等于能运行任何命令。Skill 不持有执行权。Shell 的许可不因为脚本来自某个 Skill 而放宽，也不因此收紧。
- 它不向 Shell 里的进程注入任何值。偏好与绑定类设置的求值结果随正文返回给 agent；脚本要的凭据与环境，由那一次 Shell 调用按执行环境的规则取得。
- 它不认路径。它拿到的是按能力标识取来的一个包的读口，不是宿主机上的一个目录名。目录加载到本机之后在哪是另一件事：单机装配下它是一个事实，`Skills` 把它告诉 agent，供 Shell 使用。

## 拿它量一个设计

- Skill 的成员里出现了「租户层」「工作区」「会话」这些词：错了。它只认主体和通用的依据。
- 读了正文，系统记成「已启用」或「已加载」：错了。没有激活状态。
- 新装一个 Skill，要重建 Agent 或改已有会话的系统提示词才能用：错了。不常驻的 Skill 经 `Skills` 的搜索就能用，见跨领域那一份「能发现的和装进上下文的」。
- 在系统提示词里提一句「还有某某 Skill 可以搜」：错了。让模型知道有某个具体的 Skill，就是把它常驻了。模型靠 `Skills` 自己的说明知道先搜。
- 读第三层的文件要先「打开」这个 Skill：错了。读是读文件，按路径直接读。
- 路径指到了目录之外，读到了内容：错了。读口只给包里的东西。
- 依赖不齐，正文就读不到：错了。Skill 仍被合法选入、主体有读取权、正文来源正常时，必需依赖缺席不挡读取。正文照常返回，缺什么写在搜索结果与这次读取的结果里。读取资格失效时才不给原内容。
- `Skills` 里出现执行脚本的命令，或 Skill 替脚本判执行许可、搭一条脚本桥接：错了。运行归 Shell。
- 为运行脚本先用按路径读把它读出来、再写到落点：错了。单机装配下脚本就在本机的文件系统里，Shell 直接运行。
- 为脚本的运行设计防护、隔离或沙箱：现在不做。防护与隔离不在这一阶段。
- 提交一个 Skill 没有经过人点头就发布了：错了。agent 提交的每一次都要人确认。

## 现状

上面是目标。Skill 领域内的实现（包的校验、目录的读取、读取闸门）还没有进轨道。`Skills` 入口、发布操作、常驻简介、元技能都还没有做。做到哪一步，以 `docs/domains/skills/README.md` 写的为准。
