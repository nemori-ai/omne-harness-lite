# 媒体

## 它是什么

媒体回答三个问题：一份非文字内容的字节在不在、是谁的、对不对；它有哪些别的表示、各是谁做的；按一个型号的限额，同一份内容的合规版本是什么。

- **它是一个寄存处。** 图片、语音、文件交进来，验过、放稳，才给出一个内容引用。会话日志、工具结果、模型请求的记录里放的都是引用，字节只在它这里。
- **原件不动，表示挂在原件上。** 一份媒体有三级：原件，另一种模态的表示，一段文字兜底。后两级由转换件做出来。原件永远在，表示只增不改。
- **它不认识型号。** 每次请求给模型哪一级，是 Request Context 按型号的能力选的。型号原生读得了什么，是 Model 的档案写的。媒体只管把每一级备好；型号的限额由调用方当参数给它。
- **没人认领的到期清掉，有人认领的留着。** 引用方把引用写进自己的事实之前，先来持有。人上传的内容先是暂存，受理输入时被持有；工具的产出存入时就被这次调用持有；拖到纸上的文件在画布摆上它的那一刻被持有。
- **表示什么时候做，由引用方定。** 人发的媒体在上传之后就做，发消息之前人就看到结果。工具产出的媒体只在当前型号原生读不了它时才做。机制只有一个，幂等。
- **受理时把表示写进消息。** 媒体向 Session 登记一个受理前处理件：核对引用，持有，把这份媒体当时的表示快照与媒体事实补到消息的块上。之后请求只读日志。
- **转换件分两样。** 定义是资产：哪种媒体、哪个引擎、参数、内容去哪，官方、组织、租户各能持有同名的一份。它放在点 `media.converters` 上；媒体只声明这个点并读求值的结果，各层的候选由资产从点上读出。引擎是登记进来的插件：一份声明加一个「字节进，表示出」的函数。
- **字节放哪可以换。** 存放是一个按对象存储的语义定的端口，元数据是另一个端口。引用里写着内容在哪个存放提供者。
- **引用只在一处变成字节给模型：Model 的发出。** Model 声明读媒体的端口，媒体来接。

## 它不是什么

- 它不是会话历史。哪条消息引用了哪份媒体归 Session；日志里没有媒体的字节。
- 它不决定模型读哪一份，不判断型号收不收得下。
- 它不是资产。资产是能力的定义；媒体是内容。转换件定义才是资产。
- 它不是工具大结果的卸载处。那是 Tool 自己的文字正文存放。
- 它不是核心链路的一环。核心领域不导入它；卸掉它，纯文字的会话不变。
- 存放提供者在磁盘上的布局不是契约。契约是内容引用与端口。
- 进行中的转换与失败的转换都不是事实。事实只有媒体对象与做完的表示。

## 拿它量一个设计

- 会话日志、工具的账本或模型请求的记录里出现了媒体的字节：错了。只放引用。
- 引用先交出去、字节后落盘：错了。
- 清扫先读出「到期且没人持有」再去删：错了。条件要写在删除的那一次写里。
- 引用方先写自己的日志、后来持有：错了。先持有。
- 两个租户传了同一份字节于是共用一个对象：错了。并入不跨租户。
- 用内容的摘要当存放的键：错了。删一个对象的字节会碰到同摘要的另一个。键是不透明的标识，去重靠元数据里带租户的唯一约束。
- Request Context 在组装时来问「这份有没有转写」：错了。读消息上的快照。
- 转换件定义生效而引擎不在，于是当成不需要转换：错了。答不可用。
- 发出时发现型号读不了，于是在 Model 里现转：错了。Model 不做转换。
- 没有文字兜底的内容被悄悄从请求里去掉：错了。那个型号不可选，或这次请求如实失败并点名。
- 转换引擎自己去读存放、读别的媒体、自己造内容块：错了。它只拿到这一份的读句柄，交回文字与字节。
- Session、Model 或 Tool 的成员导入了媒体的成员：错了。它们各自声明端口，媒体的适配来接。
- 媒体的核心导入了文件系统、SQL 提供者或图像库：错了。经端口。
