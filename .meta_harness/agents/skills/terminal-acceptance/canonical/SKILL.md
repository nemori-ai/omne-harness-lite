# 终端验收

你是 qa。这次交付面是终端界面。本 skill 是终端关口，不是另一份验收权。
判决、证据和停止条件仍以 qa 正文为准。交付面不是终端界面时，不要加载本 skill。

每次验收都过下面几关。结果进逐条对照表。没条件过的写进「未覆盖」，不静默跳过。

| 关 | 判什么 | 怎么判 |
|---|---|---|
| 终端矩阵 | 至少在两种终端程序、两种尺寸下结果一致 | 同一场景各跑一遍，结构层 golden 逐一对比。只在某一种下挂的标「终端差异」 |
| 非 TTY | 被重定向或没有屏时明说不行，并指出机读那一份 | 用管道起一次。不静默降级 |
| 宽字符 | CJK、emoji、组合字符不错位、不溢出行尾 | 场景输入里放一段中文与 emoji |
| resize | 中途改尺寸不丢内容、不残留 | 场景里插一次 resize |
| 退出还原 | 正常退出、Ctrl-C、被杀三种收场后，终端模式、光标、echo、替代屏都还原 | 每种收场后抓一次终端状态 |
| scrollback 卫生 | 退出后 scrollback 里没有界面残骸。替代屏进出配对 | 看退出后的屏幕与原始写日志 |
| 输入法与粘贴 | 中文输入、多行粘贴不被拆成多次提交 | 伪终端整段喂一次、逐字节喂一次 |
| 机读通道纯净 | 机读输出里没有进度、提示、诊断混入 | 解析每一行，并逐条过 Schema |

观察顺序：被测应用自带的机读记录与结构化日志，然后是差分、无头终端、原始写日志、真实终端里的终端复用器、录制、截图。
被测应用起在你自己所在终端之外的伪终端、独立终端复用器 socket 或另一个窗口。
证据另加写到伪终端的原始字节，以及打开输入录制的终端录像。
你自己的 shell 必须素：固定提示符，不加载会往终端发控制序列的集成。
终端类型、尺寸、locale 显式设置并写进证据。
