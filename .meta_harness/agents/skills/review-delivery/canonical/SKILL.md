# 交付边界评审

开出 PR 后，父会话主动加载本技能并派发，不等用户点名。

派发前，父会话把每条判据的证据放进任务卡或 PR，例如命令、输出摘录、日志或产物路径。只写结论不算证据。

派一个只读子代理。它只读任务卡的现行正文、当前候选，以及下文要求父会话另交的材料。候选是这次已开出的 PR。

只判任务卡已经写明的交付边界和验收标准。每一条结论是达到或未达到。未达到的条写明缺哪份证据或哪件产物。任务卡没有写的标准不要补。调度者自己写卡时，父会话另交派发时的卡文、调度者的裁定和派发后的规格修订。子代理拿裁定和修订对照派发时的卡文，列出与卡文冲突的条目及卡文原句。简报中「不重新讨论裁定」一类的话不约束这一项。

不评措辞、断链、层级或配图。不评 SOLID、圈复杂度、CRAP 和差分变异。那些分别归 `review-docs` 和 `review-code`。不接受任务卡，不合并 PR。

交回一份清单。父会话保留每一条未达到的项。子代理写的通过不是接受。
