# 交付边界评审

派一个只读子代理。它只读任务卡的现行正文，以及当前候选。候选是这次工作树的差异，或用户点名的 PR。

只判任务卡已经写明的交付边界和验收标准。每一条结论是达到或未达到。未达到的条写明缺哪份证据或哪件产物。任务卡没有写的标准不要补。

不评措辞，不评 SOLID，不评圈复杂度和 CRAP。那些分别归 `review-docs` 和 `review-code`。不接受任务卡，不合并 PR。

交回一份清单。父会话保留每一条未达到的项。子代理写的通过不是接受。
