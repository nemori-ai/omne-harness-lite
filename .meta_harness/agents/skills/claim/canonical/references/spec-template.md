# 本卡实施规格模板（spec.md）

方法用 Matt `to-spec`：综合已有输入，不重新访谈；先找测试接缝，越高越好、越少越好。本模板在它的骨架上加入本项目的依据与「原则与约束」。规则本身归各拥有者，本模板只组织一次交付的输入。

使用规则：

- 放在 `tmp/issue-<号>/spec.md`。正式形状、完整行为契约与验收归实际拥有者，本文件不成为第二源。
- **只写差额。** 会话级已写的线级地图主体与 `tmp/line-<线>/constraints.md` 只引用，不重抄。本卡没有新增内容的小节写「无新增，见线级 <文件>」。
- 每条依据带链接与精确修订。不写只在对话里出现过的说法。
- 不写具体文件路径与代码片段，除非原型给出的形状比文字更精确（状态机、类型形状、schema）；这时只保留决定所需的部分，并注明来自原型。拥有者正文的路径可以写。
- 接续已有 attempt 时只写已采用规格之外的差额。
