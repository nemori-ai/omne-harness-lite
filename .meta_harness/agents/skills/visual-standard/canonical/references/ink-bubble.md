# 墨框与告知笺

> 什么时候读：要做一个从形展开的东西，改墨框的样子，或改告知笺之前。
> 墨框用在哪几处、告知笺什么时候写、写几条、点了去哪，归产品正文「Agent 在屏幕上的形」与 `apps/desktop/SPEC.md#页面`；墨框这个件给什么，归 `packages/frontend/SPEC.md#墨迹`。这里写它怎样看起来、怎样动，以及为什么。

墨框是形在给人看东西时的一致样子。人一看这个样子，就知道是 agent 在给自己看东西。

## 1. 算哪些

凡是从形展开、代形说话，或从墨点展开的东西，都画在墨框里：

| 用在哪 | 墨 | 从哪个座位、朝哪边 |
| --- | --- | --- |
| 告知笺：一条强通知到了 | 浓 | 家，朝右 |
| 对话页的侧边内容，窗口不够宽时盖在页面上 | 淡 | 对话头，朝下，在头部细线下面一小步 |
| 门上的一句话：登录失效，或退出时服务端是否注销没有得到确认 | 浓 | 门，朝下 |
| 随身入口的小框：人按墨点，展开写一句话的地方 | 浓 | 从墨点展开，靠下就朝上、靠上就朝下，放不下换另一边（[墨点](motes.md)） |

永远不用墨框的：

- 应用自己的菜单、下拉、提示、弹出层、确认面板。它们是应用的平样式。
- 常驻在版面里的东西：宽窗口里停靠的侧边内容、「待你决定」页。它们不是展开。

两种样子一混，人就读不出「它在给我看」。

## 2. 一个件，一种画法

一个件：共用件墨迹块的墨框（来源叫 `InkBubble`）。新加一个从形展开的东西就用它：不另画边框、不另加阴影、不加 CSS 的进场动画。

- **写出来**：笔从圆的口接着写出引线，再接着写边，分两笔，提笔处有飞白（绕到远角，在那里提起又落下，再回到引线的根）。边按框的大小生成，不拉伸。纸从落笔处洇开，边上像宣纸上的一片水，软的。
- **内容在边合上之后才出来**：边合上之前内容不可见；边合上时内容在 `state` 里出来，湿墨干成淡边。
- **收起**：内容先走（`feedback`），墨沿来路卷回口里，纸跟着退回去，比打开稍快，但从不生硬。还在打开时就被收起（Escape、点别处），从笔所在的地方卷回去。
- **引线**：从口出来，绕过圆的一侧落到边上，不穿过圆（`TAIL_CLEAR`）。引线朝形坐的地方：框拿座位的框当原点。
- **长内容**：在边里面滚，边不动。
- **键盘**：墨框里的焦点、键盘与 Escape 照各自原来的。墨框没有焦点环，墨就是边。墨正在写时，按一个键或按一下，墨立刻写完：墨从不让人等。
- **字是页面的字**：墨从不碰字。墨的画布只在动的时候存在；静止时边是一条沿同样线条的淡的填充轮廓。深底上带着形的纸气。
- **减弱动效**：不写，直接在、直接走。

## 3. 两种墨，一只手

| 常量 | 数 | 守住什么 | 出处 |
| --- | --- | --- | --- |
| `BUBBLE_STRENGTH` 浓 | 墨框自己的线；干后的边 46% | 一两行字的墨框 | `spirit/note-ink.ts` |
| `BUBBLE_STRENGTH` 淡 | 同一条边，用细一号的线（`FINE` × `PRESS.thread`）、约一半的墨写；干后的边 26% | 一大块内容外面没有一圈重墨，还读得出是它的 | `spirit/note-ink.ts` |
| 深底的边 | 按浅底的感知对比加墨（APCA，对纸）：浓 70%、淡 46% | 深底上同样的墨读起来淡一半，两种主题读起来一样重 | `spirit/ink-bubble.css` |
| 深底的纸 | 高一档的底 `--omne-surface-field`；浅底上照旧 | 深底吃掉影子，纸和边一起把它托起来，不加一圈细线 | `spirit/ink-bubble.css` |
| 边的时长 | 第一笔 520 ms，第二笔在 340 ms 时接上、写 440 ms：约 0.8 s 合上 | 写出来看得见，又不让人等 | `spirit/body.ts` `WRITE`（`noteFirst` 一组） |

纸、圆角、影子、从圆里展开、时长，两种墨都一样。

## 4. 告知笺

告知笺是形在家旁用浓墨框写的一句话。它什么时候写、写哪一条、点了去哪、怎样收起，归产品正文与 `apps/desktop/SPEC.md`。看起来与动起来的规则：

- 浓墨，在形的右边，宽度不越出侧栏。
- 最多三行；第四行能写完全文时写第四行。写满时下沿不压住导航的第一行（[不要这样做](dont.md)第 1 条）。
- 收起时字先走，墨沿来路卷回口里。不先换成更宽的版式重排，不解开截断，不留一个空框（第 6 条）。
- 点它去别的页时，形要换座位就照常走一程，不在新座位直接写一个圆（第 7 条）。
- 告知笺不进待答数，口外的数字只写待答数。

## 5. 对话页的侧边内容（窄窗口）

- 淡墨，从对话头的座位朝下展开，在头部细线下面一小步，在头部的宽度里。上边不压在应用的线上，引线越过那条线到口里。
- 盖在页面上，不推消息与输入框。点外面收起。
- Escape 收起，焦点回到对话头那个展开控件（K7）。
- 对话区不小于 1160px 时，侧边内容停靠在旁边，是版面的一部分，用平样式，不是墨框。
