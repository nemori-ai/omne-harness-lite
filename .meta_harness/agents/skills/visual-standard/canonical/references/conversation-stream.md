# 对话流：放什么，长什么样

> 什么时候读：要改对话流里的任何东西之前：气泡、过程行、回执、决策卡片、流末尾在回复时的样子。
> 每一种条目在这个产品里做成什么样（你的话、agent 的话、推理、工具调用、标记……），归会话的包组 `SPEC.md` 的界面一节；这里写所有条目共用的原则与视觉标准。

对话流是人每天读的地方，流里的每样东西每次都要被扫一遍，所以标准比别的页面严：每样东西都要说得出它解决什么问题，说不出就不放。设计时问的是「人此刻要不要知道它」，不是「这个信息放在哪」。

## 八条原则

编号不变，代码与规格可以按编号引用（「原则 3」）。

1. **流里只有人与 agent 说的话、互相发的东西，以及 agent 此刻要人做的决定。** 系统给自己的动作贴标签会打断阅读，还让人分不清谁在说话。系统不在流里说话：没有标签和标题，不复述人刚做的事（「已附加」「已停止」「已收到你的回答」）。
2. **一份记录，两种读法。** agent 要精确的元数据，人要一句自然的话。存的形式对机器保持精确，界面把它折成人读的样子，记录不为界面让步。
3. **每样东西只出现一次，用它最自然的形式。** agent 那句话里说过的事，卡片上不再写。
4. **表面只放每次都要看的，其余放进展开。** 版本、大小、类型、技术详情，都在点开的详情里或 `⋯` 里。例外是会改变人判断的状态：它留在表面。
5. **分量跟着重要性走。** 最重的是要人做的决定：决策卡片取决定宽度、浮层底、细线抬起，带按钮，不用阴影，也不用强调色的竖条。正常的是两边说的话与发来的东西。过程行是一行：图标、名字、状态词，原地展开。最轻的是回执与状态：说明字号，弱墨，不加边框，至多一个对勾。「没有发出」也是说明字号、不加边框，但词用失败的颜色并带「重试」，因为它要人动手。
6. **一个说话人，一种声音。** agent 说的每句话，包括工作的结果、没接的原因，都在它这一侧的气泡里，同样的字体和字号。气泡外面没有第二种形式。
7. **一个面只滚一次。** 嵌套的滚动条抢滚轮；把关闭、保存放进滚动的内容里，读到一半就找不到。只有转写滚动，流里的东西都不自己滚：预览有高度上限，到上限淡出，点开看全文。打开的面板分头和正文，头固定，只有正文滚，正文滚到头底下时头下面才出现一条细线。两个例外：人打字的输入框长到上限后自己滚；宽表格可以横向滚，竖向不滚。
8. **内容按它该被读的样子呈现。** agent 写的字总是按 Markdown 渲染，流式输出时与落定后一样。人自己的话逐字显示。系统起的名字（`image.png`、粘贴时生成的名字）不显示，读屏也不念。流里没有一级标题，预览的标题与正文同字号，只加粗。

## 正在做、做完、出错

- **正在做，流里不说。** 回复进行中，流的末尾没有「正在思考」那一行，没有微光、点或转圈，agent 的名字下面没有字，消息列表里没有占位的气泡。形把它写出来（[状态](states.md)）。
- **回答边到边显示。** 流里到的字就站在那里；落定后的那份出来时在同一条消息上接替它，同一句话不出现两遍。
- **人发的一句话，任何时刻都是一个气泡。** 人的气泡出现、输入框清空，就是「发出了」。之后几份记录先后赶上来，画的始终是同一个气泡。
- **正常结束而没有话，什么都不说。** 没报错就静默；流里不写「没有收到回复」。
- **出错和没反应才说。** 运行失败或一直没有消息时，在流的末尾、它说的那一轮下面留一句话和能做的那个动作（重试、停止），句子前面不重复状态词。只说最近一轮，下一轮开始就撤掉。
- **人按了停止，回复就停在那里**，不写「已停止」。
- **等人决定时不另写一行。** 决策卡片在屏幕上，就不再写「正在等待」；任何时候都不显示内部的类型名。
- **到达和历史分开。** 人看着它来的东西淡入一次；翻到的历史不动。

## 视觉标准

流里所有东西共用的尺寸和形式。新加的东西从这里选，不另起一套。数以 token 为准。

- **泳道。** 人在右，`--omne-bubble-user` 的底；agent 在左，`--omne-bubble-assistant` 的底。宽度随内容：人的气泡至多列宽的 88%，agent 的气泡至多 `--omne-measure-reading`。两边同一个内边距 `--omne-bubble-padding`，同一个卡片圆角。
- **字。** 三档。气泡里的话用阅读字体、`--omne-text-body`。卡片与面板里的界面文字（名字、按钮）用界面字体、`--omne-text-ui`。回执、时间与状态用 `--omne-text-caption`，颜色 `--omne-ink-muted`。说话人的名字不画，留给读屏。
- **气泡里的东西。** 代码块、表格、图都在气泡里面，排在那句话下面：一条细线 `--omne-line-subtle`、控件圆角，不另加底色，所以一个气泡里只有一种边框。不再套卡片（C9）。
- **决策卡片。** 流里最重的东西。同一件事只说一次。回答框随内容长高。回答之后落成一行回执，强调全部去掉，留在转写里（N4）。
- **回执。** 气泡下面一行，说明字号和弱墨，不加边框和图标，至多一个对勾。回执只出现一次。
- **结构化数据。** 不加「结构化数据」的说明；嵌套的值写成一行摘要；空对象不显示。
- **时间。** 跨天一行日期，不写钟点；隔得久才有时间。指针停在消息上：准确时间。
- **间距。** 同一个说话人连续的块之间 `--omne-space-block`；换人、换天或隔了一段时间 `--omne-space-section`。
- **对齐。** 转写里每一行与输入框同一个左起点、同一条右边（S7、S8）。
