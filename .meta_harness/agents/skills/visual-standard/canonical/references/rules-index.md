# 规则与 token 的索引

> 什么时候读：要查一条规则的全文、它的编号、它读哪个 token、由哪道门守；要知道一件事该用哪个件。
> 道理在[设计语言](design-language.md)。数在 `packages/frontend/ui-kit/src/styles/tokens.css`，这里只写 token 的名字。

编号与设计包、各张卡引用的编号相同，所以有的编号不连续。「门」一栏写守这条规则的自动检查，名字取自[观感验收的方法](visual-acceptance.md)的第一层。一道门还没写成时，这条规则由人看。写「人看」的规则没有门。

| S2 | 圆角只有四种：芯片、控件、卡片、窗口；状态胶囊是两头圆的胶囊 | `--omne-radius-chip`、`-control`、`-card`、`-window`、`-pill` | 刻度 |

| S8 | 装着居中列的滚动容器两边都留滚动条的位置，所以列始终居中，每一行（含输入框）结束在同一条右边上 | — | 人看 |
| S9 | 时间缺省是相对的（「3 分钟前」「昨天 14:20」），精确值在提示或详情里。一处只用一种钟点格式，跟系统的 12/24 小时。超过 30 天的日期按本地写法，不写原始的 UTC | `Ago` | 时间 |

## A 动作

| 编号 | 规则 | token 或件 | 门 |

| A1 | 常用的工具动作是一个图标钮：`IconButton`，面是图标集里笔写的字形，名字在提示与可访问名称里，面上不写字。指针悬停与键盘聚焦都显出提示。刷新与重试、收起与展开、复制、关闭、编辑、新建、筛选、返回、更多、撤销、停止、发送都是这一类 | `IconButton`；图标集 | 字钮 |

| A3 | 字只留给三种钮：表单与对话框里落定的那一个（保存、登录、提交、设置、确认）；对话里要人选的选项（卡上的「不回答这一题」）；这一页唯一的主动作，带图标（「新建会话」）。另有两种控件的字就是东西本身，不是动作的说明：对象的名字作它自己的入口（列表行的标题、「后台有 n 项在跑」）；显示当前值的选择（下拉的触发、分段的项） | `Button` | 字钮 |

## 一件事一个件

一件事一个件。一页要做下表里的一件事，就用那个件。表里没有的事，先在这张表里加一行，再做。新的件放进 `packages/frontend/ui-kit/`，不在成员里私造。

| 事 | 件 | 不用于 |
| --- | --- | --- |
| 按钮、输入、多行输入、选择、开关、单选、复选、分段 | 共用件的基础控件 | 每处调用改样式；要不同就加一个变体 |
| 只有图标的动作 | `IconButton`（标签与提示必填） | 意思要用字说的动作 |
| 阅读面的偶尔动作 | 一个 `⋯` 后面的 `RecordMenu` | 一两个常用动作；一排图标按钮 |
| 图标集有的意思 | 共用件的图标 | 图标库的图标或手画的 SVG |
| 错误、提醒、能恢复的问题 | `InlineNotice`（恢复用 `onRetry`） | 成功的消息；属于某个东西的状态 |
| 空的列表或页 | `EmptyState` | 筛选字段里的无匹配 |
| 加载 | `LoadingState`、`LoadingIndicator` | 转圈；别处的骨架编排 |
| 状态词 | `StateWord`（词来自状态词表） | 句子；自造的徽标 |
| 回答过的请求变成了什么 | `ReceiptPill` | 还在等的决定 |
| 一轮的过程行 | `TraceRow` 一族 | 日常的文案 |
| 列表行的悬停与选中 | `GlideMenu` | 列表以外的行 |
| 从几项里选一项作答，整行是目标 | `ChoiceList`、`ChoiceRow` | 几个互斥的设置值（分段控件或下拉） |
| 流内内容的展开与收起 | `Disclosure`，或 `DisclosureTrigger` 加 `DisclosureContent` | 浮层；裸的 `aria-expanded` 按钮 |
| 「已保存」一类的回执 | `SaveReceipt` | 自己就是回执的控件（N1） |
| 只读的事实 | `FactList`、`FactRow` | 能改的字段 |
| 机器的文字（代码、原始报错、路径） | `CodeSurface` | 散文 |
| 有后果的确认 | `InlineConfirm`（带 `tone`）或 `ImpactPanel` | `window.confirm`、抽屉 |
| 相对时间 | `Ago` | 手写的日期 |
| 单列页 | `PageColumn` 加 `PageHeader` | 列表加阅读 |
| 列表加阅读、栏加窗格、设置行、对话的气泡与输入框、决定的面 | 共用件 `src/patterns/` 里对应的件 | 成员自己的版式 |
| 导航与列表里的计数 | 共用件的计数胶囊 | 成员自己的胶囊与徽标 |
| 到达、落定、页面的到达 | `useArrival`、`Arrive`、`useSettleCue`、`useMotionCue` | 新的关键帧或时长 |
| 形、形座位、一程、墨框、告知笺 | 共用件的墨迹块 | 成员自己画的形、边框或气泡 |
