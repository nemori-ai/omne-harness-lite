# 形的前提与十条

> 什么时候读：要给 Agent 形做任何新东西或改它之前；有人质疑一条形的规则、想破例，或要知道它从哪来、怎么查它守住了没有。
> 形在产品里是什么、坐在哪、说哪些事实，归产品正文的「Agent 在屏幕上的形」；共用件怎样承载它，归 `packages/frontend/SPEC.md#墨迹`。这里写它怎样看起来、怎样动，以及为什么。

## 1. 前提：它是什么，不是什么

- 形是 agent 在这个窗口里的样子：一支毛笔一笔写出的墨圆（圆相），留一个口，没有五官。它是 agent 本身，不是它的图片：它从来不是图标、头像或产品标志。
- 它画在页面最上面的一层，像人一样俯看界面。界面里只有空的形座位，它飞过去坐。
- 会话有很多个，形只有一个：人看着某个会话时，它代表那个会话的 agent；人没在看会话时，它在家，替这个租户的全部会话记着待答数。

下面所有规则都从「它是被写出来的墨」推出来：

- 它只会写和干。图能做的事（缩放、旋转、拉伸、滑动、淡入一个画好的形）它都不做。
- 它是一个，不是一份素材：任何时刻屏幕上只有一个它。
- 它是身体，不是控件：它的状态是它自己做出来的样子，不是旁边的一行字、一个点、一个转圈。
- 它是活的，不是装饰：没事时静着；它动，是要人看什么。
- 墨有物性：笔毛、浓淡、干湿、纸纹、每一笔都不一样。这些不是特效，是它之所以是墨。

三层分开：**笔墨**是物理（笔毛怎样着纸、墨怎样干），不知道写的是什么；**笔法**是语言（一个状态写哪一笔、什么节奏）；**审美**是法度，能量化的由检查守，量化不了的写在本技能里。新工作几乎总在后两层：写笔画、定节奏，不改笔。

## 2. 四种动，加一程

- **写**：沿中线一点点写出；写出的部分就是最终的粗细，动的那一端就是笔尖。
- **点**：按下去再带出去。
- **干**：墨原地淡去，不动。
- **重写**：旧的淡成一道痕，新的在痕上写。
- **一程**：自己去别的座位时，从圆的口一笔写到新座位，落下处写出新圆，旧圆原地干去（[移动与座位](seats-and-journeys.md)）。

## 3. 十条

每条写规则、为什么、怎么查。

### 3.1 一个身体

- **规则。** 同一时刻屏幕上只有一个形。它离开的地方什么都不留，不留印子也不留虚影。
- **为什么。** 来源的负责人看到左上角留着一个淡淡的虚影，说「感觉怪怪的」：两个圆，人就会问哪个是它。
- **怎么查。** 任何一帧里数它。一程出发时留下的圆只是在原处干去的墨，不接指针，不说话。共用件的用例守「一个页面里至多一个形」（FE-I18，`ui-kit/tests/ink.spec.tsx`）。

### 3.2 一个大小

- **规则。** 一档字号下它只有一个大小：56px 乘字号档的系数，四档是 42、56、70、84px；中楷下墨的外框约 42px。每个座位、路上都一样。座位只说中心在哪，座位的框比它小也不缩它。没有座位倍数这件事。
- **为什么。** 要它显眼，靠行为，不靠大小：大小一变，它就不像同一个身体。
- **怎么查。** 量它的盒子：56px 乘字号档。量墨的外框：小楷约 31px、中楷约 42.5px、大楷约 51.5px、老花约 63.5px。FE-I18 的用例守大小。

### 3.3 一支笔

- **规则。** 它写的每一笔都是一支笔按轻按重：主笔 `BRUSH` 与细笔 `FINE`，按的份额在 `PRESS`（[笔法](brushwork.md)的表）。圆、点、合口、数字、竖笔、路上那一笔、墨框的边，全从这两样来。字号档乘这支笔。
- **为什么。** 粗细一乱，它就不像一个身体，像几张图拼的。
- **怎么查。** 新代码里不出现自己的笔重，只出现 `BRUSH` 或 `FINE` 乘 `PRESS`。

### 3.4 只以笔法动

- **规则。** 形的每一次变化只有四种动加一程（第 2 节）。它绝不旋转、拉伸、挤压、缩放、滑动。
- **为什么。** 来源的第一版里口沿圆转、落下一圈涟漪，都是几何变形，全部取消了。变形读起来是一张图在动，写和干读起来是一只手在写。
- **怎么查。** 它的元素上只有表示位置的平移；没有 `scale`、`rotate`、`skew`，没有 CSS 动画或过渡，没有在两条线之间插值。

### 3.5 每一动都让人看见什么

- **规则。** 它去哪儿，人现在就该看哪儿；它在那儿留下的一笔说看什么。没什么可给人看的时候它不动。
- **为什么。** 它的每一个动作都是反馈：动的理由是让人更快更准地拿到信息。
- **怎么查。** 每一个动作写出两句：「人这时该看哪里」「看什么」。写不出来就删掉这个动作。

### 3.6 连续

- **规则。** 它从不跳、不切、不瞬移。任何一次移动都可以中途打断，从笔现在所在的地方接着走，没写完的那段从尾巴往笔尖干去。只有减弱动效时直接出现在终点。
- **为什么。** 来源有一版让它从一边飞出、再从另一边回来，读起来是另一个圆。改成一路一支笔以后才「非常优雅」。
- **怎么查。** 逐帧看，每一帧里都有它的墨：在写的圆，或路上那一小段活的笔。

### 3.7 状态由形自己说

- **规则。** 它在收、在想、在用工具、在写出、在等人，都是它的笔写出来或干掉（[状态](states.md)），不是旁边的一行字、几个点、一个转圈或徽标。待答数是唯一写在它身上的「字」，用它自己的笔写在口外，琥珀色。
- **为什么。** 来源的负责人要「把状态全部用主形象表达出来」：名字下面不要「思考中」、点或别的加载样子。只有一个点不好懂，所以等人回答写数字。
- **怎么查。** 它的座位旁边没有加载指示、状态词、点或徽标。对话头下面与转写末尾没有字。

### 3.8 留白：没事就静着

- **规则。** 什么都没发生时，它是一笔静止的圆，帧循环停着。唯一会重复的是「在做事」的重写，绑在真实的工作上。
- **为什么。** 会呼吸、会摇的头像已经退役。水墨以留白为常态。
- **怎么查。** 静置一分钟，它的画布不重画，性能面板里没有它的帧。

### 3.9 随性

- **规则。** 它做的每件事都有一点不一样。笔：每写一笔都从新的种子抽这一次的差别，写好就不再变。行为：一程的弯和时长、落下写圆的时长、做事时两圈之间的停，都从一个来源在设计值附近抽，范围由调用处的具名常量说。永远不松的是承诺：终点一点不差，时长守住自己的上下限，不盖住人在读的东西。减弱动效下一律是设计值。
- **为什么。** 毛笔写不出一模一样的两笔；行为都带一点随机，动作才显得随意自由。
- **怎么查。** 行为的随机只从一个随性的来源取，测试能换成种子；笔的纹理只从这一笔的种子取。范围见[时长](timing.md)第 4 节。

### 3.10 从不让人等

- **规则。** 它的表演从不挡人的手。人按下或来了真事，画出去的墨在 `--omne-motion-feedback` 里干掉，圆回到原样。墨框正在写时，一个键或一下按就让它写完。
- **为什么。** 动作立刻发生，动效解释结果。被打断时，它要优雅地回到之前的状态。
- **怎么查。** 在它写到一半时按下：墨按反馈的速度干掉，圆原样回来。

## 4. 不要 → 改成

| 不要 | 改成 | 为什么 |
| --- | --- | --- |
| 用墨画一个匀速转的弧（转圈） | 圆一遍遍重写，每遍不同，中间停 | 墨圈本来就容易读成加载圈；让它匀速转，就真成了加载圈 |
| 三个点、打字点 | 形上的一笔 | 已退役；而且是旁边的东西 |
| 进度条、百分比 | 真的步骤用真的笔；不知道多久，就重写 | 造出来的进度 |
| 眨、闪、呼吸、脉冲、光晕、霓虹 | 写一笔，或干一笔 | 亮度和几何的变化，不是笔；纸气是纸色，不是光 |
| 缩放、旋转、拉伸、挤压、滑动整个形；扩散的涟漪圈；两条线之间插值变形 | 旧的干去、新的写上；去别处走一程 | 变形读起来是一张图 |
| 切、瞬移、飞出屏幕再回来 | 一笔接着走；打断时从笔尖接着 | 跳过去的圆读起来是另一个 |
| 数得出的循环（固定节拍、固定顺序） | 从范围里抽；只在真事上重复 | 读成机器 |
| 变大来强调；座位倍数 | 用行为：去那里、写一笔 | 一个大小 |
| 不说明任何事的动、为动而动 | 没什么可看就不动 | 每一动都让人看见什么 |
| 第二个它：家里的虚影、对话头的静态头像 | 座位空着，它飞过去 | 只有一个 |
| 字、签、徽标代替它（「思考中」、状态词、加载点、旁边的计数徽标） | 形上的笔；数字用它的笔写在口外 | 状态由形自己说 |
| 钢笔的匀线、油漆的平涂、用遮罩揭开一个画好的形 | 一根根笔毛写（[笔法](brushwork.md)） | 不是毛笔 |
| 另一种颜色 | 墨一种；琥珀只写待答数 | 颜色说事实 |
| 让人等它演完 | 按反馈的速度干掉；焦点先给人 | 动作立刻发生 |
