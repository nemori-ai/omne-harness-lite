# 拿起、桌面与看窗口

> 什么时候读：要动形被人拿起、跟手、放下的样子；要动形在桌面上的样子、回去的那一笔、说话笺、观测框或签；要验「越过窗口的边不换东西」之前。
> 人能对形做什么、松在哪去哪，归产品正文的「把形拿出窗口」；共用件给哪些件，归 `packages/frontend/SPEC.md#墨迹`；形出了页面画在哪、两块画面怎样交接，归 `apps/desktop/SPEC.md#桌面层`。这里写它看起来、动起来是什么样，以及为什么。

来历：规则取自 super-assistant `40cf2f11` 的 spirit。没有搬的：通话里看着一个窗口、在应用里按 ⌘ 读应用自己的东西、把东西拖给它、住进侧栏、悬停的小品与闲时的画、快捷操作。

## 1. 拿起与跟手

- 按下就起晕；移动过 4px 才算拿起。没过 4px 松手是一下按，墨按反馈的速度干掉。
- 拿起的那一刻，它在写的东西（一程、墨框、告知笺）立刻干掉，座位上什么都不留。
- 在手里它紧跟着手：没有滞后，也不回弹。它不因为被拿着而变大、倾斜或拖出一道尾巴；状态的笔画照常写，拿起不打断它。
- **人拿着它走，不是它自己在动。**「只以笔法动」（[形的前提与十条](figure.md) 3.4）管的是它自己的动；被拿着时它的元素上仍然只有表示位置的平移。
- 越过窗口的边时它没有任何变化。任何一帧里数它，都是一个。

| 常量 | 数 | 守住什么 |
| --- | --- | --- |
| `LIFT_DISTANCE` | 4px | 一下点不被当成拖 |
| `FEELS.follow` | 临界阻尼的弹簧，刚度 1100 | 跟手，不滞后、不回弹 |
| `PRESSED` | 晕 0.4 | 按下有回应 |

## 2. 放下

- 松在窗口里：从手下一笔写回座位，就是[移动与座位](seats-and-journeys.md)的一程，起点是手下那一点。
- 松在窗口外：它落定在松手点，用慢一档的弹簧，不回弹，不贴边。整个形要在那块屏里，圆离屏边至少 8px。
- 从窗口里拿起、还拿着时按 Esc：和松在窗口里一样，一笔回座位。从桌面上拿起时 Esc 到不了它。
- 半路被再拿起：圆立刻写在手下。

| 常量 | 数 | 守住什么 |
| --- | --- | --- |
| `FEELS.travel` | 弹簧刚度 210，不回弹 | 落定是放下，不是弹一下 |
| `EDGE_KEEP` | 8px | 放下之后还找得到它 |

## 3. 在桌面上

- 它和在窗口里是同一个：同一个大小（56px 乘字号档）、同一支笔、同样的状态笔画与口外的待答数。明暗跟着应用的主题，不跟着它下面是什么。
- 没事时它静着，帧循环停着。它不逛、不眨、不做小动作。
- 它不带底、不带阴影、不带光晕。它下面是别人的窗口，墨就是墨。
- 单击要等 320ms，确认不是双击，才开或收说话笺。右键什么都不做。
- 它身边 34px 之内接指针，之外一律穿过去。

| 常量 | 数 | 守住什么 |
| --- | --- | --- |
| `DOUBLE_WAIT` | 320ms | 双击不先开一次笺 |
| `REACH` | 34px | 它不挡人点下面的东西 |

## 4. 回去

- 回去是一程：一笔从它所在的地方写到座位在屏上的位置，尾巴边走边干，落下处写出新圆，起点的圆原地干去。弯向它所在那块屏的中间，不弯出屏。时长照一程的 `flightTime`。
- 主窗口被别的窗口盖着、藏着或最小化时，那一笔照样写到座位所在的地方，然后它不在桌面上了。
- 减弱动效时直接出现在座位上。

## 5. 说话笺

- 说话笺是一个淡墨的墨框（[墨框与告知笺](ink-bubble.md)）：边从圆的口写出，边合上之后内容才出现；收起时内容先走，墨沿来路卷回口里。它从不让人等：一出来字段就有焦点，按一个键或按一下，墨立刻写完。
- 宽 360px，高随内容。先试它身边的四个位置，第一个是右下：横离它 22px，竖离它 11px；都放不下时挑出屏最少的那个，推回屏里。打开时挑一次位置，之后内容变长不换地方。
- 从上到下：图的缩略条（每张可以去掉）；「说给谁」；字段，直接写在纸上，没有边框；结局或说明的一行。末行是去对话页的图标钮、「收起」与「发送」。
- 「说给谁」是应用的平样式下拉，不是墨框。
- 结局的话：受理了写「已发送」并出现去对话页的图标钮；确定没发出用失败语气写「没有发出去：」加原因，字留着；不知道用中性的语气写「不知道有没有发出去，到对话页看一下」。读不到可以说给谁时写「现在读不到可以说给谁」。没有读屏幕的许可时写「需要在系统设置里允许 omne 录制屏幕，才能看这个窗口」，旁边一个钮「打开系统设置」。发不了图时写「现在发不了图」。
- 笺里没有字也没有图时，人点别处，笺收起；有时留着。读窗口出了别的错时写「没能看这个窗口：」加原因。

| 常量 | 数 | 守住什么 |
| --- | --- | --- |
| `NOTE_WIDTH` | 360px | 一句话写得下，又不盖住人在看的窗口 |
| `NOTE_GAP` | 横 22px、竖 11px | 笺从口里出来，不压着圆 |

## 6. 观测框与签

- 观测框是一笔带口的墨，沿窗口的边走，圆角 10px，口朝着形。它是形的笔，用细笔 `FINE`。
- 被别的窗口挡住的那几段不画，框外沿被挡到的那一段也不画：人看到的框只在露出来的边上。
- 换一个窗口时，旧框原地干去，新框写出来，不滑动、不变形。
- 按住 ⇧ 时写一笔把口合上：合上的框说「松手就发」。
- 写框的时长是 260 + 0.11 × 周长（px）毫秒，限 520 到 1200，±10%；写完湿墨在 700ms 里落到 0.86 的浓度；干去 600ms。
- 签只画在桌面上的形身边，是两三行小字，不带底：第一行是名字，后面是松手会怎样。提示色只用在「松手直接发送」那一行。
- 签的话：框着一个窗口时第一行「应用名 · 窗口标题」（没有标题或标题等于应用名时只写应用名），第二行「松手放进说话笺 · 加按 ⇧ 直接发送」；按着 ⇧ 时第二行「松手直接发送」。按着 ⌘ 而手下没有别的应用的窗口：「这里没有可看的窗口」「松手就停在这里」。每次打开应用后第一次把形拿出窗口，不按 ⌘ 时：手回到窗口里「应用里」「松手回去」；在窗口外「应用外面」「松手就停在这里，双击回到应用」「按住 ⌘ 让它看一个窗口」。最后一行只在这台机器能看窗口时写。

| 常量 | 数 | 守住什么 |
| --- | --- | --- |
| `FRAME.write` | 260 + 0.11 × 周长，限 520–1200ms，±10% | 大窗口不拖沓，小窗口不一闪而过 |
| `FRAME.settle` | 700ms 落到 0.86 | 写完的框退到背景里，不抢窗口的内容 |
| `FRAME.dry` | 600ms | 旧框走得比新框快 |
| `FRAME.corner` | 10px | 沿 macOS 窗口的圆角走 |

## 7. 交给它的图

- 松手处的那一笔圈是形自己的圆：同一支笔、同一个口，画在图上松手的那一点。
- 近看是以那一点为中心、边长 480 个屏幕点的方块，出了窗口的部分裁掉，不补白。
- 图里没有形，也没有观测框与签。
- ⌘⇧ 直接发并受理了，圆先在自己的痕上重写一遍表示收下（`WRITE.rewrite`，520ms），接着写回去的那一笔。没受理时它留在原处。

## 8. 不要 → 改成

| 不要 | 改成 | 为什么 |
| --- | --- | --- |
| 越过窗口的边时换一个东西、淡出淡入、缩一下 | 同一个圆一直在手下 | 换了东西，人就觉得它不是同一个 |
| 家里留一个虚影表示「它出去了」 | 座位空着 | 只有一个 |
| 桌面上的它带底板、阴影或描边好让它看得清 | 墨的浓淡自己站得住 | 它是墨，不是一个悬浮按钮 |
| 桌面上的它闲着时自己动 | 静着 | 留白 |
| 不按 ⌘ 就框住手下的窗口 | 只有按着 ⌘ 才有框 | 拖一下不该像在读别人的东西 |
| 框滑到下一个窗口、框跟着缩放 | 旧的干去，新的写出 | 只以笔法动 |
| 用系统的选区蓝或一个实线矩形当观测框 | 一笔带口的墨 | 它是形在看，不是系统在选 |
| 把应用的窗口拉到前面来回答一次单击 | 笺写在它身边，前面的应用不变 | 人在别处做事 |

## 9. 验收问题

1. 在座位上按下不动再松手，和以前一样吗？
2. 拿起、越过窗口的边、放下，逐帧数它，每一帧都是一个吗？有没有一帧它不在手下？
3. 放在一个浅色窗口和一个深色窗口上，它都读得出吗？
4. 它在桌面上静置一分钟，画布重画过吗？
5. 单击它时前面的应用变了吗？双击时先开过一次笺吗？
6. 回去的那一笔是写过去的，还是滑过去的？尾巴在干吗？
7. 两个窗口互相压着时，框画到挡着它的那个窗口上了吗？
8. 发出去的图里有它自己吗？
9. 减弱动效下，放下、回去、写框各是不是一次到位？
