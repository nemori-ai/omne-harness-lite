# 做法与验收

> 什么时候读：动手做形或墨框上的一个新东西（一个状态笔、一个行为、一个从形展开的东西）时：找参照、写、看、比，文件放哪，哪些检查守着；交之前过验收问题。
> 前提与十条在[形的前提与十条](figure.md)。

## 1. 做法

1. **从它给人看什么开始。** 先写出两句：人这时该看哪里，看什么。写不出来，就停在这里。
2. **找最近的那一件已接受的作品，从它的数起步**（第 2 节）。新行为先用已有的笔法拼（写、点、干、重写、一程、座位），不加新的动法。
3. **写。** 按手写的顺序写中线，弯处每 4–8 格一个点。先定墨（浓淡、干湿），再定提按，再定节奏。行为的数放进一个具名常量，随性的范围也放进一个具名常量；两者的出处与守住什么写进本技能对应的表（[笔法](brushwork.md)、[时长](timing.md)、[状态](states.md)、[移动与座位](seats-and-journeys.md)、[墨框与告知笺](ink-bubble.md)）。
4. **看。**
   - 在真实大小上看，不在放大的图上：中楷 56px 的画布，再看小楷（42px）与老花（84px）。
   - 浅色、深色两种主题，再放到深色底上看纸气。
   - 慢放四倍看笔，再按真速看三遍以上，每遍都该不一样。
   - 打断它：墨框写到一半按一个键或按一下，一程走到半路换去处，看笔从它所在的地方接着走、不让人等。再开减弱动效看一遍。
5. **和已接受的并排比。** 把新的和最近的那一件放在一起看（同一张纸上先后播，或各截一组帧排成联系表），比笔数、最粗和最细、墨的范围、节奏与留白。差得多的地方要说得出为什么。**判断**（来源没有写成规则）：这是做法，不是已有的工具。
6. **验收。** 过第 4 节的问题，跑守着的检查（第 3 节）。

## 2. 已接受的作品

本产品带的形与墨框，参照来源里这几件。来源的路径相对 super-assistant `83c1616f` 的 `desktop/src/renderer/src/`，只读，用来对照笔与节奏。

| 作品 | 来源里在哪 | 学什么 |
| --- | --- | --- |
| 圆相 | `spirit/ink.ts` `DEFAULT_HAND`、`circleStroke` | 一笔、留口、每次不同而还是那个圆 |
| 眼点、合口、待答数的数字 | `spirit/ink.ts` `eyeStroke`、`closingStroke`、`numeralStrokes` | 状态就是一笔；数字用同一支笔、自由很小 |
| 在做事的重写、在查的眼点、在写的竖排 | `spirit/doing.ts` 的 `DoingPolicy` 与它调的 `perform` | 只有真事重复；停不成拍子；竖是笔画不是字形 |
| 一程 | `spirit/travel.ts` `wayStroke`、`Journeys` | 一程是一笔：提按、飞白、尾巴在干、从笔尖接着 |
| 墨框 | `spirit/ink-bubble.tsx`、`spirit/note-bubble.tsx`、`spirit/note-ink.ts` | 笔从圆的口接着出来写成框；墨从不碰字；从不让人等；浓淡两种墨一只手 |
| 活动标记 | `components/loading-ink.ts` | 同一支笔写的三滴墨；不是圆，不是转圈 |

## 3. 文件放哪，谁守着

| 什么 | 放哪 |
| --- | --- |
| 形的身体、状态笔与它们的时长 | `packages/frontend/ui-kit/src/ink/` 的具名常量与代码 |
| 形座位、一程 | 同上 |
| 墨框、告知笺的画法 | 同上 |
| 每个常量的出处与守住什么 | 本技能对应的表 |
| 形该说哪些事实、外壳怎样合并报告 | 产品正文与 `packages/frontend/SPEC.md#形口` |

- 界面的设计门守的是整个界面的设计语言：CSS 里的时长与曲线只能是动效 token、颜色 token、对比度、刻度、可点的东西有反馈、焦点环、图标。它们不看形的墨：笔的时长在具名常量里，不在 CSS 里。
- 守形的是共用件的用例：一个页面里至多一个形、形的大小（FE-I18，`ui-kit/tests/ink.spec.tsx`）；墨框的边按框生成、引线从口出来绕过圆、两种墨一只手（观感验收的「墨框」门）。
- 没有门的：好不好看、读不读得出、像不像一只手。这些只能人看（第 1 节的第 4、5 步）。

## 4. 验收问题

### 4.1 形的验收问题

每一条答是或否；有一条是「否」就不交。

1. 说得出这一动让人看哪里、看什么？
2. 屏幕上始终只有一个形？
3. 它的大小一直没变？
4. 每一笔都是 `BRUSH` 或 `FINE` 按轻按重，没有自己的笔重？
5. 只有写、点、干、重写和一程？它身上没有缩放、旋转、拉伸、滑动、插值、CSS 动画？
6. 每一帧它都在，没有跳和切？打断时从笔尖接着走？
7. 状态是形自己说的，旁边没有字、点、转圈？
8. 没事时它静着、帧循环停着？会重复的只有真事？
9. 每次都不一样（种子、随性），而终点、时长上下限一点不差？
10. 小楷的真实大小上、浅深两种底上读得出？
11. 笔少、墨有浓淡干湿、留白多、没有细线？圆是主角？
12. 人按下、来了真事时，它 120 ms 让开？减弱动效下仍然对？
13. 数都在 `packages/frontend/ui-kit/src/ink/` 的具名常量里，出处与守住什么写在本技能的表里？

### 4.2 本产品的四问

1. 状态表里的每个事实，形上都有标记，名字下面与转写末尾都没有字？
2. 会话换了，形代表的也换了，中间没有出现过两个形或一个空窗？
3. 小楷的真实大小上、浅深两种底上，琥珀的数字读得出？
4. 墨框与应用自己的菜单摆在一起时，一眼分得出哪个是它在给我看？
