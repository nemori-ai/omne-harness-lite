# 纸、页、一叠

> 什么时候读：要把东西摆到纸上，改纸面、页、一叠或纸上一点的样子，评审纸上一样东西的状态，或要知道纸上的长度怎样随字号档与远近变之前。
> 这几件给什么、守什么不变式，归 `packages/frontend/SPEC.md#纸的面`；纸上摆着什么、谁摆的、锁没锁，归 `packages/canvas/SPEC.md`。翻面的钟在[时长](timing.md)第 6 节，形在翻面时走的一程在[移动与座位](seats-and-journeys.md)第 5 节。这里写纸上的东西怎样画、怎样动，以及为什么。

## 1. 它们是什么

| 件 | 是什么 | 材料 |
| --- | --- | --- |
| 纸面 `PaperSurface` | 一张有边的纸，铺在视口里，可以平移与缩放 | 纸是 `surface-page`，四边一圈 `elevation-hairline`；视口里纸没铺到的地方是 `surface-panel-soft` |
| 页 `PaperPage` | 纸上一样东西的外框：上面是内容（叶），下面是名字一行 | 叶是 `surface-panel`，圆角 `radius-mark`，一圈 `elevation-hairline` |
| 一叠 `PaperPile` | 几页叠在一起，整个拖动，能展开与收起 | 每一页是同一种叶；展开后排在一张浮起的面上 |
| 纸上的一点 `PaperSpot` | 把一样东西的中心摆在纸上一点，例如形座位 | 自己不画任何东西 |
| 状态栏 `PaperStatus` | 纸面下沿的一条窄栏：左边是纸自己的控件，右边是此刻看着的那一样的信息（第 4 节） | 底是 `surface-page`，上沿一条 1px 的 `line-subtle`，没有影子 |

- 纸上的东西是内容，内容是平的（C8）。平时一页只有一圈细边，没有影子。只有拿在手里的一页与展开的一叠抬起，都用 `elevation-raised` 一档。
- 纸上没有卡片套卡片（C9）：叶里面画什么归画这一类东西的领域，叶自己不再加框。

## 2. 名字一行

- 在叶的下面，与叶隔一个间距。高 4.5 个间距，中楷下是 18。说明字号、`leading-ui`、弱墨 `ink-faint`，单行，超长用省略号。
- 名字一行连同那个间距在纸上高 22，就是共用件的 `PAPER_NAME_LINE`，算在页的外框里。所以贴着纸下沿的一页，名字一行也不出纸边。换算只用这一个常量。
- 左边是把手，把手就是名字本身。右边是名字一行的旁注（`aside`），画布在这里放锁的记号与 `⋯`。名字一行里只有能动手的东西：谁摆的、什么时候这类信息不画在页上，写在纸下沿的状态栏里（第 4 节）。
- 名字一行有两个样子：平时与看着它时。看着它时指：指针在这一页上（叶或名字一行都算）、焦点在这一页里面（`:focus-within`）、这一页选中（`data-selected`）、这一页拿在手里（`data-gesture`）。纸上先看到的应当是东西本身。
  - 平时：一页的名字一行里什么都看不见，只有锁着的页有一个锁的记号。锁是这一页的状态，也是解开的控件。一叠的名字与页数、展开钮照旧在：一叠的名字是人起的，是内容。
  - 看着它时：名字（种类的叫法，拖动用的把手）与 `⋯` 出来，名字一行的弱墨深一步到 `ink-muted`。指针在纸的空白处不算看着这一页：纸面悬停时没有底，不按 C6 加深里面的弱墨。
  - 名字平时照样排着，只是不透明度为 0。所以两个样子之间名字一行的高与每件的位置都不变，把手照旧在原处，能抓、能接焦点，读屏照旧读得到。
  - 一叠展开之后，每页上面的名字同样平时看不见，指针在那一页上或焦点在那一页里时写出来。
- 内容先于元信息，宽度不够时按这个次序让位。页数、锁、`⋯` 与展开钮定宽，不缩。页上种类的叫法截断，留得下两个字宽。一叠的名字拿剩下的宽，放不下时带省略号。会话的缺省占地宽 160 下，「周报」整个看得见。
- 名字一行在 DOM 里排在叶的前面，所以 Tab 先到把手，再到叶里的东西。

## 3. 各状态的样子

| 状态 | 样子 | 标在哪 |
| --- | --- | --- |
| 平时 | 一圈细边，没有影子；名字看不见，锁着的页只有锁的记号（第 2 节） | — |
| 指针在这一页上 | 名字写出来，名字一行深一步到 `ink-muted`；`⋯` 出现；状态栏写出这一页（第 4 节） | `:hover` |
| 悬停在名字一行上 | 名字的墨深一步到 `ink-muted`，指针是抓手 | `.omne-paper-handle:hover` |
| 键盘焦点 | 把手上画 2px 的 `line-focus` 环（K2）；名字写出来；`⋯` 出现。纸面本身的环画在纸面里面，偏移是负的环宽（K1 铺满容器的办法） | `:focus-visible` |
| 选中 | 叶的那圈细边换成 1px 的 `accent`，不加底、不加影子（手感表的「卡片」选中）；名字写出来 | `data-selected` |
| 拿着（拖或改大小，过了起拖的 4px 之后） | 叶抬起到 `elevation-raised`，压在别的页上面；名字写出来；指针是抓紧的手；不选中字；只挪位置，不转、不缩 | `data-gesture` |
| 还没定（命令发出、答复没到） | 叶的不透明度 0.6。它画在读来的位置上，不画在要去的位置上；重读落下才回到实的 | `aria-busy` |
| 锁着 | 没有把手，没有四角；名字是普通的字。名字一行里有锁的图标钮，可访问名「锁着，解开」，按它解开 | `data-locked` |
| 一叠收着 | 最上面一页露全，在最左下；下面至多三页，每深一层向右 1.75 个间距、向上 2.25 个间距（中楷下 7 与 −9），露出边。下面的页不接焦点。名字一行写名字与页数（表格数字），接着 `⋯`，右边一个展开的图标钮；名字放不下时它先截断 | `data-state=closed` |
| 一叠展开 | 在名字一行下面隔一个间距排开，名字一行与收着时相同；每页按调用者给的页的大小画，每行至多四页，一行排不下就换行；整块收在视口内，靠右时向左展开，靠下时向上展开；底是一张浮起的面：`surface-page`、`radius-card`、`elevation-raised`，内边距与间隔都是块间距。每页上面写它的名字。展开钮的箭头转向下；Escape 收起，焦点回到展开钮 | `data-state=open` |

- 「拿着」与「还没定」是两件事：前者是手势的预览，松手就没了；后者是已经发出去、等服务端答复。一页不会同时画成两样。
- 拖动的预览就是松手后要交回的那个框：已经取整、已经夹在纸里。所以预览落在哪，松手后服务端答应时就画在哪。
- 纸心的形座位是一个图标钮，可访问名「回到正面」，里面只有座位、不画图标。按它或按坐在上面的形，等于按正面的家；对形按右键是翻面，归外壳。键盘焦点同把手，是 K2 的环。
- 反面的右上角是翻面的记号：图标钮「翻到正面」，离两边各一个块间距。读不到画布时它也在，所以总能回到正面。

## 4. 状态栏与谁摆的

纸上只留东西本身；关于它的信息统一写在纸下沿的一条状态栏里。每一页都挂一个记号，纸上看着就乱。

- **是什么**：反面下沿横贯的一条窄栏，排在纸面的视口下面，不随纸平移缩放。纸面的视口到它的上沿为止，所以贴着纸下沿的东西平移得出来，不会压在栏下。
- **多重**：最轻的一档，与回执同重（N3）。底与纸同色（`surface-page`），上沿一条 1px 的 `line-subtle`，没有影子。字与图标是弱墨 `ink-faint`，说明字号，图标 `icon-compact`。高是一个 `control-height`，随字号档变，不随内容变。
- **放什么**：两个口，画什么归调用者，共用件不认识纸上摆的是什么。
  - 左段放纸自己的控件。画布放查找、磁吸开关与远近读数，行为与键位不变。
  - 右段放此刻看着的那一样的信息，靠右排。看着的是：指针所在的那一样；指针不在任何一样上时是键盘焦点所在的那一样；都没有时是选中的那一样，选中几样时写「选中 N 样」。画布对一页写种类的叫法、能读到的名字（小应用写它的名字）、谁摆的、什么时候、锁着时一个锁与「锁着」；对一叠写名字、页数、谁摆的、什么时候。什么都没看着时右段空着：不写提示，不写总数。
- **谁摆的**：人是 `ContactIcon`（头与肩）加「人」，agent 是 `AssistantIcon`（开口的圆，全应用指 agent 的就是它）加「agent」，时间用 `Ago`（S9）。只分人与 agent，不写会话的标识，不用颜色或材料区分谁摆的。
- **怎样换内容**：只换不透明度（M7）。从一样换到另一样直接换字，不先隐去；出现用 `feedback`。看着的东西没有了（指针从一页移到纸的空白处）时，字先留 `layout` 那么久，再用 `state` 隐去，所以指针扫过几页之间的空白不会让栏闪成一片。隐去的那段时间里旧字还在，读屏读不到它。减弱动效时直接换，没有留与隐。
- **读屏**：右段不是 live region，指针每扫过一页都念会太吵。每一样自己带着一句「最近由人摆放 · 3 分钟前」，读屏与键盘用户不靠状态栏也读得到。状态栏是给看的人的。
- **给随身入口让位**：窗口右下角浮着随身入口的墨点，一个形那么大（56px 乘字号档），离窗口边 24px。栏右端留出一个形的大小加 `space-section` 与 `space-block`，栏里的字不进那一块；墨点浮在栏上面，栏不盖它。形座位在纸心，翻面的记号在右上角，都不在栏里。人把墨点拖到别的角时，栏不跟着让。

## 5. 长度怎样随字号档与远近变

- 纸上的长度以纸的单位记：中楷、远近为一时的一个像素。
- 纸里面的 token 都按中楷取（纸带 `omne-size-standard`）；整张纸再乘「远近 × 字号档系数」放大缩小。所以名字一行、一叠的错开、四角在每一档、每个远近下与页同比例，换字号档时纸上的东西跟着整个界面一起变。
- 纸外的东西（状态栏与它里面的控件、纸上的通知）不在纸里，只随字号档，不随远近。
- 成员不写纸上的像素：位置与大小只经这几件的属性给，屏幕上的点经 `usePaperAt` 换成纸上的点（[不要这样做](dont.md)第 13 条）。

## 6. 手的余地

- 四角是 5 个间距见方的热区，伸出叶外 1.5 个间距，什么都不画，只换成改大小的指针。四角只给指针用，不接焦点；键盘在把手上用 Shift 加方向键做到同样的大小。
- 起拖要移过 4px；没过就松手，是一下按。
- 在纸的空白处按住拖是平移；在页、一叠与纸上的一点上按下不平移。

## 7. 动

- 叶的不透明度换在 `state` 里，曲线 `ease`。名字一行两个样子之间只换不透明度，用 `feedback`，曲线 `ease`。状态栏右段怎样换见第 4 节。一叠收着时的错开走 `layout`，曲线 `ease-enter`。展开不另做到达。
- 纸上的东西出现时不做到达：它们来自读到的摆法，不是人亲手打开的。
- 只用 transform 与 opacity（M7）。纸上没有循环。
- 减弱动效时纸面、把手、四角、叶、一叠、名字一行与状态栏右段的过渡全部去掉，画纸上东西的界面模块自己写的过渡与渐显也去掉；纸上的基础控件照 M11 只留不超过 `feedback` 的颜色反馈。拿起与放下只换样子，不动。

## 8. 用到的规则

| 编号 | 在纸上怎样落 |
| --- | --- |
| C8、C9 | 平时只有细边；拿着与展开的一叠才抬起，只用 `elevation-raised` |
| 手感表的「卡片」 | 选中是一圈强调色的细边 |
| K1 | 纸面与叶都裁切，各留 `ring-room` 的余地；纸面铺满容器，环画在里面 |
| K2、K4 | 把手与纸面用 `:focus-visible` 的环；可点的都标 `data-control` |
| A3 | 远近读数是一段字，不是带字的钮；回到 100% 用纸面上的 `0` 键 |
| M2、M7、M11 | 只用动效 token；只动 transform 与 opacity；减弱动效时没有过渡 |
| T3 | 名字一行用说明字号与 `leading-ui`，不写行高的数 |
| N3 | 状态栏与回执同重：说明字号、弱墨、没有边框与影子，只有上沿一条细线 |
| S9 | 状态栏里谁摆的那一句用相对时间，经 `Ago` |
| I4、I6 | 状态栏里的图标用 `currentColor`，墨跟着字是 `ink-faint`（它们不是控件，不取控件图标的 `ink-muted`）；取图标集里已有的意思：人是 `ContactIcon`，agent 是 `AssistantIcon`，锁是 `LockIcon`。页上锁的记号是控件，照 I4 静止时 `ink-muted` |

## 9. 怎样验

问题在[观感验收的方法](visual-acceptance.md)第 8 节。共用件的用例：`paper.spec.tsx`（预览与交回、键盘、锁着、一叠、纸上的一点）、`paper-quiet.spec.tsx`（名字一行平时与看着它时）、`paper-status.spec.tsx`（状态栏的两个口、换内容、减弱动效）、`snap.spec.ts`（磁吸、不出纸边、远近）、`paper-motion.spec.ts`（减弱动效下没有过渡）。
