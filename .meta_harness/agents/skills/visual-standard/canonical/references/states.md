# 状态：形上的每一笔

> 什么时候读：要加一个状态、改一个状态在形上的样子，要知道某件事现在用哪一笔说，或要知道减弱动效下每个状态留什么之前。
> 本产品有哪些事实、形上大致是什么样，是产品正文「Agent 在屏幕上的形」里的状态表；事实经形口报来（`doing`、`moment`、`waiting`），形口的形状归 `packages/frontend/SPEC.md#形口`。这里写每一笔怎样写、多久、减弱动效下留什么。

## 1. 原则

- 一个状态就是在形上写一笔或干一笔。不加字、点、转圈、徽标、光。
- 只为真事变：人在对它做什么（指针停在它上面、按下），或它代表的会话真的在做什么。没事时是静止的圆。
- 一笔一个意思，在哪里都是这个意思。新的状态用新的笔，不借已有的那一笔去说另一件事。
- 状态笔短，说完就停：现有的都在 200–620 ms 里写完，只有「在做事」会重复。**判断**（来源没有写成规则）：新的状态笔也照这个量级。
- 真事优先：来了真事，正在画的墨在 `--omne-motion-feedback` 里干掉，圆回到原样，再说真事。

## 3. 在写：一页竖排

- 形旁边 2–4 竖，从同一条顶线垂下（在形的上三分之一，不像雨那样散落）。每竖从上往下写，起笔轻按，收笔多半顿住（垂露），偶尔出锋（悬针），脚下不留墨滴。
- 第一竖离形最近、最长，往外一竖比一竖远：在形的左边从右往左，像中文的竖排。左边放不下就站右边，镜像，从左往右。
- 间距不匀，每竖略斜，手写的不齐。相邻两竖不像；三竖以上不成阶梯，升降都不行；四竖少见。所以它不读成暂停号、信号格、梳子或条形码。
- 写完停一会，从第一竖起干，再起一页，长短不同。没有横，没有像字的笔样。
- 竖排不压在座位那一行里画着的东西上：量座位所在那一行里和座位齐高、画出来的东西（图标、图片、只有字的元素；按钮量它的图标，不量它的留白），取左边最近的右沿、右边最近的左沿；左边要留出 `COLUMNS_REACH`，再空出 `COLUMNS_CLEAR`。两边都不够，站宽一点的那边，一页写得少、挨得近，至少两竖。

| 常量 | 数 | 守住什么 | 出处 |
| --- | --- | --- | --- |
| `COLUMNS` | 细笔 `FINE`；离形 7.5 格，顶在 18–21.5，页高 23–27；竖距 5.2–7.4；斜 ±0.7；长度占页高：第一竖 0.9–1，其余 0.34–0.84，相邻至少差 0.2，最短 7 格；竖数：四竖 0.2，否则两竖 0.4、三竖 0.6（合起来约 32% / 48% / 20%）；收笔垂露约七成、悬针约三成 | 读成手写的一页，不读成符号 | `working-states.md` |

### 「在写」试过、拿掉的

三次都在小楷的真实大小上、浅深两种底看过，都是读法错了，不是笔不好。

- **行草的笔样**（形旁几笔连写，像字）：小楷上只剩折和斜，读成「Z Z」，是睡觉，不是写字。教训：这个尺寸上像字的笔样就是符号；写字要用笔画本身，不用字形。
- **形左边的几横**（一横一行）：圆旁边一叠横，读成漫画里的速度线，圆像在往右冲。教训：圆是会动的东西，和它能走的方向平行的线就是它的轨迹；旁边的笔不能顺着运动的方向。
- **形下面的几横**：居中、往下变短，读成灯泡的螺口；放宽、从左起，又读成云下的风雨。教训：圆加下面一叠横是图标的构图；页不能和形拼成一个轮廓。

竖排三条都避开了：竖是笔画不是字形；竖和横向的运动不平行，往下垂又有同一条顶线和顿住的收笔，不读成落下；它站在形的一侧，和形之间留着空，不拼成一个图形。

还剩两种读法，知道，留着：三四竖并排时偶尔读成数数的划道；一竖刚落笔那一下只是一个按下的点，会读成一个眼点。在写和在查一次只有一个，不混。

## 4. 换状态的时序

- **在写从第一段字起。** 「在写」从回复的第一段字到了算起，不从开始调用模型算起：模型还在想，一个字没写。新的一次调用在它的字来之前又是在想。
- **至少看得见。** 在查、在写一出来，至少停 `DWELL` 才让给下一个。
- **短的工具只看一次。** 信号说过、形还没写的最近一件事（在查、在写）记着欠着，等当前的状态可以让开时写出来。同一种接连几次是一次；换了一种就欠新的那一种。
- **在两笔之间换。** 换状态都等正在写的那一笔写完（一遍在想、一竖、一个眼点），不在半笔上换。
- **不落后太远。** 一件事从发生到形开始写它，最多 `LAG`。
- **一眨眼不是在想。** 在想是一轮在跑的底色，不是一件事：它不停 `DWELL`；信号说在想说满 `SETTLE` 才写。字写完到下一件事（工具开始、又一次调用、一轮结束）之间，仍是在写。
- **做完就静。** 一轮结束，在写、在查停够了就停，在想当场停，形 520 ms 回到满墨。

## 5. 屏幕上别的地方

- 对话头下面、转写末尾、会话列表里都没有表示「在做事」的字、点、转圈。
- 读屏：一处 `role="status"`、`aria-live="polite"` 的隐藏句子说形被写成在做什么。同一句只说一次，4 s 后安静。它读的是形被写成的状态，和形一样停够 `DWELL`，所以几毫秒的工具也说「在查」。
- 东西在加载（列表、上传、读设置、重连）不是 agent 在做事：照旧用活动标记加一个词（L2）。
