# 观感验收的方法

> 什么时候读：要验一次界面改动看起来、动起来对不对；要写观感走查、截图矩阵、动效探针；要逐帧量动效；要写观感验收的报告。
> 验收的对象是看得见的结果：一个人打开应用，从登录走到每一屏，看到的是不是同一只手写出来的东西。代码怎么组织不在这里验，行为由原有的测试守。

## 1. 什么叫过

四层都过才算过，缺一层不交。

| 层 | 是什么 | 谁判 |
| --- | --- | --- |
| 1 门 | 自动检查，守住能用规则写死的那部分（第 2 节） | 机器，全绿 |
| 2 量 | 在真实页面上量出来的数：尺寸、对齐、字体、动效的时钟、焦点环（第 4 节） | 走查脚本，全部在容差内 |
| 3 看 | 每个场景的截图逐张看：该有的在，不该有的不在（第 5 节） | 执行方先自己逐张看并写结论，再交负责人看 |
| 4 像 | 把同一族的屏与参照并排放，像不像一只手；形的验收问题（第 6 节） | 人。这一层没有门 |

行为不许退：改动前能过的测试与 `page-walk` 的全部步骤，改动后仍然过。选择器可以随 DOM 改，断言的事实不许删。

「过」需要亲眼看过的证据。没有截图或量出来的数，不许写「通过」。

## 2. 第一层：门

每道门在 `packages/frontend/SPEC.md` 里是一条不变式，指到守它的测试。已知的例外只能记在基线里，基线只许变小。门放在对应的位置：共用件的测试、各成员的源码检查、`tools/product-checks`。

| 门 | 断言 |
| --- | --- |
| 令牌 | 样式只读存在的 `--omne-*` 语义变量；成员里不读调色板层，不定义自己的变量 |
| 刻度 | 没有 token 以外的字号、行高、圆角、图标大小、控件高度；成员的样式里没有 px 与 rem 的数（1px 的细线除外） |
| 动效 | 没有 token 以外的时长与曲线；`tokens.css` 声明的动效 token 与[时长](timing.md)第 1 节的表一一相同；关键帧恰好是公布的那几个 |
| 断点 | 全仓的媒体查询与脚本里的宽度只出现 768、1100、1160 |
| 环 | 环的余地是一个注册的长度；每个裁切容器都留了它（工作区的边除外）；每个滚动容器以它作滚动内边距 |
| 可点 | 没有控件族以外的可点元素；所有界面成员没有原生的 `button`、`input`、`select`、`textarea`、`details` |
| 图标 | 只画图标集里的；24 格、`currentColor`、笔画数；动只经过渡 |
| 对比 | 两套主题下正文 4.5:1、边界与焦点 3:1；悬停、选中、强调的悬停彼此分得开 |
| 一事一件 | 加载、空、错各只有一个件；胶囊、数字徽标只有共用件的那一个，成员里没有自己的 |
| 类有其规 | 渲染出来的每个类名在样式里都有规则 |
| 没人用的件 | 共用件导出的每一样至少有一处在用 |
| 状态词 | 状态词只来自状态词表；成员里不出现表外的状态说法 |
| 字钮 | 成员视图里每个带字的 `Button` 都在一张只许缩的登记表里，每一条写明它是[规则与 token 的索引](rules-index.md)的 A3 哪一种，或交给哪一程收走；登记表外多一个带字的钮就失败 |
| 禁词 | 渲染出的文字里不出现「正在生成」「正在等回复」「已连接」「强提醒」「弱提醒」，以及任何没有译成人话的结果码（用一个不认识的码去渲染，断言人话在外、码只在「详情」里） |
| 时间 | 时刻只经共用的相对时间件格式化 |
| 墨框 | 墨框的边按框生成、引线从口出来绕过圆、两种墨一只手；形在每档字号下只有一个大小 |
| 图表 | 颜色只来自图表变量；SVG；有表格视图 |
| 引用 | 代码与规格里引规范的地方都指得到存在的标题 |

## 3. 走查的环境与数据

验收在真实的页面上做：真的服务端、真的转发层、真的浏览器，不是组件的故事板。

- **起法**：脚本化的模型网关加一个全新状态目录的服务端、独立转发进程、无界面的 Chromium，和 `apps/desktop/demo/page-walk.mjs` 一样。外壳与窗口（标题栏、窗口按钮的留位）只有真的 Electron 里看得到：在 `apps/desktop` 下 `pnpm run window` 复看一遍。
- **观感走查脚本**：在 `page-walk.mjs` 旁边写一支 `visual-walk.mjs`。它先把验收数据都种出来，再逐场景截图与量数。
- **验收数据**：每个场景要看的状态都要种出来：会话的每一种条目、每一种对话状态（流式、失败、取消结果未知、输入结果未知）、每一种决策卡片、后台调用、通知、各页的有数据、空、读不到、未知，断开服务、登录失效、一个渲染时抛错的项。种不出来的不许跳过：要么补夹具，要么照 `apps/desktop/demo/charts-walk.mjs` 的办法用假客户端搭一页，并在报告里标明「假客户端」。
- **截图矩阵**：每个场景 × 两套主题 × 三个窗口（1440×900、1100×760、720×480）。字号档敏感的场景再加两档（小楷、老花）。文件名 `场景号-主题-宽度[-字号档].png`。形也在页面里，所以一张图里就有它。
- **改动前的图**：动手前用同一支脚本、同一份数据截一套，留作对照。
- **参照图**：同一族的屏（外壳、对话、列表加阅读、设置、卡、墨框）与来源的参照图并排。参照图里形画在另一个透明窗口，对照时看合成后的那一张；本仓库的形画在页面里，结果应当与合成图一样。来源自己的毛病不要照着做，以本技能为准（[不要这样做](dont.md)）。

## 4. 第二层：量

走查脚本在页面里取计算后的样式与盒子，逐条断言。容差：位置 1px，颜色取 token 解析后的值逐字相同。

- **尺寸与对齐**：侧栏宽与窄条宽等于 token；导航行高等于 `--omne-nav-row-height`；窄条里每个控件是 40px 的圆；侧栏里所有图标的中心在同一条竖线上；对话头高 84px；主列不宽于 740px；转写里每一行与输入框的左边相同、右边相同；人的气泡不宽于列的 88%，agent 的气泡与一切正文不宽于阅读宽度；卡的宽度等于决定宽度；单列页与各家族的宽度照 S6；三个窗口里页面都没有横向滚动；720×480 下没有东西被裁掉而不留痕迹。**抬起的四边**：每个抬起的件（有边线或投影的钮、字段、卡）连同它的投影与焦点环的余地，都在每个裁切它的祖先的可见范围里；件本身滚出了视野的不算（S15）。
- **字**：页面是 `lang="zh-CN"`；中文正文实际用上的第一位字体是随包的楷体（用 `document.fonts` 核对已加载）；标题、气泡、卡上的问题用阅读字体，控件与说明用界面字体，标识、命令、参数用等宽；中楷下没有小于 12px 的字，小楷下没有小于 10px 的字；没有合成的粗体与斜体；时间与数字是表格数字。
- **面与色**：有阴影的只有抬起的面（输入框、墨框的纸）与浮层（菜单、弹出、抽屉、确认面板），值只取那两档；别的元素的 `box-shadow` 只许是焦点环或细线抬起。没有渐变背景（墨框纸的洇开遮罩与代码滚动的渐隐除外）。琥珀只出现在等人回答的东西上与「注意」语气的件上，红只出现在失败的事实与不可撤销的最后一步上：逐场景统计这两种颜色出现的元素，对照允许的清单。没有被套着的卡。
- **动**：每个操作配一个探针：做一个真的指针或键盘动作，读这期间开始的动画（`getAnimations()`），断言它是该有的那一种（到达、展开、落定、浮层），时长与曲线是 token 的值。新加的操作都要加探针。一个操作里开始的主动画只有一个；操作前后都没有的滚动条，操作中途也不出现。流式回复期间转写末尾没有占位元素，对话区里没有循环动画在跑，形的那一层里有笔在动。开着减弱动效再走一遍：所有位移为零，只剩不超过 `feedback` 的不透明度变化；循环都停着，字还在；每个状态仍然有一个看得见的标记。
- **形**：任何时刻页面里只有一个形，它的盒子是 56px 乘字号档（42 / 56 / 70 / 84）。它的中心与所坐座位的中心相差不超过 1px；它不在的座位里什么都没画。状态表里的每个事实各截一组连拍，每一组里形上都有对应的笔画。墨框：边合上之前内容的不透明度是 0；收起时内容先走；淡墨框的静止边比浓墨框的淡；引线不穿过圆。
- **键盘**：用真的 Tab 走遍每一页、每种展开、每个浮层：每个可点的都走得到，每个焦点环四边完整，没有被祖先裁掉。每个浮层与墨框按 Escape 关闭，焦点回到触发它的控件。F6 在侧栏、正文、侧边区之间走。鼠标点开的东西上不留焦点环，键盘打开的有。

### 逐帧量动效

时长以 token 为准。要知道一个动实际多长，就录下来逐帧量，填一张表：

| 场景 | 做了什么 | 应该是哪种动、哪个 token | 实测 |
| --- | --- | --- | --- |
| 例：打开一个下拉，0.9 s 后按 Escape | 点下拉 → Escape | 浮层：`enter` 进，`exit` 出 | 打开 409–672 ms（263 ms）；关闭约 150 ms，之后焦点环回到触发器 |

- 录屏，按帧取图，排成联系表；每个变化记下开始与结束的毫秒，算出时长，与 token 比。
- 实测里多出来的部分要说清是什么，例如焦点回到触发器带出的焦点环与提示，不算浮层的时长。
- 参照的「实测」只说明参照的节奏；改动后同样逐帧量一遍，填同一张表。

## 5. 第三层：看

每个场景写三栏：做什么、必须看到、不许出现。例：

| 号 | 做什么 | 必须看到 | 不许出现 |
| --- | --- | --- | --- |
| A1 | 冷启动到登录门 | 形在卡的上方写出来；卡左对齐、决定宽度；快的启动看不到加载字 | 产品名；居中的落地页；两个加载状态 |

执行方先自己逐张看，每张写结论（过、不过、没看成及原因），再交负责人看。

## 6. 第四层：像不像一只手

- 把同一族的屏与参照图并排，看五样：留白的多少、字的层次、细线的轻重、选中与悬停的样子、动起来的节奏。说得出哪里不一样的，记下来改；说不出的才算像。
- 来源没有的屏没有参照图，用反过来的问法：把它与紧挨着的对话页、设置页放在一起，它看起来是不是同一个应用里长出来的；遮住文字只看版式，分不分得出它是后加的。
- 走完后回答三句：有没有哪一刻我不知道该做什么？有没有哪一刻它动了而我不知道为什么？有没有哪样东西我没要它却摆了出来？三句都要写，写「没有」也要有走过的证据。
- 形的验收问题与本产品的四问，全部是「是」（[做法与验收](making-and-checks.md)第 4 节）。

## 7. 全应用的清单

- 没有 toast；没有正常状态的字、点、线；没有「正在生成」一类的进行中文字；没有结果码直接给人看；没有原生控件；没有成员自己的胶囊与徽标；没有卡套卡；没有四个平铺的动作；没有三个以外的断点；没有假的进度。
- 琥珀只给等人回答的东西与已知事实的「注意」语气，红只在失败与不可撤销的最后一步；一轮失败不是琥珀。
- 任何时刻只有一个形，它在每档字号下一个大小；凡它展开的都是墨框，凡不是它展开的都不是。
- 减弱动效下走完全程，每个状态仍有标记。

## 8. 纸、页、一叠与翻面

在反面的纸上，按下面每一问对着屏幕答「是」或「否」，全部是「是」才过。样子的规则在[纸、页、一叠](paper.md)，翻面的钟在[时长](timing.md)第 6 节。截图矩阵加这几幕：纸上有几页、拖着一页、锁着的一页、一叠收着、一叠展开、翻面的四段与停下之后。

1. 只用键盘走得通每个动作吗：Tab 到纸面与每一页的把手；平移、远近、挪、改大小、细挪、选中、叠成一叠、展开与收起、改名、拿出来、散开、锁上与解开、拿走，每一样都不碰指针就做得到？
2. 翻到另一面之后，Tab 与 F6 只走露着的那一面，收起的那一面上没有一个控件拿得到焦点，读屏也读不到它吗？
3. 逐帧量翻面：从按键到翻面层撤下，每一次都不超过 1500 ms 吗？
4. 翻面途中点任何地方，下一帧就停在要去的那一面，这一下没有落到底下的任何控件上吗？途中再按一次 ⌘⇧P，同样立刻停下、不翻回来吗？
5. 翻面时屏幕上始终只有一个形，笔头一直在折痕上，墨影在托到一半时最深吗？
6. 拖一页：松手之前预览的框，与服务端答应之后重读画出来的框是同一个位置与大小吗？磁吸开着与关着各拖一次。
7. 发出去还没答复的一页是淡的，画在原来的位置上；答复之后才落到新位置吗？
8. 平时一页只有一圈细边、没有影子；只有拿在手里的一页与展开的一叠抬起吗？
9. 锁着的一页没有把手、没有四角，指针拖不动、方向键挪不动，名字一行里只有锁的记号可以按吗？
10. 每一页都看得出谁摆的：平时是人或 agent 的记号，看着它时写全「人」或「agent」加相对时间，而没有会话的标识吗？
11. 明暗两套、四个字号档下：名字一行完整、不压到内容；一叠错开的边、锁的记号、谁摆的记号都在；纸上的东西与中楷时同比例，只是大小变了吗？
12. 开着减弱动效：按翻面键直接换面，没有翻面层；拖动、放下、展开与收起一叠时，纸面、把手、四角、叶、一叠与界面模块自己写的过渡都没有在跑（除了基础控件照 M11 留下的颜色反馈，`getAnimations()` 为空）吗？
13. 平时一页上除了内容只有一个弱墨的记号（锁着的另有锁），没有名字、没有谁摆的那一句吗？指针悬停、键盘焦点在里面或选中时，名字与谁摆的写全，名字一行的高与每件的位置不跳吗？

## 9. 报告

1. 改动前与改动后的两套截图，同一支脚本、同一份数据。
2. 走查脚本、它的探针清单与最后一次运行的输出。
3. 每个场景的结论：过、不过、没看成及原因。
4. 每条发现：期望、看到的、证据、把握。
5. 三句话；形的验收问题与本产品的四问的答案。
6. 没做成的照实写：哪些场景用了假客户端，哪些状态种不出来，哪些门还带着基线里的例外。
7. 留给负责人定的事。
