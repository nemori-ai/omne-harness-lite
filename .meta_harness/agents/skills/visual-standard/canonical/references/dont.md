# 不要这样做

> 什么时候读：要对照来源的截图或录屏做观感，或评审一处看着像来源、但拿不准对不对的地方之前；要改纸、页、一叠或翻面之前。
> 下面十一处是来源 super-assistant `83c1616f` 在走查里录到的、和它自己的规则对不上的地方。对照参照图时不要照着做，以本技能为准。每条先写规则，再写来源录到的样子。

1. **告知笺写满三行时，下沿不压住导航的第一行。** 告知笺与它下面的导航之间留出空。来源：告知笺写满三行时，下沿压住第一行导航约 8–11px（深色，1440 宽）。
2. **窄窗口里，输入框的动作钮留在工具行的右端。** 不把它挤到工具行下面单独一行。来源：375 宽时，发送钮被挤到工具行下面单独一行、靠左。
3. **流式输出时不露出半截的 Markdown 语法。** 还没写完的语法不当成字露出来，例如列表项先没有圆点、末尾留着孤立的符号。流式与落定后读起来一样（[对话流](conversation-stream.md)原则 8）。来源：流式过程中半截 Markdown 直接露出；它的规则只说流式的字不逐字动，没说半截语法怎样显示。
4. **武装的原地确认面按「到达」出现：上浮 4px，`enter`。** 来源：武装的面只有约 60–90 ms 的可见变化。
5. **「已保存」的回执不跨换页挂着。** 人离开再回来，回执已经不在。来源：离开约 5 分钟再回来，记录的「已保存」还挂在工具条上，直到下一次按键。
6. **告知笺收起时，字先走，墨沿来路卷回口里。** 收起之前不先换成更宽的版式重排，不解开截断，不留一个空框（[墨框与告知笺](ink-bubble.md)）。来源：浅色短笺先由两行重排成一行、框变宽，字淡掉后一个空框在侧栏顶上停约 0.6 s；深色长笺的框先没了，正文解开三行截断，以四行铺在侧栏和头部上约 0.25 s 再淡去。
7. **从告知笺去对话页，形照常走一程。** 不在对话头直接写一个新圆，同时让家里的旧圆慢慢干（[移动与座位](seats-and-journeys.md)）。来源：浅色那一次，对话头直接写新圆，家里的旧圆还要约 1.6 s 才干完，这段时间屏上有两个圆；同样的动作在深色那一次有一程。
8. **一次进入里，状态只显示稳定的那一个。** 快的过程什么都不显示（W6、L4），不在几十毫秒里闪过几种状态。来源：进主对话时，头部下的连接小签在约 80 ms 里闪过「连接中」「加载中」「已断开」，旁边还叠着一个多出来的字。
9. **进对话页直接落在最新的一行。** 不先显示已载入历史的顶部，再一下跳到最新。来源：先显示历史的顶部，约 0.3 s 后才一下跳到最新消息。
10. **回答决策卡片后，卡在原地落成一行回执，下面的内容不跳。** 不留下卡那么高的空白再让下面的内容一下跳上来。来源：卡在原地淡出，留下卡那么高的空白约 430 ms，下面的内容再一下跳上来，没有过渡。
11. **减弱动效下，形与页面在同一刻换。** 形不先坐到新座位，而页面还要等一会才换。来源：减弱动效下点家里的形，形立刻坐到头部座位上，页面却还要约 0.5 s 才换，这段时间形悬在旧页的顶上。

## 纸与翻面里定了不做的

下面四条是做纸、页、一叠与翻面时定下不做的。每条先写规则，再写理由。

12. **翻面不给离开的那一面拍照。** 翻面层直接把活着的那一面朝对边压窄（[时长](timing.md)第 6 节）。理由：两面一直挂着，底下那一面已经画好，没有要等的东西。拍照要主进程截窗口，就要为翻面开一条页面与主进程之间的通道，桌面应用不许有这条通道（`apps/desktop/SPEC.md` 的 DT-50）。来源要等照片，最多等 400 ms，等不到就直接换面。
13. **界面模块不写裸像素来摆纸上的东西。** 摆一页用 `PaperPage`，摆一个点用 `PaperSpot`，屏幕上的点用 `usePaperAt` 换成纸上的点（[纸、页、一叠](paper.md)第 5 节）。理由：成员的样式里不许有 px（刻度门）。自己算出来的位置不乘远近与字号档，换一档、缩放一下就和纸错开。
14. **不引入做拖拽或无限画板的第三方库。** 平移、缩放、拖动与改大小只用 CSS 的矩阵变换、指针事件与纯几何函数。理由：那样的库自己定时长、曲线与样式，绕开 token 与动效的门；它们也自己持有位置，与「纸上的手势只交回结果」相反（`packages/frontend/SPEC.md` 的 FE-I59）。
15. **纸上不画网格底纹。** 磁吸开着时网格只决定落点，不画出来。理由：网格是正常的状态，正常的状态不画线；满纸的细线也比纸上的东西还吵。来源也没有网格底纹。
