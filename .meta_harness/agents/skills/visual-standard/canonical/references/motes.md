# 墨点

> 什么时候读：要改随身入口默认的样子、加或改墨点的一个状态，或有人想给墨点加形才有的东西（圆、座位、待答数、一程）之前。
> 随身入口在产品里是什么归产品正文的「随身入口」；共用件怎样承载墨点归 `packages/frontend/SPEC.md#墨迹`；它的三个部位与交给画法的东西归 `packages/session/SPEC.md`。这里写它怎样看起来、怎样动，以及为什么。

## 1. 它是什么，不是什么

- 墨点是随身入口默认的样子：同一支毛笔点出来的几粒墨，落在一个不画出来的圆上。
- 它不是形。形是 agent 本身，一笔写成的圆，屏幕上只有一个。墨点没有那一笔圆，不坐座位，不写待答数，不走一程。屏幕上同时有形和墨点，不违反「一个身体」。
- 它是人对 agent 说话的地方。它只说两件事：这里可以说话；打开着的会话在做事。

意象来自产品负责人 2026-11-23 的决定：水墨，点线面，大象无形，撒豆成兵。落到笔上：

| 意象 | 落到笔上 |
| --- | --- |
| 点 | 每一粒是一次「点」：按下去再带出去，主笔按「点」的份额，和形里「在查」的那一点同一支笔 |
| 大象无形 | 几粒点落在一个圆上，圆不画；每一粒顺着圆的方向带出去；圆的口和形的口开在同一处，那里不落点 |
| 墨分浓淡 | 顺着笔走的方向，第一粒最重最湿，往后一粒比一粒轻、干：一笔蘸一次墨 |
| 线 | 小框展开时，墨框的边从墨点那里接着写出来 |
| 面 | 边合上，纸洇开，内容出来 |
| 撒豆成兵 | 被拖起来时只留第一粒，别的干去；放下时其余的依次点出来；第一次出现也是一粒粒点出来 |

## 2. 守形的哪几条

墨点用形的笔墨，所以守形的这几条（[形的前提与十条](figure.md)）：一个大小（和形同一块画布，56px 乘字号档）；一支笔（只有 `BRUSH` 乘 `PRESS.dot`，轻重用按的份额说）；只以笔法动（只有点与干，没有缩放、旋转、滑动、CSS 动画；框跟着指针走是外壳在挪位置，不是墨在动）；留白（没事时静着，帧循环停着）；随性（每次点的位置、轻重都从范围里抽）；从不让人等（被拖起来时别的几粒按打断的速度干掉）。颜色只有墨。

不守的：「状态由形自己说」不归它。会话在做事由形说；墨点的重点只是呼应，减弱动效时它不动。

## 3. 状态

| 事实 | 人看到的墨点 |
| --- | --- |
| 没事 | 几粒静着 |
| 打开着的会话在做事（在想、在查、在写） | 最旧的一粒干去，原处新点一粒，一粒接一粒沿那个圆走；间歇长短不一 |
| 只剩后台的调用在跑 | 同上，间歇长得多 |
| 小框开着 | 圆心多一粒：它在听 |
| 被拖着 | 只留第一粒 |
| 减弱动效 | 都按设计值一次到位，不重点 |

## 4. 数

数在 `packages/frontend/ui-kit/src/ink/motes.ts` 的 `MOTES` 里。本产品自己定的，没有来源里的出处。

| 常量 | 数 | 守住什么 |
| --- | --- | --- |
| `count` | 5 | 笔少、留白多 |
| `radius` | 18 格（形的圆是 21） | 它比形轻，又读得出是同一个圆的影子 |
| `angles` | −15°、50°、118°、190°、258°（0 向右、90 向下） | 口（−52° 两侧各 25°）上不落点；顺着形那一笔的方向排 |
| `press` | 1.2 到 0.72 | 一粒比一粒轻 |
| `reach` | 2.6 到 1.3 格 | 一粒比一粒短 |
| `ink`、`wet` | 1 到 0.7、0.95 到 0.4 | 一笔蘸一次墨，越写越淡、越干 |
| `wander` | 1.1 格 | 每次落点不一样，还在那个圆上 |
| `dab` | 230 ms（同形「在查」的那一点） | 点一粒的时长 |
| `scatter` | 90 到 170 ms | 撒开时两粒之间的间隔 |
| `dry` | 260 ms（同形的干） | 一粒干去 |
| `lift` | 120 ms（同形的打断） | 被拖起来时别的几粒让开 |
| `rest` | 900 到 2600 ms | 在做事时两粒之间的停，不成拍子 |
| `backgroundRest` | 2800 到 6400 ms（同形在后台时） | 后台的事比前台的慢 |

## 5. 换掉它

墨点只是「随身入口的形象」这个部位自带的画法。一份 plugin 往 `session.companion.figure` 上放一份画法，就换成别的样子；那份画法只收到 `doing`、`unfolded`、`dragging`。换上去的样子不受本页约束：那是租户自己的选择。
