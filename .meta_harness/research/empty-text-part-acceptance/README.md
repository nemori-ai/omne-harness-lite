# 「图片＋空文本段」的用户消息经 OpenRouter 会不会被拒

本仓库 [issue #50](https://github.com/nemori-ai/omne-harness-lite/issues/50) 的付费实测：`pi-ai-transport` 的投影不滤空串文本段，一条「图片＋空文本块」的用户消息会把空的 `text` 段原样发上线；
上游 pi 因直连 Z.AI 拒收而在 0.87.1 起滤掉了它。这项调查要区分四件事：经 OpenRouter、在本仓库登记的图片路由上，哪些上游拒收这种段；
拒收长什么样；空文本段在图片前后有没有差别；生产路径上能不能真把这种消息发出去。顺带核对被拒请求计不计费与本次实测花了多少钱。
它能回答「哪些路由在什么形状下拒收、拒收的原文是什么」；**不能**回答投影该不该升版、怎么滤——那归 issue #50 的提案与决定。
纯文本数组里的空文本段、历史位置上的空文本段没有测。

- 调查对象与基线：OpenRouter Chat Completions，31 条声明图片输入的路由各钉一个供应商、不回退，三轮付费探针 2026-10-02T16:59:56Z–17:09:23Z，共 97 个请求；
  本仓库 `73fbfd5ff`（前两轮记的是 `c731530f9`，两者之间探针依赖的文件没有变）的投影、计划与计量器；pi `3390bd9`（0.86.1）、`a13d35a`（1.0.0）与修复提交 `1b6ddca8`；OpenRouter 文档 2026-10-02T17:16:59Z 抓取。
- 消费者：issue #50 第二项待办——投影要不要升版（[窄修复提案](../../design/record/proposals/moonshot-empty-text/README.md)、[D-115](../../design/record/decisions/moonshot-empty-text-adoption/README.md)）；[pi-ai-transport 实现节点](../../design/realization/packages/model/pi-ai-transport/README.md)。
- 最近核对：2026-10-02 / 上述窗口与版本。

## 准入核对

- **对象与版本**：上游行为没有版本号可钉，以实测窗口的时间戳为 token；其余版本 token 集中在 [evidence.md 页首](evidence.md)。
- **取得方式**：上游行为来自本会话的付费探针（请求形状、图片、凭据处理见 [E1](evidence.md#e1-探针怎样构造请求怎样保管凭据)）；结果、拒收原文与余额读数直接读原始记录；
  仓库现状由起草时逐行核对源码与测试（静态读，没有执行 `planRequest`）；上游 pi 用 `gh` 读 issue 与提交、用主检出钉住的归档读源码；OpenRouter 文档用 `curl` 抓原页。
  本会话前面那份只读调研报告是输入不是证据，它给出的仓库现状起草时都按文件与行号重新核过（静态读）。
- **凭据**：钥只在运行期间存在于会话临时目录的 0600 临时文件，脚本退出即删；输出里没有钥，组织 id 在存档时抹成 `org_…（已抹）`（[E1](evidence.md#e1-探针怎样构造请求怎样保管凭据)、[reports/provenance.json](reports/provenance.json)）。
- **花费**：0.2320266 美元，被拒请求不计费，负责人定的上限是 5 美元（[C-4](research.md#c-4-被拒请求不计费三轮收尾读数判定不了第-3-轮后补读一次判定)、[C-6](research.md#c-6-本次实测总花费约-023-美元三轮余额差之和-02004-漏算了每轮末尾未入账的部分)）。
- **局限**：每个格子一次样本；只测了「恰一条用户消息、一张图、一个空文本段」；没有测纯文本数组与历史位置；路由身份只核到响应里的供应商展示名。
