# 收工钩子：Claude Code 与 Codex CLI 在 agent 收工点能做什么、不能做什么

核对两个宿主的钩子机制在「子代理收工」与「会话收工」这两个点上的实际能力：能不能触发、能不能把一段文字反馈给 agent、
怎样保证不会反复拦、钩子自己出错时会不会拦住人、配置从哪里读、要不要信任。

这项调查要区分的是**文档写明的**、**从源码或二进制里看到的**与**没查到的**。它能回答「在收工点反馈事实，会撞上哪几条宿主行为」；
**不能**回答本项目该不该用钩子、反馈什么、拦几次——那些是选择，记在消费者那里。
它也没有在任何一个宿主上实际注册并触发过钩子：下面的结论都来自文档与静态观察。

- 调查对象与基线：Claude Code `2.1.287`（文档 `code.claude.com/docs/en/hooks.md`，2026-10-01 抓取）；
  Codex CLI `0.159.0`（文档 `developers.openai.com/codex/hooks.md`，同日抓取，现跳转到 `learn.chatgpt.com/docs/hooks.md`；源码标签 `rust-v0.159.0`）。
- 消费者：[宿主钩子的源](../../agents/hooks/README.md)（收工钩子的输出形状、退出码、去重与信任说明都据此而定）。
- 最近核对：2026-10-01 / 上述版本。

## 准入核对

- **对象与版本**：版本 token 集中在[证据记录](evidence.md)页首；两份文档的原文字节随包保存在 [sources/](sources/)，`sha256sum -c SHA256SUMS` 可校验。
- **取得方式**：首轮由一个只读的调查 subagent 完成（文档用 `curl` 取原始 Markdown，Codex 源码取自 GitHub 标签，另有本机二进制的字符串观察），
  原貌在[首轮报告](reports/2026-10-01-first-round.md.txt)。**subagent 的报告是模型输出**：主会话当日重新抓取两份文档，
  对[研究正文](research.md)的每条结论逐句核对了原文；源码与二进制一侧的观察没有复核，在证据记录里标「仅转述」。
- **来源立场**：两份文档都是厂商自述，只证明它宣称什么；没有找独立来源，也没有实测。
- **局限**：没有注册过钩子、没有触发过任何一次；软链接下的设置是否被实际执行、工作树里读哪一份设置、
  子代理交付报告之后再被拦会怎样，都在[未知](research.md#未知与下一项证据)里。两个宿主都在快速发版，结论只对上面的版本成立。
