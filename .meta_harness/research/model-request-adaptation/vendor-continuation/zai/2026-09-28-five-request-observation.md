## Public-template candidate and its boundary

For a falsifiable offline comparison, the [candidate check](../../../../../packages/model/pi-ai-transport/tests/fixtures/zai/commercial-candidate-check.mjs) strips `stream_options` and the Alibaba `cache_control` marker from the **diagnostic projection only**, renders the resulting complete wire with the existing pinned public GLM-5.3 template, and counts with the pinned GLM-5 tokenizer. For Prime control/long and FlashX control/long it obtains 211/884, respectively, versus each route's observed 210/883: residual `observed - candidate = -1` at all four points. This is a fitted observation on one English text perturbation and one common tool history. It is not a selected-route tokenizer identity, an error envelope, a bound, or a production meter. The server-side effect of the stripped cache marker is not established by this comparison.

An independent, **not yet sent** Chinese/tool/JSON/emoji holdout has four fixed requests in [the holdout probe](../../../../../packages/model/pi-ai-transport/tests/fixtures/zai/commercial-holdout-probe.mjs), two per exact provider. Its preregistered public-template counts are 242/562 for each provider. Applying the first-pair fitted residual would predict 241/561; those are hypotheses, not observations. Unlike the first pair, this holdout changes the system text, tool name/schema/arguments, observation language, and final-text vocabulary. Within each provider pair only the final user text changes. The fixture binds exact providers, disables fallback and retry, caps output at 64, reserves using the original endpoint context, and requires the paid owner's original ledger. A future result can test both absolute errors and the within-pair delta. Even agreement on this holdout would cover only these text/tool cases, not reasoning history, media, arbitrary opaque blocks, or a global upper bound.

## Applicability and failure signals

These observations apply only to the exact request bodies, selected endpoints and public catalog snapshot above. A selected endpoint change, different OpenRouter prompt conversion, cache policy, tokenizer release, or template revision invalidates extrapolation. Missing usage, provider mismatch, incomplete stream or unconfirmed settlement in a later run must be treated as unresolved evidence rather than a zero-cost success. The existing three GLM text/tool estimates and their history-reasoning rejection remain separate from the two commercial missing-meter gates; none of the five selected-route calls exercised the production public or service path.
