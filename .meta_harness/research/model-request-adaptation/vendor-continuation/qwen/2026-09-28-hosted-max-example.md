# Hosted Qwen3.8-Max prompt example (2026-09-28)

[Alibaba Model Studio's English text-generation FAQ](https://help.aliyun.com/en/model-studio/text-generation) states that the single user message `Hi` to `qwen3.8-max` is rendered with the ChatML user/end and assistant `<think>` prefix and counts 11 input tokens. [The Chinese FAQ](https://help.aliyun.com/zh/model-studio/text-generation) gives the corresponding `你好` example and also reports 11. The pinned public Qwen/Qwen3.8-2.4T-A95B tokenizer at commit `207bd685a7e3696cfaff12ded7c6a7ea0f88c996`, SHA-256 `0997f410c57a1f4e53b09e4be8f4a172d90edd9564368fb0847030937229b9f3`, independently returns 11 for each rendered example with a final newline after `<think>`. Without that newline, the English sample counts 10 in the local tokenizer.

[Qwen's public model card](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B/blob/207bd685a7e3696cfaff12ded7c6a7ea0f88c996/README.md) calls hosted Qwen3.8-Max its official version with added features; this is evidence of lineage, not byte-identical tokenizer, prompt template, or OpenRouter conversion. [OpenRouter's Qwen article](https://openrouter.ai/blog/insights/qwen-3-8/) says its `qwen/qwen3.8-max` alias resolved to dated `qwen/qwen3.8-max-0902` when observed. That is temporal routing evidence, not a permanent alias rule. The two Alibaba FAQ examples support a narrow local estimator candidate on text-only one-user requests to the fixed Max 0902 route; they do not establish system/tool/multi-turn/reasoning/media encoding, nor the six commercial models' tokenizer identities.

The exact text messages and tokenizer outputs are preserved as tests in `packages/model/pi-ai-transport/tests/fixtures/qwen/hosted-max-{hi,nihao}.txt`. No vendor or OpenRouter model request was sent for this note.
