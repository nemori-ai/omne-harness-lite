# 六个 agent harness 怎么做 CLI 与 TUI

同代的六个 agent harness——**Codex、Claude Code、Cursor、Kimi Code、DeepSeek Harness、Pi**——
各自把「人在终端里跟 agent 协作」这件事实现成了什么：**技术栈、交互范式、工程实践与设计品味、
实施取舍与代价、官方与社区记录的坑，以及性能指标**。

这项调查要区分的是：**哪些做法六家一致**（那是这一代的事实基线，另做一种选择要额外举证），
**哪些六家分歧**（那才是真的取舍空间），以及**哪些问题六家都没解决**。

- **调查对象与基线**：Codex CLI `0.154.0` + 源码 `774d6425`｜Claude Code `2.1.278`（BuildID `83effae1…`）｜
  Cursor `cursor-agent 2026.08.04-aaa8809`｜Kimi Code `0.31.0`（+ 上游 HEAD 对照）｜
  DeepSeek Harness `c291e796` / `0.1.5-rc.2`｜Pi `890f9208` / `0.86.1`。
  **全部 2026-09-21 当日取证**（DSH 源码副本为 2026-09-10 快照）。
- **消费者**：**待出现。**本项目尚无覆盖终端交付层的产品或架构正文；
  最可能的第一个消费者是未来的交付层架构设计。
- **最近核对**：2026-09-21（首轮）。

## 准入核对

六家的精确版本、取得方式与各自的局限全部记在 [证据记录](evidence.md)，**取证条件与结论不写在同一页**。
本轮有五处必须随结论一起传下去的限制：

- **没有任何 TUI 运行时性能数字。**统一实测**刻意只测非交互启动**——启动交互式 TUI 等于开一个真实会话，
  会触碰认证、写入用户状态、可能消耗额度。**首帧延迟、帧率、滚动性能本轮一概没测，也不能从别处拼出来。**
- **Cursor 一节几乎全部是反向取证。**它闭源、无 issue tracker、无源码仓库；结论来自读它的 webpack 产物，
  是**实现痕迹而非官方口径**，且**「作者自述理由」一条都没有**（检索位置已列明）。
- **三类假阴性在本轮反复出现，每个「未发现」都必须连同检索位置一起读**：
  顶层 `--help` 没列不等于没有；二进制里特征串 0 命中不等于不存在（序列可能是运行时拼装的）；
  **探针词不是实现者会用的词时，负面结论没有任何强度**——本轮有一条结论因此被推翻并已更正。
- **issue 数量不可跨家比较**：Pi 的 issue 会被机器自动关闭，DSH 不用 Issues 收 bug，Cursor 没有公开 tracker。
- **派发者的 ACP 探测方法已证失效**，该维度本轮不产出任何结论。

本家族不拥有方案选择：结论只写到「这条事实让什么变得不可能、什么要额外付出代价」为止。
