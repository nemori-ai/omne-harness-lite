AI Agents for Clean Code with "Uncle Bob" Martin

Published by Pearson

Intermediate

Learn the disciplines of using agents for software development

What you’ll learnIs this live event for you?Schedule
  • Learn the basics of effectively using AI Agents for software development.
  • Explore tips and techniques that accelerate and safeguard the AI Agent process.
  • Discover a significant suite of disciplines that allow you to maintain control of these agents over time.

Join “Uncle Bob” Martin as he introduces you to the basics of software development using AI agents. The course begins with Uncle Bob introducing agents through demos, and quickly expands into more complex demonstrations that expose the weaknesses of an undisciplined approach to AI agents. Throughout the rest of the course, he walks you through a suite of disciplines aimed at maintaining development progress while keeping the project as a whole under control.

What you’ll learn and how you can apply it

  • How to use AI agents to write code effectively
  • Learn the pitfalls of an undisciplined approach and how to avoid them
  • Discover the disciplines of acceptance testing, unit testing, mutation testing, and code quality analysis

This live event is for you because...

  • You are a programmer and are interested in utilizing AI agents
  • You want to learn how to effectively use AI agents for coding
  • You are looking to gain an introductory knowledge of AI agents

Prerequisites

  • Basic programming knowledge

Recommended Preparation

  • Attend: Clean Code with “Uncle Bob” Martin by Robert C. Martin (live training)

Recommended Follow-up

  • Watch: Clean Code Video Series by Robert C. Martin
  • Read: Clean Code: A Handbook of Agile Software Craftsmanship, 2nd Edition, by Robert C. Martin
  • Attend: Uncle Bob’s Live Trainings
  • Watch: Clean AI: Agentic Discipline (Clean Coders Video Series) by Robert C. Martin and Justin Martin

Your Instructor

Robert C. Martin

Robert C. Martin (Uncle Bob) has been a programmer since 1970. He is the co-founder of cleancoders.com, which offers online video training for software developers, and is the founder of Uncle Bob Consulting LLC, which offers software consulting, training, and skill development services to major corporations worldwide. He served as the Master Craftsman at 8th Light, Inc., a Chicago-based software consulting firm. He has published dozens of articles in various trade journals and is a regular speaker at international conferences and trade shows. He served three years as the editor-in-chief of the C++ Report and served as the first chairman of the Agile Alliance.

Martin has authored and edited many books, including Clean Architecture, The Clean Coder, Clean Code, UML for Java Programmers, Agile Software Development, Extreme Programming in Practice, More C++ Gems, Pattern Languages of Program Design 3, and Designing Object Oriented C++ Applications Using the Booch Method.
