# Robert C. Martin 整洁之道体系的当前版本：代码、架构、敏捷、工艺与 agent 时代言论

把 Martin 在 Clean Code 第二版（2025-10）、Clean 系列各书、博客与 2025-04 至 2026-09-30 的 X 帖、视频、GitHub 仓库里
对同一条原则的**最新表述**收齐，逐条判断它相对更早表述是保留、加限定、收窄还是改口；再把独立批评与实证放在每条原则旁边。

这项调查要区分的是**他现在怎么说**、**他实际怎么做（工具、阈值、实验）**、**独立证据支持到哪**。
它能回答「某条整洁之道原则的当前版本是什么、作者自己加了哪些限定」「他对 agent 写代码的立场 2026 年内怎么变的、最新一版是什么」
「哪些主张只有他的自述、哪些有反证」；**不能**回答本项目该采用哪条——那归 record 家族。

## 准入核对

- **对象与版本**：书用 ISBN 与出版社页面日期；X 帖用 status ID 与 UTC 时间戳；GitHub 用提交 SHA 或 API 抓取日期；视频用帖 ID 与时长。
- **取得方式**：一手字节在 [sources/](sources/)，`sha256sum -c SHA256SUMS` 可校验；X 帖经 FixTweet 只读接口取回，主会话逐条读过原文；
  视频转写是 whisper 机器输出，引文标「转写」。三路子代理（著作、agent 言论、独立批评）的原报告在 [首轮报告](reports/2026-09-30-first-round/)，
  主会话复核过的条目在证据记录里标「已复核」，其余标「仅转述」。
- **来源立场**：书、博客、X、GitHub、视频全部是作者自述，只证明他说了什么、做了什么；独立批评与实证另列，并标注批评者立场。
- **局限**：第二版正文只读到样章（前言、导言、第 3 章、索引）与目录；2026-08-19 的一小时访谈没有转写，只有第三方逐条整理；
  他的实验是单人、单游戏、agent 自评；X 时间线不是完整档案；视频转写是机器输出未经字幕校对。
