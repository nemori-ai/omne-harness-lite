## 完整报告正文

取证源：主检出 `tmp/sources/dsh-639ed01.tar.gz`（DSH master `639ed015`，2026-09-29，含 Cordis 4.0.4）、`tmp/sources/pi-a13d35a.tar.gz`（pi v1.0.0）；
解包在会话 scratchpad `research-peers/`。`typebox@1.3.27` 包另下载核对。路径相对各自仓库根。

**总的**：两家都不在模块顶层编译工具参数 Schema；两家都没有跨进程复用的已编译校验器缓存（无磁盘、无按哈希）。
DSH：运行时不用 Ajv（自写解释型校验器）、构建期生成＋首用物化、Ajv 只在一条冷命令里动态导入。pi：首次校验才编译，进程内 WeakMap 缓存。

### DSH（已核实）

- 库：普通包 zod `^4.4.3`（约 60 个包）；插件配置自带 `vendor/schemastery`（3.18.4）；工具参数自写 JSON Schema 子集校验器；
  Ajv `^8.20.0` 只在测试、一个 e2e、一次运行时动态导入：`packages/boot/app-boot/src/config-schema/projector.ts:150`
  `const { Ajv2020 } = await import('ajv/dist/2020.js')`，在 `createConfigProjector()` 里，只服务 `--dump-config-schema`；app-boot README:81「These dependencies load only when collection runs.」
- 工具参数：`packages/core/tools/src/schema.ts:577-598` `defineTool()` 定义时把 DSL 转 JSON Schema（不生成代码），调用时走 `validateJsonSchemaValue()` 递归解释器（`json-schema.ts:487,654`），无缓存；
  `defineTool` 在插件 `apply(ctx)` 里调用，不在模块顶层（`packages/todo/tool-todo/src/index.ts:117,135`）。
- 作者笔记拒绝 Ajv：`.agents/notes/implemented/architecture/2026-07-20-unified-json-value-schema-dsl.md:25`；`implemented/feature/2026-07-05-dynamic-workflows.md:70`
  （「it compiles validators through `new Function`…」）；`rejected/simplification/2026-07-26-dependency-swaps-rejected-by-nih-audit.md:33`；
  `archived/architecture/2026-06-11-runtime-arg-validation.md:23`「Validation cost is negligible next to a model call.」
- Typert：`packages/typert/generator/README.md:12` 生成器把 TS 类型产出为「executable schema factories」，「Generation runs only at build time」；
  `packages/typert/registry/src/service.ts:642-643` `record.value ??= record.create()`，README:12「A schema is materialized and cached when a consumer first requests it」（进程内；JSON Schema 投影不缓存，README:121）。
- Cordis：只依赖 `@standard-schema/spec`；`vendor/cordis/src/fiber.ts:50-62` `resolveConfig()` 在纤程启动或配置更新时同步调 `Config['~standard'].validate`（641-655、747）。
  Schemastery 解释型（`vendor/schemastery/src/index.ts:515`），无编译、无缓存。
- 导入开销：`.agents/notes/implemented/architecture/2026-09-15-narrow-pi-ai-runtime-imports.md:9-15` 为不在启动时执行 pi-ai 聚合入口里的 TypeBox 命名空间
  （「adding hundreds of modules to every application startup」）改细粒度入口，剖析结果「no TypeBox modules」；CI 把 `NODE_COMPILE_CACHE` 放数据盘（`2026-08-28-ci-node-compile-cache-data-disk.md`）。
- zod 4（本仓库装的 4.6.5）对象 JIT 惰性：首次同步 parse 才 `generateFastpass`，按 Schema 实例缓存（`v4/core/schemas.js:1164-1187`、`util.js:218`）。

### pi 上游 v1.0.0（`a13d35a7`，已核实）

- 库：`typebox` 1.3.27（TypeBox 1.x 新包名），ai、agent、coding-agent、protocol、durable 都依赖；1.0.0 全仓 `package.json` 无 `"ajv`。
- 工具参数：`packages/ai/src/utils/validation.ts`（与 0.86.1 逐字相同）：第 6 行 `const validatorCache = new WeakMap<object, ReturnType<typeof Compile>>()`；
  271-280 `getValidator()` 首次校验时 `Compile(schema)`，按 Schema 对象身份缓存；`validateToolArguments`（317）`structuredClone` → `Value.Convert`（非 TypeBox 的普通 JSON Schema 再走自写强制转换）→ `Check`，失败用 `Errors`；
  调用方 `packages/agent/src/agent-loop.ts:726`。工具 Schema 用 `Type.Object` 在顶层构造（只拼 JSON，不编译），如 `coding-agent/src/core/tools/read.ts:14`。
- 并非处处惰性：`coding-agent/src/modes/interactive/theme/theme-json.ts:99` `const compiledThemeSchema = Compile(ThemeJsonSchema)`、`core/model-config.ts:245` 顶层立即编译；protocol 直接用解释型 `Check`（`protocol/src/codec.ts:21`）。
- 禁 eval 环境的演变：`0e932a97d`（2025-10-01）浏览器扩展里关 Ajv；`0d7c81ec9`（2026-03-19，#2395）探测 `new Function`，被禁就跳过校验（顶层 Ajv 单例、每次 `ajv.compile` 靠实例内缓存）；
  `35ff2689e`（2026-04-22，#3474／#3112）改 TypeBox 1.x、删探测守卫（coding-agent CHANGELOG:2209）。TypeBox：`build/system/environment/evaluate.mjs:21-25` `CanEvaluate()` 只探测一次、受 `Settings.useAcceleration` 控制；
  `build/schema/build.mjs:38-41` 不能 eval 时退回 `CreateDynamicCheck`（解释执行）；另有 `Code()` 生成独立 ESM 校验模块（`build/compile/code.mjs:56-65`），pi 没用。
- 启动优化（都不针对 Schema）：惰性加载各提供方 SDK（ai CHANGELOG:1366）、推迟加载扩展编译器（coding-agent CHANGELOG:310）、打包 CLI 启动器先 `enableCompileCache()`（`scripts/build-coding-agent-bundle.mjs:229-231`）。
  没有跨进程的校验器缓存（探针：`enableCompileCache`、`Code(`、`standalone`、`cache`）。
