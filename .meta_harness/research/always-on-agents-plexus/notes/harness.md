## 5. Effect 准入、独立检查和不可被 agent 关闭的执行边界

**已承诺且已接受契约覆盖**：PF-012 rev21 §5.8“系统自带的几件”“没有放宽”规定放行判断不可替换/禁用/收窄，其他拓展件只能另加可否决关。`capability.tool-admission/v2` S-22 判定次序、S-25/26 放行凭据核对、S-30 参数绑定、S-32 不可关闭、S-34 不可用全拒、S-31 整批有人等待则均不执行。`tool-execution-runtime/v2` S-23 提交与 S-60 场景要求凭据不符/无法核对整批不执行；`loop-extension-runner/v2` S-11/S-22记录结论与回放。接受为 D-061，行政版本迁移 D-066；节点设计接受 D-062。

**局限**：这些构成 agent 决策与真实执行之间的权威边界；本次未发现“独立第二模型必须复核所有高风险动作”或“检查模型必须与执行模型异构/独立上下文”的已接受保证。安全拓展件可以调模型并须记录结果，不等于采用了某特定双模型架构。放行的语义授权表达算法及同类调用边界仍列 admission G-1，授权写入 G-2、人的资格 G-3、父摘要来源 G-12 等已有缺口。

**尚未实现**：realization/packages/tools/tool-execution-runtime 与 agent-loop/loop-extension-runner 的完整生产链未获本次实现证据；前者 README 明确 tool-admission 本批无提供者、runner 由全拒件顶上，不能把核心数据包交付等同于执行边界运行验收。

## 6. 委派授权收窄

## 7. Prompt injection 与信任标记

**已考虑**：PF-012 rev21 §5.8 把提示词注入与攻击检测放在所有消息落盘之前，并允许否决；§“拓展件是可插拔的服务”明确租户把关件缺席的可用性政策，未声明则该关会跳过，有 fail-closed 声明才不扩张。它不是一份默认已启用的完整注入防御方案。

**现行标记的精确范围**：`data.content-blocks/v3` S-4 为 `toHuman/toModel`；S-5 嵌套合取只收窄；S-8 `origin` 的四个值是 slash/skill 展开来路，只陈述出处、不授予资格，缺席不意味着人亲写。`data.messages/v3` 来源种类闭合。可见性不是可信度，origin 不是全域 taint/trust 等级。

**本次未发现**：完整的可信指令/外部数据等级、跨摘要/记忆/检索/委派的信任标签传播与降级、不得从内容自举权限的统一接受契约。不能说注入从未考虑；若主线后续判断新材料带来独有问题，需限定到上述缺少的端到端性质。昨天 Relay 投影已经多处写“外部文本/模型建议/沉默不能扩大授权”，且候选 §3.2 有真实动作检查。

## 主线追加问题的收束

1. **同一信息经摘要/记忆/跨会话复用后的纠正失效**：lite 没有完整通用传播契约；但 Relay 的 PWP-01、M01.7、S02/X30、PR-01 已要求纠正实际生效和旧索引不胜新理解，§9 覆盖派生物/删除恢复。范围再细化属于这些已有责任的承接，不能仅因尚无协议再报“没考虑”。
2. **长周期混合故障轨迹**：R/delivery-plan.md IWP-02 已要求跨边界正常/拒绝/断网/重复/撤权/重启/删除恢复证据，IV-CORE/AUTH/NODE/COOP/MEMORY 分别承接；PR-01 已组合纠正失败与索引滞后，PR-03 组合网络分区、出站与重复效果检查。尚未找到将纠正→撤权→委派→重启→unknown 全链按序/乱序的统一轨迹协议；现有依据支持将它视为验收方法补强，不支持新产品语义缺口结论。data/verification.json 自明仅文档一致性检查，未跑运行或质量测试。
3. **代码限制的只读 research lane**：现有 tool 条目 forbid 不可翻案、子≤父、准入件不可关闭，可以承接只装配/允许确定性只读工具的组合。PF-005 的 never-allow 只是不落宿主机，不是“此工具无副作用”的证明；通用 Shell/Browser 获准也不等于只读保证。具体工具/环境需兑现只读承诺，不能从名称或沙箱推断。未发现本次需要新增一项“所有主动感知都必须只读”的产品要求；Dots 的产品取舍不能自动升级为 lite 规则。
4. **跨会话目标 object**：PF-021 §二、PF-007 §6.9 明确既知未定义，排除作为首次发现 issue。

在本次已核范围，未发现足以独立满足“尚未设计、尚未考虑”门槛的新 issue；不为了凑 issue 将既知延期、技术交接、候选细化或验收增强冒充空白。
