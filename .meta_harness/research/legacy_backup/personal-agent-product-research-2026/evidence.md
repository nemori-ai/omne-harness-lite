## C2 — 已知缺口与禁止推论

- 消费对象：比较正文的差异限制、未知表和后续调查。
- 实际观察：Muse 产品页/公告的 rollout、付费与 Confidential VM 为有限/计划性陈述；其技术资料是
  “launch” 时架构自述。Grok Bot 产品/文档/条款没有公开固定模型路由、完整 API 事件 schema、
  加密/灾备/保留契约，且企业可用性页面有时间差。X help 中的 Grok 数据控制不声明适用于 Grok Bot
  的 X connector；X mention 文档不声明 Bot 唤醒。
- 支持范围：支持将这些事项列为未知或禁止推论；不支持得出“功能不存在”“安全无效”或任何厂商
  在隐瞒信息的结论。
- 后续核对：先在各产品专题新增版本化一手证据；只有同一比较维度两侧均有新资料时才修订本包结论。
