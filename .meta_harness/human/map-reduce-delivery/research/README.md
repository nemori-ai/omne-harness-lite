# Map-Reduce 交付的调研

**状态：调研材料，取证日期 2026-10-26。**本目录的文章是 [Map-Reduce 式交付推进](../README.md) 的依据，不是规则。范式页的原则与流程引用这里的结论。项目规则仍由宿主仓库的拥有者正文持有。

五篇调研各从一个角度回答同一个问题：几个互不通信的会话并行交付、由一个集成节点串行合入时，怎样分解、调度、集成和度量，才能既快又可靠。[综合](synthesis.md)把五篇合成原则、分解规则、度量账本与对比协议。

## 证据等级

各篇用同一套标注，读的时候按标注决定可信程度：

- 一手：标准制定者、论文或作者原文。文中直接给出链接。
- 二手：转述、书评或厂商材料。结论后标「二手」。
- 厂商自报：厂商发布的数字，没有独立核对。
- 未核：没有读到原文中对应的段落。使用前要复核。
- 推论：文章把理论用到本场景时的推导，没有来源直接支持。

文中出现的数值，例如服务时长与失败率，是写作时的粗估或示例，只用来示范公式，不是阈值。范式页的数值另作初值，按实测调整。

## 维护

- 调研文章保持取证时的内容。发现事实错误时就地更正，并在该处写明更正。
- 新的调研加一篇文章，并在上表加一行。结论改变了范式时，同时修改范式页与综合。
- 本目录不保存某次任务的计划、证据或待裁清单。
