# 线状态注模板

**用途：**线会话在每张卡交回后发在线父卡上的评论。它是线会话的恢复点：线会话失联后，替换会话只读[线包](line-pack.md)和最新一条状态注就能接上。用法见[范式](../README.md#线会话内部连贯归协调层新鲜归工作层)。

状态注只记当前状态，不记过程。每条状态注完整替代上一条，读取方只读最新一条。线会话压缩上下文后，从最新一条状态注重建，不从记忆重建。

复制下面的代码块作为评论正文，第一行的标记保持原样。

```markdown
<!-- line-state -->
## 线状态注 <序号>

- 交付线：<线 ID>
- 当前 taskBase：<提交号>
- 最后读到的 line-delta：<序号与评论号>
- 本条写于：<哪张卡交回之后，或哪一波收口之后>

### 队列

| 卡 | 状态 | 说明 |
| --- | --- | --- |
| <卡> | 已交回 / 进行中 / 未开始 / 被阻塞 | <被阻塞时写等待的产物> |

### 已定事项

- <本线已经确定、后续卡要遵守的决定。每条写出处：裁定评论、line-delta 序号或冻结头上的文件>

### 未定事项

- <尚未裁定的问题，本线当前怎样避开它>

### 下一步

- <下一张要取的卡，以及取卡前要核对的事>
```
