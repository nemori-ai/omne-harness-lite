# 里程碑报告骨架

**用途：**每个里程碑结束时，与上一里程碑对比的报告。用法见[跨里程碑对比协议](../README.md#跨里程碑对比协议)。分析方法与字段定义见 [research/synthesis.md](../research/synthesis.md#跨里程碑对比协议)。

复制下面的骨架，按节填写。数据缺失的字段写「缺失」，不估填。

---

## 1. 目标与方向

- 本里程碑要推动哪些结果。
- 本里程碑的方案版本，以及[方案版本表](plan-changes.md)中本次生效的调整清单。列出共干预。

## 2. 事前假设

- 引用冻结的[事前假设表](hypotheses.md)原文，写明冻结时的提交号或评论链接。

## 4. 质量侧

- 门的通过记录。
- 返工原因的占比。
- 分解错误：派发前拦下的数量与交回后发现的数量之比，按现象类与原因类分列。

## 5. 有效性威胁

按四类逐条写：

- 结论效度（conclusion）：样本量、区间宽度。
- 内部效度（internal）：共干预、时变混杂。
- 构念效度（construct）：两个里程碑的工作类型是否不同，指标定义是否改过。
- 外部效度（external）：结论能否推广到别的宿主、别的线数。
