# 线包模板

Reduce 从工作卡 binding、已接受依据和当前波生成本包，发在线父卡上。Line 首次开工和恢复时读本包和任务卡。本包只保存本次事实与引用，不授予额外权限。协作规则归[集成清单](../../../../docs/engineering/integration.md#集成节点的清单)。线会话的工作方式归 `line` 技能的 `references/work-paradigm.md`。

每个占位都替换成实际值。不适用的项写原因。命令放在 `sh` 代码块里，派发前在本机同布局演练。只读本包和一张任务卡，Line 就能确定 F、写范围、完成条件、事实来源、本线裁量、交回入口、等待命令和停止条件。缺一项时，reduce 先补齐再派发。

## 5. 交回与等待

- 波末：本线本波的卡都合入父分支后，父分支只跑一次准入，经一次 gate 合入线轨道。顺序归 `integration.md`「线父分支」。
- 关注清单：执行中前台并行关注的事归 `line` 技能 `references/work-paradigm.md`「执行中前台并行关注的事」。
- 交回物：父分支进线轨道的 PR、提升 PR（零差异时都没有）、每张卡上的五节交接报告、线父卡上的一条交回记录。交回记录首行是 `<!-- line-handoff -->`。固定项归[线会话记录](../../../../docs/engineering/integration.md#线会话记录)。交回记录发布后，Line 停写。
- 遇阻：用同一个入口交回 blocked 或 failed，写清原因和已完成部分，然后停写。
- 无远端通路：<在本机保存交回记录的位置，及打开供人带回的办法。不声称已发布>
- 状态注：<`tmp/line-<线>/state.md` 的实际路径>
- 事件接收器：<本机事件文件、接收器拥有者、配置位置。不写频道地址。接收器健康不阻止开工>

交回与等待命令：

```sh
<发布交回记录的命令>
<等线父卡下一条 delta 的 wait-cli 命令，带 --timeout>
```

等待命令作为前台阻塞的工具调用运行。不加 `nohup`、`&`、`setsid` 或 `disown`，不用后台任务模式。超时（退出码 3）后，先读回一次本线父卡的 delta，没有未处理的就用同一 `--since` 立即重跑。等待失败（退出码 2）时，Line 在状态注写 unknown，等人转告。唯一的后台进程是本机事件接收器。

## 6. 停止条件

- 缺必要的全局输入、授权或共享物修改时，暂停依赖部分，继续无依赖工作。
- 没有工作可继续时，交回 blocked 或 failed，然后停写。零差异不造空 PR。
- 普通评论、超时和旧 attempt 都不授予返工。只有 redo delta 使本线同波重做。
- 只有明确的 terminal delta 结束本线。空队列和预案里没有后续任务都不是终态。
- 期限：<本波交回期限。到期时 reduce 核对事实，沉默保持 unknown>
