# human：给人读的流程草稿

本目录保存给人读的工作流程草稿。人可以按草稿操作，也可以把它作为指令交给 agent。

- 本目录的材料不是 skill，也不是角色。生成工具不把它投影到 `.claude`、`.agents`、`.codex` 或 `.cursor`，agent 不会自动加载它。
- 每份材料在开头写明验证状态：在哪些场景走通过，哪些场景没有验证。
- 规则正文归各自的拥有者，例如 `docs/engineering/` 下的交付、集成与工作约定。草稿只给顺序、命令和已知问题。草稿与拥有者正文冲突时，以拥有者正文为准，并修订草稿。
- 一份草稿在更多场景验证后，可以按 [维护指南](../../docs/maintenance.md) 改成 skill 或写回拥有者正文，然后从本目录删除。

| 材料 | 用途 | 验证状态 |
| --- | --- | --- |
