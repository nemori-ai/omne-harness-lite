# 人类协作者指南

本区写给与 agent 协作的人。每篇讲一类设计或协作问题：怎样思考它，怎样给 agent 布置任务，怎样评审 agent 的产出。流程草稿另给出操作顺序与命令。人可以照着做，也可以把它作为指令交给 agent。

本区是学习材料，不是项目规则。
项目要求、工程规则和架构由 [docs](../../docs/README.md) 与实际成员拥有。agent 的方法由 [agents](../agents/README.md) 的 skills 与 roles 提供。
本区引用这些拥有者，不复述它们的条款。两者不一致时以拥有者正文为准，并修改本区。

- 本区的材料不是 skill，也不是角色。生成工具不把它投影到 `.claude`、`.agents`、`.codex` 或 `.cursor`，agent 不会自动加载它。
- 流程草稿在开头写明验证状态：在哪些场景走通过，哪些场景没有验证。草稿在更多场景验证后，可以按[维护指南](../../docs/maintenance.md)改成 skill 或写回拥有者正文，然后从本区删除。

本区内容在两种情况下需要更新：方法认识改变，或者引用的拥有者正文改变。
