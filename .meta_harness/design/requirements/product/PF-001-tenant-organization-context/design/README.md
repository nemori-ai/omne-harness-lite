## 本视图的覆盖限度

PF-001 的三项效用分属 PF-006、PF-010、PF-014 三个 owner；本视图只拥有**共同前提**——
作用域层次的结构定义与「差异不超三项」的范围约束。各项的字段目录、权限规则与工具装载
仍归各自 owner，本视图不接管。

四项未决中的 Q4（组织租户如何产生）使本需求当前**无法端到端验证**：
三项效用都以「用户归属若干组织」为前提，而组织的产生没有任何确认条款拥有。
