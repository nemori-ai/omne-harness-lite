## 使用与维护

- 实施者读 [v1/projection.md](v1/projection.md) 即可取得全部设计输入；
  追溯来源按 [v1/provenance.json](v1/provenance.json) 回到各权威正文。
- 本视图是派生快照，不是权威。与上游不一致时以上游为准。
- 需求或设计变更使本版不再成立时**发布新版本，不原地改旧版**——
  正在照着 v1 实施的人必须仍能找到 v1。
- 三个契约尚未冻结，因此 provenance 中各源哈希为 null；冻结后须回填。
