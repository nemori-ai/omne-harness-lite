# 投影组合与模型请求边界

模块算法及成本承诺唯一正文在`packages/core/model-message-projection/SPEC.md`（F0真实workspace成员；实际兑现须完成交付检查）；本页仅说明跨模块输入与发布责任。

## 完整模型请求输入

固定日志范围（tenant／Session／generation／tail）、消息／原响应／压缩来源、已承接位置、原调用配对及合法业务提醒构成历史输入。
当前AgentDefinition与装配版本、system prompt来源版本、runtime context合法快照与观测代际、model profile／模态与组装规则版本、工具数据版本和参数是外部输入。
每次模型计划固定这些输入，不从Context可见服务反推历史内容。模型runtime消费已固定messages＋profile／parameters／tools，只做独立计划／传输／执行／结算，不重新决定Run或另行拼Session历史。

Session组装负责读取一致日志范围与当前来源，遇来源代际变化重新取得完整输入。日志追加不必使已固定请求失效，但新的发起准入仍须核验当前工作条件与权限。
固定请求的版本／摘要证据记入原调用准备；原模型response与采用消息保持不同数据，重建从原准备和响应定位，不把当前规则悄悄用于过去请求。

## 消息边界

日志严格区分message与非消息事实。非消息只参与治理／索引；attempt开始、调度信号、栅栏、费用不变成SystemReminderMessage。
合法SystemReminderMessage仍需业务来源和内容；同一业务事实＋提醒可用关联字段追溯，不能把所有事实统一转换为提醒。
block的模型可读标记与压缩引用决定可见集合，缺标记默认不送；历史条目不改。压缩是附加消息，改变有效前缀时缓存失效，不截断为“最后摘要之后”。
工具调用及结果配对沿原callId／回复来源索引取得，禁止每个assistant消息回扫整个prefix。变换后的模型表示明确标注来源，原reply不改写；否决沿原消息规则，缓存不绕过hook或模态检查。

## 读取、缓存与发布

请求先读取已提交sourceToken和完整输入键，定位会话当前缓存。缓存包含已处理tail、规则／外部键、消息分段、块／引用／原响应索引及校验摘要。
输入相同且日志只追加时处理增量，共享未改变分段；追加压缩／承接等可能影响旧前缀时定位影响段并重建后缀，无法可靠确定时执行线性冷重建。
来源generation变化、截断／重建、规则或外部输入键变化、缓存校验失败均禁止直接复用。重建之后用预期sourceToken条件发布；并发追加可发布为明确历史token缓存，下次继续增量，不能标为最新。
缓存丢失或逐出只影响成本，不能丢工作。保留有界的当前缓存及仍被在途请求引用的不可变分段；release后可回收，不保存无限历史缓存列表。
本地缓存由Session数据提供者管理，和Agentfiber生命分开；不要求本期持久缓存才能恢复，冷建必须完整正确。缓存内不能混租户，密钥／凭据不参与内容键或日志。

## Run进度独立

ST-015-03读取Run进度投影：原Run／attempt、当前段、等待／取消／终态和已承接来源，附journal进度、projection版本、恢复来源代际及reconciled状态。
未对账真实执行时标为需要对账，不把缓存等待当执行仍活着。读取不得推进工作或追加历史。
待处理队列与Run当前选择须持久、同提交；查询投影若落后可重建或明确stale，不返回无版本的“当前”。
模型消息缓存与Run进度可分别采用不同数据结构，不扩大ST-015-03的验收为模型缓存性能测试。

## 成本声明

N是输入条目、块、压缩／配对引用边的合计；B是被检查或输出的字节，K是输出项数。
冷／全部失效重建O(N+B)，每条／每引用只做常数次处理；不将无限载荷条目视常量。
热更新O(ΔN+受影响后缀+B)，缓存定位期望O(1)或有序索引O(log N)，输出materialize必然O(K+B)。
批量压缩引用可达N，因此增量不是所有场景O(1)。本地复用与供应方prompt caching／计费完全分开，后者不在本设计保证内。
