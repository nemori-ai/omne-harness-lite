# 验证义务

行为见[设计](../design.md)，规范输入见[场景](scenarios.md)。

| 必须覆盖的场景 | 规范输入与不能替代的部分 |
|---|---|
| 多轮自主断开与重连时 `reachCount` 与 `since` 的变化，同时本能力的服务不被撤除、消费者不重跑、在途的模型调用继续；三种合法的业务拒绝仍是 `reachable`；不能确认对端时是 `unreachable` | 场景页第 1 至 4 节覆盖初始、状态转换、读到拒绝与本能力不在场。同标识换地址、异标识的识别与防冒充要对真实的端口验证，中心身份没确定时不保存副本。时钟不可用的前提单独覆盖 |

授权、来源、并发提交与外部作用要用真实组合验证。结果未知不补成成功。范围与前提不能用 Schema、Mock 或局部模型替代。
