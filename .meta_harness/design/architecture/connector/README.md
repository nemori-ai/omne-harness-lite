# Connector 接入边界

状态：连接件相关事项按当前PF-002／PF-014整体条件性搁置，不构成当前交付承诺。先由产品负责人确定是否仍作为资产存在。本区保留原 Schema 的值约束作为历史设计输入，以及尚待恢复范围的条件性技术设计；恢复范围后才可继续专项收口，不将旧五成员信封或两权限表示提升为可实施接口。

条件性技术约束见[接入设计](design.md)。新共同资产只提供[类别正文端口](../../../../packages/assets/SPEC.md#类别提供方与正文)，没有连接件类别的公开形状或 Schema。连接件产品负责人先决定是否恢复范围，再由连接件技术拥有者承接这些缺项。共同资产的类别注册能力不证明连接件已经可实施。
