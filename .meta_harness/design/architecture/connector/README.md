# Connector 接入边界

状态：连接件相关事项按当前PF-002／PF-014整体条件性搁置，不构成当前交付承诺。先由产品负责人确定是否仍作为资产存在。本区保留原 Schema 的值约束作为历史设计输入，以及尚待恢复范围的条件性技术设计；恢复范围后才可继续专项收口，不将旧五成员信封或两权限表示提升为可实施接口。

产品规则归 [PF-002](../../product.0.0.1.legacy/PF-002-assets-settings-and-permissions/README.md) 与 [PF-014](../../product.0.0.1.legacy/PF-014-inbound-intake-and-queueing/README.md)，会话归属归 [PF-015](../../product.0.0.1.legacy/PF-015-session-lifecycle-and-ownership/README.md)。
条件性技术约束见[接入设计](design.md)。新共同资产只提供[类别正文端口](../../../../packages/assets/assets/SPEC.md#accepted-public-types)，没有连接件类别的公开形状或 Schema。连接件产品负责人先决定是否恢复范围，再由连接件技术拥有者承接这些缺项。共同资产的类别注册能力不证明连接件已经可实施。
