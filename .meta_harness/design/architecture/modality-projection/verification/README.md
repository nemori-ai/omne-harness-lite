# 验证义务

设计见[设计](../design.md)，输入与预期见[规范场景](scenarios.md)。

| 能力 | 必须覆盖的场景 |
| --- | --- |
| 投影 | 没有登记、有登记与事后登记不回头三步对照。只给人看的块与嵌在工具结果里的块对照。压缩名单不让块退出。一份完整日志的逐块手算。生成的前缀上，逐条并入等于整份重算，结果单调 |
| 消息转换 | 一块失败整条否决，已做出的派生表示也不落。纯文本与只给人看的块不受转换这一侧牵连。解析不出租户时不调起转换件。否决原因不带内容。模型回复上只挂派生表示 |
| 工具可用性 | 有转换件、没有转换件、答不出三种答复。只在媒体类型键上登记时不满足 |

授权、来源、并发提交与外部效果用真实组合验证。结果未知不补成成功。这一类场景不能用 Schema、替身或局部模型替代。
