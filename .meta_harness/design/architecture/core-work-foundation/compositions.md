# 组合与交接

1. 业务 owner 准备纯数据与精确依赖；协调门在同一撤销屏障核对身份、修订、绑定、授权与预算。
2. 门分配逻辑位置后，durable-records 形成连续耐久前缀；只有耐久回执后才可开始受控效果。
3. 共同提交外的后果由 source-owned outbox、稳定身份和目标回执交接；通知只是提示，不能推进状态。
4. engineering-observation 观察真实边界并显示 gap；非关键观测失败不得回滚或改写业务提交，关键审计不可保存时在效果前 fail closed。
5. 取消停止新准入；已提交外部效果通过精确控制、补偿或 unknown 收口，不能以删除日志冒充撤销。

所有权、tenant、因果、epoch 与水位贯穿交接。提供者撤除先封闭新工作、排空所拥有资源并保留未完成责任。
