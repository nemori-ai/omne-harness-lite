| Transfer |  copy/share三终态+重确认+TTL边界；首次/重复/撞名/按层/key重放与unknown；覆内容不碰配置；每路径树边界+确认重判；分享跟随/撤销vs移除/认回；断后重接不复活、禁事件/不读/逆读序负控；源移除expired及重持有；plugin内含/外引用；各读面unknown无写；组织内分享/成员退出重入/超管不能私看；矩阵每格普通/超管；删除/提升结束share同提交及失败回滚 | examples 1～10覆盖对应旅程与每失败值反例；重持有的offer时效及plugin内含/引用区分仍受阻，不能降为成功；ownerChanged产品范围以产品正文及未决为限；removeShared+unhold新增具体未闭须独立义务。模型不覆盖IO失败、两读顺序或完整资格，只保留原成立前提 |
