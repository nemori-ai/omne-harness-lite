# 能力边界

Tools 拥有定义/发布/调用/frames/结果/控制；Human Decisions 拥有请求、唯一答复与决定后果；Command Input 只拥有输入词法和控制映射。Session/Run 通过稳定引用和等待登记消费这些事实。

## Cordis 投影

工具状态、执行 provider、人类决定和本地 I/O 分别投影为可替换插件；链接插件只连接精确代次和端口，不取得两端状态。

Context、服务引用或 AgentRef 只提供定位，不构成授权、执行权或耐久事实。每次使用仍核对
tenant、精确代次、当前资格与撤销屏障；运行插件缺席不得删除其长期 owner 的责任。
