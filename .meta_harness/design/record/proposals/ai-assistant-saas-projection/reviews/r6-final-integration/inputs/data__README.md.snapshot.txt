# 报告机器材料

这些是候选报告的机器可读附件，不是harness注册表或新接受的契约。

- [逐功能投影](feature-projections.json)：165项原文、来源状态、框架坐标、动作链、提交与恢复、验收和依赖。
- [故事与细化验收](journey-acceptance.json)：23故事、224原文行、30细化、5跨模块、6待定承诺。
- [组件责任](components.json)：13个SaaS责任节点，不要求独立部署为微服务。
- [唯一建设依赖与估算](work-plan.json)：37工作包、21里程碑、两种依赖边、未来完成判据与未校准人周情景。
- [机械核对结果](verification.json)：原文、编号、正反验收、依赖图和386来源摘要检查；不是产品运行验收。

来源与原稿在[研究包](../../../../../research/ai-assistant-saas-projection/README.md)。正文入口为[主报告](../design.md)；接受与运行状态不得从数据文件存在推断。
