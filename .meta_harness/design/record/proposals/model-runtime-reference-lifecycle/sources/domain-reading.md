## 领域对象与责任

对象表可定位 9 个相关对象，全部沿 `SO` 既有 UL 键。执行尝试是视图、句柄是属性，不计作对象；其语义分别沿 `SU` 的 UL-run-attempt、UL-runtime-handle。没有重分解对象。

| 本稿条目／原对象 | 身份与归属 | 本轮责任及生灭要点 | 依据 |
|---|---|---|---|
| O-01 / UL-session | 会话身份；创建时固定租户 | 长期归属、调用可查、取消目标、持久输入与恢复关联；归档不删除身份与历史 | SO 对应条目；S15 §6.1、§6.12、§6.19、§6.21 |
| O-02 / UL-run | 恰属一个 Session；身份在持久事实中，格式未述 | 关联工作、成本、失败、终态；无执行者仍可等待；终态不回退 | SO；S12 §4 Run、§6.13、§6.17 |
| O-03 / UL-agent-runtime | 生命周期属 Session，推进原 Run 的一次尝试；自身标识方式未述 | 发起和消费，持句柄；替换对应新尝试，不能带走其他执行 | SO；S12 §6.13、§6.18 |

| O-05 / UL-tool-execution | 可恢复执行身份；Session／原 Run／原尝试 | 本轮仅作为取消与旧模型建议的邻接消费者；前后台不因 Agent runtime 更换而变化，不在本稿设计工具全线 | SO；S12 §6.13、§6.18 |
| O-06 / UL-session-log | 一个 Session 一份 | 追加历史事实，换尝试、终结、归档不删除；不是 Run 私产 | SO；S12 §4「会话日志」、§6.12 |
