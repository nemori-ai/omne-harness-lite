# 模型调用结果确认后的副本释放：差分领域读数

2026-09-29，pre-review candidate。继承原T29领域读数及PF013 rev16的调用身份、会话归属、三个终态、句柄非宿主、原账和不可变日志性质，仅补用户最新明确要求。作者已读原机制，**本次新增双盲未达成**；未将此页冒作事前盲读。产品后继由PF013作者另起草，本页不接受产品选择。

新要求来源：主线于本会话2026-09-29转交用户要求——提供ACK，由消费方自行确认处理/保管结果后清理模型侧不再需要的副本；超长期运行，不永久积累临时副本；不等所有消费者，不以完整正式Session实现为前置。原无GC选择撤销；不改原日志、状态、费用和未知费用，不把旧引用伪报不存在，不影响其它调用。技术API/存储表示不由本页定义。

| A1 明确确认 | 有资格承接结果的消费方已经处理或自行保存结果后确认 | 系统接受可识别的这次确认；不要求所有曾持句柄者同意，不强制先写正式会话消息 | 用户明确；模型调用消费边界 |
| A2 真实清理 | 该结果已经确认，不再需要模型侧副本 | 可以辨别尚待清理与已释放；不能永久默认保留，也不能把仅收到命令报成已经删除 | 用户明确；模型调用负责 |
