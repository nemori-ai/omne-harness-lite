# 性质、承载与反向核对

## A/B：基线与封存限制

基线是 `301f9e00` 的已接受目标态及当前实现。既有节点在 `packages/model/pi-ai-transport`，不新开包；原 owner、凭据、时钟、停止和持久装配继续承担各自责任。领域对象从 objects.md 的 UL-model-call、UL-model-response、UL-content-block 取，依据为 PF-013 rev16 与 PF-009 rev9；未经装配反查索引核实。

作者收到派发时已知道 reader/协议机制，因此**双盲未达成**。详细机制阅读前封存的领域读数 SHA256 为 `65e62eecbd1cc194e6f64fd1059630bb133431d9ed2f1ae5660bbfaf20e233fa`；该任务文件不是长期设计权威，以下给出完整采用候选性质与修正依据。

首稿 R1 擅自推导“调用者必须区分拒答来源”；主线要求回到产品核对后，发现 PF-009/013 未承诺独立永久拒答属性，MR9 S20 明允原始留存失败/过期。因此撤回这项新增要求，R1 改为**文字不丢、不伪造来源**，不借方法制造 CB 升版。首稿 R7 泛称所有内容不得泄漏也过宽：D-095/v6 明确真实 reply/tool 回显不在此次内容改写授权，当前只继承其来源界限，不宣称完整内容秘密保证。两项为有依据的第二次读数，不享有双盲声明。

## C：对象与六问

新增 refusal 字段不是有身份领域对象；既有模型调用持有本次流，模型响应体记录真实结果，内容块承载字面文本。落点是 **#1 数据映射**：没有新领域操作、授权、独立生命周期或可见性维度。原 raw 存储要求不改变。

六问依次为：无新可注入行为；无独立 fiber 判据；无新 isolate；既有依赖关系不改且不新建 inject；无新事件；装卸保持原 reader stop/stopped 和调用租约。没有跨 owner 新提交，也没有新后台 drain。纯公开 reader 与 service 消费它的关系不变。

## D：四张对账表

| 表 A 性质 | 承载判断 | 具体前提/责任 |
|---|---|---|
| R1/R2 | 能 | CB3 文本已可承载，映射顺序在 v14 明定；raw 来源只依 MR9 原保留政策 |
| R3/R4 | 能 | 原首内容门、SA3 和 MR9 判定不改，只新增一种非空文本来源 |
| R5 | 有前提地能 | 当前 frame 已解析并提供合法统计；未到达的未来统计没有保证，失败仍停止 |
| R6 | 有前提地能 | 既有停止/时限装配有效；reader 不能绕过 abort，也不能保证上游永不发送后的自然结束 |
| R7/R8 | 能 | 保持既有来源政策和唯一 reader，不复制 vendor 分支 |

| 表 B 内核不提供什么 | 原始要求下的责任 |
|---|---|
| 可靠投递、时序、背压 | SSE reader 与现有配置/时限，不从 Cordis 推出网络保证 |
| 持久恢复、跨进程身份、事务 | 已有 MR/SL 与调用结算；本映射没有新持久字段或提交 |
| 外部效果回滚、有序异步清理 | 不撤销付费调用；沿同一 owner 等 stopped，不以 dispose 算网络已静止 |
| 权限边界/沙箱 | 同一租户与原始留存访问规则，本变更不开放 raw 给模型/普通呈现 |

| 表 C 原边界 | 复查 |
|---|---|
| 首内容之前可重试、之后不可 | 拒答非空片段现在正确进入既有内容门；类型错误发生在首片段前则仍未开口 |
| MR 四收场、reply 三 ending | 不新增值；content_filter/error 不因文本出现而变成功 |

| 计量与使用依据 | receipt 不更改实际 usage；新的文本成为真实历史输入，basis 固定，不能拿旧输出摘要冒充新回复 |

| 表 D 代价与信号 | 判断 |
|---|---|
| 半径、组合数、新身份 | 无新 service/fiber/isolate；实例数量不变 |

## E/F/G：落地范围、验证与投影

只替换 transport 已接受 design.md 中 refusal 的“不承载/空数组忽略”两处规则；其它图音工具、未知成员和错误顺序不改变。CB3/AR2/SA3/MS6/MR9/RT10 **无需语义升版**，T29 候选不受本稿抢占。没有新增共享代数、跨 owner 语义或并发装卸协议，故不为该值映射复制 TLA 状态机；真实符合性反例比同义形式模型更直接。

反向核对：dispose 仍由原调用 owner 停连接并等待 stopped；依赖消失沿原租约不额外重启长调用；无新增事件泄漏；跨进程的原 envelope/MR/结算协议保持，字段映射不倚赖进程内身份。外部费用不可回滚。

长期提供者投影及实施门见 [v14](../../../realization/packages/model/pi-ai-transport/v14-refusal-design.md)。独立评审后若采用，由主线将已审节点投影写入既有 PF-013 projection 的下一版并记录来源摘要；本稿未获 product/projection 写权限，不伪造该产物或采用状态。精确采用前这一项为显式交接，不阻止独立评审。
