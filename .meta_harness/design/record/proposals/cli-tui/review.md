## 第一次：D2 终端渲染层的强制二选一投票

按本项目的基座选择评审规矩：**中立 prompt、强制选一、看反证是否互不重复**。
两位先写反对所选候选的最强论据，再逐一否决其余，最后给改选实验。
两位的评审角度不同：一位按性质兑现，一位按五年维护税。

| | 评审 1（性质兑现） | 评审 2（五年维护） |
|---|---|---|
| **选择** | **A · pi-tui 钉版** | **A · pi-tui 钉版** |
| 反对 A 之一 | 「不打 patch」注定破产且上游无补救通道：issue 门禁自动关闭新贡献者 issue，`pi#6050` 11 秒即关，`#9186` 带 commit 未进主干 | 同一条（上游缺陷通道有门禁，「上游会修我们的中文缺陷」不是可依赖前提） |
| 反对 A 之二 | **本轮唯一真实的终端渲染数字反对 pi-tui**：DSH 报告 §6.4 的 196k 事件 transcript 渲染约 12 s、按键回显中位 796 ms，根因「每帧重渲染每个组件」；Pi `#9549` 每次 resize 写 3.9–5.2 MB、`#6665` 流式占 105% 单核 | 「整版 re-baseline」不便宜：上游明写不保留向后兼容，0.85.1 删环境变量读取，每次 re-baseline 是 API 对齐 |
| 反对 A 之三 | 18k 行里 alt-screen 1,742 + LaTeX 1,506 + 图片 696 全是非目标，适配层在隔离自己不要的东西；CI 从不在 Windows 跑 | 原生模块四路径加载全失败**静默缓存 `undefined`**，撞「禁止静默吞错」与「非 TTY 不静默降级」 |
| 仍选 A 的理由 | 中文输入法是唯一「六家都没解」的硬需求，焦点机制 + 光标标记是调研里唯一架构级 IME 机制；输入侧约 5,660 行是最无力自行积累的资产；长会话线性代价的前提是 transcript 全挂组件树，而「交付面不持有领域状态」恰好不允许那么做 | 五年真实开销是终端兼容长尾（四家 17 个月未收敛），pi-tui 交出 40+ 按 issue 命名的回归测试与观测口；运行时依赖最少；原生模块不链 Node headers，升 Node 不撞 ABI；换传输不被它挡 |
| 否决 B（Ink + React） | Cursor fork 新增的六个 render 选项与键盘协议、屏幕阅读器开关逐条对应本设计的性质要求——上游原样版在每条要求上都要被改 | Claude Code 2.1.49「Yoga WASM 线性内存只增不减」是本轮唯一与超长期待机同形的一手失效（**只对该路径成立，不推广**） |
| 否决 C（自建） | 输入侧 5,660 行是起步价；中文输入法无已知解 | 结论三的墙不因自建消失，且没有那 40+ 条回归测试 |
| 否决 D（fork pi-tui） | 0.80.6 是唯一公开的「改渲染核心改砸后回退」记录；D 换来的能力全在非目标表 | DSH 一手拒绝 vendor；Kimi 每次 re-baseline 重申约十项本地 patch；本项目人力远小于 Moonshot |

**反证互不重复的核对**：两位各三条反对里**只有「上游门禁」一条重合**；
渲染性能数字、非目标体量、re-baseline 的 API 破坏、原生模块静默吞错四条各自独立，且都能指回报告章节。
**投票有效。**

## 第二次：fable 对整套草案的独立评审

评审自述的标记法：【事实】查到的 ·【判断】我的 ·【假设】未核的。
**总评**：骨架站得住（「界面是投影」、日志唯一真相、决策池唯一答题处、界面与无界面同一契约，
都能指回 PF-008/012/014/015）；站不住的是进程与信任模型。
