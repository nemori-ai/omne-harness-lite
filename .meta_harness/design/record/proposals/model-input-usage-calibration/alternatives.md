# 当次模型响应体的计量依据怎样承载

三项都遵守用户已确认的方向、同批追加、两类失效、独立公开函数面及既有估算准入保证；不以“每轮全量重算”充当陪衬候选。比较对象是**响应写入者与后续规划者之间交接什么事实**，不是三个不同名字的 meter。

| 候选 | 承载及责任 | 必要性质怎样成立 | 成本、反例、未知 |
|---|---|---|---|
| A：仅输入前缀锚 | 响应保留本次输入身份、统计依据、准确输入 observation；全部新响应内容仍交下一次新增 meter，从已存在的 response usage 另取输出事实 | 输入锚不混输出估算；响应写入不执行输出回放转换；两类变化使锚失效 | 响应计量载荷最小。但每个调用者必须重建“这个 opaque 块来自哪次完整输出”的关联；只拿 final body 的 meter 对最新 encrypted thinking 仍不可判。若把同次输出关联纳入该载荷，即走向 C；若明确只支持可完整独立计量的新增内容，A 有真实且更窄的适用域 |
| B：合成完整 post-response 前缀量 | 收场 owner 用当时适配函数 φ 将本次 output 转成预计回放量，响应记录 `I+φ`、精度、输入/输出共同边界；下一轮直接在它上面加新增 | 原回复完整选入且原前缀、依据均未变时，完整 post-response 值可复用；estimated 永不升级 exact | 下一请求可能未选全部回复、被 veto/consumed、只选可见块，写时未必知道；写入者必须持有 φ 并绑定未来投影。I 是实测但 φ 是估计时合成量整体降级；要恢复 I 的独立价值需另存/引用输入事实。读方简单，写方耦合大。只在写时已固定完整后续回放域、φ 语义稳定时有利 |
| C：输入锚＋同次输出组证据，规划时解释 | 同次响应记录输入 observation、固定投影身份、依据及已接收输出组的来源/完整性关联；已有 output/reasoning usage 保持唯一事实来源。下一规划用显式版本化 φ 解释被选回放组 | I 的实测精度单独保留；φ、新增 δ 各自分级；输出未选入不计，来源不全不伪精确；两类变化全量回退 | 规划比 B 多一次窄 φ 调用，需校验同次输出组/块顺序/身份。不建立逐块精确账，不存每个 signature 的猜测 token；耐久证据不必携带实现 closure。未知 φ 仍可能 unavailable，不能靠候选形状消除事实缺口 |

## 推荐与改票条件

作者推荐 **C**：它保留上游已知输入事实，同时把依赖“这次实际怎样回放”的判断放在本次规划。并不要求 C 新建插件、计量数据库或每条消息的精确 token 分摊。响应载荷复用 usage/route/reply 的已有事实，新增的只是当前接口缺少的来源与对应关系。

若证据表明目标范围新增内容全部可被廉价 meter 独立覆盖，且调用者本已有可信输出关联，可改为 A，删除没有边界价值的输出组载荷；不能一面依赖 opaque 输出 usage，一面把它的关联责任留空。若未来需求把后续回放域在写入前完全固定，且 φ 可准确稳定执行，B 才可能减少读方工作；当前回复处置与下次组装存在独立变化，不满足该前提。

依据：百万 token 现有 meter 单次 warm 中位 3.490s，说明避免反复处理稳定历史有实际收益；该性能观察不区分 A/B/C 的上游正确性。区分正确性的证据是输入锚精度、φ 回放映射与来源匹配的正反场景，尚待后继规格和提供者验证。推荐不产生采用。
