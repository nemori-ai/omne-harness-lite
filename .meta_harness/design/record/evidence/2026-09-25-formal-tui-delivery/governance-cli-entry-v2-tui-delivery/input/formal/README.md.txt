# TUI有限交付交错模型（候选）

两个界面修订、至多一个目标、输入完成/实际输出/业务完成与CG静止独立。验证可见预览后确认、真实输入/输出与CG结束后恢复/释放、退出后无旧重绘；五个突变各有可触发性质。队列容量由模型形状直接限制，因此不把它绑定为容量证明，真实输出上界须实现测试。

假设最终EndPaste/FinishWrite/FinishWork/CloseCG/Restore/Release弱公平，来源帧可信、模式恢复是已确认的抽象完成事件。不能从该模型证明模拟器身份、粘贴来源、UTF-8、所有异常close会成功、模式控制IO或无限输入也有界退出。普通业务语义归CG，不在此重建。
