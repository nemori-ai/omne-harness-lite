# 有限使用生命周期

UseLifecycle抽象一整次固定original登录的使用、最多两个顺序调用、外部选择变更一次；网络完成与本地结算分开。对应S2固定身份与关闭准入、S3远端/本地不合并、S11资源保有。valid检查FixedIdentity、NoLateAdmission、NoEarlyRelease、RemoteTruth及在可调度/步骤最终结束的公平前提下EventuallyClosed。

四负控分别允许跟随外部新选择、关闭后再准入、网络完就释放本地依赖、把本地失败改写远端结果。各应触发对应不变量反例。持久CAS归CLS1模型；这里不重证它，不含密码学、OS/SQL/真实网络取消、缓存权限依赖、秘密过滤或所有31路由，不冒充全系统证明。规范场景与真实组成测试承接这些范围。

执行记录在版本外verification链接；模型文件存在不代表已运行或已接受。
