# D-114：Cordis 集成约定，与服务定义全部放 `core`

本项目做出来的东西怎样以 Cordis 插件与服务的方式接进系统，这份约定的接受记录；同时把能力接缝的 Cordis 服务定义一律收进 `packages/core/`。

- 输入与下游：来源是两份研究（DSH 的 Cordis 集成约定、架构判断辅助）与约定正文 [`realization/cordis-integration-conventions.md`](../../../realization/cordis-integration-conventions.md)；下游是实现映射区的布局、红线与节点模板、realization-drafter 的输入、手册的映射行。
- 范围定位：只接受约定与 `core` 的收录范围；不迁存量代码、不改任何契约，读数另行交付。

## 准入核对

有权者：负责人（产品与架构负责人）。接受记录：2026-10-02 访谈里的逐条裁定与同日对主会话自主推进的授权，原话与时间在[决定正文第一节](decision.md#一裁定原话)。精确修订：约定正文在本记录入库的那次提交。取代：两层布局里 `core/` 的收录范围，见[第四节](decision.md#四取代与影响)。
