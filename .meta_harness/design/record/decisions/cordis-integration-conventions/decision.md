## 三、理由与保留前提

- **定义只有一处，接缝才是真的。**今天服务键与接口写在提供者包里，消费者为拿它们 import 提供者——32 对注入边里 14 对因此同时是 import 边，`storage`、`clock` 的键常量各有三份。定义进 `core` 且键只写一次，换提供者不用改消费者。
- **以 DSH 为起点，只改有理由改的。**17 条里照用的照用；改的地方各有一条可复核的理由（例如 DSH 的补丁函数遇到找不到的行 id 只告警，运维者写错一个 id 会静默不生效，约定改为启动失败）；不取的单列。
- **约定写装配，不写契约。**它不进 `spec/`、不改任何契约语义，符合 D-112；它依赖的内核行为都有 basis 条目与在 4.0.4 上通过的 probe。
- 保留前提：约定核于 `@deepseek-ai/cordis` 4.0.4 与 DSH `639ed015`；Cordis 升版时先跑 basis 的全部 probe，失败的条目对应的规则跟着复核。

## 五、主会话自定的几处

负责人的裁定没有直接说到、由主会话按裁定与证据定下的。负责人不同意哪一条，改那一条即可。

| 处 | 主会话的定法 | 理由 |
|---|---|---|
| 定义包的粒度（IC-1） | 一份能力契约一个定义包 | 契约是带版本的语义单位；按领域合成一包会让不相干的契约一起变，全放一包则谁都依赖全部。客户端专用的接缝（`clientLocalState` 等）照样进 `core`，是 R6 的直接后果 |
| 没有能力契约的接缝（IC-1、IC-3） | 定义放进拥有那份协议形状的 `core` 包（`storage` → `core/storage`，`clock` → `core/offer-expiry`），JSDoc 写 `@owner` 代替 `@contract` | 这两个接缝被依赖最多，必须有家；放进形状的拥有者，不另开 `core/clock`（会与 `infra/clock` 撞名） |
| 定义包与提供者包的名字（IC-7） | 定义包取契约名；提供者包取限定名（`session-log-jsonl`），只有一个提供者时也一样 | 采用 DSH 的 shell 接缝做法（`dsh-shell` ↔ `dsh-bash-local`）；被 import 最多的是定义。代价：7 个已建包要改名并连带节点目录与链接，清单写在约定里 |
| 键怎么写（IC-2） | `static readonly provide = '键'`，构造函数 `super(ctx, <类>.provide)`，导出的键常量取自它 | 一处字面量；自建加载器与读数不实例化也读得出 |
| 一个插件提供几个键（IC-2） | 插件体里逐个 `new` 各键的子类，登记都在这条插件的 fiber 上；也可一个键一条 fiber，按撤除与在途语义选 | 已接受的多面节点（组织治理、账号身份、模型档案目录、资产治理）都是「一个插件、一条 fiber、几个服务面」；补了 probe 证明前一种做法成立 |
| 契约词汇的纯函数（IC-5） | 放定义包根入口；跨成员 import 的例外只有同一提交的事务内读函数，声明时写出共同存储对象 | 不然例外会成常态，读数失去意义 |
| 运行时对象（IC-1、IC-16） | 不进插件树；装配入口 provide 成服务、插件 inject，定义放在拥有那份形状的 `core` 包 | 插件树只放可序列化的数据，才能分层打补丁与打印；代价是 `storage-sql` 等三个节点的配置形状要出修订 |
| 事件命名（IC-10） | `<声明它的包名>/<事件>`，跨成员事件取定义包名；通知用过去分词，控制用动词原形 | 范围取包名唯一且能机检；时态区分通知与控制 |
| 通知的失败（IC-12） | `emit` 的监听者不得返回 Promise；要等异步监听者用 `parallel`；两种都由发起方包住 | `emit` 包不住异步监听者的 reject，`parallel` 会把它抛给发起方 |
| `inject` 允许键常量（IC-8） | 字符串字面量或从定义包 import 的键常量 | 键只在定义里写一次，常量就是对那一处的引用；DSH 只许字符串字面量 |
| 悬空补丁（IC-16） | 启动即失败；发行层的行 id 是对运维者的稳定承诺 | DSH 只告警，写错的 id 会静默不生效；宁可升级时大声失败 |
| 加载器（IC-16） | 自建 | SYS-KERNEL 只采用 Cordis 本体；DSH 的 `cordis-plugin-loader`／`-include` 要引入须另立采用决定 |
| 编号族 `IC-` | 登记进 `registry/id-namespaces.json` | 读数、核对表与评审按编号引用 |
