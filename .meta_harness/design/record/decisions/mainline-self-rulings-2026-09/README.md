# D-040：主线在自驱授权下的自定裁决汇编（2026-09-23 夜～2026-09-24）

产品负责人 2026-09-23 晚离开前授权设计主线**自驱推进计划全部阶段**：真正待裁的单列等他回来，过度设计与过早引入的复杂度剔除，
经调研或 subagent 讨论后能裁的自决。此后到 2026-09-24 晚，主线为让起草与修订不停在「等一句话」上，作出了一百余条裁定，
逐条附推理链记在任务区账本，并已落进候选契约与产品正文的「主线裁定，待产品负责人确认」处。
本决定把这些裁定**逐字**搬进设计链，作为那类依据的长期落点——任务区会被清理，契约里的依据不能指向一个会消失的地方。

- **输入与下游**：任务区账本 `tmp/assets-runtimes/pending-user-rulings.md` §二、§二′（主线自定行）与简报 `briefs/spec-revision-2-2026-09-24.md`「主线裁定」表（均为过程材料，原文已抄入[决定正文](decision.md)）；下游是本程全部候选契约里标「主线裁定」的条款、产品正文里标「主线裁定 2026-09-2x，待产品负责人确认」的 decisions 条目。
- **范围定位**：只解决「主线在授权范围内定了什么、凭什么」。**不解决**：产品负责人当场裁过的（归 [D-039](../assets-runtimes-split-and-rulings/README.md)）、契约条款本身（归契约）、这些裁定是否被追认（留产品负责人）。
