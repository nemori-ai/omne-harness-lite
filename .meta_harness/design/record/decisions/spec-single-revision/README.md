# D-113：规格只留最新一版——路径去掉版本号，原地修订，修订号记在登记里

负责人 2026-10-01 裁决：规格**永远只保存最新一版**，被覆盖的旧版及时丢弃，形式化的正版持续维护；规格仍是权威。
本决定记下这条裁决落成的长期规则（终态）、到达终态之前的过渡规矩与分批，以及它取代了哪些「旧版保留」的规则。

- **输入与下游**：来源是负责人当日的裁决、[现状盘点](inventory.md)与三份[独立评审](reviews/README.md)；
  下游是[规格区](../../../spec/README.md)与[身份清单](../../../registry/README.md)的规矩、检查器、每一份契约的每一个消费者（依赖它的契约、实现映射的绑定、需求覆盖、形式任务、投影、读规格的测试与随包的 Schema）。
- **范围定位**：定方向与过渡规矩。**不表示**切换已经做了：现在树里仍是带版本号的目录、65 个旧版都还在，检查器仍按「冻结字节不可改」判；
  迁移是一场要另立方案的工程。
