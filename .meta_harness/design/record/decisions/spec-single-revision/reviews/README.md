# 三份独立评审：终态取哪一种

「规格只留最新一版」落成长期规则有两种终态可选，这属于基座级选择，按工作区的做法派了三位独立评审：
**同一份中立简报、强制二选一、各自到仓库里复核事实、互不相见**。

| 文件 | 评审者 | 结论 |
|---|---|---|
| [brief.md](brief.md) | 简报原文（主会话写） | — |
| [review-1.md](review-1.md) | Claude Fable 5.1，只读 | 选乙 |
| [review-2.md](review-2.md) | Claude Opus 5.5，只读 | 选乙 |
| [review-3.md](review-3.md) | Claude Opus 5.5，只读 | 选乙 |

三份都是原文，没有删改；文中出现的本机路径、会话临时目录是当时的工作位置。

**三份的反证互不重复**，这是把它们算作独立意见的依据：

- 第一份最重的反证是「冻结从机器保证退成流程保证」「旧字节在树里没有名字」「迁移推翻了目录结构不变的声明」。
- 第二份是「对账器没建成之前，响亮的失败会换成静默的漂移」，并指出组织治理纠缠的不是两条线而是一整簇（治理 v1／v2／v3、账号 v1／v3、时限 v1／v2）。
- 第三份是「一份正文容不下并存的候选，并行修订会撞号」，以及冻结边界从「整个版本目录」变成「按清单」后会漏登。

**简报的偏差**（评审指出，如实记下）：对乙多写了一句「本仓库已有这样一个对账器」的先例，而那个对账器只管产品 rev 的引用，
规格的对账器还得新写；对甲的描述漏写了「全部消费者包括别的契约的冻结字节」这个后果。两处方向相反，三份结论都是在指出它们之后给的。

评审是意见，不是接受；接受了什么见[决定正文](../decision.md)。
