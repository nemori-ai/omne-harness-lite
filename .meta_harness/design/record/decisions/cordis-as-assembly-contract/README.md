# D-112：Cordis 是装配时要满足的契约规范，不是建模的视角

负责人 2026-10-01 重定内核的定位：**Cordis 仍是内核，是全系统集成装配时要满足的契约规范；领域与能力独立于它建模。**
本决定记下这条裁决、它取代了哪些「以 Cordis 为视角」的说法，以及设计手册主线随之怎样改。

- **输入与下游**：来源是工作区 `research/clean-code-doctrine-current/` 的研究结论与负责人当日的裁决；
  下游是 [SYS-KERNEL](../../../foundation/cross-system-constraints/requirements.md#sys-kernel)、`harness-design-handbook` skill 的主线与评审判据、
  做架构与规格设计的角色、[产品区的约定](../../../product/AGENTS.md)与投影模板。
- **范围定位**：只解决「Cordis 在设计方法里处在什么位置」。**不解决**：Cordis 的采用边界与版本（归 SYS-KERNEL 与 [D-025](../cordis-adoption-version/README.md)）；
  任何契约、节点或实现的接受状态；已有架构材料的重写。
