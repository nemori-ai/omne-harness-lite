# 验证义务与方法

本页维护节点验证义务、责任与方法限制，不维护执行台账。规范与采用版本从契约及本节点 design 读取；实际实现从成员入口读取。结果、配置和反例留工作树 tmp。下列义务列出不表示实现、检查或接受完成，未决语义按原 owner 接续。

契约验证义务归 [AI](../../../spec/capabilities/account-identity/verification.md)、[OG](../../../spec/capabilities/organization-governance/verification.md)、[AR](../../../spec/compositions/account-registration/verification.md)、[OE](../../../spec/data/offer-expiry/verification.md) 与 [entry](../../../spec/compositions/governance-center-entry/verification.md)。装配义务由本节点 design 的范围产生，不从已有测试反推。

## 覆盖缺口

- 启动失败日志逐阶段核恰一条、点名失败项且不含值：config、配对自检、遗留快照恢复、只读核对、建快照、迁移、fiber、钟不可读、恢复快照分别构造，不用其他失败阶段结果代替。
- AI S-43/OG S-54 的联合夹具须实际同一文件/外键、两个独立连接，夹具若属宿主产出需自测。LoginStateId 部署唯一须实际撞 login_state 主键，不用其他约束名覆盖。
- IV 装配给表未有精确条款编号时保留它的结构义务，不凭绑定缺失消除责任。pg 迁移单事务与迁移后启动失败撤回分开：U-3 后者须 pg owner 定手段，部署前闭合；不能以 SQLite 快照证明 pg。
- U-5 确认删除已生效而目录落盘失败若无故障点则保留方法缺口。U-4 确认后开闸失败按现行有限结果：无已确认提交丢失、旧版不能再起、重启先核钟；不另外承诺这一支旧版可起。
- 私钥 config/store 搜索只有窄边界，同进程 fiber 树可达不构成硬隔离。NORMAL 无断电级保证；FULL 也须真实断电夹具，跨 OS 和方言结果分别判读。租约表外部删除、生产库被非守卫实例打开属于运维前提，节点不能检测。
- config 校验产出的对象与守卫/openSignal 同引用属于装配机制前提，须来源核对与能失败的实际探针。清扫节奏、中心资产入口不可达、跨进程锁/时间顺序及 clock 严格时刻按当前 owner/gap 接续。
- 后继资产/档案的追加迁移、装载/撤除顺序、清单配置失败不泄露值、官方记录幂等重登与同一存储约束域分别演练，未采用候选不能仅由本页授予采用状态。中心无资产事件订阅者须静态负控和开闸前真实监听集合核对。

## Docker R5 停止绑定验收

最终 helper 须核显式 SIGTERM 配置与真实容器一致，running/restarting 单次请求，完整 wait 值与同 ID 退出一致；空值、矛盾、丢回执为 unknown，初始 exited 不重启。启动失败始终非零且 stderr 保留收场事实；维护取消与实际完成竞争按原结果结算。与长 IO、close 残余、第二 owner、timer 和重建治理组合验证，机制实验不能代替产品路径。

## Docker 制品与恢复的验证边界

- 正常安装、坏配置矩阵、TLS、真实 Unix socket、跨 OS 治理和重建分别核实际制品身份。具名模拟 amd64 不等于原生 amd64；私有 Engine 的运行不等于物理网络验收。原校验函数拒绝额外挂载不自动证明完整 start 拒绝。
- 在线备份须真实 FileHandle、并行业务与隔离拒绝、调用者消失后的查询；不能外推为物理设备 EIO 或任意断连时序。
- 停止/重启、exit0/exit1、健康过期、锁交错须同一确切容器 ID；同 schema 换镜像不证明新 schema 迁移、失败升级或断电。任务真实完成前资源保持，同根 busy，不同根独立；unknown 不被后续查询改写，也不得重发原请求。
- Engine 离线 timer 不拉起 Engine 或已停止中心。中心 SIGKILL 与 Engine 意外退出后的恢复分别核已确认治理、原备份与快照隔离；显式恢复 Engine 不证明宿主自动启动或 Engine 损毁灾备。
- 健康探针须同进程绑定 PID/连接、严格期限和输出边界；外层 Docker 超时与服务端取消分别观察资源回收。内部计时器不保证强制中断永不结束的模块加载；改变 index 的传递依赖、导入副作用或探针进程模型时重核加载、退出、期限和回收。
