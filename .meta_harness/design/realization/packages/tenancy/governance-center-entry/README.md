## 能力与边界

入口与运维是同包的两张网络面，装配安排同起同停。入口提供 TLS 监听、封闭的业务路由、认人、判定次序和答复映射。运维面使用本机 Unix 套接字，只消费存储、时钟及公共维护资源，不引用治理服务。业务路由、只读运维和静态导入边界保持独立。

构造不执行 I/O。setup 启动资源并等待时钟可读，超界沿具名错误失败。就绪不等于开闸，两张网络面在新准入处直接检查同代 EntryOpening。确认、开放和依赖保活由宿主拥有，运行回调与完成句柄不进入序列化配置。

停止先关闭准入，随后等待真实业务、维护和 setup 前缀结束，再释放本实例资源和订阅。网络排空上界不能代替实际业务完成。重复 close 观察同一个稳定 Promise，启动与清理同时失败须保留两个错误。旧提供者的完成责任不得转交新实例。

31 条路由、租户拒绝、同提交、改密准备和最终重核保持原语义。认人只通过出示物交换，不以线上 `LoginStateId` 认人。注册保持三个独立提交。协议投影、矛盾检查、校验、编码、最终活动、真实提交和字节交付的次序不变。

中心标识由占位行读或铸。已铸合形才可复用，读写失败、缺行或非法值须区别收场。表丢失由迁移前核对阻挡。本包只碰自己的中心表，不能防止其他写者把已铸值改回 NULL，或把仅含占位行的新表拼入已有事实。此边界不能提升为完整防篡改保证。

## 分层状态与责任

已迁工厂、绑定、准入、资源和通知以模块旁 SPEC 为准。未迁操作、失败和协议条款仍由精确 EC/HT 源约束。接受、实现与验证分别判断，文件存在或静态图符合不授予业务验收。

TLS 证书链与私钥是部署配置，客户端防冒充确认、中心标识比较、“问不到”的呈现和据点副本归客户端。入口 G-2～G-4、G-7、G-8 的未承诺部分继续按 [缺口表](design.md#实施缺口与消费者影响)处理。载荷内部重复成员的延伸读法 N-3 不能被结构迁移静默提升为契约新条款。运行中时钟回拨归时钟提供者。

旧 N-18 的等钟错误定位从现行公开 `GovernanceCenterClockTimeoutError` 及提供者 SPEC 读取，不再要求装配靠旧说明文本识别。装载顺序、迁移合成、预检、配置来源、日志、撤除总观察阈值、确认与开闸及 serving 观察上界均归 [宿主 SPEC](../../../../../../apps/tenancy-host/SPEC.md)，不由本包独立测试代替。

## 固定 Schema 与维护

[固定图装配](fixed-schema-precompile-design.md)只改变编译与加载时机，保留原契约、领域拒绝、返回值和租户保证。固定图构建、新鲜性、失败清理及首次实际消费时的同步原生加载须按其验证义务检查。SC-2 继续约束 Schema 输入叶子，有限生成物入口不放开其他治理或写入依赖。

维护沿 [维护设计](maintenance.md)与现行提供者 SPEC。资源保持同 fd 稳定检查、不可撤销发布、未知耐久、残余报告和清理错误优先级。首次工作根创建须串行，原位源变动的精确 hash/fstat 分支仍须独立验证。恢复仅保持隔离，同机备份不涵盖整机或磁盘毁损。

## 验证与阅读入口

[验证义务](verification.md)规定决策、字节、framing、JSON、transport、中心身份、维护与生命周期的范围。须用真实 TLS、Unix 套接字、SQLite 文件库和实际参与者组合，答复字节与传输实例逐字节比较。形式正配置和负控分别核对，它们只检查契约模型，不证明本节点源码。

[绑定表](bindings.yaml)只在逐项前提成立时适用，不能把旧版本或历史制品范围自动提升到现行实现。静态检查不能证明事务、租户授权或真实关闭。CLI/TUI 的终端范围归客户端，任意终端支持、实际公司部署、Agent 工作会话和 Web/desktop 不在本节点有限验证范围。

当前契约由实际拥有者维护。候选比较、接受过程和每次执行结果留本工作树 `tmp/`，不在本页维护运行台账。
