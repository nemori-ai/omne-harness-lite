验收沿 v4 的核心四组，并以以下范围替换历史入口验收：清空 dist 后 build/typecheck/test；MP5 全定义真实 Schema 编译；当前快照完整保留和无损数反例；旧运行入口 import 失败；MP2 规范资源供真实 LC6/MR7 固定闭包成功编译；旧 shape 在当前接收边界拒绝且用户数据未改；README/README_ZH 仅演示当前执行面。资源能导入不表示支持旧调用。
