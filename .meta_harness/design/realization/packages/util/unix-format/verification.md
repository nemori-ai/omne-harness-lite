# unix-format 验证与证据

## 验证范围与限制

验证资源覆盖公开入口的正反例、边界、独立 oracle、构建后的包名消费及类型负例。有限输入的跨语言比较不证明所有输入行为相同；已采用的格式差异以 design.md 为准。主动 toXml 的合法性和业务格式选择归调用者，不由本包扩大；本包不因格式化验证引入 timeout、brand 或 core 业务政策。
