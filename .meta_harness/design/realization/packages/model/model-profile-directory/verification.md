## 覆盖缺口

- **没有任何证据**：全部义务未开始；取值问法与 P-1r 两处受阻（MPD-N1、MPD-N2）。
- **离线用据点副本调模型**（PF-016 §6.17／§6.20）在保管方缺席的本版没有兑现，只能证「如实收成 `credentialUnavailable`」那一半。
- `bindings.yaml` 为空，与本页一致：没有一条契约承诺已有会失败的证据。
- R-2 在 pg 上的兑现（范围键非空、唯一约束覆盖已撤回行）只有在 pg 上跑 S-26 才算覆盖；sqlite 上的通过不代表 pg。
