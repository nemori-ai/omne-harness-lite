## 覆盖缺口

- **没有任何证据**：全部义务未开始；行为模型未建（G-14），场景受阻于会话日志提供者与装配清单读面。
- `bindings.yaml` 为空，与本页一致。
- **执行环境句柄解析出真值**要等两样来路有提供者（契约 G-20），在那之前只能证「解析失败时不给默认」那一半。
