## 覆盖缺口

- **没有任何证据**：全部义务未开始。导入那一半与映射表是纯函数，有实现即可测；兼容件被调到的全部场景受阻于执行环境（HI-N1）与 runner 的会话日志；句柄解析不出、中止即停这两支可用替身先跑。
- `bindings.yaml` 为空，与本页一致。
- **真执行环境上的停与确认退出**（超时、撤除、取消三种来源）要等执行环境那一侧有提供者；本机进程组替身只证执行器这一侧的次序。
