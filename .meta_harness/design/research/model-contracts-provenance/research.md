# 模型档案历史候选：可继续消费的结论

- 档案身份、来源、revision、撤回状态与路由约束应稳定可引用；official/customized 不等于授权。
- 模态、工具、参数、窗口和价格是有来源/时间/修订的能力事实，声明等级不能替代真实支持。
- OpenRouter provider allow-list 与 fallback 意图属于请求约束；档案本身不发送请求、不拥有 Session 选择，也不证明实际出口。

旧候选以 `(tenant_id,routing_name)` 和“同名 relist 复活身份”描述生命周期；当前 MC-01 采用不复用
profileId 和新 revision，因此该旧行为只保留为被取代的来源差异。历史 Schema 的 aptitude 九键、
revision、授权、唯一性和跨 tenant 引用均不完整，不能进入新 catalog。
