# 个人长期运行 Agent 产品研究（2026）

本主题集中保存 Meta AI Muse 与 xAI Grok Bot 的产品研究。根目录拥有两个已取证产品之间的
**比较判断、适用范围和未决差异**；产品子目录各自拥有原始观察、证据 URL 和产品级未知项：
[Muse 专题](meta-ai-muse/README.md) 与 [Grok Bot 专题](xai-grok-bot/README.md)。

- 调查对象与基线：2026-09-16 的 Meta AI Muse（`ai.meta.com/muse/`）与 xAI Grok Bot
  （`x.ai/bot`），均以各自一手公开资料为证据边界；不是性能评测、渗透测试或采购建议。
- 消费者：后续个人长期运行 agent 的能力覆盖、运行时/持久状态、外部工具授权、记忆与用户治理
  设计；不直接接受产品选择、规格或本项目实现映射。

## 准入核对

两项产品都公开主张“长期工作、外部工具和人类审批”，但对工作环境归属、跨 agent 隔离、授权
执行点、状态删除和产品可用性的事实不同。这些差异会持续影响后续能力边界判断；集中为一个主题
不会合并各产品的事实拥有者，原始 URL、访问日期和产品级未知项仍由对应子目录唯一维护。
