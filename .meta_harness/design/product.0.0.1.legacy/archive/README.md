# 已退役的产品设计

这里保存**不再有效**的 topic 原件。当前为空。

## 退役的规矩

退役是一次**明确的动作**，不是「不再维护」的默认状态。
一个 topic 只有在其全部内容被另一个 topic 吸收时才退役；
**部分被吸收的不退役**，它修订自己的范围并继续存在。

退役时做四件事：

1. 取代它的 topic 在 `README.md` 的 front-matter 声明 `supersedes`
2. 旧 topic 整个移进本目录
3. 旧 topic 里加 `RETIRED.md`：退役日期、被谁取代、**条款级去向映射**
4. 旧 topic 的原件**不再修改**——包括其中已知的错误

第 3 步的映射不可省：退役前被引用过的每条内容都要能查到它现在在哪，
否则历史引用会断在半空。

第 4 步的道理是：错误的记录同样是历史。修正写进取代它的那个 topic，
不要回去粉饰旧的。

## 归档后的地位

- **是**：历史事实的原件，可查当时确认了什么、由谁确认。
- **不是**：有效的产品设计。归档的 topic 不驱动任何设计，
  其内容不得被引为依据，也不计入覆盖关系。
