## 使用与维护

- 实施者读当前版本的 `projection.md` 即可取得全部设计输入；
  按当前条款引用回到各权威正文；投影不保存来源快照或形成史。
- 本视图是**某一时刻的派生快照**，不是权威。与上游不一致时以上游为准。
- 需求变更或设计变更导致内容不再成立时**发布新版本，不原地改旧版**——
  正在照着旧版实施的人必须仍能找到他实施的那一版。
- 旧版本保留并标注被谁取代；不删除。
