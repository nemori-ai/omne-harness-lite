## Slash、技能与键盘控制

**IN-01**：SlashCommand 是独立定义资产，绑定精确 Skill/Prompt 及参数
Schema、作用域和效果类型；来自所选 definition/plugin 版本的命令目录
按当前权限披露。命令词法仅作用于输入开头，命令名为 ASCII 字母起始、
后续字母/数字/下划线/连字符，最长 64 字符；多命令以显式 ` /` 起始的
下一命令分隔，参数用一个完整 JSON 对象表示，后续 ` -- ` 后为普通正文。
JSON 对象按标准 JSON 解析其字符串/括号，不靠空格猜测边界。最多命令数
为可查询有界配置，缺省 8；该数为本版本的可配置实施默认，不是来源产品要求。

例如 `/review {"depth":"short"} /style {} -- 请检查此文` 产生两个有序
上下文装载意图和一份普通正文。未知命令、非法参数、数量超限、失效引用
整份输入在受理前拒绝；用户显式选择 literal 模式可原样发送以 `/` 起始的
文本，错误解析不自动回退聊天。上下文装载型意图随同一普通输入耐久
排队／取批，固定定义和内容引用；实际使用仍重检，禁止从命令执行任意代码。
系统控制/有序命令按 Session SE-07 与 Run RN-03/RN-05 的已登记操作进入协议，不把所有 slash 限定为
上下文装载。语法不等于模型的多命令工具参数范式。

**IN-02**：keyboard binding 归全局用户账号设置，客户端按平台能力读取。
绑定必须显式保存目标种类、稳定定义引用、目标对象或作用域、参数和设置 revision；目标可以是
具名 Session/Run 控制、获准命令、Skill 装载入口、命令目录入口或具名交互流程。按键只选择这份
显式绑定，不把键名、显示文案或客户端缓存解释成权限、宏、slash 文本或任意脚本。

控制类绑定固定用户当时观察的精确 Session/Run 与 observed epoch，沿当前授权和
`capability.run@1` 的 RN-03/RN-05 受理；旧目标结束返回 stale/ended，不能重定向到后来工作。
命令、Skill 或流程类绑定等价于用户显式发起其目标：重新解析当前定义/选用/参数和权限，沿
Session SE-06/SE-07 的受理、排队与去重规则；它不伪造 slash 输入，也不能跳过目标自己的
准入、预算或人类决定。目标失效、来源缺席、设置冲突和结果 unknown 分别明确返回。

按键捕获和服务端受理分开记录，受理回执与实际结果分开呈现。冲突／不支持／系统保留键明确
呈现，不自行改键；输入法和文本选择上下文优先按客户端声明处理，所有绑定都有等价显式入口。
UI 渲染和捕获实现属于后续应用装配。
