# 能力契约

本目录按 `<topic>/` 保存能力契约信息包；新主题使用 [本地规格模板包](../.templates/capability/README.md)。
先读包入口，按需要读取精确版本正文、模型或版本外证据；模板占位不成为可采用契约。

只有能独立解释责任、承诺和变化边界的能力进入这里；内部算法、提供者类或通用关注点名称不足以形成能力。
若整体性质不能归属单一能力则转 compositions；责任仍未定时返回能力覆盖分析。

从实际子目录、[规格入口](../README.md)及唯一 catalog 发现精确身份、版本与接受依据；
本目录索引只导航 topic，不维护另一份版本或接受清单。空索引表示尚未取得对应采用范围。
