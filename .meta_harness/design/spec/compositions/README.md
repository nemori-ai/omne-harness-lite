# 组合契约

本目录按 `<topic>/` 保存组合契约信息包；新主题使用 [本地规格模板包](../.templates/composition/README.md)。
先读包入口，按需要读取精确版本正文、模型或版本外证据；模板占位不成为可采用契约。

只有跨能力整体性质、责任交接或合法交错不能由任一单项能力独占时进入这里；仅汇总依赖不构成组合契约。
参与方版本、保护者或失败后接续责任不明时停止发布，先回能力契约或提案闭合。

从实际子目录、[规格入口](../README.md)及唯一 catalog 发现精确身份、版本与接受依据；
本目录索引只导航 topic，不维护另一份版本或接受清单。空索引表示尚未取得对应采用范围。
