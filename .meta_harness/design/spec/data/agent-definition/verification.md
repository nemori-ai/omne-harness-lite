## 对齐义务

- `AssetReference` 与 `capability.asset-evaluation/v3` S-6、S-7 C14 的既有形状与集合约束逐字对齐；按 registry M2，只作定义性引用，不登 data→capability 依赖。本包 S-3 自足声明本窄投影的纯值规则；后续消费者单向采用本 data 投影，不再起同义字段或赋予数组次序含义。形状变化须共同演化版本，不原地改已冻结 v3。
- `AttributeDeclaration` 直接 `$ref` `data.asset-model/v3`，没有副本；Duration 与 RouteName 分别直接引用其家，规范域 JSON 中的绝对 `$ref` 也指向相同定义。
- 新调用方须显式采用本包，不以现有 `asset-model/v3` 壳校验已通过来主张可以解释 body。通用正文不透明限制与本窄规则采用的边界要在整批独立评审核对。
