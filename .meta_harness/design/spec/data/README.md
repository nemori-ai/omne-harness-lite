# 数据契约

本目录按 `<topic>/` 保存数据契约信息包；新主题使用 [本地规格模板包](../.templates/data/README.md)。
先读包入口，按需要读取精确版本正文、模型或版本外证据；模板占位不成为可采用契约。

只有多个能力或消费者共享且必须保持同一含义的身份、值或关系进入这里；单一能力内部表示留给其能力或提供者。
消费者与规范含义无法明确时停止建包，先定位语义拥有者。

从实际子目录、[规格入口](../README.md)及唯一 catalog 发现精确身份、版本与接受依据；
本目录索引只导航 topic，不维护另一份版本或接受清单。空索引表示尚未取得对应采用范围。
