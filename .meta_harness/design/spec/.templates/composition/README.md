## 版本包

`v-next/` 是待命名的候选版本目录占位，复制后按实际版本规则改名并同步所有引用，不能作为发布版本。
必要的 Schema、Alloy、TLA+ 行为模型和规范场景按性质加入同一版本目录；未选用时无需空文件。
`formal/` 提供可选论证入口，按需要加入 TLA+、TLC 检查输入的引用、Alloy 或证明映射；
未选用时可删除该目录并移除本页导航，已触发的证据义务仍须满足。
所有已发布规范工件保持不可变；追加规范模型也需新版本，执行记录留在版本目录外。
本入口只导航接受/采用依据，不代替唯一 catalog；推荐版本不会自动升级消费者。
