## 版本与证据边界

用于定义规范的模型、性质及假设随规范版本冻结；已发布后增改规范工件需新版本。
执行配置、命令、原始输出、反例和证明结果在版本外保存，绑定实际模型与输入快照；
若某检查场景/配置本身被发布为规范工件，则同样遵守冻结边界。
实际结果由 topic 的验证入口导航，本页维护规范到论证对象的对应，不填随运行变化的通过状态。
