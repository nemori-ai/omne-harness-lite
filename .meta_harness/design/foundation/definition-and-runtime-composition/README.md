# SYS-COMPOSITION：定义、装配与活体

本信息包拥有 **SYS-COMPOSITION** 的当前确认范围；它保存需要兑现的结果与
明确未决项，不选择能力边界、Cordis 插件或提供者。

- 目标基线：`omne-harness-lite-design-2026-09-15`
- 来源：**本次新增确认**（2026-09-17），非从旧基线迁入
- 当前状态：C1–C5 已确认；机制边界一节的结论依赖尚未落地的 probe，标注为有条件
- 下游状态：能力覆盖、规格和提供者映射由后续纵线建立

一句话：**[SYS-DYNAMIC](../fully-dynamic-system/README.md) 是根目标，本条是据以达成它的组织方式。**
完全动态要求绑定能演化，而演化要有发生的位置——本条把那个位置定在**装配**这一段上。

```text
定义（数据）  ──装配(定义, 作用域)──→  活体（计算资源）
  不含绑定                                持有已捕获的绑定
  可复制、可迁移                          可回收、可重建
```
