# 桌面应用

本 topic 回答一个产品问题：给人用的第一个图形界面是什么，它有哪两面、人怎样在两面之间翻面、正面有哪几部分，人在每一部分能做什么、受阻时看到什么。它只定义应用这一层自己的事实。登录、会话、资产、设置、问题卡与画布的规则归各自的 topic，本 topic 引用它们，不重新定义。

正文依据产品负责人 2026-11-11 到 2026-11-13 对桌面应用的决定：第一种图形界面是桌面端，有登录、会话管理、设置、对话四部分；以及 2026-11-17 的决定：加「资产」一部分，资产自己的设置在那里改，「设置」只放不属于任何资产的设置；问题在对话页里作答；以及 2026-11-16 与 2026-11-18 的决定：资产这一部分对任何资产类别通用，人在里面看、新建、禁用、启用、移除资产；以及 「待负责人接受：日期与原话」 对观感与 agent 在屏幕上的形的决定：一个形代表 agent，四个字号档，随应用带中文字体。<!-- OD-9 -->以及 2026-11-24 的决定：画布作为应用的反面，人把应用直接翻过去看它，正面不为它设导航入口。以及 2026-11-25 的决定：形可以被拿出应用的窗口，留在桌面上，能回去，能被放到别的应用的窗口上看它；产品行为取自参考项目 super-assistant 的最新版。以及 2026-11-26 的决定：把这两次改造的配套补齐，扩展要一致：一套皮肤在应用画的每一处都算数，对 agent 说一句话只有一块笺，告知跟着形。正文是 draft，整体产品接受尚无依据。
