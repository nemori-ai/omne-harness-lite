# 桌面应用

本 topic 回答一个产品问题：给人用的第一个图形界面是什么，它有哪几部分，人在每一部分能做什么、受阻时看到什么。它只定义应用这一层自己的事实。登录、会话、设置与问题卡的规则归各自的 topic，本 topic 引用它们，不重新定义。

正文依据产品负责人 2026-11-11 到 2026-11-13 对桌面应用的决定：第一种图形界面是桌面端，有登录、会话管理、设置、对话四部分；以及 2026-11-17 的决定：加「资产」一部分，资产自己的设置在那里改，「设置」只放不属于任何资产的设置；问题在对话页里作答；以及 2026-11-16 与 2026-11-18 的决定：资产这一部分对任何资产类别通用，人在里面看、新建、禁用、启用、移除资产。正文是 draft，整体产品接受尚无依据。
