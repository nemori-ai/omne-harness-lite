## 执行与范围

可执行场景与装配前提见 [Agent 验收入口](../../../../packages/agent/agent/acceptance/README.md)。阶段 1 只核对完整普通回复、无工具空批和既有内部窄接续。工具、扩展、Session 与 Run 集成均不在该切片内。S2 核对台账认回，不包含阶段 3 的纯观察求值。

实际杀死的是执行子进程。内存 Journal、脚本 Model 与材料保管者在父进程中存活。场景不证明 Journal 宿主退出后的耐久性、公开 resume 或接管，也不表示全部 CAP 已实现。
