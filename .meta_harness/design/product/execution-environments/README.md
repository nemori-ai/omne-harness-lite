# 执行环境

本 topic 维护执行环境的产品后果、概念、能力状态、阶段承诺与未决。正文 revision 3 为草案。产品需求描述规定落点策略在执行环境之外求值、执行环境只在允许清单内匹配，并说明绑定层、连续性、环境要求、落点、设施、获取与租约、受管资源及恢复授权等概念。整体产品及技术接受尚无依据；正式维护位置不提升采用状态。已有明确规则继续保持，0.0.0 → 0.1.0 阶段里，产品负责人已选定里程碑 M1 支持的七项能力；其余未选择能力仍计缺项。
