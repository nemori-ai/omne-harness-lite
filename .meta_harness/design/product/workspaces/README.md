# 工作区

本 topic 维护工作区的产品后果、能力状态、阶段承诺与未决。产品与技术分解经过审阅，整体产品及技术接受尚无依据；采用更新时常驻工具保持形状的规则依据 [RFC-0012](../../../../docs/rfcs/RFC-0012-tool-dynamics.md) 及 [#618 的决定](https://github.com/nemori-ai/omne-harness-lite/issues/618#issuecomment-6314971717)写回；正式维护位置不提升采用状态。已有明确规则继续保持，0.0.0 → 0.1.0 未选择能力仍计缺项。
