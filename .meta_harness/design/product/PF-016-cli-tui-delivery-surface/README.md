# PF-016：命令行交付面

**这套系统的产品设计已经把会话、运行、卡片、受理定得很细，却没有一处回答「人从哪里进来」。**
本 topic 给出第一个[交付面](design.md#交付面)：**一个装在用户自己机器上的命令行应用**——
同事各自安装、注册、登录、被邀请进组织，在自己的机器上开会话、跟 agent 协作、答卡片、翻历史；
研发者用同一份东西把整条链跑完并留下可核对的记录。

**边界只有一句话：它是投影与入口，不拥有任何领域语义。**
屏上的每一条都指得回[会话日志](../PF-012-agent-loop-and-run/design.md#会话日志)里的一条；
人做的每一件事都走[已有的那两类路](design.md#54-人做的每一件事走的都是已有的路)。
账号、组织、邀请、隶属归 [PF-001](../PF-001-identity-scope-and-agent-constraints/README.md)；
会话怎么活归 [PF-015](../PF-015-session-lifecycle-and-ownership/README.md)。
**本 topic 不改这些概念里的任何一个，也不在它们之上另造一套**；
它新增的[五个概念](#关系)只回答一件它们没回答过的事——
**这些事实各自落在哪一侧**，以及人从哪一面碰到它们。
