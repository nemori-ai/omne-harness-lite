## 一处值得记下的对照

**同一个问题，两家做法正相反：**

| | 提醒的标签归谁 |
|---|---|
| **DSH** | **生产者**自己烘进内容，core 只做原样透传 |
| **legacy** | **框架**拥有转义，生产者伪造不了 |

**两家相反，恰好说明这是个真的设计选择，不是实现细节。**
本 topic 取第三条路——**它是一种类型，标识由系统在出门前加**，
理由见 [decisions 第二节](../decisions.md#二pm-推导)。
