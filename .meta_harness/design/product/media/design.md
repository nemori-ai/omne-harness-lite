# 媒体产品设计

采用范围见[topic 入口](README.md)。项目要求取 [requirements](../../../../docs/requirements.md)，责任边界取[媒体领域](../../../../docs/domains/media/README.md)。

## 产品需求描述

人和 agent 说话，不只用文字。一张截图、一段语音、一份 PDF，常常比一段描述更直接。agent 干活时也会拿到图片：它打开的一张图，它截下的屏幕。这些内容要可靠地保存，在历史里看得到，并且真的被模型读到。

模型的能力各不相同。有的原生读得了图片，有的读得了语音与 PDF，有的只读文字。人不应该为此操心：他只管把内容发出去，系统按当前模型的能力决定给它原件，还是给它一份转出来的文字，并且告诉人模型实际读的是哪一份。

这一份产品正文定义「媒体」：系统怎样保管非文字内容，怎样为它准备别的表示，人在哪里发、在哪里看。模型怎样选择与调用归[模型调用](../model-invocation/design.md)；一次请求里每块内容用哪一份归[Context](../runtime-context/design.md)；工具怎样产出内容归[工具执行](../tool-execution/design.md)与[元能力](../meta-capabilities/design.md)。

它是接在核心上的一块。一个部署没有开放它，文字的会话照常工作；带图片、语音、文件的消息发不出去，并说明原因。之后再开放，此前保存的媒体都在。

### 发出去

人在输入框里把图片贴进来、把文件拖进来、选一个文件，或者按住录一段话。命令行用附件参数做同样的事。内容先上传，上传完成之后才能随消息发出。上传中断了可以接着传，不用从头来。

每种媒体有大小上限，语音另有时长上限。超过时在上传那一刻拒绝，并说出上限是多少。声称的类型与实际内容不符的被拒绝：系统以内容为准。

上传的内容属于上传它的那个租户。别的租户读不到它，引用不了它，也无从知道它存在。

### 为它准备别的表示

一份媒体有三级表示：原件；另一种模态的表示；一段纯文字的兜底。后两级由转换件做出来，例如语音转成文字、PDF 提取出文字。原件永远保留，转出来的东西挂在原件上，不替代它。

人发的媒体在上传完成之后就做转换，不等到发消息，也不看当前用的是哪个模型。所以人在发出之前就能看到转出来的文字；转不了也在这时知道，可以重录、换一个文件，或者改成打字。

转换的结局有四种，人看得到是哪一种：

- 这种媒体没有生效的转换件：原件照常保存，没有文字兜底。
- 转出来了。
- 这份内容本身转不出：例如没有文字层的扫描件、没有人声的录音。原件照常保存，没有文字兜底。
- 转换失败：转换件此刻不可用、出错或超时。这份内容暂时不能随消息发出，人可以重试。系统不把失败说成「不需要转换」，也不用空白或捏造的文字冒充结果。

消息受理之后，它带的表示就固定了。之后转换件换了、升级了，已有的消息不重做。

### 模型读哪一份

每次请求，系统对每一块媒体按当前模型的能力依次试：模型原生读得了就给原件；读不了就给另一种模态的表示；再不行给文字兜底。图片超过模型的大小限制时，给一份缩小的版本，这仍算原件这一级。

三样都不行时，这次请求如实失败，并指出是哪一块内容，不悄悄跳过它。

每条带媒体的消息上标出模型这一次读的是什么：原件、缩小的图、转写的文字、提取的文字。转换会损失信息，系统不让人误以为模型看过原图。

### 换模型

会话中途换模型，历史不用重发。有文字兜底的内容，下一次请求自动换一份：从读原件的模型换到只读文字的模型，改给文字；换回来，又给原件。

一份没有文字兜底的内容，只有原生读得了它的模型能用。换模型时，读不了它的模型不可选，并指出是哪几块内容挡住的。

### 在历史里看

历史里看得到原件：图片显示缩略图，点开看原图；语音可以回放，旁边是转写；文件显示名字、类型与大小，可以取回。命令行里显示每一块的类型、大小与模型读的是哪一份。

### agent 拿到的图片

agent 用工具得到的图片，例如打开一个图片文件、截下屏幕，和人发的图片是同一种东西：原件被保管，模型直接看到。当前模型读不了图片时，这样的工具在原位显示不可用并说明原因，不先执行再丢掉结果。

工具产出的媒体不在产出时做转换。只有当前模型原生读不了它、而这种媒体有生效的转换件时，才在采用这个结果时转换。

### 转换件可以换

用哪个转换件处理哪种媒体，是一份[资产](../assets-and-rules/design.md)。发行版自带语音与 PDF 两份。组织与租户可以各自持有同名的一份来替换它，或者禁用它；换了之后只影响此后上传的内容。

一份转换件定义写明：处理哪种媒体，用哪个转换引擎，给引擎什么参数，内容会被送到哪里。内容要送出本机时，界面在转换之前说明去向。

转换引擎是可以装上、卸下的部件。一份生效的定义指向的引擎此刻不在时，这种媒体的转换答不可用，系统不退到别的引擎，也不当成没有转换件。

### 存在哪里

媒体的字节存在哪里由部署决定：本机的磁盘，或者一个对象存储。换存放的地方不改变上面任何一条规则。此前的引用继续有效。

没有被任何消息或工具结果引用的上传内容，过一段时间自动清掉。已经被引用的保留。

### 关键用户旅程

**J-ME01 发一张图片。** 人贴进一张截图，写一句话，发出。模型原生读图片：它读到原图。历史里显示缩略图，标「模型读的是原件」。

**J-ME02 发一段语音。** 人录一段话。上传完成后附件上出现转写的文字。人确认无误，发出。当前模型不读语音：它读到转写。历史里可以回放原声，标「模型读的是转写」。

**J-ME03 换到读得了语音的模型。** 接上一条，人换了模型再问一句。这一次模型听到的是原声，不重新转写。

**J-ME04 发一份 PDF。** 人拖进一份报告。上传后提取出文字。模型原生读 PDF 的读原文件，其余的读提取的文字。一份没有文字层的扫描件提不出字：只有原生读 PDF 的模型可选。

**J-ME05 转换不可用。** 语音的转换引擎此刻不在。人录完之后看到「转换暂时不可用」与重试；这段语音不能随消息发出。人改成打字，消息照常发出。

**J-ME06 agent 截屏。** agent 列出屏幕，截下第二块屏，接着描述屏上的内容。模型读到的是那张截图。

**J-ME07 租户换掉语音的转换件。** 租户的管理者在资产页的「转换件」里新建一份同名的定义，指向另一个引擎。此后上传的语音由新的引擎转写；此前的消息不变。

**J-ME08 没有开放媒体。** 部署没有开放它。文字会话照常；输入框没有附件入口；经协议发来带图片的消息被拒并说明原因。

## 能力定义

| 能力标识 | 定义与范围 | 需求位置 |
| --- | --- | --- |
| CAP-ME01 上传与保存 | 图片、语音、文件先上传再随消息发出；可续传；超限与类型不符在上传时拒绝；内容属于上传它的租户，别的租户读不到也探不出 | J-ME01、J-ME02、J-ME04 |
| CAP-ME02 原件保留 | 原件永远保留、永不改写；历史里只留引用，凭引用取到的始终是当初那一份 | J-ME01、J-ME03 |
| CAP-ME03 预先转换 | 人发的媒体在上传完成后转换，不看当前模型；结局分没有转换件、转出来了、转不出、失败四种，各自可见；失败不冒充成功；受理之后表示固定 | J-ME02、J-ME04、J-ME05 |
| CAP-ME04 按模型取表示 | 每次请求按当前模型的能力依次取原件、另一种模态的表示、文字兜底；图片超限给缩小的版本；都不行时如实失败并指出是哪一块 | J-ME01 至 J-ME04 |
| CAP-ME05 读的是哪一份 | 每条带媒体的消息标出模型这一次实际读的表示，与实际发出的一致 | J-ME01 至 J-ME04 |
| CAP-ME06 换模型 | 有文字兜底的内容换模型后自动换一份；没有的只让读得了它的模型可选，并指出挡路的内容 | J-ME03、J-ME04 |
| CAP-ME07 在历史里看 | 缩略图与原图、回放与转写、文件的名字类型大小与取回；命令行显示类型、大小与读的是哪一份 | J-ME01、J-ME02 |
| CAP-ME08 工具产出的媒体 | 工具产出的图片被保管，模型直接看到；模型读不了时工具原位不可用；只在需要时转换 | J-ME06 |
| CAP-ME09 可替换的转换件 | 转换件定义是资产，官方、组织、租户各能持有同名的一份；定义写明媒体种类、引擎、参数与内容去向；引擎可装卸；定义生效而引擎不在时答不可用 | J-ME05、J-ME07 |
| CAP-ME10 存放可换 | 存放的地方由部署决定，更换不改变规则，此前的引用继续有效；没人引用的上传内容到期清掉，被引用的保留 | J-ME01 |
| CAP-ME11 可装卸 | 不开放时文字会话照常，带媒体的输入被拒并说明原因；再开放时此前保存的媒体都在 | J-ME08 |

## 未决问题与待定事项

### 换模型时补做转换

一份没有文字兜底的内容挡住了某个模型时，系统是否在换模型的那一刻为它补做转换。要做它，「受理之后表示固定」这一条须写明：补做的结果是一条新的事实，不改旧的。范围没有裁定。

### 图片的文字表示

发行版不带图片的转换件。读不了图片的模型因此用不了带图片的会话。是否自带一份把图片描述成文字的转换件，没有裁定。

### 回收

被引用的媒体什么时候可以删除：会话删除时，还是另有保留期限。没有裁定；在裁定之前被引用的媒体一直保留。

### 按租户许可内容外传

转换件把内容送出本机时，是否要组织或租户先许可。没有裁定；在裁定之前由部署的装配决定装哪些引擎，界面说明去向。

### 转换的费用

收费的转换怎样进入[用量与花费](../usage-and-cost/design.md)。没有裁定。

### 视频与实时语音

视频的理解、边说边答的实时语音不在本 topic 的能力里。
