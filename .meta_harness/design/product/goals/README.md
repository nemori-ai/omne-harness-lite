# 目标

本 topic 维护会话目标的产品规则、能力定义及未决：人怎样给一个会话设一个目标，目标的正文写什么，agent 怎样围绕它推进，什么时候算完、什么时候该停，以及谁能设、改、暂停与取消。

## 阅读入口

- [产品正文](design.md)提供需求、能力定义与未决。
- [领域责任](../../../../docs/domains/goals/README.md)提供已接受的范围与协作。
- [包组规格](../../../../packages/goal/SPEC.md)维护逻辑责任、应然设计与不变式。

## 维护

产品负责人维护产品规则。技术拥有者决定成员归属、公开形状与采用。过程材料留在任务 tmp，正文不维护形成史。
