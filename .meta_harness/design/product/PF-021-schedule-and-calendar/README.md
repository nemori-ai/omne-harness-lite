# PF-021：日程与日历

日程能力供 harness agent 与用户安排跨时间的工作，支持执行、通知、执行并通知三种工作类型。
日历服务作为独立产品应用供应日历数据并提供计算；对日程而言，它是计算依赖。
系统同时提供通知能力，供系统和 agent 发送通知并送达到对应租户。
本包定义三项能力的产品责任、日程内含工作描述及单次作业的业务模型及作业会话要求；执行和通知同等重要。
系统自用日程独立归系统且只执行机械操作；采用出厂 Routine 的租户日程仍归租户。

## 关系与定位

本 topic 位于架构内核之外，消费既有身份、装配、工具、Run 与会话规则。
作业会话是对会话用途之外的执行约束的扩展，不重定义其身份、日志或生命周期。
与 PF-015 的用途分类及 PF-014 的来源承接分别衔接，范围见 [边界](design.md#八边界与依赖)。
