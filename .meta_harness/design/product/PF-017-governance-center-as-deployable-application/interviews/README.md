## 记什么、不记什么

| 记 | 不记 |
|---|---|
| 产品负责人的原话，尤其是裁决 | 逐字稿 |
| 被否决的方向及否决理由 | 纯粹的过程寒暄 |
| 当时的顾虑与假设 | 已经落进 design.md 的结论 |
| 谈话中暴露的真实使用场景 | 实现细节讨论（属技术设计） |
