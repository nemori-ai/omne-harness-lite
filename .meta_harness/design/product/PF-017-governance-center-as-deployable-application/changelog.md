# PF-017 变更历史

本页记录**产品设计本身的演进**：每次实质变更改了什么、为什么改、谁受影响。
它与 [decisions.md](decisions.md) 不同——那边记录「谁拍了什么板」，这里记录「文档因此变成了什么样」。

**修订号（rev）是产品设计的版本。**技术投影用 `provenance.json` 引用具体 rev。

## 什么算一次修订

| 算 | 不算 |
|---|---|
| 概念定义变了 | 错别字、链接修复、排版 |
| 模型中的关系变了 | 补充说明但不改变含义 |
| 产品规则增删改 | 把已有内容换个位置 |
| 目标或非目标变了 | — |
| 未决项被裁决 | 未决项被重新表述但仍未决 |

**改变含义就要记，且要改修订号。**读者据修订号判断自己手上的理解是否还成立；
不记的修订等于让下游无从判断。
