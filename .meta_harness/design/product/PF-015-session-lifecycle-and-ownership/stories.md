### ST-015-01 · 在新会话中收到第一条答复

- **价值**：用户能够从新建会话开始一次真实交流，不必通过 demo 专用运行对象发起任务。
- **覆盖场景**：[S2](acceptance.md#创建变化与恢复)、[S36](../PF-012-agent-loop-and-run/acceptance.md#一可观察的场景)
- **演示**：
  1. 以当前租户身份和合法 AgentDefinition 创建普通会话，显式给定本次采用的执行类型与模式，不指定工作区和第一条消息 → 会话建立，尚未启动任务；工作区为空，没有因创建而发出模型请求。
  2. 从普通消息入口发送一个无需工具的文本问题 → 本会话承接该问题，用户收到真实模型回复。
  3. 等到回复完成，查看本轮结果 → 无动作、队列为空，Run 为 completed；会话与记录仍在。
- **不含**：第二种入口、模式切换、工具调用、失败恢复和 Connector；已有适用的租户隔离及执行准入约束仍须成立。
- **前置**：无
- **就绪**：是

### ST-015-02 · 重新进入会话时看得到已经发生的事

- **价值**：用户离开后回来，仍能查看此前的交流和任务结果，不必重新提问。
- **覆盖场景**：[S1](../PF-010-context-management-and-assembly/acceptance.md#给用户那一侧)、[S2](../PF-010-context-management-and-assembly/acceptance.md#给用户那一侧)
- **演示**：
  1. 准备一个有多轮交流和工具结果的会话，并准备一个已有大量记录的会话 → 已知消息、结果与记录范围可核对。
  2. 离开后重新进入两个会话 → 已保存的近期交流和结果可读；大历史会话首载仅最近一段，没有全量加载。
  3. 对同一会话重复打开并查阅已加载内容 → 内容来自原记录，查阅前后日志条目没有增加或被改写。
- **不含**：往前分页、实时续收、搜索、大结果全文展开及会话重启恢复；这些不影响本卡保存和读取既有记录的责任。
- **前置**：ST-015-01、ST-012-01
- **就绪**：是

### ST-015-03 · 重启后原工作不会凭空消失或重新执行

- **价值**：用户在系统中断后仍能认回原会话与工作进度，已取得的回复不会再花一次钱生成。
- **覆盖场景**：[S13](acceptance.md#创建变化与恢复)、[S3](../PF-012-agent-loop-and-run/acceptance.md#一可观察的场景)、[S51](../PF-012-agent-loop-and-run/acceptance.md#一可观察的场景)、[S72](../PF-012-agent-loop-and-run/acceptance.md#持久化投影与完整函数输入)
- **演示**：
  1. 完成一次任务，重启系统后重新打开会话 → 原消息和任务结果仍可查，不因启动而重新执行已完成工作。
  2. 在另一轮中，让完整模型回复已保存但 Run 尚未终结时发生中断，恢复后查看同一轮 → 原回复仍在，系统只收尾一次，没有新增模型请求。
  3. 保留完整持久输入和当下条件，移除可重建的 Run 进度投影后恢复 → 重建的当前结果与同输入求值一致，能认回原 Run；不要求仅凭日志还原所有外部条件。
  4. 在缺少尝试结束条目的情况下再次恢复 → 不报数据损坏，沿已有事实继续对账；日常当前值查询不随日志长度重扫全部历史。
- **不含**：模型或工具自身失联、全部共享来源回到旧版本、模型可读块视图的缓存政策，以及具体存储或投影刷新机制。
- **前置**：ST-015-02
- **就绪**：是
