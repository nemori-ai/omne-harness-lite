# 画布

本 topic 保存画布的完整产品能力定义：人和 agent 共用的一张画布，它是应用的反面。产品负责人已确认本文的需求与规则。

## 阅读入口

- [产品正文](design.md)维护需求、关键用户旅程、可观察场景、能力定义及未决事项。
- 领域责任与工程规格：[领域页](../../../../docs/domains/canvas/README.md)维护画布的领域责任，[包组规格](../../../../packages/canvas/SPEC.md#总体架构)维护工程结构与机制。本文不代为规定事实归属与机制。
- 相关产品正文：[桌面应用](../desktop-application/design.md)拥有应用的各部分、形与随身入口；[媒体](../media/design.md)拥有媒体对象及其保留；[会话与工作](../sessions-and-work/design.md)拥有会话；[元能力入口](../meta-capabilities/design.md#动作放行与环境准入)拥有 agent 动作的放行判断。

## 维护

产品规则由产品负责人确认，技术拥有者承接所定义的能力。修改含义须核对真实消费者、统一语言和对象依据；形成过程保存在任务 tmp。
