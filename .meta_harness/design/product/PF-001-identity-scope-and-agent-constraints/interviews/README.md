## 记什么，不记什么

**记**：用户的判断与选择、他排除了什么、他给出的理由、当时未解决的争论。

**不记**：我自己的推理过程（那归 `decisions.md` 第二节）、
实现观察（那不是产品设计的输入）、一次性的排期与任务安排。

## 怎么记

逐项记录里每条给 `INT-NNN` 编号，并写清六件事：

- **actor**：谁说的。**用户本人说的，还是他人转述的**，必须分清
- **source locator**：能回去查到原话的位置
- **表达方式**：`verbatim` 还是 `paraphrase`
- **内容**：说了什么
- **上下文**：当时在谈什么
- **状态**：已确认 / 待核实 / 有争议

`actor` 与 `表达方式` 是这里最要紧的两栏。**转述不是确认**——
把转述当成用户拍板，是这份材料最容易造成的伤害。
