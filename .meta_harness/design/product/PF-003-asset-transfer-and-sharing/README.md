# PF-003：资产的转移与分享

**[PF-002](../PF-002-assets-settings-and-permissions/README.md) 说清了一个组织持有资产
之后会发生什么，但没说资产**怎么进到组织里**。本 topic 回答这个问题。**

一句话概括本 topic 的结论：**跨组织流动有两种根本不同的需要，所以有两个动作。**

| | **转移** | **分享** |
|---|---|---|
| 是谁的动作 | 同一自然人的**两个租户身份**之间 | **主体之间**的授权 |
| 所有权 | 目标方独立拥有一份 | 不动，仍属分享方 |
| 此后 | **断链**，各走各的 | **被动同步**，源方改了就跟着变 |
| 关系断了 | **留着** | **失效** |

最后一行是使用者最该记住的：
**你要不要让对方在关系结束之后还能用，决定了你该转移还是该分享。**

两者共同遵守一条系统级不变量：**团队组织里的资产不出那棵隶属树**，
一律不得进入任何个人组织。

| `extends` | 无 |

**与 PF-001 的分界**：组织怎样隶属、关系怎么建立解除，归 PF-001——那是组织**属性**的事。
关系成立或断开之后**资产**怎么样，归这里。

**与 PF-002 的分界**：资产有哪几类、怎么组合、怎么配、怎么求值，归 PF-002；
它**怎么跨组织进来**，归这里。判据是**改动它的原因**——
PF-002 因对象的种类或组合形状变，本 topic 因流动的方向或语义变。
