# PF-000 设计交流笔记

**这里保存设计这块产品时的交流记录中有价值的部分。**它是**原始材料**——
含后来没有采纳的讨论、走过的弯路、以及为什么放弃某个方向。
这些在 `decisions.md` 里看不到，那里只留结论。

## 记什么、不记什么

| 记 | 不记 |
|---|---|
| 产品负责人的**原话** | 我对原话的转述 |
| **被否决的方案**，以及否决它的理由 | 只记最后选中的那个 |
| **走过的弯路**——尤其是「本来以为是 A，后来发现是 B」 | 整理干净、看不出曲折的版本 |
| 事实性的调研结论与它的出处 | 结论（那归 `decisions.md`） |

**原话一律保留，不回改。**后来的认识变了，是在别处写清楚它怎么变的，
**不是回来把当时说的话改成现在的样子**。
