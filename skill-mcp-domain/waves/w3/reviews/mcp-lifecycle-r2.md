## D. 差分变异（general-purpose，sonnet，2026-11-05 交回）

`pnpm run mutation --base 92a8e3cdf --since f8bf19596`（6 进程，排队 1181 s，运行 312 s）退出 1：测量无效。67 个变异体：被杀 55、存活 3、无覆盖 3、没跑测试 1、超时未复核 5；47 个是 static。

**根因（本会话诊断）**：探索器在 `beforeAll` 里运行。Stryker 的命中计数在 `beforeAll` 里才清零，所以探索器触到的源码都算 static：每个这样的变异体都跑全部快层用例，破坏性的变异体让探索器挂起，于是出现「没跑测试」和超时，第一遍无效后又不复核。这是用例结构的问题，不是哪一条判据的问题。处置：每个探索都移进用例本身（`lifecycle.spec.ts` 用 `exploration()` 在第一个用例里跑一次），按用例的覆盖就看得见它，变异只跑触到它的用例。
