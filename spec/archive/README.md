# 历史规格归档

本目录保存已经退出当前权威入口的原始规格。归档材料用于审查、追溯和跨语言复现，**不是**当前有效契约，也不因文件曾标为 `current` 而表示已经接受。

- [`ddd-models/README.md`](ddd-models/README.md) 说明旧 DDD 模型的迁移状态。
- [`ddd-models/manifest.json`](ddd-models/manifest.json) 记录每个原始文件的旧路径、归档相对路径和 SHA-256。

当前可供 review 的候选归属见 [租户契约提案](../../docs/proposals/tenant-contracts/README.md) 与 [模型契约提案](../../docs/proposals/model-contracts/README.md)。
