# 旧 DDD 模型归档

`domain/` 是从 `spec/domain/` 原样物理迁移而来，内部目录、文件内容和相对引用均未改写。它记录迁移前的九项模型及其 `current` 注册状态；该状态没有接受依据，不能作为当前契约或批准记录使用。

每个原件和原路径由 [manifest.json](manifest.json) 固定。候选的语义承接和逐项映射见 [租户契约提案](../../../docs/proposals/tenant-contracts/README.md) 与 [模型契约提案](../../../docs/proposals/model-contracts/README.md)。
