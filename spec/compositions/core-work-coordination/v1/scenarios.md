# 核心能力组合验收场景

本组是提供者和应用组合必须兑现的可观察条件。有限模型只覆盖验证映射中
明确列出的抽象；表中涉及实际磁盘、模型接口或工具效果的场景尚未执行。

| ID | 条件、交错与期望 |
|---|---|
| C01 | tenant A 的 caller 带 B 的 Session、媒体、账务或 request 引用：拒绝，错误和计数不泄漏 B 的存在；授权引用本身不赋权 |
| C02 | 两个管理操作并发移除最后两个管理员：至多一个成功，仍有一名有效管理员；普通管理员不能读取私人 Session 或代答 owner-only 问题 |
| C03 | 同一 grant 只覆盖原 definition v1；fork/v2 未在版本集合：不继承；授权 provider 不可达：unavailable 而非 allow |
| C04 | 工具声明缺失/解析失败/未知词汇或 skill 缺失：工具和动作索引都不发布；新代准备失败仍可使用原合法选择；旧 disposer 不撤掉新代 |
| C05 | standard 下缺可授予权限：无效果、耐久 ask；合法批准后不创建持久 grant，重检原 Action 准入一次；confirm 有 grant 仍 ask；unattended 缺 grant deny；所有模式硬拒绝均不得 ask |
| C06 | 会话与决策池同时 approve/reject：一个唯一合法决定；评论不占答案；关 UI/卸载 Agent/重启后同一请求仍在，无超时默认答案 |
| C07 | 批准后参数、资源版本、秘密版本、环境、声明或实现换代：原后果 superseded，不执行新动作；同 call 的新 attempt 重新准入，旧批准不搬用 |
| C08 | 准入位置 n 分配后普通 revoke 在 n+1 生效，再同步 n：n 保持此前合法准入，后续拒绝；pending 授权/决定不得授权新工作；n 未耐久不得产生效果 |
| C09 | 日志完整行未回执时进程崩溃：验证、重新同步、按同 operationId 认回 committed；只剩未完成尾部可保全后截断；中间坏行/完整坏行阻止写恢复；旧 writer epoch 不得追加 |
| C10 | q1/q2 独立 pending，先答 q1：独立接续可串行运行、结束后 Run 保持 waiting；重建后答 q2 仍唯一接续。模型看到 deferred receipt 而非伪造成功；适配器无法保持该区分时拒绝该投影，不伪造答案 |
| C11 | interrupt 后答问题：保留答案但不自行驱动；resume 复核当前资格。cancel/force_stop 后迟到答复：不复活工作；随工具取消的系统请求同时关闭 |
| C12 | 输入编辑/重排/撤回与 takeBatch 竞争：只有当前修订被领取；连续 text 可取批，command 为屏障；takeCommand、执行及 settle 的断点重启认回同一 operation，不重复效果 |
| C13 | command=clear 在队列执行时只撤回当时仍 waiting 项；立即 clear 在其受理时撤回指定集合。新到或已领取项不被旧清除请求追溯抹去 |
| C14 | interrupt_then_run：旧前台支持则 detach，失败则 stop；既有后台保留；待批工具结算未执行并 supersede 审批；新输入正常排队且旧 Run 精确绑定，重试不打断后来的 Run |
| C15 | admit 后 start 在运输中，先 force_stop，执行器 inspect=not_found：不得确认安全；取消墓碑/隔离确认后迟到 start 无效果。若 start 先被接纳，必须真实 stop/隔离；unknown 保留 stopping 占位 |
| C16 | Session force_stop 进入 hold，安全停止后 Run cancelled，仍不自动取下一输入；continueQueue 在仍 stopping 时不释放占位。单 Run 强停不额外设置全会话 hold |
| C17 | 转后台在完成/中断/预算截止附近竞争：同一 attempt、唯一 owner，只有确认脱离临时资源才 background；重建 inspect/subscribe 同一执行，不重复启动 |
| C18 | 两个收费 attempt 竞争最后一单位 hard 额度：最多准入一个；终态/费用回执重复不多扣；unknown 保留预留，迟到收费归原 Step/周期；未知上界的例外须显式且不声称严格封顶 |
| C19 | 供应方订阅变更响应丢失：保留 unknown，按原外部操作核实，不重复购买。余额仍正但额度被撤销：下一准入拒绝。账单和本地估算差额不得静默抹平 |
| C20 | Session 已含音频/图片/视频/文件原生消费记录：切到不支持或模态能力 unknown 的目标拒绝；上下文压缩不删除 durable 模态依据；已知窗口不足至多一次压缩，仍不足拒绝，未知窗口显示 unknown |
| C21 | 当前 Run 忙时选模型：持久记录下一 Run 意图，当前 Run 请求保持原模型；真正应用时重检资格/模态/窗口；重复操作不重复压缩或收费 |
| C22 | 模型请求、辅助压缩/标题和重试均过 OpenRouter 与当前预算门；路由不满足必需参数拒绝。PDF 默认 OCR、静默转写/丢模态、服务端额外 tools 均不能冒充已授权原生投影 |
| C23 | 流中断/abort 但供应方已接收：unknown/partial，原 attempt 和费用保留，不凭新 ID 自动重发；已停止本地输出不声称供应方已撤销收费 |
| C24 | 上传完成前引用拒绝；已保留媒体与 GC 竞争引用提交：原件保持；派生转写使用新 ID。跨租户摘要命中不给读取权或存在性证据；临时 URL 失效不抹去耐久引用 |
| C25 | 暂行子产物先批准、父项未决：不 finalize；父拒绝封闭使用并逆序撤销后代；撤销失败保留责任和隔离。未注册完整撤销契约的发送/付款不得先做后批 |
| C26 | 帧达到有界保留量：明确 gap 与水位；订阅者各自 cursor，终态不是最后一帧；选择披露不等于模型注入，重建不重复终态计费 |
| C27 | 关键审计无法耐久保存：拒绝依赖它的新效果；非关键诊断采样/故障有缺口。查询/导出按当前授权，管理员金额读权不带私人正文 |
| C28 | 独立 skill 可 discover/load 并实际进入请求，不依赖工具槽位；多命令工具仍一个顶层模型条目，命令参数完整校验。slash 参数 JSON 含字符串分隔符不误切，未知命令整份输入拒绝或显式 literal |

实际实现应在这些交错点加入可控断点，观测耐久日志、执行 owner 和供应方
事实，核对结果与副作用次数。仅断言内部布尔字段、测试替身接受取消或上游
来源测试通过，均不足以证明相关真实提供者承诺。
