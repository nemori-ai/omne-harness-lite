# 组合符合性场景

以下为 [composition.agent-session-binding v1](contract.md) 的实现验收要求。
表中“模型”仅指 [Binding.tla](Binding.tla) 的抽象覆盖，未标为模型的场景必须由
提供者/真实组合验证，不能计作已执行的产品测试。

| 场景 | 可观察结果 | 对应与验证归属 |
|---|---|---|
| B01 跨租户附着/发布 | 真实主体与目标租户不符时拒绝，不泄漏目标存在 | CB-01/04；模型仅覆盖租户匹配，泄漏由实际入口测试 |
| B02 授权在异步准备期间撤销 | 原允许不供发布复用，新的准入拒绝；准备资源仍可清理 | CB-02/03；模型及权限提供者映射 |
| B03 Session 资格在 attach 与 publish 之间变化 | 旧附着发布失败，恢复资格后旧附着也不复活 | CB-05/06；模型，含资格修订与恢复 |
| B04 同一 Session 的两个并发激活 | Registry 预留保护唯一尝试；附着不另行产生第二份执行权 | CB-03/04；模型及既有 live-agent 验证 |
| B05 关闭时 prepare 尚未返回 | 保留占位；晚到附着/资源纳入原清理，不发布；全部归还后才解除占位 | CB-04/08/10/12；模型及真实异步 fixture |
| B06 分配成功但响应丢失 | 原尝试保持可核实/回收关联；不得把超时当作零资源失败 | CB-04；具体提供者的故障注入 |
| B07 清理失败、等待取消或未知结果 | 保持原阶段/责任；重复请求加入原过程；不释放仍被依赖资源 | CB-07/10/12；模型抽象清理未确认，其余需真实后端 |
| B08 旧附着释放在新实例出现后迟到 | 不改变新附着、新 Registry 占位或新工作 | CB-07/13；模型及精确句柄测试 |
| B09 发送移交请求后丢失回执 | 原账目不减；只有目标已确认且资源依赖解除后结算 | CB-11；模型抽象确认点，真实移交协议另验 |
| B10 Session 归档/删除与 Run/发布竞争 | Session/Run 权威按业务规则裁决，准入不能穿过已生效的失效点；封闭准入不伪报耐久归档 | CB-03/06；跨能力业务验证，模型仅抽象资格撤销 |
| B11 activated 监听器抛错或重入关闭 | 已发布事实保留，返回精确实例的当前状态；不会重新分配新实例冒充重试 | CB-03；真实 Cordis 组合，既有规格约束 |
| B12 必要提供者计划撤除 | 先关闭新使用并收口所有准备/使用者，释放完成后才实际卸载 | CB-13/14；模型仅覆盖依赖失效后的发布/新工作拒绝，计划卸载顺序由真实组合验证 |
| B13 可选贡献的空闲检查与新使用竞争 | 撤除和新使用不能同时越过门；无在途政策时繁忙拒绝 | CB-13；提供者实际并发测试 |
| B14 旧运行实例回收，后台工具或 HITL 仍存在 | 释放观察/局部资源不删除业务事实；新实例关联原工作，不重派、不伪造答复 | CB-07/11；工具/HITL/Session 组合验证 |
| B15 模型网络或某项工具不可用 | 只有实际依赖的操作受影响；获准历史读取不要求原模型、工具或 Agent 驻留 | CB-14；具体能力就绪和读取测试 |
| B16 租约失效、远端许可迟到或权限缓存过期 | 不以过期允许发布；无法兑现共同屏障时拒绝接入相应准入路径 | CB-02/03；真实提供者协议验证，模型不证明网络时序 |

实例 ready、合法 Run 位置、输入已耐久受理、工具真实停止和模型请求已发送是
不同结论。本组合的任一通过记录都不能用来代替另外一种结论的证据。
